추세와 계절성 분해

"이번 달 매출이 늘었다"는 말은 애매합니다. 진짜 성장인가, 원래 잘 되는 달인가, 그냥 운인가? 시계열을 추세 + 계절성 + 나머지 세 조각으로 쪼개면 답이 나옵니다.

1. 시계열을 이루는 세 조각

시계열 분해 (가법 모형)
yt  =  추세t  +  계절성t  +  나머지t
  • 추세장기적으로 오르내리는 큰 흐름. 이게 진짜 성장
  • 계절성일정한 주기로 반복되는 패턴 (요일, 월, 분기)
  • 나머지설명되지 않은 부분. 잔차라고도 합니다. 여기가 크면 예측이 어렵다는 뜻
import pandas as pd df = pd.read_csv("cafe_sales.csv", parse_dates=["date"]) s = df.set_index("date").asfreq("D")["sales"].interpolate() print("기간:", s.index[0].date(), "~", s.index[-1].date()) print("일수:", len(s), " 결측:", s.isna().sum())
interpolate() 를 쓴 이유
분해 함수는 결측을 허용하지 않습니다. interpolate() 는 앞뒤 값을 이어 직선으로 사이를 메웁니다. 결측이 4건뿐이라 영향은 미미합니다.

단 14강에서 배웠듯 이건 미래 정보를 씁니다. 과거를 분석하는 지금은 괜찮지만, 예측 모델에서는 ffill() 을 쓰세요.

2. 주간 계절성 분해하기

카페 데이터의 가장 뚜렷한 주기는 요일입니다. 주기 7로 분해해봅시다.

from statsmodels.tsa.seasonal import seasonal_decompose import matplotlib.pyplot as plt 분해 = seasonal_decompose(s, model="additive", period=7) fig, axes = plt.subplots(4, 1, figsize=(10, 8), sharex=True) 최근 = slice("2025-06", "2025-09") # 4개월만 확대해서 보자 axes[0].plot(s.loc[최근] / 10000, lw=0.8); axes[0].set_ylabel("원본") axes[1].plot(분해.trend.loc[최근] / 10000, lw=2, color="#dc2626"); axes[1].set_ylabel("추세") axes[2].plot(분해.seasonal.loc[최근] / 10000, lw=1, color="#0d9488"); axes[2].set_ylabel("계절성") axes[3].plot(분해.resid.loc[최근] / 10000, lw=0.6, color="#94a3b8"); axes[3].set_ylabel("나머지") axes[3].axhline(0, color="black", lw=0.6) fig.suptitle("매출 = 추세 + 계절성 + 나머지 (단위: 만원)", fontweight="bold") plt.tight_layout() plt.show()
추세폭 = 분해.trend.dropna() print(f"추세 {추세폭.iloc[0]:>10,.0f}원 → {추세폭.iloc[-1]:>10,.0f}원 " f"(2년간 +{추세폭.iloc[-1]/추세폭.iloc[0]*100-100:.0f}%)") print(f"계절성 진폭 {분해.seasonal.max() - 분해.seasonal.min():>10,.0f}원") print(f"나머지 SD {분해.resid.dropna().std():>10,.0f}원") print() print(f"원본 SD {s.std():>10,.0f}원")

숫자가 말해주는 것:

  • 추세 — 2년간 66만원 → 89만원으로 35% 성장했습니다. 이게 진짜 성장입니다.
  • 계절성 진폭 40.7만원 — 요일에 따라 이만큼 오르내립니다. 추세 변화폭(23만원)보다 큽니다. 요일 효과가 성장보다 강하다는 뜻이죠.
  • 나머지 SD 13.5만원 — 추세와 요일로 설명되지 않는 부분. 원본 SD 25만원의 절반 정도까지 줄었습니다.

3. 계절성분 읽는 법

요일이름 = ["월", "화", "수", "목", "금", "토", "일"] 계절 = pd.Series(분해.seasonal.values, index=분해.seasonal.index.dayofweek) 요일별 = 계절.groupby(level=0).mean() 요일별.index = 요일이름 print("요일별 계절성분 (평균 대비 만원)") for 요일, 값 in (요일별 / 10000).round(1).items(): 막대 = "█" * int(abs(값) / 2) 부호 = "+" if 값 > 0 else " " print(f" {요일} {부호}{값:>6.1f} {막대}")
이렇게 해석합니다 · "토요일은 추세선보다 평균 24.8만원 높고, 월요일은 16.0만원 낮다."

이 값들은 합이 0이 되도록 만들어집니다. 계절성은 "평균에서 얼마나 벗어나는가"이지 절대 수준이 아니니까요.
실무에서 쓰는 곳
  • 인력 배치 — 토요일에 24.8만원(≈50명)어치 더 온다는 걸 알면 스케줄을 짤 수 있습니다.
  • 목표 설정 — "이번 주 월요일 목표"는 전체 평균이 아니라 추세 − 16만원으로 잡아야 공정합니다.
  • 이상 감지 — 나머지(resid)가 평소보다 크게 튀면 "요일이나 추세로 설명 안 되는 일"이 일어난 것입니다.
나머지 = 분해.resid.dropna() 한계 = 3 * 나머지.std() 이상한날 = 나머지[abs(나머지) > 한계].sort_values() print(f"나머지가 3σ({한계:,.0f}원)를 넘은 날: {len(이상한날)}일\n") for 날짜, 값 in 이상한날.items(): 요일 = 요일이름[날짜.dayofweek] print(f" {날짜.date()} ({요일}) {값/10000:+8.1f}만원")

추세와 요일을 걷어내고 나니 진짜 특별했던 날들이 드러납니다. 휴점일, 방송 대박, 기계 고장 — 7강에서 IQR로 찾았던 날들과 같습니다. 다만 이번에는 "요일과 추세를 감안해도 이상하다"는 더 강한 근거가 붙습니다.

4. 가법이냐 승법이냐

두 가지 모형
가법  y = 추세 + 계절성 + 나머지
승법  y = 추세 × 계절성 × 나머지
  • 가법계절 변동 폭이 일정할 때. "토요일은 항상 +25만원"
  • 승법계절 변동이 규모에 비례할 때. "토요일은 항상 27% 더"
import numpy as np 양수 = s.replace(0, np.nan).interpolate() # 승법은 0을 허용하지 않는다 승법 = seasonal_decompose(양수, model="multiplicative", period=7) 지수 = pd.Series(승법.seasonal.values, index=승법.seasonal.index.dayofweek) 요일지수 = 지수.groupby(level=0).mean() 요일지수.index = 요일이름 print("요일별 계절지수 (1.0 = 평균)") for 요일, 값 in 요일지수.round(3).items(): print(f" {요일} {값:.3f} ({(값-1)*100:+5.1f}%)")
어느 쪽을 고를까 — 눈으로 판단하세요
  • 원본 그래프에서 진폭(위아래 폭)이 갈수록 커지면 → 승법
  • 진폭이 일정하면 → 가법
  • 모르겠으면 둘 다 해보고 나머지(resid)에 패턴이 덜 남는 쪽을 고르세요.
  • 승법은 0이나 음수를 다룰 수 없습니다. 휴점일(0원)이 있으면 처리가 필요합니다.

우리 데이터는 매출이 성장하면서 요일 변동 폭도 함께 커지므로 승법이 조금 더 자연스럽습니다. 토요일 지수 1.272는 "토요일은 그 시점 평균의 1.27배"라는 뜻이라 해석도 편합니다.

5. 연간 계절성 분해

주기가 하나만 있는 건 아닙니다. 요일 말고 계절(연간) 패턴도 있죠. 월별로 묶어서 주기 12로 분해합니다.

월평균 = s.resample("ME").mean() 연간 = seasonal_decompose(월평균, model="additive", period=12) 월별계절 = pd.Series(연간.seasonal.values, index=월평균.index.month) 월별계절 = 월별계절.groupby(level=0).mean() / 10000 print("월별 계절성분 (평균 대비 만원)") for 월, 값 in 월별계절.round(1).items(): 막대 = "█" * int(abs(값)) print(f" {월:>2}월 {값:>+6.1f} {막대}")

6~8월이 높고 1~2월이 낮습니다. 여름 성수기·겨울 비수기가 숫자로 확인됩니다. 1월(−15.6만원)과 6월(+16.8만원)의 차이는 32만원 — 요일 효과(40.7만원)보다는 작지만 무시할 수 없는 크기입니다.

2년치로 연간 계절성을 보는 건 아슬아슬합니다 주기 12로 분해하려면 최소 2주기(24개월)가 필요한데 우리는 딱 24개월입니다. 계산은 되지만 계절성분이 특정 해의 우연에 크게 흔들립니다. 2025년 4월의 방송 대박이 "4월은 원래 좋은 달"로 잘못 학습될 수 있죠. 연간 패턴을 제대로 보려면 3~5년치가 필요합니다.

반면 주간 계절성은 104주 분량이라 훨씬 믿을 만합니다. 주기가 짧을수록 적은 데이터로도 안정적입니다.

6. 계절조정 — 진짜 성장 보기

뉴스에서 "계절조정 실업률"이라는 말을 들어보셨을 겁니다. 계절성분을 빼서 순수한 흐름만 보는 것입니다.

조정 = s - 분해.seasonal # 가법이므로 빼면 된다 fig, ax = plt.subplots(figsize=(10, 4)) ax.plot(s.index, s / 10000, lw=0.4, color="#cbd5e1", label="원본") ax.plot(조정.index, 조정 / 10000, lw=0.7, color="#2563eb", label="계절조정 (요일 효과 제거)") ax.plot(분해.trend.index, 분해.trend / 10000, lw=2.5, color="#dc2626", label="추세") ax.set_ylabel("매출(만원)") ax.set_title("요일 효과를 걷어내면 성장 흐름이 선명해진다", fontweight="bold", loc="left") ax.legend(frameon=False) ax.spines["top"].set_visible(False); ax.spines["right"].set_visible(False) plt.tight_layout(); plt.show()
print(f"원본 표준편차 {s.std():>10,.0f}원") print(f"계절조정 표준편차 {조정.std():>10,.0f}원") print(f"→ 요일 효과가 전체 변동의 {(1 - 조정.std()/s.std())*100:.0f}% 를 차지")
실무 적용 · "이번 토요일 매출이 저번 수요일보다 높다"는 의미 없는 비교입니다. 계절조정을 하거나, 같은 요일끼리 비교하거나(14강의 diff(7)), 최소한 요일을 밝히고 말해야 합니다.
# 문제 1. 방문객(visitors)을 주기 7로 분해하고, 요일별 계절성분을 구해보세요. # 문제 2. 승법 모형의 나머지(resid)와 가법 모형의 나머지를 비교해보세요. # 어느 쪽이 더 작은가요? (승법의 resid 는 1 근처가 기준입니다) # 문제 3. 계절조정한 매출로 '전월 대비' 변화율을 구해보세요. # 원본으로 구한 것과 어떻게 다른가요?
모범 답안 보기
v = df.set_index("date").asfreq("D")["visitors"].interpolate() # 문제 1 분해v = seasonal_decompose(v, model="additive", period=7) 계절v = pd.Series(분해v.seasonal.values, index=분해v.seasonal.index.dayofweek) 결과 = 계절v.groupby(level=0).mean().round(1) 결과.index = 요일이름 print("요일별 계절성분 (명)") print(결과.to_string()) # 문제 2 가법잔차 = 분해.resid.dropna() 승법잔차 = 승법.resid.dropna() print(f"\n가법 나머지 SD (원) {가법잔차.std():,.0f}") print(f"승법 나머지 SD (비율) {승법잔차.std():.4f} " f"→ 평균 대비 약 {승법잔차.std()*100:.1f}%") print(f"가법을 비율로 환산하면 {가법잔차.std()/s.mean()*100:.1f}%") # 문제 3 조정월 = (s - 분해.seasonal).resample("ME").mean() 원본월 = s.resample("ME").mean() 비교 = pd.DataFrame({ "원본 전월대비(%)": 원본월.pct_change() * 100, "조정 전월대비(%)": 조정월.pct_change() * 100, }).round(2) print() print(비교.tail(6).to_string())

문제 3에서 두 값이 거의 같게 나옵니다. 당연합니다 — 한 달에는 각 요일이 4번씩 고르게 들어 있어서 월 단위로 묶는 순간 요일 효과가 저절로 상쇄되니까요. 계절조정이 필요한 건 일별·주별 비교이지 월별 비교가 아닙니다. 도구를 쓰기 전에 "이게 지금 필요한가"를 묻는 습관이 중요합니다.

15강 요약

  • y = 추세 + 계절성 + 나머지 (또는 곱셈). seasonal_decompose(s, period=7)
  • 우리 데이터: 추세 2년간 +35%, 요일 계절성 진폭 40.7만원(추세 변화보다 큼).

  • 가법=변동 폭 일정 · 승법=규모에 비례. 진폭이 커지면 승법.
  • 나머지가 크게 튄 날 = 진짜 사건. 추세·요일을 걷어낸 뒤라 근거가 강하다.
  • 주기가 짧을수록 적은 데이터로 안정적. 연간 패턴엔 3~5년치가 필요.
  • 계절조정으로 순수한 흐름을 본다. 단, 월별 비교에는 대개 불필요.
