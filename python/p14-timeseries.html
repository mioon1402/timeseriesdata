파이썬 14강 · 시계열과 예측

시계열 다루기

시간 축이 있는 데이터는 다르게 다뤄야 합니다. 순서가 정보이기 때문입니다. 리샘플링·이동평균·변화율 — 이 세 가지면 대부분의 시계열 작업이 됩니다.

이 강의에서 배우는 것
  1. 시계열 인덱스 만들기 — asfreq
  2. resample — 시간 단위 바꾸기
  3. rolling — 이동평균으로 노이즈 걷어내기
  4. shift와 diff — 과거와 비교하기
  5. 변화율 — 전월 대비, 전년 대비
  6. 시계열에서 절대 하면 안 되는 것

1. 시계열 인덱스 만들기

4강에서 set_index("date") 를 배웠습니다. 한 걸음 더 나아가 "이 데이터는 하루 간격"이라고 명시하면 pandas가 빠진 날짜를 찾아줍니다.

import pandas as pd df = pd.read_csv("cafe_sales.csv", parse_dates=["date"]) ts = df.set_index("date").asfreq("D") # D = 하루 간격 print("빈도:", ts.index.freq) print("행 수:", len(ts)) print() print("매출 결측:", ts["sales"].isna().sum(), "일") print("빠진 날짜:", ts.index.difference(df["date"]).tolist())
asfreq 가 해주는 일
  • 날짜가 빠져 있으면 빈 행을 채워 넣습니다. 3월 5일 데이터가 없으면 결측으로 만들어주죠.
  • 이게 중요한 이유: 이동평균이나 시차 계산이 날짜 간격을 가정하기 때문입니다. 중간에 날이 빠져 있으면 "7일 전"이 실제로는 9일 전일 수 있습니다.
  • 우리 데이터는 731일이 다 있어서 새로 생긴 행은 없습니다. sales 의 결측 4건은 원래 있던 POS 오류입니다.
빈도 코드뜻
D / h / min일 / 시간 / 분
W주 (일요일 기준)
ME / MS월말 / 월초
QE / YE분기말 / 연말
B영업일 (주말 제외)

2. resample — 시간 단위 바꾸기

resample 은 시계열 전용 groupby 입니다. "일별 → 월별"처럼 시간 단위를 바꿉니다.

s = ts["sales"] for 코드, 이름 in [("W", "주"), ("ME", "월"), ("QE", "분기")]: 묶음 = s.resample(코드).mean() print(f"{이름}별 {len(묶음):3d}개 첫 값 {묶음.iloc[0]:>10,.0f}원")
월합계 = s.resample("ME").sum() 월평균 = s.resample("ME").mean() 일수 = s.resample("ME").size() 표 = pd.DataFrame({ "일수": 일수, "월 총매출(만원)": 월합계 / 10000, "일평균(만원)": 월평균 / 10000, }).round(1) print(표.head(6).to_string())
월별 비교에서 가장 흔한 실수

2월은 28일, 3월은 31일입니다. 월 총매출을 비교하면 2월이 낮게 나오는데, 이건 장사가 안 된 게 아니라 날이 적어서입니다.

성과를 비교할 땐 일평균(.mean())을, 실제 금액이 궁금할 땐 합계(.sum())를 쓰세요. 보고서에 "월 매출"이라고 쓸 땐 어느 쪽인지 명시해야 합니다.

3. rolling — 이동평균

일별 데이터는 요일 효과 때문에 톱니처럼 들쭉날쭉합니다. 추세만 보고 싶을 때 이동평균으로 노이즈를 걷어냅니다.

import matplotlib.pyplot as plt fig, ax = plt.subplots(figsize=(10, 4)) ax.plot(s.index, s / 10000, linewidth=0.5, color="#cbd5e1", label="원본(일별)") ax.plot(s.index, s.rolling(7).mean() / 10000, linewidth=1.5, color="#2563eb", label="7일 이동평균") ax.plot(s.index, s.rolling(30).mean() / 10000, linewidth=2, color="#dc2626", label="30일 이동평균") ax.set_ylabel("매출(만원)") ax.set_title("이동평균으로 추세 보기", fontweight="bold", loc="left") ax.legend(frameon=False) ax.spines["top"].set_visible(False); ax.spines["right"].set_visible(False) plt.tight_layout(); plt.show()
print(f"원본 표준편차 {s.std():>9,.0f}") for w in [7, 14, 30, 90]: print(f"{w:>3}일 이동평균 표준편차 {s.rolling(w).mean().std():>9,.0f}")
창 크기 고르는 법
  • 주기와 맞추세요. 요일 효과를 없애려면 7의 배수(7, 14, 28)를 씁니다. 5일이나 10일을 쓰면 요일 효과가 덜 지워지고 오히려 이상한 물결이 생깁니다.
  • 창이 클수록 매끄럽지만 반응이 느려집니다. 30일 평균은 변화를 보름쯤 늦게 알려줍니다.
  • min_periods=1 을 주면 데이터가 부족한 앞부분도 계산합니다. 안 주면 앞의 6일은 결측이 됩니다.
fig, ax = plt.subplots(figsize=(10, 3.6)) 최근 = s.loc["2025-06":"2025-09"] / 10000 ax.plot(최근.index, 최근.values, lw=0.6, color="#cbd5e1", label="원본") ax.plot(최근.index, 최근.rolling(14).mean(), lw=2, color="#dc2626", label="14일 이동평균 (뒤로 밀림)") ax.plot(최근.index, 최근.rolling(14, center=True).mean(), lw=2, color="#0d9488", label="14일 중심이동평균") ax.legend(frameon=False, fontsize=9) ax.set_ylabel("매출(만원)") ax.set_title("center=True 를 쓰면 시차가 사라진다", fontweight="bold", loc="left") plt.tight_layout(); plt.show()
왜 빨간 선이 오른쪽으로 밀려 있나
기본 rolling(14) 은 "지난 14일의 평균"을 오늘 자리에 찍습니다. 그래서 실제 변화보다 약 7일 늦게 반응하죠.

center=True 는 앞뒤 7일씩의 평균을 오늘 자리에 찍어 시차가 없습니다. 과거를 분석할 땐 center=True가 정확하지만, 실시간 모니터링에는 쓸 수 없습니다 — 미래 데이터가 필요하니까요. 이 구분이 16강의 예측에서 결정적으로 중요해집니다.

4. shift와 diff

표 = pd.DataFrame({ "오늘": s, "어제": s.shift(1), "일주일전": s.shift(7), "전일대비": s.diff(1), "전주대비": s.diff(7), }) print((표.head(9) / 10000).round(1).to_string())
도구하는 일쓰는 곳
shift(n)값을 n칸 아래로 민다 (과거 값을 오늘 줄에)비교, 예측 변수 만들기
diff(n)현재 − n칸 전변화량, 추세 제거
pct_change(n)변화 비율성장률
shift(-n)미래 값을 오늘 줄에예측 대상 만들기 (주의!)
diff(7) 이 유용한 이유

같은 요일끼리 비교하는 것이라 요일 효과가 저절로 사라집니다. "이번 주 토요일이 지난주 토요일보다 얼마나 늘었나"를 바로 알 수 있죠.

같은 원리로 월별 데이터는 diff(12), 분기 데이터는 diff(4) 로 계절 효과를 제거합니다. 이걸 계절 차분이라고 부르고, 16강의 SARIMA 가 내부에서 하는 일이기도 합니다.

5. 변화율

월 = s.resample("ME").mean() 성장 = pd.DataFrame({ "일평균매출(만원)": 월 / 10000, "전월대비(%)": 월.pct_change() * 100, "전년동월대비(%)": 월.pct_change(12) * 100, }).round(1) print(성장.tail(8).to_string())
전월 대비는 계절성에 속습니다

1월 → 2월 매출이 늘었다고 "성장 중"이라 말하면 안 됩니다. 원래 봄으로 갈수록 오르는 계절 패턴이니까요.

전년 동월 대비(YoY)는 계절을 자동으로 통제합니다 — 작년 2월과 올해 2월은 같은 계절이니까요. 성장을 말할 땐 YoY 를 쓰세요. 다만 작년에 특별한 사건(방송 대박)이 있었다면 그것도 함께 봐야 합니다.

fig, ax = plt.subplots(figsize=(10, 3.6)) yoy = (월.pct_change(12) * 100).dropna() mom = (월.pct_change() * 100).dropna() ax.bar(mom.index, mom.values, width=20, color="#cbd5e1", label="전월 대비") ax.plot(yoy.index, yoy.values, color="#2563eb", marker="o", linewidth=2, label="전년 동월 대비") ax.axhline(0, color="black", linewidth=0.8) ax.set_ylabel("증감률(%)") ax.set_title("전월 대비는 출렁이지만, 전년 대비는 꾸준한 성장을 보여준다", fontweight="bold", loc="left", fontsize=12) ax.legend(frameon=False) ax.spines["top"].set_visible(False); ax.spines["right"].set_visible(False) plt.tight_layout(); plt.show()

6. 시계열에서 절대 하면 안 되는 것

① 순서를 섞지 마세요

일반 데이터에서는 sample() 로 무작위 추출을 해도 됩니다. 시계열에서는 안 됩니다. 순서 자체가 정보이기 때문입니다.

특히 학습/검증을 무작위로 나누면 안 됩니다. 미래 데이터로 과거를 예측하는 셈이 되어 성능이 가짜로 좋게 나옵니다(16강).

② 미래 정보를 몰래 쓰지 마세요 (데이터 누수)

rolling(7, center=True) 나 fillna(전체평균) 은 미래 데이터를 씁니다. 과거를 분석할 땐 괜찮지만, 예측 모델에 넣으면 반칙입니다.

실무에서 "검증 성능은 좋았는데 실제로는 형편없다"의 절반은 이 문제입니다. "이 시점에 내가 진짜 알 수 있었나?"를 매번 물어보세요.

구멍 = s.copy() # ✗ 전체 평균으로 채우기 — 미래 정보가 들어간다 나쁨 = 구멍.fillna(구멍.mean()) # ○ 직전 값으로 채우기 — 그 시점에 알 수 있던 정보만 좋음 = 구멍.ffill() # ○ 확장 평균 — '그때까지의' 평균만 사용 확장 = 구멍.fillna(구멍.expanding().mean()) print("결측:", 구멍.isna().sum(), "건") print(f"전체평균 대체 {나쁨.mean():>10,.0f} ← 미래 정보 사용 (예측엔 반칙)") print(f"직전값 대체 {좋음.mean():>10,.0f} ← 안전") print(f"확장평균 대체 {확장.mean():>10,.0f} ← 안전")
# 문제 1. 방문객(visitors)의 28일 이동평균을 그려보세요. # 7일 이동평균과 무엇이 다른가요? # 문제 2. 주별(W) 매출 합계를 구하고, 전주 대비 변화율을 계산해보세요. # 문제 3. 각 요일별로 '전주 같은 요일 대비' 변화율을 구해보세요. # 힌트: pct_change(7)
모범 답안 보기
v = ts["visitors"] # 문제 1 fig, ax = plt.subplots(figsize=(10, 3.5)) ax.plot(v.index, v, lw=0.4, color="#e2e8f0", label="원본") ax.plot(v.index, v.rolling(7).mean(), lw=1.2, label="7일") ax.plot(v.index, v.rolling(28).mean(), lw=2, label="28일") ax.legend(frameon=False); ax.set_ylabel("방문객(명)") ax.set_title("창이 클수록 매끄럽지만 반응이 느리다", fontweight="bold", loc="left") plt.tight_layout(); plt.show() # 문제 2 주 = s.resample("W").sum() 주표 = pd.DataFrame({"주매출(만원)": 주/10000, "전주대비(%)": 주.pct_change()*100}) print(주표.round(1).tail(6).to_string()) # 문제 3 전주대비 = s.pct_change(7) * 100 print() print("요일별 '전주 같은 요일 대비' 평균 변화율(%)") print(전주대비.groupby(전주대비.index.dayofweek).mean().round(2).to_string())

문제 3의 결과가 모두 0보다 조금 큰 비슷한 값으로 나옵니다. 이게 바로 주간 성장률입니다 — 요일 효과가 제거되고 순수한 성장만 남은 거죠. 요일마다 값이 비슷하다는 건 모든 요일이 고르게 성장하고 있다는 뜻이기도 합니다.

14강 요약

  • asfreq("D") 로 빠진 날짜를 드러낸다. 시차 계산 전에 필수.
  • resample 은 시계열 groupby. 합계와 평균을 구분할 것 (2월은 28일!).
  • rolling(7) — 창 크기는 주기의 배수로. 크면 매끄럽지만 느리다.
  • center=True 는 시차가 없지만 미래를 쓴다. 예측엔 금지.
  • diff(7) = 계절 차분. 같은 요일끼리 비교해 요일 효과 제거.
  • 성장은 전월 대비가 아니라 전년 동월 대비(YoY)로 말한다.
  • 순서를 섞지 말고, 미래 정보를 쓰지 말 것. "그때 알 수 있었나"를 매번 물어라.
