신뢰구간과 가설검정

2강부터 계속 미뤄왔던 질문에 드디어 답합니다 — "이 차이가 우연일 수는 없나?" 주말이 평일보다 37명 많다는 걸 발견했는데, 그게 진짜인지 확인해봅시다.

1. 평균의 신뢰구간

"일평균 방문객 176.5명"이라고 했을 때, 이 숫자는 731일의 표본에서 나온 것입니다. 진짜 평균(모평균)은 조금 다를 수 있죠. 얼마나 다를 수 있는지를 구간으로 나타냅니다.

import pandas as pd from scipy import stats df = pd.read_csv("cafe_sales.csv", parse_dates=["date"]) v = df["visitors"] lo, hi = stats.t.interval(0.95, len(v) - 1, loc=v.mean(), scale=stats.sem(v)) print(f"표본평균 {v.mean():.1f}명 (n = {len(v)})") print(f"표준오차 {stats.sem(v):.2f}") print(f"95% 신뢰구간 [{lo:.1f}, {hi:.1f}]") print(f"오차범위 ±{(hi - lo) / 2:.1f}명")
평균의 신뢰구간
x̄  ±  tα/2, n−1 × s√n
  • s/√n표준오차 — stats.sem() 이 계산해줍니다 (모듈 04)
  • tσ를 모르므로 z 대신 t를 씁니다. n이 크면 1.96에 수렴
  • n=731표본이 크니 구간이 ±3.5명으로 좁습니다
✗ 오해 "진짜 평균이 173.0~180.1 사이에 있을 확률이 95%다"
✓ 사실 "이 절차를 반복하면 만들어지는 구간의 95%가 진짜 평균을 포함한다"
→ 모듈 05에서 구간 200개를 그려보면 이 차이가 무슨 뜻인지 눈으로 보입니다.

2. 두 그룹 비교 — t검정

df["주말"] = df["date"].dt.dayofweek >= 5 주말 = df[df["주말"]]["visitors"] 평일 = df[~df["주말"]]["visitors"] print(f"주말 n={len(주말):3d} 평균 {주말.mean():6.1f} SD {주말.std():5.1f}") print(f"평일 n={len(평일):3d} 평균 {평일.mean():6.1f} SD {평일.std():5.1f}") print(f"차이 {주말.mean() - 평일.mean():+.1f}명") print() t, p = stats.ttest_ind(주말, 평일, equal_var=False) # Welch t검정 print(f"t = {t:.3f}") print(f"p = {p:.4g}")
equal_var=False 를 기본으로 쓰세요

기본값 True 는 두 그룹의 분산이 같다고 가정합니다. 우리 데이터에서 주말 SD는 58.4, 평일은 39.6으로 꽤 다릅니다.

equal_var=False(Welch 검정)는 그 가정 없이 계산하며, 분산이 같아도 성능이 거의 떨어지지 않습니다. 고민할 필요 없이 항상 False 를 쓰는 게 안전합니다.

상황함수
독립된 두 그룹 (주말 vs 평일)ttest_ind(a, b, equal_var=False)
짝지은 비교 (같은 사람의 전/후)ttest_rel(전, 후)
한 그룹과 기준값 (평균이 150인가?)ttest_1samp(x, 150)
세 그룹 이상 (계절별)f_oneway(a, b, c, d) (ANOVA)
정규성이 의심스러울 때mannwhitneyu(a, b) (순위 기반)

3. p값보다 중요한 것 — 차이의 신뢰구간

p = 1.1e-15 는 "차이가 없다고 보기 어렵다"만 말합니다. 차이가 얼마나 큰지는 말해주지 않죠. 구간으로 구해봅시다.

import numpy as np n1, n2 = len(주말), len(평일) var1, var2 = 주말.var(), 평일.var() 차이 = 주말.mean() - 평일.mean() se = np.sqrt(var1/n1 + var2/n2) # Welch-Satterthwaite 자유도 자유도 = (var1/n1 + var2/n2)**2 / ((var1/n1)**2/(n1-1) + (var2/n2)**2/(n2-1)) 임계값 = stats.t.ppf(0.975, 자유도) print(f"차이: {차이:.1f}명") print(f"표준오차: {se:.2f}") print(f"95% 신뢰구간 [{차이 - 임계값*se:.1f}, {차이 + 임계값*se:.1f}]")
이렇게 읽으세요 · "주말은 평일보다 28.8명에서 46.1명 더 많다(95% 신뢰). 구간이 0을 포함하지 않으므로 차이가 있다고 볼 수 있고, 최소 29명은 더 온다고 말할 수 있다."

p값 하나로는 "최소 29명"이라는 실무에 쓸 수 있는 정보를 얻을 수 없습니다.

4. 효과크기 — 차이가 얼마나 큰가

합동SD = np.sqrt(((n1-1)*var1 + (n2-1)*var2) / (n1 + n2 - 2)) d = (주말.mean() - 평일.mean()) / 합동SD print(f"합동 표준편차 {합동SD:.1f}") print(f"Cohen's d {d:.3f}") print() 크기 = "작음" if abs(d) < 0.5 else "중간" if abs(d) < 0.8 else "큼" print(f"→ 효과크기 '{크기}'")
Cohen's d
d  =  x̄1 − x̄2s합동
  • 뜻차이를 표준편차 단위로 환산. d=0.82 는 "표준편차의 0.82배만큼 차이"
  • 0.2 / 0.5 / 0.8관례적으로 작음 / 중간 / 큼
  • n과 무관p값과 달리 표본을 늘려도 안 커집니다. 그래서 "진짜 크기"를 나타냅니다
왜 p값과 효과크기를 둘 다 봐야 하나
p값효과크기 d
답하는 질문우연으로 설명되나?얼마나 큰가?
n을 늘리면작아짐 (유의해짐)안 변함
단독으로 쓰면하찮은 차이도 "유의"우연인지 알 수 없음

우리 결과는 p가 매우 작고(1e-15) d도 0.82로 큽니다. 둘 다 만족하니 "주말 효과는 실재하고 크다"고 자신 있게 말할 수 있습니다. 만약 n=10,000인데 d=0.05라면? p는 작겠지만 실무적으로는 무의미합니다.

5. 순열검정 — 가정 없이 하기

t검정은 정규성을 가정합니다. 우리 데이터는 오른쪽으로 치우쳐 있죠(왜도 2.55). 가정이 걱정된다면 모듈 06에서 손으로 했던 카드 섞기를 코드로 하면 됩니다.

rng = np.random.default_rng(42) 관측차이 = abs(주말.mean() - 평일.mean()) 전체 = np.concatenate([주말.values, 평일.values]) n = len(주말) N = 5000 극단 = 0 for _ in range(N): rng.shuffle(전체) # 라벨을 떼고 섞는다 섞인차이 = abs(전체[:n].mean() - 전체[n:].mean()) if 섞인차이 >= 관측차이: 극단 += 1 p_순열 = (극단 + 1) / (N + 1) print(f"관측된 차이: {관측차이:.1f}명") print(f"섞어서 더 극단적: {극단}회 / {N}회") print(f"순열검정 p: {p_순열:.5f}") print(f"t검정 p: {p:.4g}")
순열검정 p가 0.0002에서 멈춘 이유
5,000번 섞었으니 표현할 수 있는 최솟값이 1/(5000+1) ≈ 0.0002 입니다. 실제 p는 훨씬 작지만 해상도의 한계로 더 내려가지 않는 거죠. 더 정밀한 값이 필요하면 섞는 횟수를 늘려야 합니다.

+1을 더하는 이유는 "관측된 것 자체도 가능한 배치 중 하나"이기 때문입니다. 이걸 빼면 p가 0이 나올 수 있는데, p=0은 있을 수 없는 값입니다.
t검정 vs 순열검정
  • t검정 — 빠르고, 신뢰구간이 바로 나오고, 어디서나 통용됩니다. 기본 선택.
  • 순열검정 — 가정이 거의 없고, 원리가 투명합니다. 표본이 작거나 분포가 이상할 때, 또는 "왜 이 결론인지" 설명해야 할 때 좋습니다.
  • 둘이 비슷한 결론을 주면 안심해도 됩니다. 크게 다르면 t검정의 가정을 의심하세요.

6. 여러 번 검정할 때

요일이 7개니까 모든 쌍을 비교하면 21번의 검정입니다. α=0.05로 21번 검정하면 우연히 하나쯤은 유의하게 나옵니다.

from itertools import combinations 순서 = ["월", "화", "수", "목", "금", "토", "일"] 그룹 = {d: df[df["weekday"] == d]["visitors"] for d in 순서} 결과 = [] for a, b in combinations(순서, 2): _, pv = stats.ttest_ind(그룹[a], 그룹[b], equal_var=False) 결과.append((f"{a}-{b}", pv)) 유의 = sum(1 for _, pv in 결과 if pv < 0.05) 본페로니 = 0.05 / len(결과) 유의보정 = sum(1 for _, pv in 결과 if pv < 본페로니) print(f"검정 횟수: {len(결과)}회") print(f"보정 없이 p<0.05: {유의}쌍") print(f"본페로니 기준 p<{본페로니:.5f}: {유의보정}쌍") print() print("가장 작은 p값 3개:") for 이름, pv in sorted(결과, key=lambda x: x[1])[:3]: print(f" {이름} p={pv:.3g}")
21번 중 1번은 그냥 나옵니다

효과가 전혀 없어도 α=0.05로 21번 검정하면 적어도 한 번 유의할 확률이 1 − 0.95²¹ ≈ 66% 입니다. 3분의 2 확률로 헛것을 봅니다.

본페로니는 기준을 α/k 로 낮춥니다. 간단하지만 보수적이라 진짜 효과도 놓치기 쉽습니다. 검정이 많으면 FDR(Benjamini–Hochberg) 이 균형이 좋습니다 — statsmodels.stats.multitest.multipletests(pvals, method="fdr_bh")

7. 보고서에 쓰는 법

✗ 정보가 거의 없는 보고 "주말이 평일보다 유의하게 많았다 (p < 0.001)"
✓ 판단할 수 있는 보고 "주말 방문객이 평일보다 평균 37.4명 많았다 (95% CI: 28.8~46.1명, Cohen's d = 0.82, Welch t검정 p < 0.001, 주말 n=208 / 평일 n=523)"
반드시 함께 적을 것
  1. 효과크기 — 실무 단위로 (37.4명) 그리고 표준화된 값(d=0.82)
  2. 신뢰구간 — 최소 얼마인지가 의사결정을 좌우합니다
  3. 표본 크기 — 각 그룹별로
  4. 검정 방법 — Welch t검정인지, 순열검정인지
  5. 검정을 몇 번 했는지 — 보정했다면 방법까지
# 문제 1. 비 온 날과 안 온 날의 방문객을 t검정으로 비교하고, # 차이의 신뢰구간과 Cohen's d 까지 구해보세요. # 문제 2. 공휴일과 그 외의 방문객을 비교해보세요. # 공휴일은 35일뿐인데, 신뢰구간의 폭이 어떻게 다른가요? # 문제 3. 계절 4개 그룹의 매출을 ANOVA(f_oneway)로 비교해보세요.
모범 답안 보기
def 비교(이름, a, b): t, pv = stats.ttest_ind(a, b, equal_var=False) n1, n2 = len(a), len(b) v1, v2 = a.var(), b.var() 차 = a.mean() - b.mean() se = np.sqrt(v1/n1 + v2/n2) fr = (v1/n1 + v2/n2)**2 / ((v1/n1)**2/(n1-1) + (v2/n2)**2/(n2-1)) tc = stats.t.ppf(0.975, fr) sp = np.sqrt(((n1-1)*v1 + (n2-1)*v2) / (n1+n2-2)) print(f"[{이름}] n={n1} vs {n2}") print(f" 차이 {차:+.1f} 95% CI [{차-tc*se:.1f}, {차+tc*se:.1f}]") print(f" d={차/sp:.3f} p={pv:.4g}\n") # 문제 1 비교("비 vs 맑음", df[df["rain_mm"] > 0]["visitors"], df[df["rain_mm"] == 0]["visitors"]) # 문제 2 비교("공휴일 vs 그 외", df[df["is_holiday"]]["visitors"], df[~df["is_holiday"]]["visitors"]) # 문제 3 def 계절(m): return "봄" if m in (3,4,5) else "여름" if m in (6,7,8) else "가을" if m in (9,10,11) else "겨울" df["계절"] = df["date"].dt.month.map(계절) 그룹들 = [df[df["계절"] == s]["sales"].dropna() for s in ["봄", "여름", "가을", "겨울"]] F, pv = stats.f_oneway(*그룹들) print(f"[ANOVA] F={F:.2f}, p={pv:.3g}") print("→ 적어도 한 계절은 다르다. 어느 쌍인지는 사후검정으로 확인해야 함")

문제 2의 결과를 주목하세요. 공휴일은 35일뿐이라 신뢰구간이 훨씬 넓게 나옵니다. 같은 크기의 차이라도 표본이 작으면 "최소 얼마"라고 말할 수 있는 하한이 낮아집니다. 6강에서 "그룹 크기를 항상 함께 보라"고 한 이유가 여기서 숫자로 드러납니다.

13강 요약

  • 평균의 신뢰구간: stats.t.interval(0.95, n-1, loc=평균, scale=stats.sem(x))
  • 두 그룹 비교는 ttest_ind(a, b, equal_var=False) — Welch를 기본으로.
  • p값보다 차이의 신뢰구간을 먼저 보라. "최소 29명"이 실무에 쓰는 정보다.
  • Cohen's d 는 n에 흔들리지 않는 효과크기. p값과 함께 봐야 한다.
  • 순열검정은 가정이 거의 없고 원리가 투명하다. 해상도는 1/(N+1).
  • 여러 번 검정하면 보정이 필수. 21회면 헛것을 볼 확률이 66%.
  • 보고는 효과크기 + 신뢰구간 + p값 + n + 검정방법 세트로.
