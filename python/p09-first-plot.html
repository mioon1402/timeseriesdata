1. 그래프 하나 그려보기

import pandas as pd import matplotlib.pyplot as plt df = pd.read_csv("cafe_sales.csv", parse_dates=["date"]) fig, ax = plt.subplots(figsize=(9, 3.5)) ax.plot(df["date"], df["visitors"], linewidth=0.8) ax.set_title("일별 방문객 추이") ax.set_xlabel("날짜") ax.set_ylabel("방문객 수(명)") plt.show()

731일치가 한눈에 들어옵니다. 숫자로는 절대 안 보이던 것들이 보이죠.

  • 톱니 모양 — 주간 반복 패턴(주말↑ 평일↓)
  • 우상향 — 2년에 걸친 성장
  • 뾰족한 봉우리 하나 — 방송 대박 날(754명)
  • 바닥으로 떨어진 두 점 — 휴점일
matplotlib 기본 골격
fig, ax = plt.subplots()  # 도화지와 그림틀을 만든다
ax.plot(x, y)  # 그림틀에 그린다
plt.show()  # 화면에 표시
  • fig도화지 전체. 크기·저장·전체 제목을 담당
  • ax그림틀 하나. 축·라벨·실제 그래프는 전부 여기에
  • figsize(가로, 세로) 인치. (9, 3.5) 처럼 가로로 긴 비율이 시계열에 잘 맞습니다
plt.plot() 대신 ax.plot() 을 쓰세요

인터넷 예제에는 plt.plot(...), plt.title(...) 스타일이 많습니다. 간단할 땐 편하지만, 그림이 여러 개가 되는 순간 어디에 그려지는지 헷갈립니다.

fig, ax = plt.subplots() 로 시작하는 습관을 처음부터 들이면 §6의 다중 그래프로 자연스럽게 넘어갈 수 있습니다.

2. 한글이 깨질 때

위 그래프의 제목이 한글로 제대로 나왔다면 이 강의 페이지가 미리 한글 폰트를 등록해뒀기 때문입니다. 하지만 Colab이나 본인 컴퓨터에서는 □□□ 로 나올 겁니다.

왜 깨지나 matplotlib 의 기본 폰트(DejaVu Sans)에는 한글 글자가 아예 없습니다. 없는 글자는 두부 모양 네모(tofu)로 그려집니다. 버그가 아니라 폰트 문제입니다.

그리고 한 줄 더 반드시 넣으세요: 

plt.rcParams["axes.unicode_minus"] = False

한글 폰트를 쓰면 음수 부호(−)가 깨지는 별도의 문제가 생깁니다. 이 한 줄이 그걸 막아줍니다. 기온처럼 음수가 나오는 데이터에서 꼭 필요합니다.

print("현재 폰트:", plt.rcParams["font.family"]) print("음수 부호 처리:", plt.rcParams["axes.unicode_minus"]) fig, ax = plt.subplots(figsize=(7, 2.5)) ax.plot(df["date"], df["avg_temp"], linewidth=0.7, color="teal") ax.set_title("기온 추이 — 한글과 음수 부호 확인") ax.set_ylabel("평균기온(℃)") ax.axhline(0, color="gray", linestyle="--", linewidth=1) plt.show()

3. 네 가지 기본 그래프

월별 = df.set_index("date")["sales"].resample("ME").mean() / 10000 fig, ax = plt.subplots(figsize=(9, 3.2)) ax.plot(월별.index, 월별.values, marker="o", markersize=4) ax.set_title("월별 평균 매출") ax.set_ylabel("매출(만원)") plt.show()
순서 = ["월", "화", "수", "목", "금", "토", "일"] 요일평균 = df.groupby("weekday")["visitors"].mean().reindex(순서) fig, ax = plt.subplots(figsize=(7, 3.2)) ax.bar(요일평균.index, 요일평균.values, color="#0d9488") ax.set_title("요일별 평균 방문객") ax.set_ylabel("방문객 수(명)") plt.show()
fig, ax = plt.subplots(figsize=(7, 3.2)) ax.hist(df["visitors"], bins=30, color="#d97706", edgecolor="white") ax.set_title("방문객 수 분포") ax.set_xlabel("방문객 수(명)") ax.set_ylabel("일수") plt.show()

오른쪽으로 긴 꼬리가 보입니다. 5강에서 왜도 2.55라고 계산했던 게 이 모양입니다. 숫자보다 그림이 훨씬 빨리 이해되죠. (구간 개수를 바꿔가며 봐야 하는 이유는 모듈 02에서 슬라이더로 확인할 수 있습니다.)

fig, ax = plt.subplots(figsize=(7, 4)) ax.scatter(df["avg_temp"], df["sales"] / 10000, s=10, alpha=0.4, color="#7c3aed") ax.set_title("기온과 매출의 관계") ax.set_xlabel("평균기온(℃)") ax.set_ylabel("매출(만원)") plt.show()
산점도의 alpha 를 꼭 쓰세요 점이 731개나 되면 서로 겹쳐서 얼마나 몰려 있는지 안 보입니다. alpha=0.4 로 반투명하게 하면 겹친 곳이 진하게 나와 밀도가 드러납니다. 점이 수천 개를 넘으면 alpha 를 더 낮추거나 hexbin·2D 히스토그램을 쓰세요.

4. 어떤 그래프를 언제 쓰나

그래프답하는 질문가로축주의
선그래프 시간에 따라 어떻게 변했나 순서가 있는 것(날짜) 순서 없는 범주엔 쓰지 말 것
막대그래프 범주끼리 비교하면 어떤가 범주 (요일, 메뉴) y축은 반드시 0부터
히스토그램 값들이 어떻게 흩어져 있나 값의 구간 구간 폭을 바꿔가며 확인
산점도 두 변수가 관련이 있나 변수 하나 겹침 처리(alpha), 인과 아님
막대그래프의 y축을 0에서 시작하지 않으면 거짓말이 됩니다

막대는 길이로 크기를 표현합니다. 밑동을 잘라내면 길이 비율이 무너집니다. 아래 두 그래프는 같은 데이터입니다.

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 3.4)) ax1.bar(요일평균.index, 요일평균.values, color="#dc2626") ax1.set_ylim(140, 230) # 밑동을 잘랐다 ax1.set_title("✗ y축 140부터 — '토요일이 압도적'") ax2.bar(요일평균.index, 요일평균.values, color="#0d9488") ax2.set_ylim(0, 240) # 0부터 ax2.set_title("○ y축 0부터 — 실제 비율") plt.tight_layout() plt.show()

왼쪽만 보면 토요일이 월요일의 대여섯 배처럼 보입니다. 실제로는 1.57배입니다. 선그래프는 변화를 강조하려고 축을 자르는 게 허용되기도 하지만, 막대는 안 됩니다.

5. pandas 에서 바로 그리기

탐색 단계에서는 matplotlib 을 직접 쓰지 않고 데이터프레임에서 바로 .plot() 을 부르는 게 훨씬 빠릅니다.

ax = 요일평균.plot(kind="bar", figsize=(7, 3), color="#2563eb", title="요일별 평균 방문객", rot=0) ax.set_ylabel("명") plt.show()
월별표 = (df.set_index("date")[["visitors", "sales"]] .resample("ME").mean()) 월별표["sales"] = 월별표["sales"] / 10000 ax = 월별표.plot(figsize=(9, 3.2), secondary_y="sales", title="월별 방문객과 매출") plt.show()
secondary_y 는 단위가 다른 두 값을 한 그림에 그릴 때 오른쪽에 두 번째 y축을 만들어줍니다. 다만 두 축을 겹쳐 그리면 관계가 실제보다 강해 보이는 착시가 생기기 쉽습니다. 축 범위를 어떻게 잡느냐에 따라 두 선을 마음대로 붙이거나 떼어놓을 수 있으니, 발표용으로는 가급적 그래프를 나누세요.

6. 그림 하나에 여러 그래프

fig, axes = plt.subplots(2, 2, figsize=(11, 6.5)) axes[0, 0].plot(df["date"], df["visitors"], linewidth=0.6) axes[0, 0].set_title("일별 방문객 추이") axes[0, 1].bar(요일평균.index, 요일평균.values, color="#0d9488") axes[0, 1].set_title("요일별 평균") axes[1, 0].hist(df["visitors"], bins=30, color="#d97706", edgecolor="white") axes[1, 0].set_title("방문객 분포") axes[1, 1].scatter(df["avg_temp"], df["visitors"], s=8, alpha=0.35, color="#7c3aed") axes[1, 1].set_title("기온 vs 방문객") fig.suptitle("밀롱 커피 2년 요약", fontsize=14, fontweight="bold") plt.tight_layout() plt.show()
plt.tight_layout() 을 잊지 마세요 안 쓰면 제목과 축 라벨이 서로 겹칩니다. 여러 그래프를 배치할 때는 거의 항상 필요합니다. fig.suptitle 과 함께 쓸 때 제목이 잘리면 plt.tight_layout(rect=[0, 0, 1, 0.96]) 처럼 여백을 남기세요.
# 문제 1. 월별 평균 기온을 선그래프로 그려보세요. # 문제 2. 매출(sales)의 히스토그램을 그리고, 구간을 15개와 60개로 # 바꿔가며 모양이 어떻게 달라지는지 보세요. # 문제 3. 방문객과 매출의 산점도를 그려보세요. 어떤 모양이 나오나요?
모범 답안 보기
# 문제 1 월기온 = df.set_index("date")["avg_temp"].resample("ME").mean() fig, ax = plt.subplots(figsize=(9, 3)) ax.plot(월기온.index, 월기온.values, marker="o", color="teal") ax.axhline(0, color="gray", ls="--", lw=1) ax.set_title("월별 평균 기온"); ax.set_ylabel("℃") plt.show() # 문제 2 fig, (a, b) = plt.subplots(1, 2, figsize=(10, 3)) a.hist(df["sales"] / 10000, bins=15, color="#2563eb", edgecolor="white") a.set_title("구간 15개") b.hist(df["sales"] / 10000, bins=60, color="#2563eb", edgecolor="white") b.set_title("구간 60개") plt.tight_layout(); plt.show() # 문제 3 fig, ax = plt.subplots(figsize=(6, 4)) ax.scatter(df["visitors"], df["sales"] / 10000, s=8, alpha=0.4) ax.set_xlabel("방문객(명)"); ax.set_ylabel("매출(만원)") ax.set_title("방문객과 매출 — 거의 완벽한 직선") plt.show()

문제 3에서 점들이 거의 완벽한 직선을 이룹니다(상관계수 0.995). 당연합니다 — 매출 = 방문객 × 객단가인데 객단가가 거의 일정하니까요(6강). 이렇게 뻔한 관계는 분석할 게 없습니다. 산점도를 그려서 "너무 완벽한 직선"이 나오면 두 변수가 사실상 같은 것을 재고 있는 건 아닌지 의심해보세요.

9강 요약

  • fig, ax = plt.subplots() 로 시작하는 습관을 들일 것.
  • 한글이 깨지면 폰트 지정 + axes.unicode_minus=False.
  • 선=시간 변화 · 막대=범주 비교 · 히스토그램=분포 · 산점도=두 변수 관계.
  • 막대그래프의 y축은 반드시 0부터. 자르면 1.57배가 6배처럼 보인다.
  • 산점도는 alpha 로 겹침을 처리한다.
  • 탐색은 df.plot() 한 줄로 빠르게, 발표용은 직접 그린다.
  • 여러 그래프는 subplots(행, 열) + tight_layout().
