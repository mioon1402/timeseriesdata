숫자로 요약하기

1. 기본 통계량 총정리

import pandas as pd df = pd.read_csv("cafe_sales.csv", parse_dates=["date"]) v = df["visitors"] print(f"개수 {v.count():>10,}") print(f"합계 {v.sum():>10,}") print(f"평균 {v.mean():>10.2f}") print(f"중앙값 {v.median():>10.1f}") print(f"최빈값 {v.mode()[0]:>10}") print(f"분산 {v.var():>10,.1f}") print(f"표준편차 {v.std():>9.2f}") print(f"최솟값 {v.min():>10}") print(f"최댓값 {v.max():>10}") print(f"범위 {v.max() - v.min():>10}")
이 숫자들의 관계
분산  =  (표준편차)2      표준편차  =  √분산
2375.7 = 48.742
  • 분산단위가 제곱(명²)이라 해석이 안 됩니다. 계산 중간 단계로만 씁니다
  • 표준편차원래 단위(명)로 돌아온 값. 보고할 때는 이쪽
표준편차를 읽는 법 — 범위로 번역하세요

"평균 176.5명, 표준편차 48.7명"이라는 말은 이런 뜻입니다.

  • 평균 ± 1σ = 128 ~ 225명 안에 대략 3분의 2가 들어감
  • 평균 ± 2σ = 79 ~ 274명 안에 대략 95%가 들어감

단 이건 분포가 종 모양일 때 성립합니다(모듈 03). 우리 데이터는 오른쪽으로 치우쳐 있어 정확히 맞지는 않습니다 — §5에서 확인합니다.

2. n으로 나눌까 n−1로 나눌까

표준편차를 구할 때 분모가 두 가지입니다. 그리고 도구마다 기본값이 다릅니다. 실무에서 정말 자주 터지는 함정입니다.

import numpy as np print("pandas v.std() ", round(v.std(), 4), " ← ddof=1 (표본표준편차)") print("pandas v.std(ddof=0) ", round(v.std(ddof=0), 4), " ← 모표준편차") print() print("numpy np.std(v) ", round(np.std(v), 4), " ← ddof=0 이 기본!") print("numpy np.std(v, ddof=1)", round(np.std(v, ddof=1), 4))
두 가지 표준편차
s  =  √ 1n − 1 Σ(xi − x̄)2      σ  =  √ 1n Σ(xi − μ)2
  • s (n−1)표본표준편차. 이 데이터가 더 큰 모집단에서 뽑아온 표본일 때. 거의 항상 이쪽입니다
  • σ (n)모표준편차. 이 데이터가 전부일 때만
  • 왜 n−1표본평균은 그 표본에 가장 가까이 붙어 있어서 제곱합이 실제보다 작게 나옵니다. 분모를 줄여 보정하는 것 — 모듈 01 §5
이것 때문에 반나절을 날리는 사람이 많습니다
도구기본 분모표본(n−1)로 쓰려면
pandas .std()n−1그대로
numpy np.std()n ⚠️ddof=1 을 붙일 것
Excel STDEV.S / STDEV.P명시적STDEV.S
R sd()n−1그대로

같은 데이터인데 pandas와 numpy가 다른 값을 내면 십중팔구 이것입니다. n이 크면 차이는 미미하지만(위에서 48.7407 vs 48.7073), n이 10 이하일 때는 눈에 띄게 벌어집니다. 코드로 낼 땐 ddof 를 명시하는 습관을 들이세요.

3. 분위수 — 평균이 못 보는 것

분위 = v.quantile([0, 0.25, 0.5, 0.75, 0.90, 0.95, 1.0]) print(분위.round(1).to_string()) q1, q3 = v.quantile(0.25), v.quantile(0.75) print() print(f"IQR (가운데 50%의 폭) = {q3 - q1:.1f}명") print(f"상위 5% 기준선 = {v.quantile(0.95):.0f}명")

0.95 분위수(p95)가 260명이라는 건 "100일 중 5일은 260명 넘게 온다"는 뜻입니다. 평균 176명만 보고 인력을 배치하면 1년에 18일쯤은 아수라장이 됩니다.

실무에서 분위수를 쓰는 곳
  • 용량 설계 — 좌석·인력·서버는 평균이 아니라 p95, p99 기준으로 잡습니다.
  • 서비스 성능 — "평균 응답 200ms"보다 "p99가 4초"가 훨씬 중요한 정보입니다.
  • 이상치에 강함 — IQR은 극단값이 계산에 아예 안 들어갑니다(7강에서 자세히).

주의: 분위수는 평균 낼 수 없습니다. 지점 3곳의 p95를 평균 내도 전체 p95가 아닙니다. 원본 데이터를 합쳐서 다시 계산해야 합니다.

4. 변동계수 — 단위가 다른 것끼리 비교

"방문객(명)과 매출(원) 중 어느 쪽이 더 들쭉날쭉한가?" 표준편차를 그냥 비교할 수는 없습니다 — 48.7명과 249,538원은 단위가 다르니까요. 평균 대비 비율로 바꾸면 비교가 됩니다.

변동계수 (Coefficient of Variation)
CV  =  sx̄  × 100 (%)
  • 해석"평균의 몇 %만큼 흔들리는가". 단위가 사라져 서로 다른 지표를 비교할 수 있습니다
  • 주의평균이 0에 가깝거나 음수가 섞이면 의미가 없습니다. 기온 같은 데이터엔 쓰면 안 됩니다
for col in ["visitors", "sales", "avg_temp"]: s = df[col].dropna() cv = s.std() / s.mean() * 100 print(f"{col:10s} 평균 {s.mean():>10,.1f} 표준편차 {s.std():>9,.1f} CV {cv:>6.1f}%")
기온의 CV 79%는 의미 없는 숫자입니다 기온은 영하로 내려가 평균이 작아지는 값입니다. 평균이 0에 가까우면 CV가 무한대로 튀고, 평균이 음수면 부호까지 뒤집힙니다. CV는 항상 양수이고 절대영점이 있는 값(매출, 인원, 길이, 무게)에만 쓰세요. 섭씨온도는 조건을 만족하지 않습니다.

5. 왜도와 첨도 — 모양을 숫자로

for col in ["visitors", "sales", "avg_temp"]: s = df[col].dropna() print(f"{col:10s} 왜도 {s.skew():>7.3f} 첨도 {s.kurt():>7.3f} " f"평균 {s.mean():>9,.1f} 중앙값 {s.median():>9,.1f}")
지표뜻읽는 법
왜도 (skew) 좌우 비대칭 정도 + 면 오른쪽 긴 꼬리 · 0이면 대칭 · − 면 왼쪽 긴 꼬리
절댓값 0.5 넘으면 눈에 띄는 치우침
첨도 (kurtosis) 꼬리의 두께 정규분포가 0(pandas 기준). 클수록 극단값이 자주 나옴

visitors 의 왜도가 2.55, 첨도가 26.6 으로 매우 큽니다. "방송 대박 하루(754명)" 때문입니다. 값 하나가 이 지표들을 통째로 흔든 겁니다. 반면 avg_temp 는 왜도가 거의 0 — 사계절이 대칭적으로 오가니까요.

평균과 중앙값을 나란히 보세요 · visitors 는 평균 176.5, 중앙값 169로 평균이 더 큽니다. 이것만으로도 "오른쪽으로 치우쳤다"를 알 수 있습니다. 왜도를 계산하기 전에 이 비교부터 하는 게 빠릅니다.
왜도가 크면 무엇을 바꿔야 하나
  • 대표값을 평균 → 중앙값으로 바꾼다
  • 퍼짐을 표준편차 → IQR로 바꾼다
  • "평균 ± σ" 해석을 쓰지 않는다 (음수 구간이 나올 수 있음)
  • 필요하면 로그 변환 후 분석한다

5강 요약

  • 분산 = 표준편차². 보고할 땐 단위가 살아 있는 표준편차로.
  • ddof 함정 — pandas는 n−1, numpy는 n이 기본. 명시할 것.
  • 분위수는 용량 설계(p95·p99)와 이상치에 강한 요약(IQR)에 쓴다. 평균 낼 수 없다.
  • CV = s/x̄ 로 단위가 다른 지표를 비교. 단, 음수가 있는 값엔 쓰지 말 것.
  • 왜도 > 0.5면 치우침 → 중앙값·IQR로 전환. 평균 vs 중앙값 비교가 더 빠르다.
  • 중심값은 반드시 퍼짐·n과 함께 보고한다.
