seaborn으로 빠르게

10강에서 여러 줄로 하던 걸 한 줄로 끝냅니다. seaborn은 matplotlib 위에 얹힌 도구라, 탐색은 seaborn으로 빠르게 → 발표용은 matplotlib으로 다듬기가 실무 흐름입니다.

seaborn 은 브라우저에서 추가 설치가 필요합니다
  • 이 강의의 첫 셀은 seaborn 을 내려받느라 30초 이상 걸릴 수 있습니다.
  • 한 번 받으면 이후 셀은 빠릅니다.
이 강의에서 배우는 것
  1. 한 줄의 차이
  2. 분포 보기 — histplot, kdeplot
  3. 범주 비교 — boxplot, violinplot, barplot
  4. 관계 보기 — scatterplot, regplot
  5. 상관 히트맵

1. 한 줄의 차이

import pandas as pd import matplotlib.pyplot as plt import seaborn as sns df = pd.read_csv("cafe_sales.csv", parse_dates=["date"]) fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(11, 3.4)) # matplotlib — 데이터를 직접 넘긴다 ax1.hist(df["visitors"], bins=30, edgecolor="white") ax1.set_title("matplotlib") # seaborn — 데이터프레임과 '열 이름'을 넘긴다 sns.histplot(data=df, x="visitors", bins=30, ax=ax2) ax2.set_title("seaborn") plt.tight_layout() plt.show()
seaborn 의 문법 규칙
sns.그래프종류( data=df, x="열이름", y="열이름", hue="열이름", ax=ax )
  • data데이터프레임 통째로. seaborn 은 열 이름으로 말이 통합니다
  • x, y가로·세로에 놓을 열 이름 (값이 아니라 이름!)
  • hue색으로 구분할 세 번째 변수. seaborn 의 최대 강점 (§6)
  • ax그릴 그림틀. 생략하면 알아서 새로 만듭니다
seaborn 이 대신 해주는 것들
  • 축 라벨을 자동으로 붙입니다 (열 이름으로)
  • 범례를 자동으로 만듭니다
  • 색을 알아서 고릅니다 (기본 팔레트가 무난합니다)
  • 그룹별 계산(평균, 신뢰구간)을 내부에서 해줍니다

덕분에 탐색 속도가 몇 배 빨라집니다. 다만 자동으로 해주는 만큼 세밀한 제어는 어렵습니다 — §7 참고.

2. 분포 보기

fig, axes = plt.subplots(1, 3, figsize=(13, 3.4)) sns.histplot(data=df, x="visitors", bins=30, ax=axes[0]) axes[0].set_title("histplot — 도수") sns.histplot(data=df, x="visitors", bins=30, kde=True, ax=axes[1]) axes[1].set_title("kde=True — 매끄러운 곡선 겹치기") sns.kdeplot(data=df, x="visitors", fill=True, ax=axes[2]) axes[2].set_title("kdeplot — 곡선만") plt.tight_layout() plt.show()
KDE 곡선을 조심하세요

밀도곡선은 보기 좋지만 없는 데이터를 만들어냅니다. 방문객 수는 0 이하가 될 수 없는데, 곡선은 0보다 왼쪽까지 부드럽게 이어집니다. 위 그림의 왼쪽 꼬리를 보세요.

곡선의 매끄러움은 대역폭(bandwidth)이라는 임의의 설정에 달려 있습니다 — 히스토그램의 구간 폭과 똑같은 문제죠(모듈 02). 탐색용으로는 좋지만, 보고서에는 히스토그램이 더 정직합니다.

3. 범주 비교

순서 = ["월", "화", "수", "목", "금", "토", "일"] fig, axes = plt.subplots(1, 3, figsize=(14, 3.6)) sns.boxplot(data=df, x="weekday", y="visitors", order=순서, ax=axes[0]) axes[0].set_title("boxplot — 다섯 숫자 요약") sns.violinplot(data=df, x="weekday", y="visitors", order=순서, ax=axes[1]) axes[1].set_title("violinplot — 분포 모양까지") sns.barplot(data=df, x="weekday", y="visitors", order=순서, ax=axes[2]) axes[2].set_title("barplot — 평균 + 신뢰구간") plt.tight_layout() plt.show()
barplot 의 검은 세로선이 무엇인지 아세요?
그건 95% 신뢰구간입니다. seaborn 이 부트스트랩으로 자동 계산해줍니다. "이 평균을 얼마나 믿을 수 있나"를 그림이 알아서 말해주는 거죠 (모듈 05).

상자그림의 다섯 숫자(최소·Q1·중앙값·Q3·최대)와 동그란 이상치 점은 7강에서 배운 1.5 IQR 울타리 그대로입니다.

4. 관계 보기

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(11, 3.8)) sns.scatterplot(data=df, x="avg_temp", y="sales", alpha=0.4, s=18, ax=ax1) ax1.set_title("scatterplot") # regplot — 산점도 + 회귀선 + 신뢰밴드를 한 번에 sns.regplot(data=df, x="avg_temp", y="sales", scatter_kws={"alpha": 0.25, "s": 12}, line_kws={"color": "#dc2626"}, ax=ax2) ax2.set_title("regplot — 회귀선까지") plt.tight_layout() plt.show()

regplot 이 그려준 붉은 선이 최소제곱 회귀선이고, 그 주변의 옅은 띠가 회귀선의 95% 신뢰구간입니다. 선이 어떻게 정해지는지는 모듈 07에서 직접 그어볼 수 있고, 숫자로 구하는 법은 12강에서 배웁니다.

5. 상관 히트맵

수치열 = df[["visitors", "sales", "avg_temp", "rain_mm"]] 상관 = 수치열.corr() fig, ax = plt.subplots(figsize=(5.5, 4.5)) sns.heatmap(상관, annot=True, fmt=".2f", cmap="RdBu_r", center=0, vmin=-1, vmax=1, square=True, ax=ax) ax.set_title("변수 간 상관계수") plt.tight_layout() plt.show()
히트맵 설정 3가지가 중요합니다
  • cmap="RdBu_r" — 발산형 색상. 음수는 파랑, 0은 흰색, 양수는 빨강
  • center=0 — 0을 흰색으로 고정. 이게 없으면 약한 양의 상관이 진한 빨강으로 보입니다
  • vmin=-1, vmax=1 — 눈금을 −1~1로 고정. 안 하면 데이터에 따라 색 기준이 달라져 서로 다른 히트맵을 비교할 수 없습니다
visitors ↔ sales 의 0.99 를 보고 놀라지 마세요 매출 = 방문객 × 객단가인데 객단가가 거의 일정하니(6강), 두 변수는 사실상 같은 것을 재고 있습니다. 이런 관계는 발견이 아니라 정의상 당연한 것입니다. 히트맵에서 1에 가까운 값이 보이면 "둘이 사실 같은 변수 아닌가?"를 먼저 의심하세요. (회귀 모델에 둘 다 넣으면 다중공선성 문제가 생깁니다.)

6. hue — 세 번째 변수를 색으로

seaborn 의 진짜 강점입니다. hue 한 줄로 그룹별 비교가 됩니다.

df["비"] = df["rain_mm"] > 0 fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 3.8)) sns.scatterplot(data=df, x="avg_temp", y="sales", hue="비", alpha=0.45, s=18, ax=ax1) ax1.set_title("비 여부로 색 나누기") sns.boxplot(data=df, x="weekday", y="visitors", order=순서, hue="비", ax=ax2) ax2.set_title("요일 × 비 여부") plt.tight_layout() plt.show()

오른쪽 그림 하나로 "모든 요일에서 비 오는 날이 낮다"가 보입니다. 6강에서 표로 확인했던 걸 그림 한 장이 대신하죠. 교란변수를 통제한 비교를 시각화하는 가장 빠른 방법입니다.

# 변수가 몇 개 안 될 때, 모든 조합을 한 번에 훑는다 작은표본 = df[["visitors", "avg_temp", "rain_mm", "비"]].sample(300, random_state=42) g = sns.pairplot(작은표본, hue="비", height=1.9, plot_kws={"alpha": 0.5, "s": 12}) plt.show()
pairplot 은 탐색 초반에 딱 한 번 돌려보기 좋습니다. 대각선은 각 변수의 분포, 나머지는 두 변수의 산점도입니다. 다만 변수가 많으면 매우 느리고 읽기도 어렵습니다. 5~6개 이하일 때만 쓰세요. 표본도 줄여서(sample) 돌리는 게 좋습니다.

둘을 섞어 쓰는 게 정답입니다

seaborn 은 결국 matplotlib 위에서 돕니다. 그래서 seaborn 으로 그린 뒤 matplotlib 문법으로 다듬을 수 있습니다. 

fig, ax = plt.subplots(figsize=(9, 4))
sns.boxplot(data=df, x="weekday", y="visitors", ax=ax)   # seaborn 으로 그리고
ax.set_title("...", fontweight="bold", loc="left")        # matplotlib 으로 다듬기
ax.spines["top"].set_visible(False)
sns.set_theme(style="whitegrid") # seaborn 의 기본 스타일 fig, ax = plt.subplots(figsize=(9, 4)) sns.boxplot(data=df, x="weekday", y="visitors", order=순서, ax=ax, color="#93c5fd", showfliers=False) # 여기서부터는 matplotlib 문법 ax.set_title("주말로 갈수록 손님이 늘고, 편차도 커진다", fontsize=13, fontweight="bold", loc="left", pad=12) ax.set_xlabel(""); ax.set_ylabel("방문객(명)") ax.spines["top"].set_visible(False) ax.spines["right"].set_visible(False) plt.tight_layout() plt.show()
# 문제 1. 계절별 매출 분포를 boxplot 으로 그려보세요. # 힌트: 월을 계절로 바꾸는 함수는 4강에서 만들었습니다 # 문제 2. 기온과 방문객의 regplot 을 그리되, # 주말/평일을 hue 로 구분해보세요. # 힌트: regplot 에는 hue 가 없습니다. lmplot 을 쓰세요 # 문제 3. 상관 히트맵에 '주말' 열을 추가해서 다시 그려보세요.
모범 답안 보기
def 계절(m): if m in (3, 4, 5): return "봄" if m in (6, 7, 8): return "여름" if m in (9, 10, 11): return "가을" return "겨울" df["계절"] = df["date"].dt.month.map(계절) df["주말"] = df["date"].dt.dayofweek >= 5 # 문제 1 fig, ax = plt.subplots(figsize=(7, 3.6)) sns.boxplot(data=df, x="계절", y="sales", order=["봄", "여름", "가을", "겨울"], ax=ax) ax.set_title("계절별 매출 분포", fontweight="bold", loc="left") plt.show() # 문제 2 — hue 가 필요하면 lmplot (figure 를 직접 만든다) sns.lmplot(data=df, x="avg_temp", y="visitors", hue="주말", height=4, aspect=1.5, scatter_kws={"alpha": 0.3, "s": 12}) plt.show() # 문제 3 상관2 = df[["visitors", "sales", "avg_temp", "rain_mm", "주말"]].corr() fig, ax = plt.subplots(figsize=(6, 4.8)) sns.heatmap(상관2, annot=True, fmt=".2f", cmap="RdBu_r", center=0, vmin=-1, vmax=1, square=True, ax=ax) plt.tight_layout() plt.show()

문제 2에서 주말 선이 평일 선보다 위에 있고, 기울기는 비슷하게 나옵니다. "주말이라서 손님이 많은 것"과 "기온이 높아서 손님이 많은 것"이 따로 작동한다는 뜻이죠. 이렇게 선이 평행하면 두 효과가 독립적이고, 선이 교차하면 상호작용이 있는 것입니다.

11강 요약

  • sns.그래프(data=df, x="열", y="열", hue="열") — 열 이름으로 말이 통한다.
  • 분포: histplot · kdeplot. KDE는 없는 데이터를 만든다(0 이하 꼬리).
  • 범주: boxplot(기본) · violinplot(모양) · barplot(평균+신뢰구간). 막대만 쓰면 퍼짐이 안 보인다.
  • 관계: regplot 이 회귀선과 신뢰밴드까지 그려준다.
  • 히트맵은 center=0, vmin=-1, vmax=1 을 반드시 설정.
  • hue 한 줄로 그룹별 비교 — 교란변수를 통제한 시각화의 지름길.
  • 탐색은 seaborn, 완성본은 matplotlib. 둘은 섞어 쓸 수 있다.
