1. 데이터 불러오기

우리가 다룰 데이터는 가상의 카페 "밀롱 커피"의 2년치 영업 기록입니다. 하루에 몇 명이 왔고, 얼마를 벌었고, 그날 날씨는 어땠는지가 들어 있습니다.

파이썬에서 표 형태 데이터를 다루는 도구는 pandas입니다. 엑셀을 코드로 다룬다고 생각하면 거의 맞습니다.

import pandas as pd df = pd.read_csv("cafe_sales.csv") df.head()

세 줄이 각각 무슨 일을 했는지 뜯어봅시다.

코드뜻
import pandas as pd pandas 라는 도구를 가져오되, 앞으로 pd 라는 짧은 이름으로 부르겠다는 선언. 거의 모든 파이썬 코드가 이 관례를 씁니다.
pd.read_csv("...") CSV 파일을 읽어 데이터프레임(DataFrame) 으로 만듭니다. 데이터프레임 = 행과 열이 있는 표.
df.head() 맨 위 5줄만 보여줍니다. 데이터가 수만 줄이어도 화면이 터지지 않게 하는 습관.
고쳐보기
  • df.head() → df.head(10) 로 바꾸면 10줄이 나옵니다.
  • df.tail() 로 바꾸면 마지막 5줄이 나옵니다. 데이터가 어디서 끝나는지 확인할 때 씁니다.
  • df.sample(5) 는 무작위로 5줄을 뽑습니다. 앞뒤만 보면 놓치는 문제를 발견할 때 좋습니다.

2. 얼마나 큰 데이터인가

분석을 시작하기 전에 항상 확인해야 하는 첫 숫자는 "몇 행 몇 열인가"입니다.

print("행과 열:", df.shape) print("행 개수:", len(df)) print("열 이름:", list(df.columns))

df.shape 는 (731, 7) 처럼 나옵니다. 731행 7열이라는 뜻이죠. 731일 = 약 2년치입니다. 날짜가 하루도 빠지지 않았다는 것도 이 숫자로 짐작할 수 있습니다.

행 개수를 꼭 확인하세요 실무에서 가장 흔한 사고 중 하나가 데이터가 잘린 줄 모르고 분석하는 것입니다. 엑셀에서 내보내다 만 파일, 쿼리에 걸린 LIMIT 1000, 필터가 남아 있는 시트… "2년치인데 왜 300행이지?" 를 맨 처음에 물어야 나중에 결론을 뒤집지 않습니다.

3. 어떤 열이 있고, 각 열은 무슨 타입인가

df.info()

여기서 세 가지를 읽어야 합니다.

  • Non-Null Count — 값이 채워진 개수. 731이 아닌 열이 있다면 결측치가 있다는 뜻입니다. 위 결과에서 sales와 avg_temp를 보세요.
  • Dtype — 자료형. int64는 정수, float64는 실수, object는 대개 문자열입니다.
  • memory usage — 메모리 사용량. 데이터가 커지면 신경 써야 합니다.
왜 date 열이 object(문자열)일까요?
pandas는 CSV를 읽을 때 날짜를 자동으로 알아보지 못합니다. 우리 눈에는 2024-01-01 이 날짜지만, 컴퓨터에게는 그냥 열 글자짜리 문자열입니다. 그래서 지금 상태로는 "3월 데이터만 골라줘" 같은 걸 할 수 없습니다. 이걸 진짜 날짜로 바꾸는 방법은 4강에서 다룹니다.

결측치가 정확히 몇 개인지는 이렇게 셉니다.

df.isna().sum()

isna()는 각 칸이 비어 있으면 True, 아니면 False인 표를 만듭니다. 파이썬에서 True는 1, False는 0으로 취급되므로 sum()을 하면 열마다 빈 칸이 몇 개인지 세어집니다. 자주 쓰는 관용구니 통째로 외워두세요.

df.describe()

여덟 줄이 나옵니다. 각각이 무엇인지 알아야 데이터를 읽을 수 있습니다.

5. 요약값을 읽는 법

숫자가 나왔다고 끝이 아닙니다. 이 숫자들이 무엇을 말하는지 읽을 줄 알아야 합니다. 여기서부터가 통계입니다.

평균과 표준편차
x̄  =  1n Σ xi      s  =  √ 1n−1 Σ ( xi − x̄ )2
  • x̄평균. 모든 값을 더해 개수로 나눈 값 — 데이터가 균형을 이루는 지점
  • s표준편차. 각 값이 평균에서 평균적으로 얼마나 떨어져 있는지
  • n−1표본에서 계산할 때 쓰는 분모. pandas 의 std()는 기본이 n−1 입니다

표준편차가 왜 "평균에서 떨어진 정도"인지 그림으로 보고 싶다면 통계 모듈 01 · 평균은 시소, 분산은 넓이를 먼저 보세요. 점을 끌어보면 5초 만에 이해됩니다.

실무에서 제일 먼저 보는 것 · mean 과 50%(중앙값)를 비교하세요. 둘이 비슷하면 좌우대칭에 가까운 데이터, 평균이 훨씬 크면 오른쪽으로 긴 꼬리가 있다는 신호입니다.

직접 확인해봅시다. 매출의 평균과 중앙값을 나란히 놓고 봅니다.

mean = df["sales"].mean() median = df["sales"].median() print(f"평균 {mean:,.0f}원") print(f"중앙값 {median:,.0f}원") print(f"차이 {mean - median:,.0f}원 ({(mean/median - 1) * 100:+.1f}%)")

평균이 중앙값보다 조금 높게 나올 겁니다. 왜일까요? describe()의 min과 max를 다시 보세요. 매출이 0원인 날과 유난히 폭발한 날이 섞여 있습니다. 실제로 이 데이터에는 임시 휴점 이틀과 방송에 소개된 하루가 들어 있습니다.

# 방문객이 가장 많았던 날 3일 print("=== 최고 ===") print(df.nlargest(3, "visitors")[["date", "weekday", "visitors", "sales"]]) # 가장 적었던 날 3일 print() print("=== 최저 ===") print(df.nsmallest(3, "visitors")[["date", "weekday", "visitors", "sales"]])
이상치를 발견하면 지우기 전에 물어보세요
  • 왜 이런 값이 나왔나? 휴점? 시스템 오류? 진짜 대박?
  • 0원인 날은 "장사가 안 된 날"이 아니라 "장사를 안 한 날"입니다. 둘을 섞어서 평균을 내면 "우리 카페 평균 매출"이 실제보다 낮게 나옵니다.
  • 방송에 나온 날을 지우면 매출이 안정돼 보이지만, 마케팅 효과를 분석하려면 그날이 제일 중요한 데이터입니다.

이상치 처리에 정답은 없습니다. 다만 무엇을 왜 뺐는지 기록으로 남기는 것은 정답입니다.

아래 셀은 비어 있습니다. 위에서 배운 걸 조합해서 직접 답을 찾아보세요. 틀려도 됩니다. 오류가 나면 무엇이 문제인지 힌트가 함께 나옵니다.

# 문제 1. 방문객 수(visitors)의 평균과 표준편차를 출력해보세요. # 힌트: df["visitors"].mean() , .std() # 문제 2. 기온(avg_temp)의 최댓값과 최솟값은? # 문제 3. 매출(sales)이 가장 높았던 날 5일을 뽑아보세요. # 힌트: df.nlargest(5, "열이름")
모범 답안 보기
# 문제 1 print(f"방문객 평균 {df['visitors'].mean():.1f}명") print(f"방문객 표준편차 {df['visitors'].std():.1f}명") # 문제 2 print(f"최고기온 {df['avg_temp'].max()}도, 최저기온 {df['avg_temp'].min()}도") # 문제 3 df.nlargest(5, "sales")[["date", "weekday", "visitors", "sales"]]

문제 1의 답을 보면 평균 약 170명, 표준편차 약 45명쯤 나옵니다. 이건 "보통 날은 170명 안팎이고, 대체로 125~215명 사이에서 움직인다"는 뜻입니다 (평균 ± 1 표준편차). 표준편차를 이렇게 범위로 번역해서 읽는 습관을 들이세요.
