날짜를 날짜답게

지금까지 date 열은 그냥 열 글자짜리 문자열이었습니다. 이걸 진짜 날짜로 바꾸는 순간, "3월만 보여줘" "주말만" "월별 합계"가 전부 한 줄이 됩니다. 시계열 분석의 출발점입니다.

이 강의에서 배우는 것
  1. 왜 굳이 변환해야 하나
  2. to_datetime — 문자열을 날짜로
  3. 형식이 섞여 있을 때
  4. dt 접근자 — 날짜에서 꺼내 쓰기
  5. 파생 열 만들기
  6. 날짜를 인덱스로 — 기간 자르기
  7. 실전: 주말 효과는 얼마나 되나

1. 왜 굳이 변환해야 하나

문자열 상태로도 df["date"].str[5:7] == "03" 처럼 잘라 쓸 수는 있습니다(2강). 하지만 이런 문제가 생깁니다.

  • 계산이 안 됩니다. "이 날짜의 30일 뒤"를 구할 수 없습니다.
  • 요일을 모릅니다. 2025년 3월 15일이 무슨 요일인지 문자열은 답하지 못합니다.
  • 월말 처리가 지옥입니다. 2월이 28일인지 29일인지, 12월 31일 다음이 무엇인지…
  • 정렬이 위험합니다. 형식이 조금만 달라도 엉뚱하게 정렬됩니다.

pandas의 datetime 타입으로 바꾸면 이 모든 걸 pandas가 알아서 해줍니다.

2. to_datetime

import pandas as pd df = pd.read_csv("cafe_sales.csv") print("변환 전:", df["date"].dtype) df["date"] = pd.to_datetime(df["date"]) print("변환 후:", df["date"].dtype) print() print(df["date"].head(3))

datetime64 라고 나오면 성공입니다. 이제 이 열은 날짜로서 동작합니다.

읽을 때 바로 변환하기 매번 따로 변환하기 번거로우면 read_csv 에서 한 번에 처리할 수 있습니다. 
df = pd.read_csv("cafe_sales.csv", parse_dates=["date"])
실무에서는 이쪽을 더 많이 씁니다.

3. 형식이 섞여 있을 때

3강에서 본 지저분한 데이터에는 날짜가 세 가지 형식으로 섞여 있었습니다. 이럴 때 어떻게 되는지 직접 봅시다.

messy = pd.read_csv("cafe_sales_messy.csv") print("원본 형식:", messy["날짜"].head(3).tolist()) 변환 = pd.to_datetime(messy["날짜"], format="mixed", errors="coerce") print() print("변환 성공:", 변환.notna().sum(), "건") print("변환 실패:", 변환.isna().sum(), "건") print() print("실패한 것들:", messy.loc[변환.isna(), "날짜"].head(3).tolist())

format="mixed" 는 2024-01-01 과 2024/01/03 처럼 표준에 가까운 형식은 알아서 처리합니다. 하지만 1월 1일, 2024 같은 한국어 표기는 못 읽습니다. errors="coerce" 덕분에 오류로 멈추지 않고 결측으로 남았죠.

# 정규식으로 월·일·연도를 뽑아낸다 부분 = messy["날짜"].str.extract(r"(\d+)월\s*(\d+)일,\s*(\d{4})") 부분.columns = ["month", "day", "year"] 한국식 = pd.to_datetime(부분, errors="coerce") print("한국식 해석 성공:", 한국식.notna().sum(), "건") # 두 결과를 합친다 — 먼저 성공한 쪽을 쓰고, 비어 있으면 다른 쪽으로 최종 = 변환.fillna(한국식) print("최종 변환 성공:", 최종.notna().sum(), "/", len(messy), "건") print() print(최종.head(4).tolist())
실무 순서
  1. errors="coerce" 로 일단 변환하고 실패 건수를 센다
  2. 실패한 값들을 .unique() 로 뽑아 패턴을 파악한다
  3. 패턴별로 처리해서 fillna 로 합친다
  4. 끝나면 결측이 0인지 다시 확인한다

처음부터 완벽한 코드를 짜려 하지 말고, 실패를 눈으로 보고 대응하는 게 빠릅니다.

4. dt 접근자

날짜로 바꾸고 나면 .dt 를 붙여 원하는 부분을 꺼낼 수 있습니다. (문자열에 .str 을 붙였던 것과 같은 원리입니다.)

print("연도: ", df["date"].dt.year.head(3).tolist()) print("월: ", df["date"].dt.month.head(3).tolist()) print("일: ", df["date"].dt.day.head(3).tolist()) print("요일번호:", df["date"].dt.dayofweek.head(3).tolist(), " (0=월요일)") print("요일이름:", df["date"].dt.day_name().head(3).tolist()) print("주차: ", df["date"].dt.isocalendar().week.head(3).tolist()) print("분기: ", df["date"].dt.quarter.head(3).tolist())
속성뜻주로 쓰는 곳
.dt.year / .month / .day연·월·일기간별 집계
.dt.dayofweek요일 번호 (0=월 … 6=일)주말 판별
.dt.day_name()요일 이름 (영어)그래프 라벨
.dt.quarter분기 (1~4)분기 실적
.dt.days_in_month그 달의 일수일평균 계산
.dt.strftime("%Y-%m")원하는 형식의 문자열로보고서 표기
요일 번호는 0부터입니다 dayofweek 는 월요일이 0, 일요일이 6입니다. "주말"은 >= 5 로 판별합니다. 영어권 달력처럼 일요일이 0일 거라 착각하면 토·일 대신 금·토를 주말로 세게 됩니다. 헷갈리면 day_name() 과 나란히 출력해 확인하세요.

5. 파생 열 만들기

꺼낸 값을 새 열로 저장해두면 이후 분석이 훨씬 편해집니다.

df["연"] = df["date"].dt.year df["월"] = df["date"].dt.month df["주말"] = df["date"].dt.dayofweek >= 5 # 계절도 만들어보자 — 월을 구간으로 묶는다 def 계절(m): if m in (3, 4, 5): return "봄" if m in (6, 7, 8): return "여름" if m in (9, 10, 11): return "가을" return "겨울" df["계절"] = df["월"].map(계절) df[["date", "weekday", "연", "월", "주말", "계절"]].head()
map 과 apply
  • .map(함수) — Series의 값을 하나씩 바꿉니다. 위처럼 쓰면 됩니다.
  • .map({"봄": 1, "여름": 2}) — 딕셔너리를 주면 값을 갈아끼웁니다. 더 빠릅니다.
  • 가능하면 벡터 연산이 더 좋습니다. df["date"].dt.dayofweek >= 5 는 함수 호출 없이 한 번에 처리돼 훨씬 빠릅니다.

6. 날짜를 인덱스로 — 기간 자르기

날짜를 인덱스로 삼으면 강력한 기능들이 열립니다.

ts = df.set_index("date") # 문자열로 기간을 지정할 수 있다 print("2025년 3월:", len(ts.loc["2025-03"]), "일") print("2024년 여름:", len(ts.loc["2024-06":"2024-08"]), "일") print() print(f"2025년 3월 평균 매출: {ts.loc['2025-03', 'sales'].mean():,.0f}원") print(f"2024년 여름 평균 매출: {ts.loc['2024-06':'2024-08', 'sales'].mean():,.0f}원")

ts.loc["2025-03"] 한 줄로 3월 데이터 31일치가 나옵니다. 문자열을 잘라 비교하던 2강 방식과 비교해보세요. 훨씬 읽기 쉽습니다.

# ME = Month End(월말 기준). W = 주, QE = 분기, YE = 연 월별 = ts["sales"].resample("ME").mean() print("월별 평균 매출 (만원)") print((월별 / 10000).round(0).head(12).to_string())
resample 은 시계열 전용 groupby 입니다. 날짜 인덱스가 있어야만 쓸 수 있고, "월별로", "주별로" 묶는 걸 한 줄로 해냅니다. 14강에서 이동평균과 함께 본격적으로 다룹니다.

7. 실전: 주말 효과는 얼마나 되나

주말 = df[df["주말"]] 평일 = df[~df["주말"]] print(f"주말 {len(주말):3d}일 평균 방문객 {주말['visitors'].mean():.1f}명") print(f"평일 {len(평일):3d}일 평균 방문객 {평일['visitors'].mean():.1f}명") print() 차이 = 주말["visitors"].mean() - 평일["visitors"].mean() print(f"차이 {차이:+.1f}명 ({차이 / 평일['visitors'].mean() * 100:+.1f}%)")

주말이 평일보다 약 37명(22%) 많습니다. 꽤 큰 차이죠. 그런데 여기서 2강에서 배운 습관을 다시 꺼내야 합니다 — 이 차이가 우연일 가능성은 없을까요?

차이를 볼 때 함께 봐야 하는 것

평균만 보지 말고 퍼짐도 같이 보세요. 두 그룹의 표준편차가 크면, 평균이 달라 보여도 실제로는 많이 겹칠 수 있습니다.

for 이름, 그룹 in [("주말", 주말), ("평일", 평일)]: v = 그룹["visitors"] print(f"{이름} n={len(v):3d} 평균 {v.mean():6.1f} 표준편차 {v.std():5.1f} " f"범위 {v.min():.0f}~{v.max():.0f}")

표준편차가 각각 50명 안팎입니다. 평균 차이 37명보다 퍼짐이 더 큽니다. 그렇다면 "주말이 더 낫다"고 단정해도 될까요? 이 질문에 답하는 게 13강(가설검정)이고, 그 개념을 그림으로 보고 싶다면 모듈 06에서 카드를 직접 섞어볼 수 있습니다.

# 문제 1. 계절별 평균 매출을 구해보세요. # 힌트: df.groupby("계절")["sales"].mean() # 문제 2. 2025년 데이터만 골라 월별 평균 방문객을 구해보세요. # 힌트: df[df["연"] == 2025] 로 거르고 groupby("월") # 문제 3. 각 달의 '일수'를 구해서 새 열로 넣어보세요. # 힌트: df["date"].dt.days_in_month
모범 답안 보기
# 문제 1 계절순 = ["봄", "여름", "가을", "겨울"] print((df.groupby("계절")["sales"].mean() / 10000).round(1).reindex(계절순)) # 문제 2 print() print(df[df["연"] == 2025].groupby("월")["visitors"].mean().round(1)) # 문제 3 df["그달일수"] = df["date"].dt.days_in_month print() print(df[["date", "그달일수"]].head(3).to_string(index=False))

문제 1에서 여름이 가장 높고 겨울이 가장 낮게 나옵니다. 아이스 음료 단가가 높고 손님도 많은 계절이니까요. reindex 로 계절 순서를 지정하지 않으면 가나다순으로 나와 "가을 → 겨울 → 봄 → 여름"처럼 이상하게 정렬됩니다.

4강 요약

  • pd.to_datetime() 또는 read_csv(parse_dates=[...]) 로 진짜 날짜 만들기.
  • 형식이 섞이면 format="mixed", errors="coerce" → 실패 건수를 확인하고 패턴별로 대응.
  • .dt.year · .month · .dayofweek(0=월) · .day_name() · .quarter
  • 자주 쓰는 조건은 파생 열로 저장해두면 이후가 편하다.
  • set_index("date") → loc["2025-03"] 로 기간을 문자열로 자를 수 있다.
  • resample("ME") 는 시계열 전용 groupby. 14강에서 본격적으로.
  • 그룹 간 평균 차이를 볼 땐 표준편차와 표본 수를 함께 볼 것.
