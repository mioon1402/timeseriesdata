0. 기초 다지기 — "독립"이 무슨 뜻인가

일상어의 "독립"과 크게 다르지 않습니다. "다른 것들로 만들어낼 수 없다"는 뜻입니다.

색으로 생각해보기
빨강·파랑·노랑이 있으면 독립입니다 — 어느 하나도 나머지 둘을 섞어 만들 수 없죠.
여기에 보라를 추가하면? 보라는 빨강+파랑이니 종속입니다. 새로운 방향을 하나도 더해주지 못합니다.

선형대수의 독립도 정확히 이겁니다 — "이 벡터가 나머지의 선형결합으로 만들어지는가?"

1. 선형독립과 선형종속

정의
c1v1 + c2v2 + ⋯ + cnvn = 0
이 식의 해가 c₁ = c₂ = ⋯ = 0 뿐이면 → 선형독립
0이 아닌 c 로도 만들 수 있으면 → 선형종속
  • 왜 이 식인가종속이면 어떤 vk 를 좌변에서 옮겨 "나머지의 선형결합" 으로 적을 수 있습니다. 그게 "만들어낼 수 있다"의 정확한 표현이죠
  • 6강과 연결벡터들을 열로 세워 A 를 만들면, 이 식은 Ac = 0 입니다. 독립 ⟺ 영공간이 원점뿐

개수보다 방향 · 2차원 평면에서는 벡터가 3개 이상이면 무조건 종속입니다. 방향이 2개뿐인 곳에 3개를 놓았으니 하나는 반드시 나머지의 조합이죠. 각도를 0°나 180°로 맞춰보면 2개일 때도 종속이 됩니다.

2. 기저 — 딱 필요한 만큼

기저(Basis) 는 공간을 설명하는 데 필요한 최소한의 벡터 모음입니다. 두 조건을 동시에 만족해야 합니다.

기저의 두 조건
① 공간을 생성한다 (Span)  — 모자라지 않다
② 서로 선형독립이다  — 남지 않는다
  • ①만벡터가 너무 많음. 중복이 있습니다
  • ②만벡터가 모자람. 공간을 다 못 덮습니다
  • 둘 다딱 맞음. 공간의 모든 점을 정확히 한 가지 방법으로 표현할 수 있습니다
기저는 유일하지 않습니다
ℝ² 의 표준기저는 (1,0), (0,1) 이지만, (1,1), (1,−1) 도 훌륭한 기저입니다. 같은 방을 다른 좌표축으로 재는 것과 같죠.

그리고 어떤 기저를 고르느냐가 문제의 난이도를 바꿉니다. 13·14강에서 고유벡터를 기저로 삼으면 복잡한 변환이 단순한 대각행렬이 되는 걸 보게 됩니다.

3. 차원과 랭크

기저를 어떻게 고르든 벡터의 개수는 항상 같습니다. 그 불변의 개수를 차원(Dimension) 이라고 합니다.

정리 · 모든 기저의 크기는 같다
더 적은 개수로 공간을 덮을 수 있다면 → 원래 기저가 종속이 됨 (②에 모순)
더 많은 개수를 쓰면 → 차원을 넘겨 반드시 종속이 됨 (역시 모순)
⟹ 크기는 하나로 고정된다
랭크 (Rank)
r = 피봇의 개수 = dim C(A) = dim C(AT)
  • 놀라운 사실행 랭크 = 열 랭크. "독립인 행의 개수"와 "독립인 열의 개수"가 언제나 같습니다. 행렬이 아무리 찌그러진 모양이어도요
  • 계산소거해서 남은 피봇을 세면 끝입니다(3·6강)

4. 네 가지 기본 부분공간

6강에서 N(A) 와 C(A) 를 봤습니다. AT 에 대해서도 똑같이 두 개를 정의하면 총 네 개가 됩니다.

이름기호정의사는 곳차원
열공간C(A) A의 열들의 Spanℝᵐr
영공간N(A) Ax = 0 의 해ℝⁿn − r
행공간C(AT) A의 행들의 Spanℝⁿr
좌영공간N(AT) ATy = 0 의 해ℝᵐm − r
"좌"영공간이라는 이름의 유래
ATy = 0 의 양변을 전치하면 yTA = 0T — y 가 A 의 왼쪽에서 곱해지죠. 그래서 "왼쪽 영공간"입니다.

5. 차원 정리 (Big Picture)

선형대수의 Big Picture

행공간 dim–
영공간 dim–
열공간 dim–
좌영공간 dim–
차원 정리 (Rank–Nullity Theorem)
입력 쪽 ℝⁿ   r + (n − r) = n
출력 쪽 ℝᵐ   r + (m − r) = m
  • 읽는 법입력 차원 n 은 살아남는 부분(r) 과 0으로 사라지는 부분(n−r) 으로 정확히 나뉩니다
  • 보존 법칙랭크가 커지면 영공간이 그만큼 작아집니다. 총량은 항상 n 입니다
A 가 하는 일 한 문장 · A 는 행공간의 벡터를 열공간으로 1:1 옮기고, 영공간의 벡터는 전부 원점으로 뭉갭니다. 입력 공간이 두 조각(행공간 + 영공간)으로 정확히 쪼개지고, 한 조각만 살아남는 거죠. 위 그림이 그 이야기입니다.
직교성 — 8강 예고
네 공간은 차원만 맞물리는 게 아니라 기하학적으로도 수직입니다. ℝⁿ 안에서 행공간 ⟂ 영공간, ℝᵐ 안에서 열공간 ⟂ 좌영공간. 왜 그런지는 8강에서 세 줄로 증명합니다.

6. numpy 로 확인하기

import numpy as np np.set_printoptions(precision=3, suppress=True) def 판정(벡터들, 이름=""): A = np.column_stack(벡터들) # 벡터를 열로 세운다 r = np.linalg.matrix_rank(A) n = A.shape[1] print(f"{이름:22s} 벡터 {n}개, 랭크 {r} → " f"{'독립' if r == n else '종속 (' + str(n - r) + '개가 남아돈다)'}") 판정([[1, 0], [0, 1]], "(1,0), (0,1)") 판정([[1, 2], [2, 4]], "(1,2), (2,4)") # 평행 판정([[1, 0], [0, 1], [3, 5]], "2차원에 벡터 3개") 판정([[1, 0, 0], [0, 1, 0], [0, 0, 1]], "3차원 표준기저")
rng = np.random.default_rng(0) for m, n in [(3, 5), (5, 3), (4, 4), (2, 7)]: A = rng.integers(-3, 4, size=(m, n)).astype(float) print(f"{m}×{n} 행렬: rank(A) = {np.linalg.matrix_rank(A)}, " f"rank(Aᵀ) = {np.linalg.matrix_rank(A.T)}") print("\n→ 모양이 어떻든 항상 같다. 이것이 '행 랭크 = 열 랭크' 정리다.") print(" 그래서 랭크는 min(m, n) 을 넘을 수 없다.")
from scipy.linalg import null_space A = np.array([[1., 2., 2., 2.], [2., 4., 6., 8.], [3., 6., 8., 10.]]) m, n = A.shape r = np.linalg.matrix_rank(A) print(f"A 는 {m}×{n} 행렬, 랭크 r = {r}\n") print(f" 행공간 dim = r = {r} (ℝ^{n} 안)") print(f" 영공간 dim = n - r = {n - r} (ℝ^{n} 안)") print(f" {'':30s}합 = {n} = n ✓") print() print(f" 열공간 dim = r = {r} (ℝ^{m} 안)") print(f" 좌영공간 dim = m - r = {m - r} (ℝ^{m} 안)") print(f" {'':30s}합 = {m} = m ✓") print("\n실제로 세어보면:") print(" null_space(A) 모양:", null_space(A).shape, "→ 영공간 차원", null_space(A).shape[1]) print(" null_space(A.T) 모양:", null_space(A.T).shape, "→ 좌영공간 차원", null_space(A.T).shape[1])
N = null_space(A) # 영공간 기저 LN = null_space(A.T) # 좌영공간 기저 # 행공간의 벡터는 A 의 행들의 선형결합 행공간_벡터 = A.T @ np.array([1.5, -2.0, 0.7]) print("행공간 벡터 · 영공간 벡터 =", np.round(행공간_벡터 @ N, 12)) print("열공간 벡터 · 좌영공간 벡터 =", np.round((A @ np.array([1., 2., -1., 0.5])) @ LN, 12)) print() print("→ 전부 0. 네 공간은 짝을 지어 수직이다. 8강에서 증명합니다.")
def 진단(A): m, n = A.shape r = np.linalg.matrix_rank(A) print(f"{m}×{n}, rank={r}") print(f" 열이 독립 (영공간 = 0) : {r == n} → 해가 있다면 유일") print(f" 행이 독립 (좌영공간 = 0) : {r == m} → 어떤 b 든 해가 존재") print(f" 정사각 + 풀랭크 (가역) : {m == n and r == n}") print() 진단(np.array([[1., 0.], [0., 1.], [1., 1.]])) # 키가 큰 행렬 진단(np.array([[1., 2., 3.], [4., 5., 6.]])) # 납작한 행렬 진단(np.array([[2., 1.], [1., 3.]])) # 정사각 가역
모양으로 미리 알 수 있는 것
  • 키가 큰 행렬 (m > n, 식이 미지수보다 많음) — 열이 독립이면 해는 유일하거나 아예 없습니다. 현실 데이터가 대개 이 모양이라 최소제곱법(10강)이 필요합니다.
  • 납작한 행렬 (m < n, 미지수가 식보다 많음) — 영공간이 반드시 존재합니다(n − r ≥ n − m > 0). 해가 있으면 무한히 많습니다. 딥러닝의 과매개변수(overparameterized) 모델이 이 상황입니다.

7강 요약

  • 선형독립 = Σcᵢvᵢ = 0 의 해가 전부 0 뿐. = 영공간이 원점뿐.
  • 기저 = 생성 + 독립. 모자라지도 남지도 않는 최소 집합입니다. 유일하지 않습니다.
  • 차원 = 기저의 크기(항상 같음). 랭크 = 피봇 개수 = 열공간 차원 = 행공간 차원.
  • 네 부분공간: 행공간(r), 영공간(n−r), 열공간(r), 좌영공간(m−r).
  • 차원 정리: 입력 쪽 r + (n−r) = n, 출력 쪽 r + (m−r) = m. 랭크가 크면 영공간이 작아집니다.
  • A 는 행공간 → 열공간을 1:1 로 옮기고 영공간은 원점으로 뭉갭니다.
