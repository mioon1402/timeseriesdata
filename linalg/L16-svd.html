특이값 분해 (SVD)

고유분해는 정사각행렬에만, 스펙트럼 정리는 대칭행렬에만 통했습니다. SVD 는 어떤 모양의 행렬에도 항상 존재합니다. 그리고 그림은 딱 하나입니다 — 단위원이 타원이 된다. 선형대수의 최종 병기라 불리는 이유입니다.

0. 기초 다지기 — 고유분해의 한계

분해조건문제
A = SΛS−1정사각 + 독립 고유벡터 n개 전단행렬처럼 실패할 수 있음. S가 직교가 아니라 수치적으로 불안정
S = QΛQT대칭행렬 완벽하지만 적용 범위가 너무 좁음
A = UΣVT없음 모든 m×n 실수 행렬에 항상 존재
왜 항상 되는가 — 한 줄 아이디어
고유분해는 같은 기저를 입력과 출력에 쓰려다 실패합니다. SVD 는 입력 쪽과 출력 쪽에 서로 다른 기저를 씁니다.

"입력 공간에 좋은 직교 기저 V 를 고르고, 출력 공간에도 따로 직교 기저 U 를 골라서 둘 사이를 그냥 늘이기만 하도록 만든다" — 자유도가 두 배라서 언제나 성공합니다.

1. 단위원 → 타원

아래에서 행렬 값을 바꿔보세요. 왼쪽의 원 위 벡터가 오른쪽의 타원 위로 갑니다. 직교하는 두 방향(초록·보라)이 변환 후에도 직교한다는 게 핵심입니다.

입력 — 단위원과 v₁, v₂

출력 — 타원과 σ₁u₁, σ₂u₂

v₁ (입력 축)–
v₂–
특이값 σ₁, σ₂–
u₁ (출력 축)–
조건수 σ₁/σ₂–
랭크–
SVD 의 기하학적 사실 · "단위원 위에서 서로 직교한 두 방향을 잘 고르면, 변환 후에도 여전히 직교하게 만들 수 있다."

그 입력 쪽 방향이 v₁, v₂, 출력 쪽 방향이 u₁, u₂, 늘어난 배율이 σ₁, σ₂ 입니다. 그리고 이 방향들이 타원의 장축·단축이죠.

2. A = UΣVᵀ — 회전·늘림·회전

특이값 분해
A  =  U Σ VT
  • V입력 쪽 직교 기저 (n×n). 열이 오른쪽 특이벡터 vi
  • Σ특이값 σ₁ ≥ σ₂ ≥ ⋯ ≥ 0 을 대각에 둔 m×n 행렬. 전부 0 이상입니다
  • U출력 쪽 직교 기저 (m×m). 열이 왼쪽 특이벡터 ui
벡터 수준으로 풀면
A vi  =  σi ui
  • 고유값과 비교Ax = λx 는 같은 x 가 양쪽에 있지만, SVD 는 들어간 것(v)과 나온 것(u)이 다릅니다. 그 자유도 덕분에 정사각이 아니어도 됩니다
세 동작으로 읽기
Ax = U Σ VT x 를 오른쪽부터:

①VT — 입력 공간에서 회전 (v 축들을 좌표축에 맞춤)
②Σ — 각 축을 σ배 늘림 (여기서만 모양이 변함)
③U — 출력 공간에서 회전

어떤 선형변환이든 "돌리고 → 늘이고 → 돌리기"로 분해된다는 뜻입니다. 늘이는 것 말고는 아무 일도 안 일어납니다.

3. 어떻게 찾는가 — AᵀA 의 힘

비대칭 직사각 행렬에서 어떻게 직교 기저를 찾을까요? 대칭행렬을 스스로 만들어냅니다.

유도
ATA = (UΣVT)T(UΣVT) = VΣTUTUΣVT = V (ΣTΣ) VT
↑ 이건 대칭행렬의 스펙트럼 분해(15강)다!
  • VATA 의 고유벡터 (n×n 대칭)
  • UAAT 의 고유벡터 (m×m 대칭)
  • σi= √(고윳값). ATA 는 PSD 라 고윳값이 음수가 아니므로(15강) 제곱근이 항상 실수입니다
15강이 여기서 쓰입니다 · ATA 는 항상 대칭이고 항상 PSD 였습니다. 그래서 스펙트럼 정리가 언제나 적용되고, 고윳값이 음수가 아니라 √를 씌울 수 있죠. SVD 가 항상 존재하는 진짜 이유가 이것입니다.
실제 계산은 ATA 로 하지 않습니다 11강에서 봤듯이 ATA 를 만들면 조건수가 제곱됩니다. σ 가 작은 쪽이 반올림 오차에 묻혀버리죠.

위 유도는 "왜 존재하는가"를 설명할 뿐이고, numpy.linalg.svd 는 A 를 직접 다루는 이중대각화 + QR 반복 알고리즘을 씁니다.

4. 특이값이 알려주는 것

특이값에서얻는 것
0이 아닌 σ 의 개수랭크. 가장 믿을 만한 랭크 계산법입니다
σ1 (최대)최대 확대율. ‖A‖₂ (스펙트럼 노름)
σ1 / σr조건수. 계산이 얼마나 위험한지
Π σi|det| (정사각일 때). 부피 확대율(12강)
σ 가 급격히 작아지는 지점정보의 유효 차원. 압축·잡음 제거의 기준(17강)
랭크는 SVD 로 판정합니다
12강에서 det 로 특이성을 판정하면 안 된다고 했습니다. 소거로 세는 피봇 개수도 반올림 오차에 취약합니다.

실제로 np.linalg.matrix_rank 는 내부에서 SVD 를 돌려 "충분히 큰 σ 의 개수" 를 셉니다. "얼마나 0에 가까운가"를 연속적인 값으로 볼 수 있어서죠.

5. SVD 와 네 부분공간

7강의 Big Picture 가 SVD 로 완전히 채워집니다. U 와 V 의 열들이 네 부분공간의 정규직교 기저를 그대로 줍니다.

부분공간기저차원
행공간 C(AT) v1 … vrr
영공간 N(A) vr+1 … vnn − r
열공간 C(A) u1 … urr
좌영공간 N(AT) ur+1 … umm − r
왜 이렇게 되나 · σi = 0 이면 Avi = 0·ui = 0 — 그 vi 는 영공간에 있습니다. σi > 0 인 vi 들은 행공간을 이루고, 그 상들 ui 가 열공간을 이룹니다.

게다가 전부 정규직교입니다. 8강에서 증명한 직교성이 기저 수준에서 눈에 보이게 정리된 셈이죠.

6. numpy 로 확인하기

import numpy as np np.set_printoptions(precision=4, suppress=True) A = np.array([[3., 0.], [4., 5.]]) U, σ, Vt = np.linalg.svd(A) # 주의: 세 번째는 V 가 아니라 Vᵀ 다 print("U =") print(U) print("\nσ =", σ, " ← 내림차순, 전부 0 이상") print("\nVᵀ =") print(Vt) print() print("복원 U @ diag(σ) @ Vᵀ =") print(U @ np.diag(σ) @ Vt) print("A 와 같은가:", np.allclose(U @ np.diag(σ) @ Vt, A))
svd 는 V 가 아니라 VT 를 돌려줍니다 vi 를 꺼내려면 Vt[i] (행) 또는 Vt.T[:, i] (열) 입니다. 반면 ui 는 U[:, i] (열)이죠. 한쪽은 행, 한쪽은 열이라 헷갈리기 쉽습니다.
for i in range(2): v = Vt[i] # i번째 오른쪽 특이벡터 (행!) u = U[:, i] # i번째 왼쪽 특이벡터 (열!) print(f"i={i}: A@v = {np.round(A @ v, 4)} σ·u = {np.round(σ[i] * u, 4)} " f"같은가: {np.allclose(A @ v, σ[i] * u)}") print() print("UᵀU =", np.round(U.T @ U, 10).tolist(), " ← 직교") print("VᵀV =", np.round(Vt @ Vt.T, 10).tolist(), " ← 직교")
각도 = np.linspace(0, 2*np.pi, 8, endpoint=False) 원 = np.column_stack([np.cos(각도), np.sin(각도)]) # 단위원 위 8개 점 타원 = 원 @ A.T # 각 점에 A 를 적용 print(f"{'입력(길이 1)':>22} {'출력':>22} {'길이':>8}") for i in range(len(원)): print(f"{str(np.round(원[i], 3)):>22} {str(np.round(타원[i], 3)):>22} {np.linalg.norm(타원[i]):8.4f}") print() print(f"출력 길이의 최대 = {np.linalg.norm(타원, axis=1).max():.4f} (σ₁ = {σ[0]:.4f} 에 근접)") print(f" 최소 = {np.linalg.norm(타원, axis=1).min():.4f} (σ₂ = {σ[1]:.4f} 이상)") print("→ 점을 촘촘히 찍을수록 정확히 σ₁, σ₂ 에 도달한다")
AtA = A.T @ A print("AᵀA =") print(AtA, " 대칭:", np.allclose(AtA, AtA.T)) print() print("AᵀA 의 고윳값 =", np.sort(np.linalg.eigvalsh(AtA))[::-1]) print("σ² =", σ ** 2) print("같은가:", np.allclose(np.sort(np.linalg.eigvalsh(AtA))[::-1], σ ** 2)) print() print("AAᵀ 의 고윳값 =", np.sort(np.linalg.eigvalsh(A @ A.T))[::-1], " ← 같다") print("→ AᵀA 와 AAᵀ 는 크기가 달라도 0 아닌 고윳값이 동일하다")
행렬들 = { "정사각 가역" : np.array([[3., 0.], [4., 5.]]), "키가 큰 4×2" : np.array([[1., 0.], [0., 1.], [1., 1.], [2., -1.]]), "납작한 2×4" : np.array([[1., 2., 3., 4.], [5., 6., 7., 8.]]), "랭크 1 (특이)" : np.array([[1., 2., 3.], [2., 4., 6.]]), "영행렬" : np.zeros((2, 3)), } for 이름, Mx in 행렬들.items(): U2, s2, Vt2 = np.linalg.svd(Mx) 복원 = U2[:, :len(s2)] @ np.diag(s2) @ Vt2[:len(s2)] print(f"{이름:16s} {str(Mx.shape):8s} σ = {np.round(s2, 4)}") print(f"{'':16s} 랭크 {np.linalg.matrix_rank(Mx)} 복원 정확: {np.allclose(복원, Mx)}") print() print("→ 어떤 모양이든, 특이해도, 영행렬이어도 SVD 는 존재한다")
B = np.array([[3., 0.], [4., 5.]]) U3, s3, Vt3 = np.linalg.svd(B) print("σ =", s3) print() print("랭크 =", int((s3 > 1e-10).sum()), " (numpy:", np.linalg.matrix_rank(B), ")") print("‖B‖₂ (최대확대) =", s3[0], " (numpy:", round(np.linalg.norm(B, 2), 6), ")") print("조건수 =", s3[0] / s3[-1], " (numpy:", round(np.linalg.cond(B), 6), ")") print("|det| =", np.prod(s3), " (numpy:", round(abs(np.linalg.det(B)), 6), ")")
C = np.array([[1., 2., 3.], [2., 4., 6.], [1., 1., 1.]]) U4, s4, Vt4 = np.linalg.svd(C) r = int((s4 > 1e-10).sum()) m, n = C.shape print("σ =", np.round(s4, 6), " 랭크 r =", r) print() print(f"열공간 기저 = U 의 앞 {r}열") print(np.round(U4[:, :r], 4)) print(f"\n좌영공간 기저 = U 의 나머지 {m-r}열") print(np.round(U4[:, r:], 4)) print(f"\n행공간 기저 = Vᵀ 의 앞 {r}행") print(np.round(Vt4[:r], 4)) print(f"\n영공간 기저 = Vᵀ 의 나머지 {n-r}행") print(np.round(Vt4[r:], 4)) print() print("확인: C @ (영공간 기저) =", np.round(C @ Vt4[r:].T, 10).ravel())

실무에서 SVD
  • 랭크·조건수 판정 — matrix_rank, cond, lstsq 가 전부 내부에서 SVD 를 씁니다.
  • 차원 축소 — PCA 는 사실 중심화한 데이터 행렬의 SVD 입니다. 공분산 행렬을 만들지 않아 더 정확합니다(20강).
  • 압축·잡음 제거 — 작은 σ 를 버립니다(17강).
  • 추천 시스템 — 사용자-아이템 행렬을 저랭크로 근사(18강).
  • 의사역행렬 — 역행렬이 없어도 가장 합리적인 해를 줍니다(18강).

16강 요약

  • SVD 는 모든 m×n 행렬에 항상 존재합니다. 조건이 없습니다.
  • 그림 하나: 단위원 → 타원. 직교하던 두 방향이 변환 후에도 직교합니다.
  • A = UΣVT = 회전 → 늘림 → 회전. 벡터로는 Avi = σiui.
  • 고유분해와의 차이: 입력 기저와 출력 기저가 다릅니다. 그 자유도 덕에 항상 성공합니다.
  • 존재 이유: ATA 가 항상 대칭·PSD 라서 스펙트럼 정리가 적용되고 σ = √λ 가 실수입니다(15강).
  • σ 에서 랭크·노름·조건수·|det| 를 전부 읽습니다. 랭크 판정의 표준입니다.
  • U, V 의 열이 네 부분공간의 정규직교 기저입니다 — 7강 Big Picture 의 완성.
