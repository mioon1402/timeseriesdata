행렬식은 넓이다

ad − bc 라는 공식만 외우면 행렬식은 그냥 이상한 숫자입니다. 하지만 그 숫자에는 딱 하나의 기하학적 뜻이 있습니다 — 변환이 넓이(부피)를 몇 배로 만드는가. 그걸 알면 "왜 det=0 이면 역행렬이 없는가"가 당연해집니다.

0. 기초 다지기 — 넓이부터 다시

두 벡터 u, v 를 두 변으로 하는 평행사변형을 그려봅시다. 그 넓이가 곧 |행렬식| 입니다.

2×2 행렬식
det abcd  =  a d − b c    |값| = 두 열이 만드는 평행사변형의 넓이
  • 3×3세 열이 만드는 평행육면체의 부피
  • n×nn차원 초평행육면체의 부피. 그림은 못 그려도 뜻은 같습니다
  • 기호det(A) 또는 |A|. 절댓값 기호와 헷갈리지 마세요 — |A| 는 음수일 수 있습니다
변환의 관점으로 읽으면
4강에서 A의 열 = 기저벡터가 가는 곳이라고 했습니다. 원래 e₁, e₂ 가 만드는 단위 정사각형(넓이 1)이 변환 후 넓이 |det A| 인 평행사변형이 되는 겁니다.

즉 det = 넓이 확대율입니다. 단위 정사각형이 그렇게 되면 다른 모든 도형도 같은 비율로 변합니다.

det = 0 의 뜻 · 넓이가 0이라는 건 평행사변형이 선으로 납작하게 눌렸다는 뜻입니다. 2차원이 1차원으로 차원이 줄어든 것이죠. 서로 다른 점들이 같은 자리로 뭉개졌으니 되돌릴 방법이 없습니다.

그래서 det = 0 ⟺ 특이행렬 ⟺ 역행렬 없음 ⟺ 열이 종속 ⟺ 영공간이 원점보다 큼. 6·7강에서 배운 것들이 전부 한 숫자로 요약됩니다.

2. 부호는 무엇을 뜻하나

위에서 [두 열 바꾸기] 를 눌러보세요. 넓이는 그대로인데 부호가 뒤집힙니다.

부호 = 배향(orientation)
u 에서 v 로 가는 회전 방향이 반시계면 +, 시계면 − 입니다.

3차원에서는 오른손 법칙 vs 왼손 법칙에 해당합니다. det 가 음수라는 건 변환이 거울 반사를 포함한다는 뜻이죠 — 오른손 장갑이 왼손 장갑이 되는 겁니다.

그래서 회전행렬은 det = +1, 반사행렬은 det = −1 입니다(19강).

3. 행렬식을 정의하는 세 가지 규칙

행렬식은 복잡한 공식이 아니라 세 가지 성질로 완전히 정의됩니다. 나머지는 전부 여기서 따라 나옵니다.

세 가지 공리
① det(I) = 1  — 한 변이 1인 정육면체의 부피는 1
② 두 행을 바꾸면 부호가 바뀐다  — 배향이 뒤집힘
③ 한 행에 대해 선형이다  — 한 행을 c배 하면 전체도 c배
  • ③의 뜻한 변의 길이를 2배로 늘리면 넓이도 2배. 그리고 한 행이 두 벡터의 합이면 행렬식도 두 개의 합으로 쪼개집니다
  • 놀라운 점이 셋만으로 n×n 행렬식이 유일하게 결정됩니다. ad−bc 도 여기서 나옵니다

4. 거기서 나오는 성질들

성질왜기하학적 뜻
두 행이 같으면 det = 0 바꿔도 같아야 하는데 부호는 뒤집혀야 함
D = −D ⟹ D = 0		 납작함 (두 변이 겹침)
소거해도 det 불변 ③에서 "같은 행 두 개" 항이 0이 되어 사라짐 평행사변형을 기울여도 넓이는 같다
삼각행렬 det = 대각 원소의 곱 소거로 삼각형을 만들면 부피는 변의 곱 직육면체의 부피 = 가로×세로×높이
det(AB) = det(A)det(B) 변환을 연달아 하면 확대율이 곱해짐 가장 유용한 성질
det(AT) = det(A) — 행으로 재나 열로 재나 부피는 같다
det(A−1) = 1/det(A) det(A)det(A−1) = det(I) = 1 되돌리면 확대율도 역수
det(cA) = cn det(A) n개 행이 각각 c배 모든 변을 c배 → 부피는 cn 배
det(A + B) ≠ det(A) + det(B) 곱셈은 잘 되는데 덧셈은 전혀 안 됩니다. 가장 흔한 착각입니다. 아래 코드에서 반례를 확인해보세요.

5. 계산법 — 여인수 전개와 크라머 공식

여인수 전개 (Cofactor Expansion)
det(A) = a11C11 + a12C12 + ⋯ + a1nC1n
Cij = (−1)i+j Mij
  • Mij소행렬식. i행과 j열을 지우고 남은 (n−1)×(n−1) 행렬의 행렬식
  • (−1)i+j체스판처럼 +−+− 부호가 번갈아 붙습니다
  • 요령0이 가장 많은 행이나 열로 전개하면 계산이 확 줍니다
크라머 공식 (Cramer's Rule)
xi  =  det(Bi)det(A)   Bi = A 의 i번째 열을 b 로 바꾼 행렬
  • 아름답지만실무에서는 쓰지 않습니다. 행렬식을 n+1 번 계산해야 하는데, 여인수 전개는 O(n!) 입니다
  • 비교가우스 소거는 O(n³). n=20 이면 20! ≈ 2.4×1018 vs 8000 — 비교가 안 됩니다
실무에서 det 를 구하는 법 · 여인수 전개가 아니라 LU 분해 후 대각 원소를 곱합니다(3강). O(n³) 이죠. np.linalg.det 도 그렇게 합니다.

그리고 사실 "이 행렬이 특이한가"를 판정할 때 det 를 쓰면 안 됩니다. 아래에서 이유를 봅니다.

6. numpy 로 확인하기

import numpy as np np.set_printoptions(precision=4, suppress=True) A = np.array([[3., 1.], [1., 2.]]) print("det =", np.linalg.det(A)) print("손계산 ad - bc =", 3*2 - 1*1) print() print("→ 두 열 (3,1), (1,2) 이 만드는 평행사변형의 넓이가 5")
B = np.array([[2., 1.], [1., 2.]]) dA, dB = np.linalg.det(A), np.linalg.det(B) print(f"det(A) = {dA:.4f}") print(f"det(B) = {dB:.4f}") print(f"det(AB) = {np.linalg.det(A @ B):.4f} vs det(A)·det(B) = {dA*dB:.4f}") print(f"det(Aᵀ) = {np.linalg.det(A.T):.4f}") print(f"det(A⁻¹) = {np.linalg.det(np.linalg.inv(A)):.4f} vs 1/det(A) = {1/dA:.4f}") print(f"det(2A) = {np.linalg.det(2*A):.4f} vs 2²·det(A) = {4*dA:.4f}") print() print(f"det(A+B) = {np.linalg.det(A + B):.4f} vs det(A)+det(B) = {dA+dB:.4f}") print(" ↑ 덧셈은 성립하지 않는다!")
C = A.copy() print("원본 det =", np.linalg.det(C)) C[1] -= (C[1, 0] / C[0, 0]) * C[0] # 2행에서 1행의 배수를 뺀다 (3강) print("소거 후 =") print(C) print("det =", np.linalg.det(C), " ← 그대로") print() print("삼각행렬이 되었으니 대각 원소의 곱으로도 확인:") print(" ", C[0, 0], "×", round(C[1, 1], 4), "=", round(C[0, 0] * C[1, 1], 4)) print() print("→ 평행사변형을 '기울여도' 밑변과 높이가 그대로라 넓이가 안 변한다")
def 여인수_det(M): M = np.asarray(M, dtype=float) n = len(M) if n == 1: return M[0, 0] 총합 = 0.0 for j in range(n): 소행렬 = np.delete(np.delete(M, 0, axis=0), j, axis=1) # 0행과 j열 삭제 총합 += ((-1) ** j) * M[0, j] * 여인수_det(소행렬) return 총합 E = np.array([[ 2., 1., 1.], [ 4., -6., 0.], [-2., 7., 2.]]) print("여인수 전개 =", 여인수_det(E)) print("numpy =", round(np.linalg.det(E), 10))
b = np.array([5., -2., 9.]) def 크라머(A, b): detA = np.linalg.det(A) 해 = [] for i in range(A.shape[1]): B_i = A.copy() B_i[:, i] = b # i번째 열을 b 로 교체 해.append(np.linalg.det(B_i) / detA) return np.array(해) print("크라머 :", np.round(크라머(E, b), 6)) print("solve :", np.linalg.solve(E, b)) print() import time, math for n in [5, 10, 15, 20]: print(f"n={n:2d} 여인수 전개 {math.factorial(n):>22,}회 vs 소거법 {n**3:>8,}회")
특이성 판정에 det 를 쓰지 마세요 det 는 스케일에 극도로 민감합니다. 완벽히 멀쩡한 행렬도 크기를 조금 줄이면 det 가 0에 가까워지고, 거의 특이한 행렬도 키우면 det 가 커집니다.

대신 조건수(np.linalg.cond)나 랭크(matrix_rank)를 쓰세요. 아래에서 확인합니다.
# 완벽하게 멀쩡한 단위행렬을 100배 줄인다 좋은행렬 = 0.01 * np.eye(20) print("0.01·I(20×20)") print(" det =", np.linalg.det(좋은행렬), " ← 0 처럼 보인다!") print(" 조건수 =", np.linalg.cond(좋은행렬), " ← 1. 완벽한 행렬") print(" 랭크 =", np.linalg.matrix_rank(좋은행렬), "/ 20") print() # 거의 특이한 행렬 나쁜행렬 = np.array([[1., 1.], [1., 1 + 1e-12]]) print("[[1,1],[1,1+1e-12]]") print(" det =", np.linalg.det(나쁜행렬)) print(" 조건수 =", f"{np.linalg.cond(나쁜행렬):.3e}", " ← 사실상 특이") print() print("→ det 의 크기는 '특이한 정도' 를 말해주지 않는다. 조건수를 보세요.")

실무에서 행렬식
  • 변수 변환의 야코비안 — 적분에서 좌표를 바꿀 때 dx dy = |det J| du dv. 넓이 확대율이 그대로 쓰입니다.
  • 다변량 정규분포 — 확률밀도에 1/√det(Σ) 가 들어갑니다. 공분산 행렬의 "퍼진 부피" 로 정규화하는 거죠.
  • 컴퓨터 그래픽스 — 변환의 det 부호로 면의 앞뒤가 뒤집혔는지 판정합니다.
  • 고윳값 — 다음 강의의 특성방정식 det(A − λI) = 0 이 행렬식의 가장 중요한 쓰임새입니다.

12강 요약

  • |det| = 넓이(부피) 확대율. 단위 정사각형이 얼마나 커지는가.
  • 부호 = 배향. 음수면 거울 반사가 섞여 있습니다. 회전은 +1, 반사는 −1.
  • det = 0 ⟺ 납작해짐 ⟺ 특이행렬 ⟺ 역행렬 없음 ⟺ 열이 종속.
  • 공리는 셋 — det(I)=1, 행 교환 시 부호 반전, 행에 대해 선형.
  • det(AB) = det(A)det(B) 는 성립하지만 det(A+B) ≠ det(A)+det(B).
  • 소거해도 det 는 안 변합니다 — 그래서 실제 계산은 LU 로 O(n³).
  • 크라머 공식은 이론용입니다. 그리고 특이성 판정에는 조건수를 쓰세요.
