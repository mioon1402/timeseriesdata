벡터공간과 부분공간

지금까지는 벡터를 화살표로만 봤습니다. 이제 한 단계 추상화합니다. "더하기와 상수배가 되고, 그 결과가 밖으로 안 나가는 집합"이라면 무엇이든 벡터공간입니다. 숫자 배열뿐 아니라 다항식도, 함수도 벡터가 됩니다. 그리고 이 추상화 덕분에 신호 처리와 머신러닝이 같은 언어를 쓰게 됩니다.

0. 기초 다지기 — "닫혀 있다"가 무슨 뜻인가

앞으로 "덧셈에 대해 닫혀 있다"는 말이 계속 나옵니다. 어려운 말 같지만 뜻은 아주 단순합니다.

닫혀 있다 (closed) = 밖으로 안 나간다

집합 안에서 두 개를 골라 연산을 했을 때, 그 결과가 여전히 그 집합 안에 있으면 "닫혀 있다"고 합니다.

예 · 짝수는 덧셈에 대해 닫혀 있습니다 (짝수 + 짝수 = 짝수).
반례 · 홀수는 닫혀 있지 않습니다 (3 + 5 = 8, 짝수가 되어 밖으로 나감).

벡터공간에서 필요한 건 딱 두 연산에 대한 닫힘입니다 — 더하기와 상수배. 1강에서 배운 그 둘이죠.

1. 벡터공간의 정의와 뜻밖의 예시들

벡터공간(Vector Space) 은 덧셈과 스칼라배가 정의되어 있고, 그 결과가 항상 자기 안에 머무르며, 결합·분배법칙 같은 상식적인 규칙 8가지를 만족하는 집합입니다.

"벡터 = 화살표"라는 생각을 여기서 버려야 합니다 고등학교에서 배운 "크기와 방향을 가진 양"은 2·3차원에서만 통하는 설명입니다. 진짜 정의에는 화살표도, 크기도, 방향도 나오지 않습니다. "더하고 상수배할 수 있으면 벡터"입니다. 그래서 아래 것들이 전부 벡터가 됩니다.
벡터공간여기서 "벡터"는어디서 쓰나
ℝⁿ실수 n개의 목록가장 기본. 데이터 한 줄
모든 2×2 행렬행렬 하나 행렬도 더하고 상수배할 수 있죠 (4강)
차수 n 이하 다항식3x² − x + 5 같은 식 하나 곡선 피팅, 스플라인 (20강)
모든 연속 함수함수 하나 신호 처리. 푸리에 변환의 무대 (20강)
모든 무한 수열수열 하나시계열, 차분방정식 (14강)
추상화의 이득 · "함수도 벡터"라고 인정하는 순간, 함수를 다른 함수들의 선형결합으로 분해하는 게 자연스러워집니다. 그게 바로 푸리에 변환(신호 = 사인파들의 선형결합)이고, 테일러 급수(함수 = 다항식들의 선형결합)입니다. 선형대수를 배우면 이 둘이 같은 이야기로 보입니다.
단 하나 반드시 있어야 하는 것 — 영벡터
어떤 벡터공간이든 영벡터 0 을 반드시 포함해야 합니다. 0 × v = 0 인데 스칼라배에 닫혀 있어야 하니 피할 수 없죠. 다항식 공간에서는 "0 다항식", 함수 공간에서는 "항상 0인 함수"가 영벡터입니다.

2. 부분공간 — 조건은 딱 세 개

부분공간(Subspace) 은 큰 벡터공간 안에 들어 있으면서 그 자체로도 완전한 벡터공간인 부분집합입니다. 8가지 공리를 다 확인할 필요는 없고, 세 가지만 보면 됩니다.

부분공간 판정 — 이 셋만 확인
①  0 ∈ S  영벡터를 포함한다
②  u, v ∈ S ⟹ u + v ∈ S  덧셈에 닫혀 있다
③  u ∈ S, c 는 스칼라 ⟹ c u ∈ S  상수배에 닫혀 있다
  • ①은 사실③에서 c = 0 을 넣으면 나옵니다. 그래도 가장 빨리 반례를 찾는 방법이라 먼저 확인합니다
  • 직관"안에서 아무리 더하고 늘려도 밖으로 못 나가는 영역"
ℝ³ 안의 집합부분공간?이유
원점을 지나는 직선✓ 더해도 늘려도 그 직선 위
원점을 지나는 평면✓ 같은 이유
원점을 안 지나는 평면✗ 영벡터가 없음 (①에서 탈락)
1사분면 전체✗ c = −1 을 곱하면 3사분면으로 나감
{0} (원점 하나)✓ 가장 작은 부분공간. 영공간이 이럴 때가 있습니다(6강)
ℝ³ 전체✓ 가장 큰 부분공간. 자기 자신도 부분공간입니다

3. 원점을 지나지 않으면 왜 안 되나

아래에서 직선을 위아래로 움직여 보세요. 직선 위의 두 점(파랑, 초록)을 더한 결과가 빨간 점입니다.

점 u–
점 v–
u + v–
① 원점 포함?–
② 합이 직선 위?–
부분공간인가–
절편을 0으로 놓았을 때만 · 두 점을 더한 결과가 같은 직선 위에 남습니다. 조금이라도 띄우면 빨간 점이 직선에서 떨어져 나갑니다. "원점을 지나야 한다"는 조건은 미학적 취향이 아니라 계산의 결과입니다.
왜 그런가 — 한 줄 증명
직선을 y = 2x + b 라 합시다. 직선 위의 두 점 (x₁, 2x₁+b) 와 (x₂, 2x₂+b) 를 더하면 (x₁+x₂, 2(x₁+x₂) + 2b) 입니다. 절편이 b 가 아니라 2b 가 되어버렸죠. b = 0 일 때만 2b = b 라서 제자리에 남습니다.

4. Span은 항상 부분공간이다

1강에서 Span(가능한 모든 선형결합의 집합)을 배웠습니다. Span 은 어떤 벡터들로 만들든 항상 부분공간입니다. 증명이 놀랄 만큼 짧습니다.

정리 · Span(v₁,…,vk) 은 부분공간이다
① 모든 ci = 0 으로 두면 0 이 나옴 ✓
② (선형결합) + (선형결합) = 계수를 더한 또 하나의 선형결합 ✓
③ c × (선형결합) = 계수에 c 를 곱한 또 하나의 선형결합 ✓
  • 뜻벡터 몇 개를 아무렇게나 집어와도, 그들이 만드는 Span 은 자동으로 안전한 공간이 됩니다
왜 중요한가 · 6강에서 배울 열공간은 "행렬 A의 열들이 만드는 Span"으로 정의됩니다. 이 정리 덕분에 열공간은 증명 없이 자동으로 부분공간입니다. "행렬이 도달할 수 있는 모든 곳"이 깔끔한 공간을 이룬다는 뜻이죠.

# ② y = 2x + 1 — 원점을 지나지 않는 직선 u2 = np.array([0., 1.]) v2 = np.array([1., 3.]) print("y = 2x + 1 위의 두 점:", u2, v2) print("합 =", u2 + v2, " → 직선 위?", 직선위인가(u2 + v2, 절편=1)) print("영벡터 포함?", 직선위인가(np.zeros(2), 절편=1)) print() print("→ 세 조건 중 두 개가 깨졌다. 부분공간이 아니다.")

6. 실무: 데이터가 사는 진짜 차원

고차원 데이터는 사실 저차원에 산다
  • 이미지 — 사람 얼굴 사진은 784차원(28×28) 벡터지만, 실제 "사람 얼굴처럼 보이는" 이미지들은 그 안의 훨씬 얇은 부분공간에 몰려 있습니다. 무작위 784차원 벡터를 뽑으면 노이즈가 나오지 얼굴이 나오지 않죠.
  • 이것이 차원 축소의 근거입니다. 데이터가 실제로 사는 부분공간을 찾아 그쪽으로만 표현하면 정보를 거의 안 잃고 차원을 줄일 수 있습니다 → PCA(15강)와 SVD(16강).
  • 센서 데이터 — 온도계 10개를 한 방에 두면 10차원 데이터가 나오지만 실제 자유도는 1~2차원입니다(방 전체 온도 + 위치별 편차). 나머지는 중복이죠.
"부분공간"과 "부분집합"은 다릅니다 부분집합은 그냥 "안에 들어 있다"는 뜻이지만, 부분공간은 거기에 더해 세 조건을 만족해야 합니다. ℝ² 안의 원(circle)은 부분집합이지만 부분공간은 아닙니다 — 원 위의 두 점을 더하면 원 밖으로 나가니까요.

실무에서 "데이터가 저차원 구조에 있다"고 할 때는 엄밀히는 다양체(manifold)인 경우가 많습니다. 휘어 있어도 되니까 부분공간보다 넓은 개념이죠. 선형대수는 평평한 것만 다룹니다.

5강 요약

  • 닫혀 있다 = 연산 결과가 밖으로 안 나간다.
  • 벡터공간은 화살표가 아닙니다 — 행렬·다항식·함수·수열도 벡터입니다. 그래서 푸리에 변환과 회귀분석이 같은 언어를 씁니다.
  • 부분공간 조건 세 개: 영벡터 포함, 덧셈에 닫힘, 상수배에 닫힘.
  • 원점을 지나야 합니다. 조금이라도 띄우면 두 점을 더했을 때 밖으로 나갑니다.
  • Span 은 항상 부분공간입니다. 덕분에 열공간(6강)이 자동으로 안전합니다.
  • 고차원 데이터는 대개 훨씬 얇은 부분공간에 몰려 있습니다 — 차원 축소의 근거.
