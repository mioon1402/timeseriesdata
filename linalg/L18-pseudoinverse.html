의사역행렬과 추천 시스템

Ax = b 를 풀 때 세상은 세 가지뿐입니다. 해가 하나, 해가 없음, 해가 무한히 많음. 역행렬은 첫 번째 경우에만 답합니다. 그런데 나머지 두 경우에도 "가장 합리적인 답"을 돌려주는 연산자가 있습니다. 이름은 의사역행렬 A+ 입니다.

0. 기초 다지기 — 역행렬이 없다는 것

역행렬 A−1 은 "A 가 한 일을 정확히 되돌리는 행렬"입니다. A−1A = I 죠. 그런데 이게 존재하려면 조건이 꽤 빡빡합니다.

역행렬이 존재할 조건
① 정사각이어야 한다 (m = n)
② 랭크가 꽉 차야 한다 (det ≠ 0)
  • 현실데이터 행렬은 거의 항상 이 조건을 어깁니다. 측정이 미지수보다 많거나(세로로 긴 행렬), 적거나(가로로 긴 행렬), 열끼리 겹쳐서 랭크가 모자라거나
왜 되돌릴 수 없는가 — 두 가지 고장

① 뭉갰다 (정보 손실). A 가 평면을 직선으로 눌러버리면, 직선 위의 한 점이 어디서 왔는지 알 방법이 없습니다. 후보가 무한히 많죠. → 해가 무한히 많음

② 못 닿는다 (도달 불가). A 의 출력은 열공간 안에만 있습니다. b 가 열공간 밖에 있으면 Ax = b 를 만족하는 x 는 아예 없습니다. → 해가 없음

A+ 는 이 두 고장을 각각 "가장 짧은 답을 고른다", "가장 가까이 간다" 로 해결합니다.

1. 해가 무한히 많을 때 — 최소노름해

미지수 2개, 식 1개짜리 시스템을 봅시다. a x₁ + b x₂ = c. 이걸 만족하는 점 (x₁, x₂) 는 직선 전체입니다 — 무한히 많죠. 그중 어느 걸 고를 것인가?

해 직선 위에서 원점에 가장 가까운 점 = 최소노름해

A⁺b (최소노름해)–
그 길이 ‖x‖–
내가 고른 해–
그 길이 ‖x‖–
둘 다 식을 만족?–
A⁺b 가 짧은 만큼–
슬라이더를 어떻게 움직여도 파란 점(A⁺b)이 항상 제일 짧습니다. 그리고 파란 점은 언제나 원점에서 직선에 내린 수선의 발이고, A+b 는 항상 행공간 위에 있습니다 (여기서는 직선의 법선 방향 (a, b) 위).
최소노름해가 뜻하는 것
x+ = A+b =  해 중에서  ‖x‖ 가 가장 작은 것
  • 왜 짧은 게 좋은가"근거 없이 크게 주장하지 않는다"는 뜻입니다. 데이터가 강제하지 않는 성분은 0으로 둡니다. 머신러닝의 정규화와 정확히 같은 철학이죠
  • 기하학해집합은 특수해 + 영공간(7강)입니다. 그 평평한 집합에서 원점에 가장 가까운 점은 유일하고, 그건 영공간에 수직인 점 — 즉 행공간 위의 점입니다

2. SVD 로 A⁺ 를 만든다

16강에서 A = UΣVT 였습니다. "돌리고 → 늘이고 → 돌리기"였죠. 되돌리려면 순서를 뒤집고 각 단계를 뒤집으면 됩니다. 회전은 전치로 되돌리고, 늘림은 나눗셈으로 되돌리고.

의사역행렬의 정의
A+ = V Σ+ UT
  • Σ+Σ 를 전치한 뒤, 0이 아닌 σ 는 1/σ 로 바꾸고 0 은 그대로 0 으로 둡니다. 이 "0은 0으로 둔다"가 전부입니다
  • 왜 0을 0으로σ = 0 인 방향은 A 가 완전히 뭉갠 방향입니다. 정보가 없으니 되돌리려 하지 않고 그냥 포기합니다. 1/0 = ∞ 로 두면 잡음이 무한대로 증폭되죠
  • A 가 가역이면σ 가 전부 0이 아니므로 A+ = A−1 이 됩니다. 의사역행렬은 역행렬의 확장입니다
크기 확인 — 항상 A 를 뒤집은 모양
A 가 m×n  ⇒  A+ 는 n×m
  • 그래서A+b 는 항상 n차원 벡터 — 미지수 개수와 맞습니다. 계산이 언제나 성립하죠
A⁺A = I 가 아닙니다
역행렬처럼 보이지만 양쪽 모두 항등행렬이 되지는 않습니다. A+A 는 행공간으로의 정사영, AA+ 는 열공간으로의 정사영입니다. (둘 다 대칭이고 제곱하면 자기 자신 — 9강의 정사영 행렬이죠.) A 가 가역일 때만 두 정사영이 전체 공간이 되어 I 가 됩니다.

3. 해가 없을 때 — 최소제곱해

이번엔 반대입니다. 식이 미지수보다 많아서 정확한 해가 없습니다. 10강에서 풀었던 ATAx̂ = ATb 기억나시나요? 그 답이 바로 A+b 입니다.

A⁺ 는 두 경우를 한 공식으로 삼킨다
열이 독립 (세로로 긴 A)  ⇒  A+ = (ATA)−1AT  ← 최소제곱
행이 독립 (가로로 긴 A)  ⇒  A+ = AT(AAT)−1  ← 최소노름
둘 다 아니어도  ⇒  A+ = VΣ+UT  ← 언제나 통함
  • 그리고 동시에랭크가 모자라 최소제곱해조차 무한히 많을 때, A+b 는 그중에서도 가장 짧은 것을 줍니다. "가장 가까이 가되, 가장 겸손하게" 입니다
한 문장 정의

A+b 는 ‖Ax − b‖ 를 최소로 만드는 x 들 중에서, ‖x‖ 가 최소인 것입니다.

해가 있으면 첫 번째 조건이 0이 되어 정확한 해들 중 가장 짧은 것, 해가 유일하면 그냥 그 해가 됩니다. 세 경우가 하나의 문장으로 통합됩니다.

4. A⁺ 의 정의 — 무어-펜로즈 네 조건

사실 A+ 의 공식적인 정의는 SVD 가 아니라 아래 네 개의 등식입니다. 이걸 모두 만족하는 행렬은 정확히 하나뿐이라는 게 정리의 내용입니다.

무어-펜로즈 조건
① A A+ A = A   A 를 망가뜨리지 않는다
② A+ A A+ = A+   A⁺ 도 망가뜨리지 않는다
③ (A A+)T = A A+   열공간 정사영이다
④ (A+ A)T = A+ A   행공간 정사영이다
  • 읽는 법①② 는 "약한 의미의 역"이고, ③④ 가 "직교" 정사영이 되게 못 박습니다. ③④ 가 없으면 조건을 만족하는 행렬이 여러 개 생겨버립니다
  • 유일성네 조건을 모두 만족하는 행렬은 유일합니다. 그래서 "the" pseudoinverse 라고 부릅니다

5. 추천 시스템 — 빈칸 채우기

여기까지가 도구입니다. 이제 진짜 응용을 봅시다. 사용자 5명이 영화 4편에 매긴 별점 표가 있는데, 아직 안 본 칸이 있습니다. 그 칸을 어떻게 채울까요?

사용자 × 영화 별점표 — 랭크 k 로 복원하기

특이값 σ–
복원 오차–
A(1행4열) 예측–
D(4행2열) 예측–
E(5행3열) 예측–
담긴 에너지–
k=2 로 충분합니다. 특이값이 12.2, 8.3 다음에 1.4 로 뚝 떨어지죠. 설명에 필요한 축이 사실상 두 개라는 뜻입니다.

'취향 좌표 보기'를 켜보세요. 다섯 명이 두 무리로 갈라집니다 — A·B·E 와 C·D. 아무도 "장르"를 알려준 적이 없는데 SVD 가 별점만 보고 스스로 찾아냈습니다. 가로축(축1)은 별점을 얼마나 후하게 주는가, 세로축(축2)이 액션이냐 로맨스냐를 가릅니다.

그리고 빈칸이 저절로 채워집니다. 비슷한 취향의 다른 사람이 매긴 점수가, 랭크가 낮다는 제약을 통해 그 칸으로 흘러들어옵니다. 이게 협업 필터링입니다.

k=4 로 끝까지 올려보세요. 오차가 0% 가 되면서 빈칸 예측도 0점으로 돌아옵니다 — 원본을 그대로 복사했으니까요. 예측을 만들어내는 것은 "랭크를 낮춘다"는 제약 그 자체입니다.
부호는 아무 의미가 없습니다
ui 와 vi 의 부호를 둘 다 동시에 뒤집어도 σu vT 는 그대로입니다. 그래서 라이브러리마다, 실행할 때마다 축의 방향이 뒤집혀 나올 수 있습니다. 실제로 이 페이지의 그림과 아래 numpy 셀의 결과는 부호가 반대입니다. 의미가 있는 건 "누가 어느 쪽에 모이는가"이지 부호 자체가 아닙니다.
왜 채워지는가
R ≈ Uk Σk VkT = (사용자 취향) × (영화 성격)
  • Uk 의 i번째 행사용자 i 의 취향 좌표 (k개 숫자)
  • Vk 의 j번째 행영화 j 의 성격 좌표 (k개 숫자)
  • 예측 별점두 좌표의 내적. 취향과 성격이 같은 방향이면 높은 점수가 나옵니다(5강의 내적!)
  • 핵심5×4 = 20개 숫자를 5×2 + 2 + 2×4 = 20 → 사실상 몇 개의 축으로 설명한 것. 설명이 압축되면 빈칸이 예측됩니다
실제 추천 시스템은 이렇게 단순하지 않습니다
진짜 데이터는 99% 이상이 빈칸입니다. 여기처럼 0으로 채우고 SVD 를 돌리면 "안 본 영화 = 0점"으로 오해해 결과가 망가집니다. 실무에서는 관측된 칸에서만 오차를 재는 방식(행렬 완성, ALS, 암묵적 피드백)을 씁니다. 다만 "낮은 랭크로 설명한다"는 아이디어는 그대로입니다.

6. 극분해 — 회전 × 늘림

SVD 를 조금만 다르게 묶으면 또 하나의 유명한 분해가 나옵니다. 복소수를 reiθ 로 쓰는 것과 완전히 같은 발상이라 극분해라고 부릅니다.

극분해
A = UΣVT = (U VT)(V Σ VT) = Q S
  • Q = UVT직교행렬 (회전/반사). 모양은 안 바꾸고 방향만 바꿉니다
  • S = VΣVT대칭 · 양의 준정부호(15강). 방향은 안 바꾸고 늘리기만 합니다
  • 복소수 비유z = r·eiθ 에서 eiθ가 Q(회전), r이 S(크기)
  • 쓰임컴퓨터 그래픽스에서 찌그러진 변환에서 "순수한 회전"만 뽑아낼 때, 연속체 역학에서 변형을 회전과 변형률로 나눌 때

7. numpy 로 확인하기

여기까지 말한 것을 전부 코드로 확인합니다.

① 최소노름해 — 해가 무한히 많은 경우

import numpy as np np.set_printoptions(precision=4, suppress=True) A = np.array([[1., 2.]]) # 식 1개, 미지수 2개 b = np.array([3.]) x_plus = np.linalg.pinv(A) @ b x_alt = np.array([3., 0.]) # 눈으로 찾은 다른 해 print("A⁺b =", x_plus, " 길이 =", round(float(np.linalg.norm(x_plus)), 4)) print("다른 해 =", x_alt, " 길이 =", round(float(np.linalg.norm(x_alt)), 4)) print() print("둘 다 식을 만족하는가:", A @ x_plus, A @ x_alt) print("A⁺b 는 행공간 (1,2) 의 배수인가:", x_plus / np.array([1., 2.]))

② A⁺ 를 SVD 로 직접 조립해보기

import numpy as np np.set_printoptions(precision=4, suppress=True) A = np.array([[3., 1., 4.], [1., 0., 1.], [4., 1., 5.]]) # 3열 = 1열 + 2열 → 랭크 2 (특이!) U, s, Vt = np.linalg.svd(A) print("특이값 =", s) # 마지막이 사실상 0 print("랭크 =", np.linalg.matrix_rank(A)) # Σ⁺ : 0 이 아닌 σ 만 뒤집는다 tol = s.max() * 1e-10 s_plus = np.array([1/x if x > tol else 0.0 for x in s]) A_plus = Vt.T @ np.diag(s_plus) @ U.T print("\n수동 A⁺ 와 np.linalg.pinv 가 같은가:", np.allclose(A_plus, np.linalg.pinv(A))) print("A⁻¹ 는? →", end=" ") try: np.linalg.inv(A) except np.linalg.LinAlgError as e: print("불가능:", e)

③ A⁺A 와 AA⁺ 는 항등행렬이 아니라 '정사영'

import numpy as np np.set_printoptions(precision=4, suppress=True) A = np.array([[1., 0.], [1., 1.], [1., 2.], [1., 3.]]) # 4×2, 세로로 긴 행렬 Ap = np.linalg.pinv(A) print("A⁺A (2×2) =\n", Ap @ A) # ← 이건 I 가 맞다 (열이 독립) print("\nAA⁺ (4×4) =\n", A @ Ap) # ← 이건 I 가 아니다 print("\nAA⁺ 는 대칭인가:", np.allclose((A@Ap).T, A@Ap)) print("AA⁺ 를 제곱하면 자기 자신인가:", np.allclose((A@Ap) @ (A@Ap), A@Ap)) print("→ 대칭 + 멱등 = 정사영 행렬 (9강)") print("AA⁺ 의 대각합(=랭크) =", round(float(np.trace(A@Ap)), 4))

④ 최소제곱해와 완전히 같은 답

import numpy as np np.set_printoptions(precision=4, suppress=True) A = np.array([[1., 0.], [1., 1.], [1., 2.], [1., 3.]]) b = np.array([1., 3., 4., 6.]) # 한 직선 위에 없는 점 4개 x1 = np.linalg.pinv(A) @ b x2 = np.linalg.lstsq(A, b, rcond=None)[0] x3 = np.linalg.solve(A.T @ A, A.T @ b) # 정규방정식 (10강) print("pinv =", x1) print("lstsq =", x2) print("정규방정식 =", x3) print("셋이 같은가:", np.allclose(x1, x2) and np.allclose(x1, x3)) print("\n잔차 ‖Ax−b‖ =", round(float(np.linalg.norm(A@x1 - b)), 4), " ← 0 이 아니다(해가 없으니)")

⑤ 무어-펜로즈 네 조건 검증

import numpy as np rng = np.random.default_rng(0) A = rng.normal(size=(5, 3)) @ rng.normal(size=(3, 4)) # 5×4, 랭크 3 Ap = np.linalg.pinv(A) 조건 = { "① A A⁺ A = A": np.allclose(A @ Ap @ A, A), "② A⁺ A A⁺ = A⁺": np.allclose(Ap @ A @ Ap, Ap), "③ (A A⁺)ᵀ = A A⁺": np.allclose((A @ Ap).T, A @ Ap), "④ (A⁺ A)ᵀ = A⁺ A": np.allclose((Ap @ A).T, Ap @ A), } for k, v in 조건.items(): print(k, "→", v) print("\nA 의 랭크 =", np.linalg.matrix_rank(A), " (정사각도 아니고 꽉 차지도 않음)")

⑥ 추천 시스템 — 화면 위 별점표와 같은 데이터

import numpy as np np.set_printoptions(precision=2, suppress=True) 영화 = ["액션1", "액션2", "로맨스1", "로맨스2"] 사람 = list("ABCDE") R = np.array([[5., 4., 1., 0.], # 0 = 아직 안 봄 [4., 5., 1., 1.], [1., 1., 5., 4.], [1., 0., 4., 5.], [5., 5., 0., 1.]]) U, s, Vt = np.linalg.svd(R, full_matrices=False) print("특이값 =", s) print("→ 2개 다음에 뚝 떨어진다. 취향 축은 사실상 2개") k = 2 R2 = U[:, :k] @ np.diag(s[:k]) @ Vt[:k] print("\n랭크 2 복원:") print(R2) print("\n빈칸 예측:") for i, j in [(0, 3), (3, 1), (4, 2)]: print(f" {사람[i]} 의 '{영화[j]}' → {R2[i, j]:.2f} 점")

⑦ 취향 좌표를 직접 들여다보기

⑧ 극분해 A = QS

import numpy as np np.set_printoptions(precision=4, suppress=True) A = np.array([[2., 1.], [0., 3.]]) U, s, Vt = np.linalg.svd(A) Q = U @ Vt # 회전(또는 반사) S = Vt.T @ np.diag(s) @ Vt # 대칭 · 양의 정부호 print("Q =\n", Q) print("S =\n", S) print() print("QS = A 인가:", np.allclose(Q @ S, A)) print("Q 가 직교인가:", np.allclose(Q.T @ Q, np.eye(2))) print("det Q =", round(float(np.linalg.det(Q)), 4), " → +1 이면 순수 회전") print("S 가 대칭인가:", np.allclose(S, S.T)) print("S 의 고윳값 =", np.linalg.eigvalsh(S), " → 전부 양수 = 양의 정부호") print("S 의 고윳값 = A 의 특이값:", np.allclose(np.sort(np.linalg.eigvalsh(S)), np.sort(s)))

⑨ 왜 1/0 을 0 으로 두는가 — 잡음 증폭 실험

import numpy as np rng = np.random.default_rng(7) U0, _ = np.linalg.qr(rng.normal(size=(6, 6))) V0, _ = np.linalg.qr(rng.normal(size=(6, 6))) s = np.array([10., 5., 2., 0.5, 1e-6, 1e-9]) # 뒤 두 개가 거의 0 A = U0 @ np.diag(s) @ V0.T b = A @ np.ones(6) b_noisy = b + rng.normal(scale=1e-4, size=6) # 아주 작은 잡음 x_inv = np.linalg.inv(A) @ b_noisy # 전부 뒤집는다 x_pinv = np.linalg.pinv(A, rcond=1e-3) @ b_noisy # 작은 σ 는 버린다 print("정답 x = 전부 1") print("inv 로 푼 x 의 최대 크기 =", f"{np.abs(x_inv).max():.3e}") print("pinv 로 푼 x =", np.round(x_pinv, 3)) print() print("→ 작은 σ 를 뒤집으면 1e-4 짜리 잡음이", f"{np.abs(x_inv).max():.0e}", "배로 폭발한다.") print(" 버리는 편이 훨씬 정확하다. 이것이 A⁺ 의 rcond 이다.")

import numpy as np np.set_printoptions(precision=4, suppress=True) # 문제 1 — 손 풀이: x = t(2,4) 로 두면 2(2t)+4(4t)=20t=10 → t=0.5 A1 = np.array([[2., 4.]]) print("문제 1: 손으로 t=1/2 →", 0.5 * np.array([2., 4.])) print(" pinv →", np.linalg.pinv(A1) @ np.array([10.])) # 문제 2 — 영행렬의 의사역행렬은 영행렬 (모든 σ 가 0 → 전부 0 으로 둔다) O = np.zeros((3, 2)) print("\n문제 2: O⁺ =\n", np.linalg.pinv(O), " (모양은 2×3 으로 뒤집힘)") print(" 네 조건 만족:", all([np.allclose(O@np.linalg.pinv(O)@O, O), np.allclose(np.linalg.pinv(O)@O@np.linalg.pinv(O), np.linalg.pinv(O))])) # 문제 3 — k=1 이면 '취향 축 하나' 뿐, k=4 면 원본을 그대로 복원(빈칸=0) R = np.array([[5., 4., 1., 0.], [4., 5., 1., 1.], [1., 1., 5., 4.], [1., 0., 4., 5.], [5., 5., 0., 1.]]) U, s, Vt = np.linalg.svd(R, full_matrices=False) for k in (1, 2, 4): Rk = U[:, :k] @ np.diag(s[:k]) @ Vt[:k] print(f"\n문제 3: k={k} 오차 {np.linalg.norm(R-Rk)/np.linalg.norm(R):.1%}" f" A의 '로맨스2' 예측 {Rk[0,3]:.2f}") print("\n→ k=1: 축이 하나뿐이라 '액션파/로맨스파' 구분만 남고 세부가 사라진다.") print("→ k=4: 랭크가 꽉 차 원본을 그대로 복원 → 빈칸이 0 인 채로 돌아온다.") print(" 즉 예측을 만드는 것은 '랭크를 낮춘다'는 제약 그 자체다.")
실무에서 의사역행렬
  • 회귀 — sklearn.linear_model.LinearRegression 내부가 scipy.linalg.lstsq, 즉 SVD 기반입니다. 열이 겹쳐도(다중공선성) 터지지 않는 이유죠.
  • 로봇 역기구학 — 관절이 필요보다 많을 때(여유 자유도) 가장 적게 움직이는 관절 조합을 A⁺ 로 고릅니다.
  • 추천 · 행렬 완성 — 저랭크 가정으로 빈칸을 메웁니다(17강 + 이번 강).
  • 주의 — rcond — np.linalg.pinv(A, rcond=…) 의 문턱값이 결과를 크게 바꿉니다. 너무 작으면 잡음 폭발, 너무 크면 진짜 신호까지 버립니다. ⑨번 셀이 그 실험입니다.
  • 주의 — 크기 — pinv 는 밀집 SVD 를 돌립니다. 수만 차원이면 lsqr 같은 반복법으로 가야 합니다.

18강 요약

  • A+ = VΣ+UT. 0 이 아닌 σ 만 뒤집고, 0 은 0 으로 둡니다.
  • A+b 는 ‖Ax−b‖ 최소 → 그중 ‖x‖ 최소. 세 경우를 한 문장으로 통합합니다.
  • 해가 무한할 때는 최소노름해(원점에서 내린 수선의 발), 해가 없을 때는 최소제곱해(10강).
  • A+A 는 행공간 정사영, AA+ 는 열공간 정사영. 항등행렬이 아닙니다.
  • 무어-펜로즈 네 조건을 만족하는 행렬은 유일합니다.
  • 극분해 A = QS — 회전 × 늘림. 복소수의 reiθ.
  • 추천 시스템은 저랭크 제약으로 빈칸을 예측합니다. 사용자 좌표 · 아이템 좌표의 내적이 예측 별점이죠.
