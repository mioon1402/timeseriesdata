선형변환의 기하학

지금까지 행렬을 숫자표로 다뤘습니다. 이번 강의는 그 숫자들이 공간에 무슨 짓을 하는지 눈으로 봅니다. 회전, 반사, 납작하게 누르기, 비스듬히 밀기 — 모든 행렬은 이 몇 가지의 조합입니다. 그리고 보는 좌표계를 바꾸면 같은 변환이 훨씬 단순해집니다.

0. 기초 다지기 — '선형'이 뜻하는 것

선형변환은 그냥 "직선을 직선으로 보내는 변환"입니다. 정확히는 두 가지 규칙만 지키면 됩니다.

선형의 두 조건
T(u + v) = T(u) + T(v)
T(c·u) = c·T(u)
  • 그림으로① 격자선이 여전히 직선이고, ② 평행이던 선은 계속 평행이고, ③ 원점이 그대로입니다. 이 세 개가 지켜지면 선형입니다
  • 아닌 예"모든 점을 오른쪽으로 3 옮기기"는 선형이 아닙니다 — 원점이 움직이니까요. 이런 건 아핀변환이라 부르고, 7절의 동차좌표로 다룹니다
  • 왜 중요한가선형이면 기저벡터가 어디로 가는지만 알면 나머지 모든 점의 행선지가 자동으로 정해집니다. 무한한 점을 숫자 4개로 다 적을 수 있죠

1. 행렬의 열 = 기저벡터가 가는 곳

이게 이 강의에서 가장 중요한 한 문장입니다. 행렬을 볼 때마다 이걸 떠올리면 됩니다.

열을 읽는 법
A 10 = A 의 1열     A 01 = A 의 2열
  • 뜻1열은 e₁=(1,0) 이 도착하는 자리, 2열은 e₂=(0,1) 이 도착하는 자리입니다
  • 나머지 점은(x, y) = x e₁ + y e₂ 이므로 A(x,y) = x·(1열) + y·(2열). 도착한 두 벡터의 선형결합일 뿐입니다(4강)
  • 실전 요령행렬을 보면 세로로 잘라 두 벡터로 읽으세요. 그 두 벡터를 그리면 그림이 바로 보입니다

3. 여섯 가지 기본 변환

회전 (각도 θ)
R = cos θ−sin θ sin θcos θ   det = +1
  • 외우는 법1열은 e₁ 이 가는 곳 — 단위원 위에서 각도 θ 인 점, 즉 (cos θ, sin θ). 2열은 거기서 90° 더 돈 (−sin θ, cos θ)
  • 고윳값실수 고유벡터가 없습니다(θ ≠ 0, 180°). 방향이 안 변하는 벡터가 없으니 당연하죠. λ 는 복소수로 나옵니다(20강)
반사 (x축 기준)
F = 10 0−1   det = −1,   λ = 1, −1
  • 고유벡터축 위 방향은 그대로(λ=1), 축에 수직인 방향은 뒤집힘(λ=−1)
  • 특징두 번 반사하면 제자리 — F² = I. 자기 자신이 역행렬입니다
투영 (x축 위로)
P = 10 00   det = 0,   λ = 1, 0
  • 정보 손실평면 전체가 직선 하나로 뭉개집니다. 되돌릴 수 없습니다 — 9강의 정사영, 18강의 A⁺ 이야기죠
  • 멱등P² = P. 이미 그림자인 것에 다시 그림자를 만들어도 그대로입니다
전단 (밀기)
S = 1k 01   det = +1,   λ = 1, 1
  • 그림책을 옆으로 민 모양. 높이는 그대로, 위쪽만 옆으로 밀립니다. 그래서 넓이가 안 변합니다(det=1)
  • 대각화 불가고윳값이 1 하나뿐인데 고유벡터도 x축 방향 하나뿐입니다. 기저를 만들 수 없어 대각화가 안 되는 대표 사례(14강)
확대 / 찌그러뜨리기
2002  모든 방향 2배, det=4     2000.5  가로 2배·세로 반, det=1
  • 눈여겨볼 점오른쪽은 넓이가 그대로인데도 모양이 완전히 달라집니다. det=1 이 "아무 일 없음"을 뜻하지 않습니다

4. 행렬식의 부호가 말해주는 것

det A 를 읽는 법
|det A|  =  넓이가 몇 배가 되는가
det A > 0  ⇒  방향 유지 (시계 반대 → 시계 반대)
det A < 0  ⇒  방향 뒤집힘 (거울에 비친 것처럼)
det A = 0  ⇒  차원 붕괴 (평면 → 직선 또는 점)
  • 뒤집힘이란오른손을 아무리 회전시켜도 왼손이 되지 않습니다. 거울에 비춰야 되죠. det < 0 이 정확히 그 "거울에 비추기"가 섞였다는 뜻입니다
  • 확인위 도구에서 반사를 누르고 주황 도형의 글자가 뒤집히는지 보세요

5. 합성 — 곱하기의 순서

변환을 연달아 하면 행렬을 곱하면 됩니다. 다만 읽는 방향에 주의해야 합니다.

오른쪽부터 적용된다
(BA)x = B(Ax)   ← A 를 먼저, 그 다음 B
  • 순서가 바뀌면결과가 달라집니다 — AB ≠ BA. "돌린 뒤 밀기"와 "민 뒤 돌리기"는 다른 그림입니다
  • 회전끼리는예외적으로 순서가 상관없습니다. R30R45 = R75 = R45R30 — 각도가 그냥 더해지니까요
  • 재밌는 사실반사 두 번 = 회전입니다. det 가 (−1)×(−1) = +1 이 되죠. 아래 ⑤번 셀에서 확인합니다

6. 기저를 바꾸면 행렬이 단순해진다

같은 변환이라도 어떤 좌표계에서 보느냐에 따라 행렬이 달라집니다. 그리고 잘 고르면 놀랄 만큼 단순해집니다.

같은 변환, 두 좌표계 — 왼쪽은 표준 기저, 오른쪽은 고유벡터 기저

오른쪽 그림에서는 격자가 "휘지" 않습니다. 두 축을 따로따로 늘였다 줄였다 할 뿐이죠. 같은 변환인데 보는 좌표계만 바꿨더니 이렇게 단순해집니다.

이게 대각화(14강)가 하는 일의 전부입니다. "어려운 문제는 좌표계를 잘못 골라서 어려운 것" — 선형대수의 가장 큰 교훈입니다.
기저 변환 공식
A새 기저 = B−1 A B
  • B새 기저벡터를 열로 세운 행렬. "새 좌표 → 표준 좌표" 번역기입니다
  • 읽는 순서오른쪽부터 — B(새 좌표를 표준으로 번역) → A(표준에서 변환) → B−1(다시 새 좌표로 번역)
  • 닮음이렇게 얻은 행렬을 닮은 행렬이라 하고, 고윳값·행렬식·대각합이 전부 같습니다. 본질은 같고 옷만 갈아입은 셈이죠
  • B 를 고유벡터로 채우면결과가 대각행렬 Λ 가 됩니다. 그게 A = BΛB−1 입니다

7. 3차원과 동차좌표

2차원에서 본 이야기가 3차원에서도 그대로입니다. 다만 회전축이 생기죠. 그리고 게임·그래픽스에서 쓰는 한 가지 트릭을 소개합니다.

3차원 회전 — z축 기준
cos θ−sin θ0 sin θcos θ0 001
  • 읽기왼쪽 위 2×2 는 xy평면에서의 회전, 오른쪽 아래 1 은 z는 건드리지 않음
  • 회전축3차원 회전은 항상 λ=1 인 실수 고유벡터를 하나 갖습니다. 그게 바로 회전축입니다 (오일러 정리)
동차좌표 — 이동을 행렬에 넣는 트릭

"오른쪽으로 3, 위로 2 옮기기"는 선형이 아닙니다(원점이 움직이니까). 그런데 차원을 하나 늘려 점 (x, y) 를 (x, y, 1) 로 적으면?

103 012 001 xy1 = x+3y+21

이동이 행렬 곱셈이 되었습니다. 덕분에 회전·확대·이동을 전부 하나의 4×4 행렬로 합쳐 GPU 에 한 번만 넘길 수 있습니다. 모든 3D 게임 엔진이 이렇게 동작합니다.

8. numpy 로 확인하기

① 여섯 가지 변환의 지문 — det 와 λ

import numpy as np np.set_printoptions(precision=3, suppress=True) θ = np.pi / 6 # 30도 변환 = { "회전 30°": np.array([[np.cos(θ), -np.sin(θ)], [np.sin(θ), np.cos(θ)]]), "반사 x축": np.array([[1., 0.], [0., -1.]]), "투영 x축": np.array([[1., 0.], [0., 0.]]), "전단 k=1": np.array([[1., 1.], [0., 1.]]), "확대 2배": np.array([[2., 0.], [0., 2.]]), "찌그리기": np.array([[2., 0.], [0., 0.5]]), } for 이름, A in 변환.items(): λ = np.linalg.eigvals(A) d = np.linalg.det(A) 복소 = "" if np.allclose(λ.imag, 0) else " ← 실수 고유벡터 없음" print(f"{이름:9s} det={d:+6.3f} λ={np.round(λ, 3)}{복소}")

② 행렬의 열 = 기저벡터의 행선지

import numpy as np A = np.array([[3., 1.], [1., 2.]]) e1, e2 = np.array([1., 0.]), np.array([0., 1.]) print("A e₁ =", A @ e1, " ← A 의 1열") print("A e₂ =", A @ e2, " ← A 의 2열") print() x = np.array([2., 3.]) print("A x =", A @ x) print("2·1열+3·2열 =", 2 * A[:, 0] + 3 * A[:, 1], " ← 같다") print("\n→ 기저벡터의 행선지만 알면 모든 점의 행선지가 정해진다.")

③ det 의 부호 = 방향이 뒤집혔는가

import numpy as np def 방향(A): d = np.linalg.det(A) if abs(d) < 1e-12: return "붕괴 (차원이 줄었다)" return "유지" if d > 0 else "뒤집힘 (거울상)" for 이름, A in [("회전 90°", np.array([[0., -1.], [1., 0.]])), ("반사", np.array([[0., 1.], [1., 0.]])), ("투영", np.array([[1., 0.], [0., 0.]])), ("확대 3배", np.array([[3., 0.], [0., 3.]]))]: print(f"{이름:8s} det={np.linalg.det(A):+.2f} 넓이 {abs(np.linalg.det(A)):.2f}배 방향 {방향(A)}")

④ 합성의 순서는 중요하다

import numpy as np np.set_printoptions(precision=3, suppress=True) def 회전(도): t = np.radians(도) return np.array([[np.cos(t), -np.sin(t)], [np.sin(t), np.cos(t)]]) S = np.array([[1., 1.], [0., 1.]]) # 전단 R = 회전(30) print("R S (전단 먼저, 그 다음 회전) =\n", R @ S) print("S R (회전 먼저, 그 다음 전단) =\n", S @ R) print("\n같은가:", np.allclose(R @ S, S @ R)) print("\n하지만 회전끼리는 순서가 상관없다:") print(" R30 R45 == R75 :", np.allclose(회전(30) @ 회전(45), 회전(75))) print(" R45 R30 == R75 :", np.allclose(회전(45) @ 회전(30), 회전(75)))

⑤ 반사 두 번 = 회전

import numpy as np np.set_printoptions(precision=3, suppress=True) def 반사(도): # 원점을 지나고 각도 도° 인 직선에 대한 반사 t = np.radians(2 * 도) return np.array([[np.cos(t), np.sin(t)], [np.sin(t), -np.cos(t)]]) F1, F2 = 반사(0), 반사(30) print("det F1 =", np.linalg.det(F1), " det F2 =", np.linalg.det(F2)) print("\nF2 F1 =\n", F2 @ F1) print("det =", round(float(np.linalg.det(F2 @ F1)), 4), " → +1, 회전이 되었다") t = np.radians(60) R60 = np.array([[np.cos(t), -np.sin(t)], [np.sin(t), np.cos(t)]]) print("\nR60 과 같은가:", np.allclose(F2 @ F1, R60)) print("→ 두 거울의 각도가 30° 면 회전각은 그 두 배인 60°.")

⑥ 기저를 바꾸면 대각행렬이 된다

import numpy as np np.set_printoptions(precision=4, suppress=True) A = np.array([[2., 1.], [1., 2.]]) λ, B = np.linalg.eig(A) # B 의 열이 고유벡터 print("고윳값 =", λ) print("고유벡터(열) =\n", B) D = np.linalg.inv(B) @ A @ B print("\nB⁻¹AB =\n", D, " ← 완벽한 대각행렬") print("\n닮은 행렬은 무엇이 같은가:") print(" 대각합 A:", round(float(np.trace(A)), 4), " D:", round(float(np.trace(D)), 4)) print(" 행렬식 A:", round(float(np.linalg.det(A)), 4), " D:", round(float(np.linalg.det(D)), 4)) print(" 고윳값 A:", np.sort(np.linalg.eigvals(A)), " D:", np.sort(np.linalg.eigvals(D)))

⑦ 하우스홀더 반사 — 임의 방향으로 뒤집기

import numpy as np np.set_printoptions(precision=4, suppress=True) u = np.array([1., 2.]) u = u / np.linalg.norm(u) # 반사 '거울면의 법선' H = np.eye(2) - 2 * np.outer(u, u) print("H =\n", H) print("det H =", round(float(np.linalg.det(H)), 4), " → −1, 반사가 맞다") print("H² = I 인가:", np.allclose(H @ H, np.eye(2))) print() print("법선 방향 u 는 뒤집힌다: H u =", H @ u, " = −u:", np.allclose(H @ u, -u)) w = np.array([-2., 1.]) / np.sqrt(5) # u 에 수직 print("거울면 위 w 는 그대로: H w =", H @ w, " = w:", np.allclose(H @ w, w)) print("\n→ 11강 QR 분해에서 쓴 그 반사가 이것이다.")

⑧ 동차좌표 — 이동까지 행렬 하나로

import numpy as np np.set_printoptions(precision=3, suppress=True) def 이동(dx, dy): return np.array([[1., 0., dx], [0., 1., dy], [0., 0., 1.]]) def 회전(도): t = np.radians(도) return np.array([[np.cos(t), -np.sin(t), 0.], [np.sin(t), np.cos(t), 0.], [0., 0., 1.]]) 점 = np.array([1., 0., 1.]) # (1, 0) 을 동차좌표로 print("이동만:", (이동(3, 2) @ 점)[:2]) print() # '원점에서 90도 돌린 뒤 (3,2) 만큼 이동' — 하나의 행렬로 합친다 합성 = 이동(3, 2) @ 회전(90) print("합성 행렬 =\n", 합성) print("적용 결과:", (합성 @ 점)[:2]) print() print("순서를 바꾸면 (먼저 이동, 그 다음 회전):", (회전(90) @ 이동(3, 2) @ 점)[:2]) print("→ 결과가 다르다. 그래픽스에서 순서를 틀리는 것이 가장 흔한 버그다.")

⑨ 3차원 회전의 회전축 찾기

import numpy as np np.set_printoptions(precision=4, suppress=True) def 회전x(도): t = np.radians(도) return np.array([[1., 0., 0.], [0., np.cos(t), -np.sin(t)], [0., np.sin(t), np.cos(t)]]) def 회전z(도): t = np.radians(도) return np.array([[np.cos(t), -np.sin(t), 0.], [np.sin(t), np.cos(t), 0.], [0., 0., 1.]]) R = 회전z(40) @ 회전x(25) # 두 회전을 섞으면? 여전히 회전이다 print("det R =", round(float(np.linalg.det(R)), 6), " (회전이면 +1)") print("RᵀR = I 인가:", np.allclose(R.T @ R, np.eye(3))) λ, V = np.linalg.eig(R) i = int(np.argmin(np.abs(λ - 1))) # λ = 1 인 고유벡터 = 회전축 축 = np.real(V[:, i]); 축 = 축 / np.linalg.norm(축) print("\n고윳값 =", np.round(λ, 4)) print("회전축 =", np.round(축, 4)) print("정말 안 움직이는가:", np.allclose(R @ 축, 축))

import numpy as np np.set_printoptions(precision=3, suppress=True) # 문제 1 — 1열 (0,1): e₁ 이 위로 간다. 2열 (−1,0): e₂ 가 왼쪽으로. # → 반시계 90° 회전 A1 = np.array([[0., -1.], [1., 0.]]) print("문제 1: A e₁ =", A1 @ np.array([1., 0.]), " A e₂ =", A1 @ np.array([0., 1.])) print(" → 반시계 90° 회전. det =", round(float(np.linalg.det(A1)), 3), " λ =", np.round(np.linalg.eigvals(A1), 3), "(복소수 = 실수 고유벡터 없음)") print(" 네 번 적용하면 제자리:", np.allclose(np.linalg.matrix_power(A1, 4), np.eye(2))) # 문제 2 — 넓이 2배 + 방향 뒤집기 A2 = np.array([[2., 0.], [0., -1.]]) print("\n문제 2: det =", np.linalg.det(A2), "→ ① 넓이가 2배가 되고 ② 방향이 뒤집힌다(거울상).") # 문제 3 — 전단은 100번 해도 전단. k 만 100 이 된다 S = np.array([[1., 1.], [0., 1.]]) S100 = np.linalg.matrix_power(S, 100) print("\n문제 3: S¹⁰⁰ =\n", S100) print(" det =", round(float(np.linalg.det(S100)), 6), " ← 여전히 1, 넓이는 그대로") print(" 고윳값 =", np.linalg.eigvals(S100), " ← 여전히 1, 1") print(" → 전단의 거듭제곱은 전단. k 만 100 배가 된다.") print(" 대각화가 안 되는 행렬이라 λ 만 봐서는 이 폭주를 알 수 없다(14강).")
실무에서 선형변환
  • 그래픽스 · 게임 — 모델 → 월드 → 카메라 → 화면. 네 번의 좌표계 변환을 4×4 행렬 하나로 합쳐 GPU 에 넘깁니다.
  • 이미지 처리 — 회전·기울기 보정·원근 교정이 전부 행렬 하나입니다 (cv2.warpAffine, cv2.warpPerspective).
  • 로보틱스 — 관절마다 동차변환 행렬을 곱해 손끝 위치를 계산합니다.
  • 데이터 분석 — 표준화·백색화·PCA 가 전부 좌표계 갈아타기입니다(20강).
  • 주의 — 부동소수점 — 회전을 수천 번 곱하면 직교성이 조금씩 무너집니다. 주기적으로 QR 이나 SVD 로 다시 직교화해야 합니다.

19강 요약

  • 행렬의 열 = 기저벡터가 도착하는 자리. 이 한 문장이면 그림이 보입니다.
  • 선형변환은 격자를 직선으로 유지하고, 평행을 유지하고, 원점을 고정합니다.
  • 회전(det=+1, 실수 λ 없음), 반사(det=−1, λ=±1), 투영(det=0, λ=1,0), 전단(det=+1, λ=1,1 · 대각화 불가).
  • |det| = 넓이 배율, 부호 = 방향 유지/뒤집힘, 0 = 붕괴.
  • 합성은 오른쪽부터. AB ≠ BA 가 기본입니다.
  • 기저 변환 B−1AB — 고유벡터를 기저로 삼으면 대각행렬이 됩니다.
  • 동차좌표로 차원을 하나 늘리면 이동까지 행렬 곱셈이 됩니다.
