최소제곱법과 회귀

현실 데이터로 만든 방정식은 거의 항상 해가 없습니다. 점 100개를 지나는 직선 같은 건 존재하지 않으니까요. 그런데 양변에 AT 를 곱하는 단 한 번의 조작으로 풀리는 방정식이 됩니다. 그리고 그 답이 바로 선형회귀입니다.

0. 기초 다지기 — 왜 해가 없는가

점 네 개 (0,1), (1,2), (2,2), (3,5) 를 전부 지나는 직선 y = ct + d 를 찾는다고 합시다.

c·0 + d = 1
c·1 + d = 2
c·2 + d = 2
c·3 + d = 5

미지수는 2개(c, d)인데 식은 4개입니다. 이런 걸 과결정계(Overdetermined system) 라고 합니다. 1·2번 식만 보면 c=1, d=1 인데, 3번 식에 넣으면 2+1=3 ≠ 2 로 어긋납니다. 해가 없습니다.

행렬로 쓰면
01 11 21 31 cd  =  1225
  • A4×2 — 키가 큰 행렬. 열이 2개뿐이니 열공간은 4차원 공간 속의 2차원 평면입니다
  • b4차원 벡터. 그 얇은 평면 위에 있을 확률은 사실상 0 — 그래서 해가 없습니다(6강)
실무의 기본 상황 · 데이터가 많을수록(m 이 클수록) 해는 더 확실히 없어집니다. 그러니 "해를 구한다"가 아니라 "가장 덜 틀리는 값을 고른다" 로 문제를 바꿔야 합니다. 그게 최소제곱법입니다.

1. "가장 가까운" 을 정의하기

b 에 도달할 수 없다면, 도달할 수 있는 곳 중 가장 가까운 데까지 갑시다. "가장 가깝다"는 오차 벡터의 길이가 최소라는 뜻입니다.

최소제곱 문제
‖ e ‖2 = ‖ b − A x ‖2  를 최소로 만드는 x̂ 를 찾아라
  • ‖e‖²= 각 오차를 제곱해서 더한 것. 그래서 최소제곱(least squares)입니다
  • 9강과 같음도달 가능한 곳 = 열공간. 가장 가까운 점 = b 를 열공간으로 투영한 것. 이미 푼 문제입니다
한 줄 요약 · 풀 수 없는 Ax = b 대신 풀 수 있는 Ax̂ = p 를 풉니다. 여기서 p 는 b 의 그림자(9강)입니다.

2. 정규방정식

정규방정식 (Normal Equation)
ATA x̂ = ATb
  • 유도오차가 열공간과 직교 ⟹ AT(b − Ax̂) = 0 ⟹ 정리하면 위 식 (9강과 동일)
  • 크기ATA 는 n×n 정사각·대칭입니다. 4×2 였던 문제가 2×2 로 줄었습니다
  • 가역 조건A의 열이 선형독립이면 ATA 는 가역입니다. 실무에서 이게 깨지는 경우가 §6
왜 AT 를 곱하니 풀리는가
마법이 아닙니다. AT 를 곱하는 것은 "오차의 열공간 성분만 보겠다"는 뜻입니다.

b 를 p(열공간) + e(좌영공간) 로 쪼개면(9강), ATb = ATp + ATe = ATp + 0 — 도달 불가능한 성분 e 가 저절로 지워집니다. 남은 건 원래부터 풀 수 있던 문제죠.

잔차의 합이 항상 0 · 이건 우연이 아닙니다. ATe = 0 인데 A의 둘째 열이 전부 1(절편 항)이므로 그 성분이 Σeᵢ = 0 을 뜻합니다. 절편을 넣은 회귀에서는 잔차 평균이 반드시 0 인 이유입니다.
[이상치 하나 던지기] 를 눌러보세요 점 하나가 멀리 떨어지면 직선 전체가 그쪽으로 끌려갑니다. 오차를 제곱하기 때문에 멀리 있는 점이 제곱만큼 큰 발언권을 갖거든요.

최소제곱법의 가장 큰 약점입니다. 대안은 절댓값 오차(L1 회귀), Huber 손실, 또는 이상치 제거 후 재적합입니다.

4. 왜 하필 제곱인가

절댓값을 쓰면 이상치에 강한데, 왜 통계와 공학은 제곱을 택했을까요? 이유가 셋 있습니다.

이유설명
기하가 맞아떨어진다 제곱합 = 유클리드 거리의 제곱. 그래서 "가장 가까운 = 수직 투영"이 성립합니다. 절댓값을 쓰면 이 아름다운 그림이 깨집니다.
미분이 된다 제곱은 매끄러워 딱 떨어지는 공식이 나옵니다. 절댓값은 0에서 꺾여 반복 알고리즘이 필요합니다.
답이 하나다 열이 독립이면 최소점이 유일합니다. 절댓값은 답이 여러 개일 수 있습니다.
통계적 근거도 있습니다
오차가 정규분포를 따른다고 가정하면, 최대가능도추정(MLE) 이 정확히 최소제곱법과 같아집니다. "제곱을 쓴다"는 곧 "오차가 정규분포일 것이다" 라고 가정하는 것과 같죠.

그래서 오차가 두꺼운 꼬리를 가진 데이터(금융 수익률 등)에서는 최소제곱법이 잘 안 맞습니다. 가정이 틀렸으니까요.

5. numpy 로 확인하기

import numpy as np np.set_printoptions(precision=4, suppress=True) t = np.array([0., 1., 2., 3.]) y = np.array([1., 2., 2., 5.]) A = np.column_stack([t, np.ones_like(t)]) # [t | 1] — 기울기와 절편 print("A =") print(A) print("b =", y) print() print("rank(A) =", np.linalg.matrix_rank(A)) print("rank([A|b]) =", np.linalg.matrix_rank(np.column_stack([A, y]))) print("→ 랭크가 다르다 = b 가 열공간 밖 = 해가 없다 (6강)")
AtA = A.T @ A Atb = A.T @ y print("AᵀA =") print(AtA, " ← 2×2 로 줄었고 대칭이다") print("\nAᵀb =", Atb) print() x_hat = np.linalg.solve(AtA, Atb) # inv 대신 solve (4강) print("x̂ = (기울기 c, 절편 d) =", x_hat) print(f"→ 직선: y = {x_hat[0]:.2f} t + {x_hat[1]:.2f}")
ls, 잔차합, 랭크, 특이값 = np.linalg.lstsq(A, y, rcond=None) print("lstsq :", ls) print("polyfit :", np.polyfit(t, y, 1)) print("직접 :", x_hat) print() print("전부 같은가:", np.allclose(ls, x_hat) and np.allclose(np.polyfit(t, y, 1), x_hat)) print() print("※ 실무에서는 lstsq 를 쓰세요. 정규방정식을 직접 풀면") print(" AᵀA 를 만드는 과정에서 조건수가 제곱이 되어 오차가 커집니다 (§6).")
p = A @ x_hat # 예측값 = 그림자 e = y - p # 잔차 = 오차 print("예측 p =", p) print("잔차 e =", e) print() print("Aᵀe =", A.T @ e, " ← 0. 잔차가 열공간과 직교 (9강)") print(" 첫째 성분 = Σ tᵢeᵢ = 0") print(" 둘째 성분 = Σ eᵢ = 0 ← 절편이 있으면 잔차 합이 0") print() P = A @ np.linalg.inv(A.T @ A) @ A.T print("투영행렬로 계산한 예측 =", P @ y) print("같은가:", np.allclose(P @ y, p)) print("P² = P :", np.allclose(P @ P, P), " trace(P) =", round(np.trace(P), 6), "= 열 개수")
y_bar = y.mean() SST = ((y - y_bar) ** 2).sum() # 총 변동 SSR = ((p - y_bar) ** 2).sum() # 설명된 변동 SSE = (e ** 2).sum() # 남은 변동 print(f"SST (총) = {SST:.4f}") print(f"SSR (설명) = {SSR:.4f}") print(f"SSE (잔차) = {SSE:.4f}") print(f"SSR + SSE = {SSR + SSE:.4f} ← SST 와 같다") print() print(f"R² = SSR/SST = {SSR/SST:.4f} = 1 - SSE/SST = {1 - SSE/SST:.4f}") print() print("이 분해가 성립하는 이유는 (p - ȳ) ⟂ e 이기 때문 — 피타고라스 정리(8강)") print("직교 확인:", round((p - y_bar) @ e, 12))
# y = a + b·t + c·t² 는 미지수 a,b,c 에 대해서는 여전히 '선형' 이다 t2 = np.linspace(0, 4, 9) y2 = 2 - 1.5 * t2 + 0.6 * t2 ** 2 + np.random.default_rng(0).normal(0, 0.3, size=9) A2 = np.column_stack([np.ones_like(t2), t2, t2 ** 2]) # [1 | t | t²] 계수, *_ = np.linalg.lstsq(A2, y2, rcond=None) print("설계행렬 A2 의 처음 3행 =") print(A2[:3]) print() print(f"추정: y = {계수[0]:.2f} + {계수[1]:.2f} t + {계수[2]:.2f} t²") print(f"참값: y = 2.00 + -1.50 t + 0.60 t²") print() print("→ '선형회귀' 의 '선형' 은 t 가 아니라 '계수' 에 대한 것이다.") print(" 열을 무엇으로 채우든(t², log t, sin t) 방법은 똑같다.")
y3 = y.copy() print("원래 :", np.linalg.lstsq(A, y3, rcond=None)[0]) y3[2] = 12.0 # 점 하나를 크게 흔든다 print("이상치:", np.linalg.lstsq(A, y3, rcond=None)[0]) print() print("→ 점 하나가 기울기와 절편을 통째로 끌고 갔다.") print(" 제곱이 큰 오차에 큰 발언권을 주기 때문이다.")
# 문제 1. 점 (1,1), (2,3), (3,4) 에 최소제곱 직선을 맞춰보세요. # 문제 2. 그 결과의 잔차를 구하고, 합이 0인지 Aᵀe = 0 인지 확인하세요. # 문제 3. 절편 없이(원점을 지나는 직선 y = ct) 맞추면 잔차 합이 0일까요? # 직접 확인해보세요. # 아래에 직접 써보세요

tt = np.array([1., 2., 3.]); yy = np.array([1., 3., 4.]) # 문제 1 AA = np.column_stack([tt, np.ones_like(tt)]) ans, *_ = np.linalg.lstsq(AA, yy, rcond=None) print(f"문제 1: y = {ans[0]:.3f} t + {ans[1]:.3f}") # 문제 2 ee = yy - AA @ ans print(f"문제 2: 잔차 {np.round(ee, 6)} 합 {ee.sum():.2e} Aᵀe {np.round(AA.T @ ee, 9)}") # 문제 3 — 절편 열이 없으면 '잔차 합 = 0' 이 보장되지 않는다 AA0 = tt.reshape(-1, 1) ans0, *_ = np.linalg.lstsq(AA0, yy, rcond=None) ee0 = yy - AA0 @ ans0 print(f"\n문제 3: y = {ans0[0]:.3f} t (절편 없음)") print(f" 잔차 {np.round(ee0, 4)} 합 {ee0.sum():.4f} ← 0 이 아니다") print(" Aᵀe =", np.round(AA0.T @ ee0, 9), " ← 이건 여전히 0") print(" '잔차 합 = 0' 은 절편 열(전부 1)이 있을 때만 나오는 결과다.")

6. 실무: 언제 무너지는가

최소제곱이 실패하는 세 가지
  • 다중공선성 — 설명변수 하나가 다른 것들의 조합에 가까우면 ATA 가 거의 특이해집니다. 계수가 터무니없이 커지고 부호가 뒤집히며, 데이터를 조금만 바꿔도 확 변합니다. → 능형회귀(Ridge) 로 ATA + λI 를 쓰거나, 변수를 줄입니다.
  • 이상치 — 위에서 본 대로 제곱이 이상치를 증폭합니다. → 잔차 그림을 반드시 그려보고, 필요하면 robust 회귀.
  • 수치 오차 — ATA 를 만드는 순간 조건수가 제곱이 됩니다. 원래 1e8 이면 1e16 이 되어 정밀도가 날아가죠. → 정규방정식을 직접 풀지 말고 QR 분해(11강)나 lstsq(내부적으로 SVD)를 쓰세요.
"R²가 높으면 좋은 모델"이 아닙니다 R²는 변수를 추가하면 무조건 올라갑니다. 쓸모없는 변수를 넣어도요. 그래서 수정 R² 나 검증 데이터 성능을 봐야 합니다.

그리고 R²는 인과관계와 아무 상관이 없습니다. 아이스크림 판매량으로 익사 사고를 예측하면 R²가 높게 나오지만, 진짜 원인은 여름입니다.

10강 요약

  • 데이터가 많으면 Ax=b 는 거의 항상 해가 없습니다(과결정계).
  • "해를 구한다" 대신 "오차 제곱합을 최소로" — 그건 곧 열공간으로 투영(9강)입니다.
  • 정규방정식 ATA x̂ = ATb. AT 를 곱하면 도달 불가능한 성분이 저절로 지워집니다.
  • 절편 열(전부 1)이 있으면 잔차 합이 반드시 0 입니다.
  • R² = 피타고라스: SST = SSR + SSE 가 성립하는 건 직교 때문입니다.
  • "선형"회귀의 선형은 계수에 대한 것 — 열에 t², log t 를 넣어도 됩니다.
  • 약점 셋: 이상치·다중공선성·수치 오차. 실무에서는 lstsq 나 QR 을 쓰세요.
