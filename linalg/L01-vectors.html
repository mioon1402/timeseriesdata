벡터와 선형결합

선형대수학 전체가 단 하나의 식 위에 서 있습니다. c₁v₁ + c₂v₂ + ⋯ + cₙvₙ — 재료가 될 벡터들과, 그걸 얼마나 섞을지 정하는 가중치. 앞으로 배울 모든 것(연립방정식, 부분공간, 고윳값, SVD)이 결국 "이 선형결합을 찾아라"는 문제로 되돌아옵니다.

이 강의에서 배우는 것
  1. 벡터 — 숫자 목록이자 화살표
  2. 덧셈과 스칼라배 (직접 끌어보기)
  3. 선형결합이 공간을 채운다
  4. 평행한 두 벡터는 평면을 못 만든다
  5. numpy 로 계산해보기
  6. 실무에서 이게 무슨 뜻인가

1. 벡터 — 숫자 목록이자 화살표

벡터는 순서가 있는 숫자 목록입니다. 그게 정의의 전부입니다. 다만 2차원·3차원에서는 이걸 화살표로 그릴 수 있어서, 숫자만으로는 안 보이던 성질이 눈에 들어옵니다.

벡터 = 좌표 = 화살표
v  =  32   ⟷   원점에서 오른쪽 3, 위로 2 만큼 간 화살표
  • 성분각 축 방향으로 얼마나 가는지. 개수가 곧 차원입니다
  • 꼬리보통 원점에 고정합니다(위치벡터). 그래야 "숫자 = 화살표"가 1:1이 됩니다
  • 고차원1000픽셀 이미지 = 1000차원 벡터. 그림은 못 그려도 성질은 똑같습니다

2. 덧셈과 스칼라배

벡터공간을 떠받치는 연산은 딱 두 개입니다 — 더하기와 상수배. 아래에서 파란 점과 초록 점을 끌어 보세요.

u–
v–
a·u–
b·v–
a·u + b·v–

두 가지를 확인해 보세요.

  • 스칼라를 음수로 내리면 화살표가 정반대로 뒤집힙니다. 방향은 유지되고 부호만 바뀝니다.
  • 덧셈은 이어 붙이기입니다. a·u의 머리에서 b·v를 이어 붙인 끝점이 곧 합입니다. 순서를 바꿔도 같은 자리에 도착하죠 — 그래서 평행사변형이 생깁니다.
두 연산
스칼라배   c u₁u₂ = c u₁c u₂
덧셈   u₁u₂ + v₁v₂ = u₁ + v₁u₂ + v₂
  • 성분별대수적으로는 같은 자리끼리 계산하면 끝입니다. 규칙이 이것뿐이라 고차원으로 그대로 올라갑니다

3. 선형결합이 공간을 채운다

스칼라배와 덧셈을 동시에 쓴 것이 선형결합(Linear Combination)입니다. 위 그림에서 이미 하고 있었죠 — a·u + b·v 가 바로 그것입니다.

선형결합
w  =  c1 v1 + c2 v2 + ⋯ + cn vn
  • vi재료가 되는 벡터들. 무엇을 섞을 것인가
  • ci가중치(스칼라). 각 재료를 얼마나 넣을 것인가
  • w합성된 결과. 이 식 하나가 선형대수 전체입니다

그럼 a와 b를 모든 값으로 바꾸면 a·u + b·v는 어디까지 갈 수 있을까요? 아래에서 [흔적 남기기]를 켜고 슬라이더를 움직여 보세요.

c₁·v₁–
c₂·v₂–
결과 w–
지나간 점0
Span · 두 벡터의 가능한 모든 선형결합을 모은 집합을 그 벡터들이 생성(Span)하는 공간이라고 합니다. 평행하지 않은 두 벡터의 Span은 평면 전체입니다 — 흔적이 화면을 다 덮었죠.

재료가 두 개라고 2차원이 되는 게 아닙니다 v₂ = −1.5·v₁ 처럼 한 벡터가 다른 벡터의 상수배라면, 아무리 섞어도 같은 직선 위를 벗어나지 못합니다. 벡터의 개수가 아니라 서로 다른 방향의 개수가 공간의 크기를 결정합니다. 이것이 나중에 배울 선형독립·랭크·차원의 씨앗입니다.

5. numpy 로 계산해보기

이제 손으로 그린 것을 코드로 확인합니다. 아래 [실행]을 누르면 브라우저 안에서 진짜 파이썬이 돌아갑니다. 설치는 필요 없습니다.

import numpy as np u = np.array([3, 1]) v = np.array([1, 3]) print("u =", u) print("v =", v) print("u + v =", u + v) print("2u =", 2 * u) print("-1.5v =", -1.5 * v)

np.array([3, 1]) 가 벡터입니다. 덧셈과 상수배가 파이썬 기본 연산자 그대로 동작하는 게 numpy의 핵심입니다.

파이썬 리스트와 헷갈리지 마세요 [3, 1] + [1, 3] 은 [3, 1, 1, 3] 이 됩니다 — 이어 붙이기죠. 2 * [3, 1] 은 [3, 1, 3, 1] 이고요. 벡터 연산을 하려면 반드시 np.array 로 감싸야 합니다. 아래에서 직접 확인해 보세요.
리스트 = [3, 1] 배열 = np.array([3, 1]) print("리스트 + 리스트 :", 리스트 + [1, 3]) print("배열 + 배열 :", 배열 + np.array([1, 3])) print() print("리스트 * 2 :", 리스트 * 2) print("배열 * 2 :", 배열 * 2)
# 가중치를 바꿔가며 어디로 가는지 본다 for c1, c2 in [(1, 1), (2, -1), (0.5, 0.5), (0, 0), (-1, 2)]: w = c1 * u + c2 * v print(f"{c1:>5} · u + {c2:>5} · v = {w}")

가중치 (c₁, c₂) 를 정하면 결과 w 가 하나 정해집니다. 거꾸로, 원하는 w 를 만들려면 어떤 가중치를 써야 할까요? 그 질문이 바로 연립방정식이고, 2강의 주제입니다.

# 재료 벡터들을 '열'로 세워 붙이면 행렬이 된다 A = np.column_stack([u, v]) print("A =") print(A) print() c = np.array([2, -1]) # 가중치를 모은 벡터 print("A @ c =", A @ c) # @ 가 행렬 곱 print("2u - 1v =", 2 * u - 1 * v) print("같은가:", np.array_equal(A @ c, 2 * u - 1 * v))
가장 중요한 한 줄 · A @ c 는 A의 열벡터들을 c의 값만큼 섞은 것입니다. 행렬 곱을 "행과 열의 내적"으로만 외우면 여기서 막힙니다. 행렬 = 열벡터 묶음, 곱셈 = 그 열들의 선형결합 — 이 시각이 앞으로 전부를 좌우합니다.
p = np.array([4, -2, 7]) I = np.eye(3, dtype=int) # 3차원 단위행렬 = 표준기저 e1, e2, e3 print("e1, e2, e3 =") print(I) print() 재구성 = p[0] * I[:, 0] + p[1] * I[:, 1] + p[2] * I[:, 2] print("4·e1 + (-2)·e2 + 7·e3 =", 재구성) print("원래 p =", p)

우리가 "좌표 (4, −2, 7)" 이라고 부르던 것은 사실 표준기저를 그만큼씩 섞은 선형결합의 가중치였습니다. 좌표는 처음부터 선형결합이었던 셈이죠.

6. 실무에서 이게 무슨 뜻인가

선형결합으로 읽는 현실
  • 신호 처리 — 덧셈은 중첩(superposition), 스칼라배는 증폭·감쇠입니다. 잡음 섞인 신호 = 원신호 + 잡음벡터.
  • 이미지 — 28×28 흑백 이미지는 784차원 벡터 하나입니다. "평균 얼굴"은 얼굴 벡터들의 가중평균(선형결합)이죠.
  • 포트폴리오 — 종목별 수익률 벡터를 비중만큼 섞은 것이 포트폴리오 수익률입니다. 비중이 곧 ci 입니다.
  • 임베딩 — 단어 벡터에서 king − man + woman ≈ queen 이 성립하는 것도 그저 선형결합입니다.
"벡터는 크기와 방향을 가진 양"이라는 정의의 한계 고등학교에서 배운 이 정의는 2·3차원 물리 벡터에는 잘 맞지만, 다항식이나 함수도 벡터라는 사실을 설명하지 못합니다. 선형대수의 진짜 정의는 "더하기와 상수배가 되고 그 결과가 밖으로 안 나가는 것"입니다. 2강 이후로는 이 관점으로 갈아타는 게 좋습니다.

1강 요약

  • 벡터 = 순서 있는 숫자 목록. 2·3차원에서만 화살표로 그릴 수 있을 뿐, 성질은 차원과 무관합니다.
  • 연산은 덧셈(머리-꼬리 잇기)과 스칼라배(늘이기·뒤집기) 둘뿐입니다.
  • 둘을 합친 선형결합 c₁v₁ + ⋯ + cₙvₙ 이 이 과목의 중심 식입니다.
  • 가능한 모든 선형결합의 집합이 Span. 방향이 다른 두 벡터의 Span은 평면 전체입니다.
  • 벡터가 평행하면 아무리 섞어도 직선을 벗어나지 못합니다 — 개수가 아니라 방향의 개수가 중요합니다.
  • numpy 에서 A @ c 는 A의 열들을 c 만큼 섞는 것입니다. 이 한 문장이 앞으로 계속 쓰입니다.
