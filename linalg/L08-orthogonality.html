내적과 직교성

지금까지는 더하기와 상수배만 있었습니다. 길이도 각도도 없었죠. 내적(dot product) 하나를 도입하는 순간 기하학이 통째로 들어옵니다 — 길이, 각도, 수직, 피타고라스 정리, 그리고 다음 두 강의의 투영과 최소제곱법까지.

0. 기초 다지기 — 내적은 그냥 곱해서 더한 것

정의는 놀랄 만큼 단순합니다. 같은 자리끼리 곱해서 전부 더하면 끝입니다.

내적 (Dot Product / Inner Product)
u · v  =  uTv  =  u1v1 + u2v2 + ⋯ + unvn
  • 결과스칼라(숫자 하나)입니다. 벡터가 아닙니다
  • uTv전치를 붙이면 (1×n)(n×1) = 1×1 — 행렬 곱으로 쓴 것일 뿐 같은 계산입니다(4강)
  • 교환u·v = v·u. 이건 순서를 바꿔도 됩니다
왜 이 이상한 계산이 "각도"를 알려주나
직관은 이렇습니다. 두 벡터가 같은 방향을 보면 각 성분의 부호가 맞아떨어져 곱이 전부 양수 → 합이 큰 양수. 반대 방향이면 곱이 음수 → 큰 음수. 수직이면 양수 항과 음수 항이 정확히 상쇄되어 0이 됩니다.

즉 내적은 "얼마나 같은 방향을 보고 있는가"의 점수입니다.

1. 길이(노름)와 각도

자기 자신과 내적하면 u·u = u₁² + u₂² + ⋯ 입니다. 어디서 많이 본 모양이죠 — 피타고라스 정리입니다.

길이 (Norm)
‖u‖  =  √uTu  =  √u12 + u22 + ⋯ + un2
  • ‖u‖"노름"이라 읽습니다. 절댓값 기호 두 개를 씁니다
  • 단위벡터u / ‖u‖ — 길이를 1로 맞춘 것. 방향만 남기고 크기를 버립니다
각도
cos θ  =  uTv‖u‖ ‖v‖
  • −1 ≤ cos θ ≤ 1항상 성립합니다. 이걸 코시-슈바르츠 부등식 |uTv| ≤ ‖u‖‖v‖ 이라고 합니다
  • 데이터에서이 값이 코사인 유사도입니다. 문서·추천 시스템에서 "방향만 비교" 할 때 씁니다 — 길이(문서 분량)는 무시하고요

2. 직교 — 내적이 0이면 수직

직교의 정의
u ⟂ v   ⟺   uTv = 0
  • 왜cos 90° = 0 이므로 분자가 0이어야 합니다
  • 영벡터0 은 모든 벡터와 직교합니다 (내적이 항상 0이니까요). 각도가 정의되지 않는 예외적인 경우입니다

3. 피타고라스 정리, 고차원으로

직교의 정의만 가지고 세 줄로 피타고라스 정리가 나옵니다. 그것도 차원에 상관없이요.

증명 · u ⟂ v 일 때
‖u + v‖2 = (u+v)T(u+v)
          = uTu + uTv + vTu + vTv
          = ‖u‖2 + 0 + 0 + ‖v‖2
  • 핵심가운데 교차항이 0으로 사라지는 것이 전부입니다. 직교가 아니면 이 항들이 남아 정리가 깨집니다
왜 이게 그렇게 중요한가 · 직교하면 "따로따로 재서 더해도 된다"는 뜻입니다. 복잡한 것을 서로 간섭하지 않는 조각으로 쪼갤 수 있다는 거죠.

통계의 분산 분해(총변동 = 설명된 변동 + 잔차), 신호의 주파수 분해, 회귀의 R² 가 전부 이 한 줄 위에 서 있습니다.

4. 직교 부분공간과 흔한 오해

두 부분공간 V, W 가 직교한다는 건 V의 어떤 벡터든 W의 어떤 벡터와도 직교한다는 뜻입니다. 예외가 없어야 합니다.

"교실의 바닥과 벽은 직교한다"는 틀렸습니다 3차원에서 바닥 평면과 벽 평면은 직각으로 만나 보이지만 직교 부분공간이 아닙니다.

두 평면은 교선(바닥과 벽이 만나는 선)을 공유합니다. 그 선 위의 벡터 v 는 양쪽 모두에 속하죠. 직교하려면 vTv = 0 이어야 하는데, 그건 v = 0 일 때뿐입니다. 모순이죠.

규칙: 영벡터 말고 겹치는 부분이 있으면 직교 부분공간이 될 수 없습니다.

5. 네 부분공간의 직교성 증명

7강에서 예고한 것을 이제 증명합니다. 놀랄 만큼 짧습니다.

정리 · 행공간 ⟂ 영공간
① x ∈ N(A) 이면 정의상 Ax = 0
② Ax 를 행 관점으로 풀면 각 성분이 (A의 i번째 행)T x = 0
      ⟹ x 는 A의 모든 행과 직교
③ 행공간의 벡터는 행들의 선형결합 v = c₁r₁ + ⋯ + cmrm
      ⟹ vTx = c₁(r₁Tx) + ⋯ = 0 + ⋯ + 0 = 0 ∎
  • 열 쪽도같은 논리를 ATy = 0 에 적용하면 열공간 ⟂ 좌영공간이 나옵니다
  • 4강 관점③번 줄이 핵심입니다 — "각 행과 직교하면 그 행들의 모든 조합과도 직교한다"
Big Picture 완성 · ℝⁿ 은 행공간과 영공간이라는 두 개의 수직한 조각으로 완전히 쪼개집니다. 차원도 r + (n−r) = n 으로 딱 맞고, 각도도 90°죠. 이런 관계를 직교 여공간(orthogonal complement) 이라고 부릅니다.

그래서 어떤 벡터든 "행공간 성분 + 영공간 성분"으로 유일하게 나눌 수 있습니다. 그 나누는 도구가 9강의 투영입니다.

6. numpy 로 확인하기

import numpy as np np.set_printoptions(precision=4, suppress=True) u = np.array([3., 4.]) v = np.array([-4., 3.]) w = np.array([1., 2.]) print("u · v =", u @ v, " ← 0 이면 수직") print("u · w =", u @ w) print() print("‖u‖ =", np.linalg.norm(u), " = √(u·u) =", np.sqrt(u @ u)) print() def 각도(a, b): cos = (a @ b) / (np.linalg.norm(a) * np.linalg.norm(b)) cos = np.clip(cos, -1, 1) # 반올림 오차로 1.0000001 이 되는 걸 막는다 return np.degrees(np.arccos(cos)) print(f"u 와 v 사이 각 = {각도(u, v):.1f}°") print(f"u 와 w 사이 각 = {각도(u, w):.1f}°")
np.clip 을 꼭 넣으세요 수학적으로 cos θ 는 −1과 1 사이지만, 부동소수점 계산에서는 1.0000000000000002 가 나올 수 있습니다. 그러면 arccos 가 nan 을 뱉습니다. 벡터가 거의 평행할 때 실제로 자주 터지는 버그입니다.

실무에서 내적
  • 추천·검색 — 코사인 유사도. 임베딩 벡터끼리의 내적이 곧 관련도 점수입니다.
  • 신경망 — 뉴런 하나가 하는 일이 입력 벡터와 가중치 벡터의 내적입니다. "이 패턴과 얼마나 닮았나"를 재는 거죠.
  • 상관계수 — 평균을 뺀 두 데이터 벡터의 코사인 유사도가 정확히 상관계수입니다. "상관 0 = 직교"인 이유가 이것입니다.
  • 주의 — 내적은 단위(스케일)에 휘둘립니다. 키(cm)와 몸무게(kg)를 그냥 내적하면 숫자가 큰 쪽이 지배합니다. 표준화 후에 쓰세요.

8강 요약

  • 내적 = 같은 자리끼리 곱해서 더한 숫자 하나. uTv.
  • 길이 ‖u‖ = √(uTu) — 피타고라스의 일반화. 각도 cos θ = uTv / (‖u‖‖v‖) — 코사인 유사도.
  • 직교 ⟺ 내적이 0. 내적의 부호가 같은 방향인지 반대인지를 알려줍니다.
  • 피타고라스는 교차항 uTv 가 0으로 사라지기 때문에 성립합니다. = "직교하면 따로 재서 더해도 된다".
  • 영벡터 말고 겹치는 부분이 있으면 직교 부분공간이 아닙니다 (바닥과 벽).
  • 행공간 ⟂ 영공간, 열공간 ⟂ 좌영공간. ℝⁿ 이 수직한 두 조각으로 완전히 쪼개집니다.
