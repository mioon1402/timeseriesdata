0. 기초 다지기 — 왜 식을 빼도 되는가

연립방정식을 풀 때 우리는 아무렇지 않게 이런 일을 합니다.

①  2x + y = 7
②   x + y = 4
① − ② 를 하면   x = 3

"왜 빼도 되지?" 를 한 번은 짚고 가야 합니다. ②가 참인 식이라면 좌변과 우변은 같은 수입니다. 같은 수를 ①의 양변에서 빼는 것이니 등식은 그대로 유지되죠. 그리고 결정적으로 — 원래 두 식을 만족하던 (x, y)는 새 식도 여전히 만족합니다.

핵심 · 소거는 방정식을 바꾸는 것처럼 보이지만 해집합은 전혀 건드리지 않습니다. 모양만 다루기 쉽게 바꿀 뿐이죠. 아래 그림에서 직접 확인하게 됩니다 — 직선은 움직이는데 교점은 제자리입니다.
허용되는 연산왜 안전한가
어떤 행에 0이 아닌 수를 곱한다 등식의 양변에 같은 수를 곱하는 것
한 행에 다른 행의 배수를 더하거나 뺀다 참인 등식을 더하는 것 (위에서 본 이유)
두 행의 순서를 바꾼다 식을 적는 순서는 의미가 없음
0을 곱하면 안 됩니다 0 × (2x + y = 7) 은 0 = 0 이 됩니다. 항상 참이지만 아무 정보도 없죠. 식 하나를 통째로 잃어버리는 셈입니다. "0이 아닌 수"라는 단서가 그래서 붙습니다.

2. 피봇과 상삼각행렬 U

소거할 때 기준으로 삼아 나누는 대각선 위의 원소를 피봇(Pivot)이라고 합니다. 위 예에서 첫 번째 피봇은 2였죠. "2번째 행에서 x를 없애려면 1번째 행을 몇 배 해서 빼야 하나?" 의 답이 배수(multiplier)이고, 그건 (없앨 값) ÷ (피봇) 입니다.

소거의 목표 — 왼쪽 아래를 0으로
211 4−60 −272  →  211 0−8−2 001  = U
  • 피봇굵게 표시된 2, −8, 1. 대각선 위에서 소거의 기준이 되는 값
  • U상삼각행렬(Upper triangular). 대각선 아래가 전부 0
  • 배수각 소거에서 쓴 수. 이걸 버리지 않고 모아두면 L이 됩니다(§5)

U 형태가 되면 맨 아래 식부터 풀 수 있습니다. 마지막 행은 미지수가 하나뿐이니 바로 나오고, 그 값을 위로 대입하면 그 위도 미지수가 하나가 되죠. 이것을 후진 대입법(Back Substitution)이라고 합니다.

왜 굳이 삼각형 모양을 만드나 삼각형이면 순서대로 하나씩 풀 수 있기 때문입니다. n개 미지수를 한꺼번에 상대하는 대신, 1개짜리 문제를 n번 푸는 것으로 바뀌죠. 컴퓨터가 연립방정식을 푸는 방식이 지금도 이것입니다.

3. 피봇이 0이면

소거하려는 자리의 피봇이 0이면 나눌 수가 없습니다. 이걸 피봇 실패(Pivot breakdown)라고 하는데, 두 가지 경우가 있습니다.

상황대응의미
아래쪽 행에 0이 아닌 값이 있다 행 교환(Row exchange) 후 계속 진행 일시적인 문제. 해는 여전히 유일하게 존재
아래쪽이 전부 0이다 더 진행 불가 특이행렬. 역행렬이 없고, 해가 없거나 무한히 많음
2강과 이어집니다
피봇을 n개 다 확보 = 열들이 서로 독립 = 해가 하나
피봇이 모자람 = 열 중 일부가 다른 열의 조합 = 해가 없거나 무한
2강에서 그림으로 본 것을 알고리즘이 자동으로 판정해주는 셈입니다.

4. 기본행렬 — 행 연산도 행렬 곱이다

여기서 관점이 한 번 도약합니다. "2번 행에서 1번 행의 2배를 뺀다"는 손으로 하는 조작처럼 보이지만, 사실 행렬 하나를 왼쪽에 곱하는 것과 완전히 같습니다.

단위행렬 I 에 딱 그 연산 하나만 가해서 만든 행렬을 기본행렬(Elementary Matrix) E 라고 합니다.

기본행렬 E₂₁ — "2행에서 1행의 ℓ₂₁배를 뺀다"
E21 = 100 −ℓ2110 001     E21 A = (2행이 소거된 A)
  • ℓ212행에서 1행을 몇 배 뺐는지 (배수)
  • 왼쪽 곱왼쪽에 곱하면 행이 조작됩니다. 오른쪽에 곱하면 열이 조작되죠 — 헷갈리기 쉬운 지점입니다

그러면 소거 전체는 기본행렬들을 차례로 곱하는 것으로 적힙니다.

소거 = 기본행렬들의 곱
( E32 E31 E21 ) A  =  U
  • 순서오른쪽부터 적용됩니다. E₂₁ 이 먼저, E₃₂ 가 마지막. 함수 합성과 같은 순서입니다

5. A = LU 유도

이제 위 식을 뒤집어 A 만 남겨봅시다. 각 기본행렬의 역행렬을 왼쪽부터 차례로 곱하면 됩니다.

유도
①  Ek ⋯ E2 E1 A = U
②  A = ( E1−1 E2−1 ⋯ Ek−1 ) U
③  L ≔ E1−1 E2−1 ⋯ Ek−1  ⟹  A = L U

기본행렬의 역행렬은 구하기가 우스울 정도로 쉽습니다. "뺐던 만큼 도로 더해주면" 되니까 부호만 뒤집으면 끝이죠.

역행렬은 부호만 뒤집으면 된다
E21 = 100 −ℓ10 001  ⟹  E21−1 = 100 +ℓ10 001
가장 놀라운 부분 · 이 역행렬들을 순서대로 곱하면 배수 ℓij 들이 서로 섞이지 않고 제자리에 그대로 들어갑니다. 그래서 L 은 따로 계산할 필요가 없습니다. 소거하면서 쓴 배수를 그 자리에 적어두기만 하면 그게 곧 L 이죠. 아래 코드에서 직접 확인합니다.
A = LU
A  =  100 ℓ2110 ℓ31ℓ321 피봇** 0피봇* 00피봇
  • L하삼각행렬(Lower). 대각선은 전부 1, 아래는 소거에 쓴 배수들
  • U상삼각행렬. 대각선은 피봇들
왜 분해해두면 이득인가 같은 A 에 대해 b 만 바꿔가며 여러 번 풀어야 할 때가 실무에서 아주 흔합니다(매일 들어오는 새 관측값 등).
  • 매번 소거하면 매번 O(n³) 이 듭니다.
  • 한 번 A = LU 로 쪼개두면, 이후에는 Lc = b(전진 대입) → Ux = c(후진 대입) 두 번으로 끝나 O(n²) 입니다.
n이 1000이면 1000배 가까이 차이 납니다.

6. numpy 로 직접 구현하기

import numpy as np np.set_printoptions(precision=3, suppress=True) # 보기 좋게 A = np.array([[ 2., 1., 1.], [ 4., -6., 0.], [-2., 7., 2.]]) b = np.array([5., -2., 9.]) U = A.copy() c = b.copy() L = np.eye(3) # 배수를 적어둘 자리 for j in range(3): # j 번째 열을 소거 for i in range(j + 1, 3): # 그 아래 행들에 대해 m = U[i, j] / U[j, j] # 배수 = 없앨 값 ÷ 피봇 L[i, j] = m # 버리지 말고 적어둔다 U[i] -= m * U[j] c[i] -= m * c[j] print(f"{i+1}행 -= {m:.3g} × {j+1}행") print(U, "\n")
print("L =") print(L) print("\nU =") print(U) print("\nL @ U =") print(L @ U) print("\nA 와 같은가:", np.allclose(L @ U, A))
확인 · L 의 대각선 아래 값 2, −1, −1 은 우리가 소거하며 출력한 배수와 정확히 같습니다. 따로 계산한 게 아니라 그냥 받아 적은 것입니다.
# U x = c 를 아래 행부터 푼다 n = 3 x = np.zeros(n) for i in range(n - 1, -1, -1): 이미_구한_부분 = U[i, i+1:] @ x[i+1:] x[i] = (c[i] - 이미_구한_부분) / U[i, i] print(f"x[{i}] = ({c[i]:.3g} - {이미_구한_부분:.3g}) / {U[i,i]:.3g} = {x[i]:.3g}") print("\n직접 구한 해 :", x) print("numpy 의 해 :", np.linalg.solve(A, b))
나쁜A = np.array([[0., 1.], [2., 3.]]) print("첫 피봇 =", 나쁜A[0, 0], " → 0 이라 나눌 수 없다") print() # 해결책: 행을 바꾼다 바꾼A = 나쁜A[[1, 0]] # 1행과 0행을 교환 print("행 교환 후:") print(바꾼A) print("이제 첫 피봇 =", 바꾼A[0, 0], " → 진행 가능") print() # 아래가 전부 0이면 교환해도 소용없다 = 특이행렬 특이 = np.array([[1., 2.], [2., 4.]]) print("특이행렬 det =", np.linalg.det(특이)) print("→ 피봇을 2개 확보할 수 없다. 역행렬 없음")
scipy 의 lu() 는 우리가 손으로 한 것과 다른 답을 줍니다 scipy.linalg.lu(A) 는 PA = LU 형태로, P(행 교환 행렬)를 함께 돌려줍니다. 피봇이 0이 아니어도 절댓값이 가장 큰 값을 피봇으로 쓰려고 일부러 행을 바꾸기 때문입니다 (부분 피봇팅, partial pivoting).

왜냐면 아주 작은 수로 나누면 반올림 오차가 폭발하거든요. 그래서 실제 라이브러리는 교과서 순서를 그대로 따르지 않습니다. 아래에서 직접 비교해 보세요 — 다르게 나오는 게 정상입니다.
from scipy.linalg import lu P, L2, U2 = lu(A) print("P (행 교환 행렬) =") print(P) print("\nP 가 단위행렬인가:", np.allclose(P, np.eye(3)), " ← False 면 행을 바꿨다는 뜻") print() print("우리가 구한 U =\n", U) print("\nscipy 의 U =\n", U2) print() print("둘 다 맞는 분해인가:") print(" 우리 것 : L @ U == A →", np.allclose(L @ U, A)) print(" scipy : P @ L2 @ U2 == A →", np.allclose(P @ L2 @ U2, A))
import time from scipy.linalg import lu_factor, lu_solve rng = np.random.default_rng(0) n = 300 큰A = rng.random((n, n)) + n * np.eye(n) # 잘 풀리는 행렬로 b들 = rng.random((50, n)) # 우변 50개 t = time.perf_counter() for bb in b들: np.linalg.solve(큰A, bb) # 매번 처음부터 t1 = time.perf_counter() - t t = time.perf_counter() lu_piv = lu_factor(큰A) # 한 번만 분해 for bb in b들: lu_solve(lu_piv, bb) # 대입 두 번씩 t2 = time.perf_counter() - t print(f"매번 소거 : {t1*1000:7.1f} ms") print(f"한 번 분해 후 : {t2*1000:7.1f} ms") print(f"→ 약 {t1/t2:.1f} 배 빠름 (n={n}, 우변 {len(b들)}개)")
# 문제 1. 아래 행렬을 손으로 소거해 U 와 L 을 구하고, 코드로 확인해보세요. # [[1, 2], # [3, 8]] # 문제 2. 그 A 에 대해 b = [5, 19] 일 때 해를 후진 대입으로 구해보세요. # 문제 3. [[0, 1], [1, 0]] 은 피봇이 0 입니다. # 행을 바꾸면 무엇이 되나요? det 는 얼마인가요? # 아래에 직접 써보세요
모범 답안 보기
# 문제 1 — 2행에서 1행의 3배를 뺀다 A1 = np.array([[1., 2.], [3., 8.]]) m = A1[1, 0] / A1[0, 0] # = 3 U1 = A1.copy(); U1[1] -= m * U1[0] L1 = np.array([[1., 0.], [m, 1.]]) print("배수 =", m) print("U =\n", U1) print("L =\n", L1) print("L@U == A :", np.allclose(L1 @ U1, A1)) # 문제 2 b1 = np.array([5., 19.]) c1 = b1.copy(); c1[1] -= m * c1[0] # 우변도 같이 소거 y = c1[1] / U1[1, 1] x = (c1[0] - U1[0, 1] * y) / U1[0, 0] print("\n해 =", [x, y], " 확인:", np.linalg.solve(A1, b1)) # 문제 3 — 행을 바꾸면 단위행렬이 된다 A3 = np.array([[0., 1.], [1., 0.]]) print("\n행 교환 후:\n", A3[[1, 0]]) print("det =", np.linalg.det(A3), " ← 행을 한 번 바꾸면 부호가 뒤집힌다 (12강)")

3강 요약

  • 소거는 해집합을 건드리지 않습니다. 직선은 움직여도 교점은 제자리입니다.
  • 피봇으로 나눠 배수를 정하고, 그만큼 빼서 아래를 0으로 만듭니다 → U(상삼각).
  • U가 되면 후진 대입으로 아래부터 하나씩 풀립니다.
  • 피봇이 0이면 행 교환. 아래가 전부 0이면 특이행렬(해가 없거나 무한).
  • 행 연산은 기본행렬을 왼쪽에 곱하는 것과 같습니다.
  • A = LU — 소거에 쓴 배수를 그 자리에 적어두면 그게 L입니다. 따로 계산하지 않습니다.
  • 실제 라이브러리는 수치 안정성 때문에 행을 바꿉니다(PA = LU). 교과서와 답이 달라도 둘 다 맞습니다.
