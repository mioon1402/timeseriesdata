영공간과 열공간

행렬 A 하나 안에 두 개의 부분공간이 숨어 있습니다. 하나는 A가 0으로 뭉개버리는 입력들(영공간), 다른 하나는 A가 도달할 수 있는 모든 출력(열공간)입니다. 이 둘을 알면 Ax = b 에 대해 물을 수 있는 모든 질문에 답할 수 있습니다.

이 강의에서 배우는 것
  1. 기초 다지기 — 동차와 비동차
  2. 영공간 N(A) — A가 0으로 보내는 것들
  3. 열공간 C(A) — A가 도달할 수 있는 곳
  4. 두 공간을 눈으로 보기 (직접 해보기)
  5. RREF와 특별해 구하기
  6. 완전해 = 특수해 + 영공간
  7. numpy 로 확인하기

0. 기초 다지기 — 동차와 비동차

앞으로 두 종류의 방정식을 구분해서 다룹니다. 이름만 어렵지 차이는 단순합니다.

이름모양특징
동차 (Homogeneous) Ax = 0 항상 해가 있습니다 — 최소한 x = 0 은 되니까요. 질문은 "그것 말고 또 있는가?"
비동차 (Non-homogeneous) Ax = b (b ≠ 0) 해가 없을 수도 있습니다. 질문은 "과연 풀리는가?"
x = 0 을 자명한 해(trivial solution)라고 부릅니다
"당연한 답"이라는 뜻입니다. A·0 = 0 이니 언제나 성립하죠. 선형대수에서 재미있는 질문은 언제나 "자명하지 않은 해가 있는가?" 입니다.

1. 영공간 N(A)

영공간(Nullspace) N(A) 는 Ax = 0 을 만족하는 모든 x 의 집합입니다.

정의와 증명 — 영공간은 부분공간이다
N(A) = { x : A x = 0 }
  • ① 영벡터A·0 = 0 이므로 0 ∈ N(A) ✓
  • ② 덧셈Ax=0, Ay=0 이면 A(x+y) = Ax + Ay = 0 + 0 = 0 ✓
  • ③ 상수배A(cx) = c(Ax) = c·0 = 0 ✓
  • 크기A 가 m×n 이면 x 는 n차원 → N(A) ⊆ ℝⁿ
영공간의 의미 · A 를 "센서"나 "관측기"라고 생각하면, 영공간은 그 센서가 전혀 감지하지 못하는 신호들입니다. 들어와도 출력이 0이니 있었는지조차 알 수 없죠 — 정보의 손실입니다.

그래서 영공간이 원점 하나뿐({0})이면 좋은 것입니다. 아무것도 잃지 않는다는 뜻이니까요. 그때 A 의 열들은 선형독립입니다(7강).

2. 열공간 C(A)

2강에서 Ax 는 A의 열들의 선형결합이라고 했습니다. 그럼 x 를 모든 값으로 바꿔가며 만들 수 있는 결과들을 전부 모으면? 그게 열공간(Column space) C(A) 입니다.

정의
C(A) = { A x : x 는 아무 벡터 } = Span( A 의 열들 )
  • 부분공간?5강에서 Span 은 항상 부분공간이라고 했으니 증명 끝입니다
  • 크기열들이 m차원이므로 C(A) ⊆ ℝᵐ. 영공간과 사는 동네가 다릅니다
가장 중요한 정리
Ax = b 에 해가 있다  ⟺  b ∈ C(A)
  • 읽는 법"목표 b 가 A의 열들이 만드는 공간 안에 있어야 한다" — 2강에서 그림으로 본 그것입니다

4. RREF와 특별해 구하기

영공간을 실제로 계산하려면 3강의 소거를 끝까지 밀어붙입니다. 대각선 위쪽까지 0으로 만들고 피봇을 1로 나눈 형태를 기약행사다리꼴(RREF, Reduced Row Echelon Form) 이라고 합니다.

RREF 의 조건
① 각 행에서 처음 나오는 0이 아닌 값(피봇)이 1 이다
② 피봇이 있는 열의 나머지 원소는 전부 0 이다
③ 0으로만 된 행은 맨 아래로 간다
  • 왜 하나소거를 해도 해집합은 안 변하므로(3강), Ax=0 대신 훨씬 읽기 쉬운 Rx=0 을 풀면 됩니다
피봇 열 vs 자유 열
RREF 에서 피봇이 있는 열에 해당하는 변수는 종속 변수(값이 정해짐),
피봇이 없는 열의 변수는 자유 변수(아무 값이나 넣어도 됨)입니다.

자유 변수 하나에 1, 나머지에 0 을 넣어 만든 해를 특별해(Special solution) 라고 하고, 특별해들의 Span 이 곧 영공간 전체입니다.

5. 완전해 = 특수해 + 영공간

이제 Ax = b 의 해가 전부 몇 개고 어떤 모양인지 정리합니다. 해 하나 xp 를 어떻게든 찾았다고 합시다.

완전해의 구조
A(xp + xn) = A xp + A xn = b + 0 = b
⟹   x완전 = xp + (영공간의 아무 벡터)
  • xp특수해(Particular). 아무거나 하나면 됩니다
  • xn영공간의 벡터. 더해도 결과가 안 변합니다
  • 기하학해집합은 영공간을 xp 만큼 평행이동한 것. 원점을 안 지나므로 부분공간이 아닙니다(5강)
어디서 본 구조 · 미분방정식에서 배운 "일반해 = 특수해 + 동차해" 와 글자 그대로 같은 정리입니다. 선형이기만 하면 대상이 무엇이든 이 구조가 나옵니다 — 회로 해석, 제어 시스템, 차분방정식 전부요.

6. numpy 로 확인하기

import numpy as np np.set_printoptions(precision=3, suppress=True) def rref(M, tol=1e-10): """기약행사다리꼴과 피봇 열 목록을 돌려준다.""" R = M.astype(float).copy() 행수, 열수 = R.shape 피봇열 = [] r = 0 for c in range(열수): if r >= 행수: break # 이 열에서 절댓값이 가장 큰 행을 위로 (수치 안정성 — 3강 참고) i = np.argmax(np.abs(R[r:, c])) + r if abs(R[i, c]) < tol: continue # 이 열엔 피봇이 없다 = 자유 열 R[[r, i]] = R[[i, r]] R[r] /= R[r, c] # 피봇을 1로 for j in range(행수): # 그 열의 나머지를 전부 0으로 if j != r and abs(R[j, c]) > tol: R[j] -= R[j, c] * R[r] 피봇열.append(c) r += 1 return R, 피봇열 A = np.array([[1., 2., 2., 2.], [2., 4., 6., 8.], [3., 6., 8., 10.]]) R, 피봇 = rref(A) print("RREF =") print(R) print("\n피봇 열:", 피봇, " 자유 열:", [c for c in range(A.shape[1]) if c not in 피봇]) print("랭크 r =", len(피봇))
def 특별해들(A): R, 피봇 = rref(A) n = A.shape[1] 자유 = [c for c in range(n) if c not in 피봇] 해목록 = [] for f in 자유: x = np.zeros(n) x[f] = 1 # 이 자유 변수만 1 for i, p in enumerate(피봇): x[p] = -R[i, f] # 나머지는 RREF 가 알려준다 해목록.append(x) return np.array(해목록).T # 열마다 특별해 하나 N = 특별해들(A) print("특별해 (열마다 하나) =") print(N) print("\nA @ N (전부 0이어야 함) =") print(A @ N) print("\n영공간 차원 =", N.shape[1])
rng = np.random.default_rng(0) for _ in range(3): 가중치 = rng.normal(size=N.shape[1]) n_vec = N @ 가중치 # 특별해들의 아무 선형결합 print(f"x = {np.round(n_vec, 2)} → A@x = {np.round(A @ n_vec, 9)}") print("\n→ 영공간의 어떤 벡터를 넣어도 결과는 0. 이게 '부분공간' 이라는 뜻이다.")
from scipy.linalg import null_space N2 = null_space(A) print("scipy 의 영공간 기저 =") print(N2) print("\n모양:", N2.shape, " ← 차원은 우리 것과 같다:", N.shape[1] == N2.shape[1]) print("A @ N2 최대 오차:", np.abs(A @ N2).max()) print() print("기저 벡터가 서로 달라도 괜찮습니다 —") print("같은 공간을 서로 다른 축으로 표현한 것뿐입니다 (7강 '기저는 유일하지 않다').")
def 풀리는가(A, b): r = np.linalg.matrix_rank(A) rb = np.linalg.matrix_rank(np.column_stack([A, b])) return r, rb, r == rb b1 = A @ np.array([1., 0., 1., 0.]) # 일부러 열공간 안에서 만든 b b2 = np.array([1., 0., 0.]) # 아무렇게나 고른 b for 이름, b in [("열공간 안의 b", b1), ("임의의 b", b2)]: r, rb, ok = 풀리는가(A, b) print(f"{이름:14s} rank(A)={r} rank([A|b])={rb} → {'풀린다' if ok else '해 없음'}") print() print("b 를 붙였는데 랭크가 늘어났다 = b 가 열들의 조합으로 안 만들어진다 = 열공간 밖")
b = b1 xp, *_ = np.linalg.lstsq(A, b, rcond=None) # 특수해 하나 print("특수해 xp =", np.round(xp, 3)) print("A @ xp =", np.round(A @ xp, 6), " = b ?", np.allclose(A @ xp, b)) print() for k in [0.0, 3.7, -12.5]: x = xp + k * N[:, 0] # 영공간을 아무만큼 더해도 print(f"xp + {k:>6} · n₁ → A@x = {np.round(A @ x, 6)} 해인가: {np.allclose(A @ x, b)}") print() print("→ 해가 '무한히 많다'. 정확히는 xp 를 지나는 2차원 평면 전체다") print(" (영공간 차원이 2이므로)")

실무에서 영공간·열공간
  • 다중공선성 — 회귀에서 설명변수 하나가 다른 것들의 조합이면 ATA 의 영공간이 생겨 계수가 불안정해집니다. "왜 계수 부호가 뒤집히지?" 의 범인이 대개 이것입니다(10강).
  • 역문제 — CT·MRI 재구성처럼 관측에서 원본을 복원할 때, 영공간에 있는 성분은 원리적으로 복원 불가입니다. 그래서 정규화(regularization)로 "그럴듯한 답"을 고릅니다.
  • 제어 이론 — 도달 가능한 상태 = 열공간. "이 시스템으로 원하는 상태에 갈 수 있나?"가 곧 b ∈ C(A) 질문입니다.

6강 요약

  • 영공간 N(A) = Ax=0 의 해집합. A가 0으로 뭉개는 입력들 = 잃어버리는 정보. ℝⁿ 안에 삽니다.
  • 열공간 C(A) = A의 열들의 Span. A가 도달할 수 있는 모든 곳. ℝᵐ 안에 삽니다.
  • Ax=b 가 풀린다 ⟺ b ∈ C(A). 코드에서는 랭크 비교로 판정합니다.
  • RREF 로 피봇 열과 자유 열을 가르고, 자유 변수마다 특별해를 하나씩 만들면 그 Span 이 영공간입니다.
  • 완전해 = 특수해 + 영공간. 미분방정식의 "일반해 = 특수해 + 동차해"와 같은 구조입니다.
  • 영공간이 커지면 열공간이 작아집니다. 그 균형이 7강의 차원 정리입니다.
