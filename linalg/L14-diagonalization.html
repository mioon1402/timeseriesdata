0. 기초 다지기 — 왜 거듭제곱이 어려운가

숫자는 2100 을 바로 구할 수 있습니다. 그런데 행렬 A100 은요? 행렬 곱을 99번 해야 합니다. n×n 이면 99 × n³ 번의 곱셈이죠.

단 대각행렬이라면 이야기가 다릅니다.

대각행렬의 거듭제곱은 공짜
300210  =  31000210
  • 왜대각행렬은 축끼리 섞이지 않습니다. 각 축이 독립적으로 λ배씩 늘어날 뿐이죠
전략 · "일반 행렬을 대각행렬로 바꿔 계산하고 되돌린다." 바꾸는 방법이 고유벡터를 축으로 삼는 것입니다.

1. A = SΛS⁻¹ 유도

고유벡터 x₁, …, xn 이 서로 독립이라고 합시다. 이들을 열로 세워 행렬 S 를 만듭니다.

유도 — 두 줄
A S = A [ x1 ⋯ xn ] = [ λ1x1 ⋯ λnxn ] = S Λ  ← 각 열이 λ배 되었을 뿐
⟹ A = S Λ S−1  그리고  Λ = S−1 A S
  • S고유벡터 행렬. 열이 고유벡터
  • Λ대각행렬. 대각선에 고윳값들 (람다 대문자)
  • S−1 존재?고유벡터가 n개 독립이어야 합니다. 이게 대각화의 유일한 조건입니다
읽는 법 — 세 단계의 여정
A x 를 S Λ S−1 x 로 읽으면:

①S−1 — 고유벡터 좌표계로 갈아탄다
②Λ — 각 축을 λ배 늘린다 (여기가 전부!)
③S — 원래 좌표계로 돌아온다

복잡해 보이던 변환이 "적절한 축에서 보면 그냥 늘이기" 였던 겁니다. 이것이 8강 기저 변환(19강에서 다시)의 가장 중요한 사례입니다.

2. Aᵏ 가 붕괴한다

가운데가 약분된다
A2 = (SΛS−1)(SΛS−1) = SΛ(S−1S)ΛS−1 = SΛ2S−1
⟹   Ak = S Λk S−1
  • Λᵏ대각 원소를 각각 k제곱하면 끝. 행렬 곱이 딱 두 번으로 줄었습니다
  • 더 중요한 건k가 커질 때 무슨 일이 일어나는지 보인다는 점입니다 — λk 만 보면 되니까요

3. 대각화가 안 되는 경우

13강의 전단행렬 [[1,1],[0,1]] 을 떠올려보세요. 고윳값이 1, 1 로 중복인데 독립인 고유벡터가 하나뿐이었습니다. 그러면 S 가 특이행렬이 되어 S−1 이 없습니다.

상황대각화
고윳값이 전부 다름 ✓ 항상 가능 (다른 λ의 고유벡터는 자동으로 독립)
고윳값이 중복이지만 고유벡터가 충분 ✓ 가능 (예: 단위행렬)
고윳값이 중복이고 고유벡터가 부족 ✗ 불가능 (결손행렬, defective)
대칭행렬 ✓ 항상 가능, 게다가 직교 고유벡터로 (15강)
대각화 불가능해도 방법은 있습니다
조르당 표준형(Jordan form)이라는 "거의 대각"인 형태로 만들 수 있지만, 수치적으로 불안정해서 공학에서는 거의 안 씁니다. 대신 SVD(16강)를 쓰죠 — SVD는 어떤 행렬이든, 정사각이 아니어도 항상 가능합니다.

4. 차분방정식 — 반복하면 어디로 가나

시간에 따라 상태가 uk+1 = A uk 로 변하는 시스템을 차분방정식이라고 합니다. 그러면 uk = Ak u0 이죠.

현재 상태 uk–
‖uk‖–
고윳값–
지배 고유벡터와의 각–
장기 거동–
고유벡터로 쪼개서 보면
u0 = c1x1 + ⋯ + cnxn  ⟹  uk = c1λ1kx1 + ⋯ + cnλnkxn
  • 각 축이 따로고유벡터 방향끼리 섞이지 않으므로 각각 λk 배씩 갑니다
  • 지배 고윳값|λ| 가 가장 큰 항이 k가 커질수록 나머지를 압도합니다. 그래서 모든 시작점이 결국 그 방향으로 수렴합니다 — 위에서 확인해보세요
가장 큰 |λ|장기 거동예
> 1무한히 발산복리, 인구 폭발, 불안정한 제어
= 1정상상태로 수렴마르코프 체인, 페이지랭크
< 1원점으로 붕괴감쇠 진동, 안정한 시스템

5. 미분방정식과 안정성

시간이 연속이면 du/dt = Au 가 됩니다. 해는 스칼라 eat 와 똑같은 모양입니다.

행렬 지수함수
u(t) = eAt u(0),    eAt = I + At + (At)22! + (At)33! + ⋯
대각화하면   eAt = S eΛt S−1,   eΛt = diag( eλ₁t, …, eλₙt )
  • 무한급수가대각화 덕분에 정확한 해석적 해로 바뀝니다. Λ 의 지수함수는 대각 원소를 각각 지수함수로 바꾸면 끝이니까요
  • 주의eAeB ≠ eA+B — AB = BA 일 때만 성립합니다. 행렬은 순서가 중요하니까요(4강)
안정성 판정 — 고윳값의 실수부
λ = a + b i 일 때   eλt = eat( cos bt + i sin bt )
a < 0 → 0 으로 수렴 (안정)
a > 0 → 발산 (불안정)
a = 0 → 진폭 유지, 진동 (중립)
  • 실수부 a커지느냐 줄어드느냐를 결정
  • 허수부 b얼마나 빨리 도느냐(진동 주파수)를 결정
  • 차이 주의이산(차분)은 |λ| < 1, 연속(미분)은 Re(λ) < 0 이 안정 조건입니다. 기준이 다릅니다

6. numpy 로 확인하기

import numpy as np np.set_printoptions(precision=4, suppress=True) A = np.array([[2., 1.], [1., 2.]]) λ, S = np.linalg.eig(A) Λ = np.diag(λ) print("S (고유벡터를 열로) =") print(S) print("\nΛ =") print(Λ) print("\nS Λ S⁻¹ =") print(S @ Λ @ np.linalg.inv(S)) print("\nA 와 같은가:", np.allclose(S @ Λ @ np.linalg.inv(S), A))
k = 10 직접 = np.linalg.matrix_power(A, k) 대각화 = S @ np.diag(λ ** k) @ np.linalg.inv(S) print(f"A^{k} 직접 계산 =") print(직접) print(f"\nS Λ^{k} S⁻¹ =") print(대각화) print("\n같은가:", np.allclose(직접, 대각화)) print() print("λ^k =", λ ** k, " ← 대각 원소를 k제곱한 것뿐")
전단 = np.array([[1., 1.], [0., 1.]]) w, v = np.linalg.eig(전단) print("고윳값 =", w, " ← 1 이 두 번 (중복)") print("고유벡터 =") print(v) print("\n고유벡터 행렬의 랭크 =", np.linalg.matrix_rank(v), "/ 2") print("→ 독립인 고유벡터가 1개뿐이라 S⁻¹ 가 없다. 대각화 불가.") print() print("그래도 거듭제곱은 규칙적이다:") for k in [1, 2, 5]: print(f" 전단^{k} =", np.linalg.matrix_power(전단, k).ravel()) print("→ 위쪽 값이 k 로 '선형' 증가. 지수가 아니라서 λ^k 로 설명이 안 된다.")
# 열의 합이 1 인 행렬. 각 열이 '그 상태에서 어디로 갈 확률' M = np.array([[0.9, 0.2], # 도시 → 도시, 시골 → 도시 [0.1, 0.8]]) # 도시 → 시골, 시골 → 시골 print("열의 합 =", M.sum(axis=0), " ← 확률이므로 각 열이 1") w, v = np.linalg.eig(M) print("고윳값 =", w, " ← 하나가 정확히 1") print() u = np.array([1., 0.]) # 전부 도시에서 시작 for t in [0, 1, 5, 20, 100]: 상태 = np.linalg.matrix_power(M, t) @ u print(f" t={t:3d}: 도시 {상태[0]:.4f} 시골 {상태[1]:.4f}")
i = np.argmin(np.abs(w - 1)) 정상 = np.real(v[:, i]) 정상 = 정상 / 정상.sum() # 확률이므로 합을 1로 print("정상상태 =", 정상) print("M @ 정상 =", M @ 정상, " ← 변하지 않는다. 그래서 '정상' 상태") print() print("시작점을 바꿔도 같은 곳으로 가는가:") for 시작 in [np.array([1., 0.]), np.array([0., 1.]), np.array([0.3, 0.7])]: 끝 = np.linalg.matrix_power(M, 200) @ 시작 print(f" {시작} → {np.round(끝, 6)}") print() print("→ 두 번째 고윳값 0.7 의 성분이 0.7²⁰⁰ ≈ 0 으로 사라졌기 때문")
from scipy.linalg import expm 시스템들 = { "안정 (Re λ < 0)": np.array([[-1., 1.], [0., -2.]]), "불안정 (Re λ > 0)": np.array([[1., 0.], [0., 0.5]]), "진동 (Re λ = 0)": np.array([[0., -2.], [2., 0.]]), } u0 = np.array([1., 1.]) for 이름, B in 시스템들.items(): λs = np.linalg.eigvals(B) crit = λs.real.max() print(f"{이름} λ = {np.round(λs, 3)} 최대 실수부 = {crit:+.2f}") for t in [0., 1., 3.]: u = expm(B * t) @ u0 print(f" t={t:.0f} u = {np.round(u, 4)} ‖u‖ = {np.linalg.norm(u):.4f}") print()
from scipy.linalg import expm 직접 = expm(A) 대각화 = S @ np.diag(np.exp(λ)) @ np.linalg.inv(S) print("expm(A) =") print(직접) print("\nS e^Λ S⁻¹ =") print(대각화) print("\n같은가:", np.allclose(직접, 대각화)) print() print("무한급수를 직접 더해도 같은가 (20항까지):") from math import factorial 급수 = sum(np.linalg.matrix_power(A, n) / factorial(n) for n in range(20)) print(np.round(급수, 6)) print("일치:", np.allclose(급수, 직접))

모범 답안 보기
# 문제 1 — x축 성분만 3^100 으로 폭발, y축은 0.5^100 으로 소멸 A1 = np.array([[3., 0.], [0., 0.5]]) u = np.linalg.matrix_power(A1, 100) @ np.array([1., 1.]) print("문제 1:", u) print(" 방향 =", u / np.linalg.norm(u), " ← 사실상 (1,0). 지배 고유벡터") # 문제 2 M2 = np.array([[0.7, 0.4], [0.3, 0.6]]) w2, v2 = np.linalg.eig(M2) i2 = np.argmin(np.abs(w2 - 1)) st = np.real(v2[:, i2]); st = st / st.sum() print("\n문제 2: 정상상태 =", st, " 확인:", M2 @ st) # 문제 3 — 고윳값 -2 와 +3. 하나라도 양수면 불안정 A3 = np.array([[-2., 0.], [0., 3.]]) print("\n문제 3: λ =", np.linalg.eigvals(A3)) print(" 최대 실수부 =", np.linalg.eigvals(A3).real.max(), "> 0 → 불안정") print(" x 방향은 잦아들지만 y 방향이 폭발한다")
실무에서 대각화
  • 페이지랭크 — 웹 링크 마르코프 행렬의 고윳값 1 고유벡터가 순위입니다(20강). 실제로는 Aku 를 반복하는 멱승법을 씁니다 — 수십억 차원에서 대각화는 불가능하니까요.
  • 제어 시스템 — 극점(pole) = 고윳값. 전부 좌반평면에 있어야 안정입니다.
  • 진동 해석 — 각 고유모드가 독립적으로 진동합니다. 그래서 모드 분해가 가능하죠.
  • 주의 — 실무에서는 대각화보다 SVD(16강)를 훨씬 많이 씁니다. 항상 존재하고, 수치적으로 안정하며, 정사각이 아니어도 되니까요.

14강 요약

  • A = SΛS−1 — S는 고유벡터를 열로 세운 행렬, Λ는 고윳값 대각행렬.
  • 읽는 법: 고유벡터 좌표로 갈아타 → 각 축을 λ배 → 되돌아온다.
  • Ak = SΛkS−1 — 가운데가 약분되어 붕괴합니다.
  • 대각화 조건은 독립인 고유벡터 n개. 전단행렬처럼 부족하면 불가능합니다.
  • 차분방정식은 |λ| 가 가장 큰 항이 지배합니다 → 모든 시작점이 그 방향으로 수렴.
  • 미분방정식은 eAt = SeΛtS−1. 안정성은 고윳값의 실수부 부호가 결정합니다.
  • 안정 조건이 이산은 |λ|<1, 연속은 Re(λ)<0 — 헷갈리지 마세요.
