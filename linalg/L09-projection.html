투영과 투영행렬

손전등을 수직으로 비추면 생기는 그림자 — 그게 투영입니다. 단순해 보이지만, 이 연산 하나가 회귀분석·최소제곱법·PCA 의 심장입니다. 그리고 공식은 외울 필요가 없습니다. "오차가 직교한다"는 한 줄에서 저절로 굴러 나오거든요.

0. 기초 다지기 — 왜 하필 수직으로 내리나

상황을 정리해봅시다. 우리가 가려는 곳은 직선(또는 평면) 위인데, 목표 b 는 그 밖에 있습니다. "갈 수 있는 데까지만 가자" 라면 어디로 가야 가장 가까울까요?

가장 가까운 점 = 수직으로 내린 발
직선 위의 아무 점이나 골라 b 까지의 거리를 재보세요. 수직으로 내린 지점에서 그 거리가 최소가 됩니다. 비스듬히 가면 항상 더 멉니다 — 피타고라스 정리 때문이죠(8강).

그래서 "가장 가까운 근사"라는 최적화 문제가 "수직으로 내려라"라는 기하 문제로 바뀝니다. 이 번역이 선형대수가 최적화에 쓰이는 핵심 이유입니다.

1. 직선 위로 투영하기

먼저 가장 단순한 경우 — 벡터 a 가 만드는 직선 위로 b 를 내려봅시다.

파란 점(방향 a)과 빨간 점(목표 b)을 끌어 보세요.

방향 a–
목표 b–
계수 x̂–
그림자 p–
오차 e = b − p–
aᵀe (0이어야)–
유도 — 조건은 "오차가 a 와 직교" 하나뿐
① 그림자는 직선 위 ⟹ p = x̂ a
② 오차가 직교 ⟹ aT(b − x̂ a) = 0
③ 풀면  aTb = x̂ (aTa)  ⟹  x̂ = aTbaTa
  • x̂얼마나 가야 하는지의 배수. "엑스 햇"이라 읽습니다
  • p = a x̂그림자 벡터. p = a (aTb) / (aTa)
이 공식, 어디서 봤죠 · (aTb) / (aTa) 는 8강의 코사인 유사도와 사실상 같은 식입니다. 그리고 푸리에 계수를 구하는 식도, 회귀계수를 구하는 식도 이 모양입니다. 전부 "이 방향 성분이 얼마나 들어 있나" 를 묻고 있으니까요.

2. 부분공간으로 투영하기

이제 직선이 아니라 행렬 A 의 열들이 만드는 공간(열공간) 위로 내려봅시다. 논리는 토씨 하나 안 바뀝니다.

유도 — 오차가 모든 열과 직교
① 그림자는 열공간 안 ⟹ p = A x̂
② 오차가 모든 열과 직교 ⟹ AT(b − A x̂) = 0
③ 정리하면  ATA x̂ = ATb  ← 정규방정식 (10강)
④ x̂ = (ATA)−1ATb  ⟹  p = A(ATA)−1ATb
  • ②의 뜻ATe = 0 은 오차가 좌영공간에 있다는 뜻입니다(7강). 열공간 ⟂ 좌영공간이니 당연하죠(8강)
  • ATA 는 가역?A의 열이 선형독립이면 가역입니다. 중복된 열이 있으면 안 됩니다 — 10강에서 다룹니다

3. 투영행렬 P 와 그 성질

투영행렬
P  =  A ( ATA )−1 AT     p = P b
  • 역할어떤 벡터를 넣어도 열공간으로 눌러 줍니다
  • 주의(ATA)−1 를 따로 떼어 A−1(AT)−1 로 쪼개면 안 됩니다. A 가 정사각이 아니면 A−1 자체가 없습니다
두 가지 성질 — 기하학에서 바로 나온다
P2 = P  이미 눌린 걸 또 눌러도 그대로
PT = P  대칭행렬
  • P² = P그림자에 다시 손전등을 비추면? 제자리입니다. 이런 성질을 멱등(idempotent) 이라고 합니다
  • Pᵀ = P전치해보면 (A(ATA)−1AT)T = A((ATA)−1)TAT = P. ATA 가 대칭이라 그 역행렬도 대칭이기 때문입니다
남는 것도 투영입니다
e = b − p = (I − P) b 이므로, I − P 도 투영행렬입니다. 다만 직교 여공간(좌영공간)으로 투영하죠.

b = Pb + (I−P)b — 어떤 벡터든 열공간 성분 + 좌영공간 성분으로 유일하게 쪼개집니다. 8강에서 예고한 그 분해입니다.

4. P 를 고유값으로 읽기

13강을 미리 살짝 당겨오면, 투영행렬은 고유값이 0 아니면 1뿐입니다. 의미를 생각하면 당연합니다.

벡터 위치P 를 곱하면고유값
이미 열공간 안그대로 (Pv = v)1
직교 여공간 안원점으로 (Pv = 0)0
trace(P) = 랭크 · 고유값이 1인 게 r 개, 0인 게 나머지이므로 대각합이 곧 투영하는 공간의 차원입니다. 통계에서 자유도(degrees of freedom) 를 셀 때 정확히 이 값을 씁니다.

5. numpy 로 확인하기

import numpy as np np.set_printoptions(precision=4, suppress=True) a = np.array([2., 1.]) # 방향 b = np.array([1., 3.]) # 목표 x_hat = (a @ b) / (a @ a) p = x_hat * a # 그림자 e = b - p # 오차 print("x̂ =", x_hat) print("p =", p) print("e =", e) print() print("a · e =", a @ e, " ← 0 이면 수직으로 잘 내렸다") print("‖b‖² =", b @ b, " = ‖p‖² + ‖e‖² =", p @ p + e @ e, " (피타고라스)")
# 직선 위의 여러 점과 b 사이 거리를 재본다 print(f"{'배수 t':>8} {'점 t·a':>16} {'b 까지 거리':>12}") for t in [0.0, 0.5, x_hat - 0.3, x_hat, x_hat + 0.3, 1.5, 2.0]: 점 = t * a d = np.linalg.norm(b - 점) 표시 = " ← 최소!" if np.isclose(t, x_hat) else "" print(f"{t:8.2f} {str(np.round(점, 2)):>16} {d:12.4f}{표시}")
A = a.reshape(-1, 1) # 열이 하나인 행렬로 P = A @ np.linalg.inv(A.T @ A) @ A.T print("P =") print(P) print() print("P @ b =", P @ b, " ← 위에서 구한 p 와 같다") print() print("P² = P 인가 :", np.allclose(P @ P, P)) print("Pᵀ = P 인가 :", np.allclose(P.T, P)) print("trace(P) =", np.trace(P), " = 투영하는 공간의 차원")
A2 = np.array([[1., 0.], [0., 1.], [1., 1.]]) # 두 열이 만드는 평면 b3 = np.array([1., 2., 6.]) P2 = A2 @ np.linalg.inv(A2.T @ A2) @ A2.T p2 = P2 @ b3 e2 = b3 - p2 print("그림자 p =", p2) print("오차 e =", e2) print() print("A2ᵀ @ e (모든 열과 직교해야) =", A2.T @ e2) print("trace(P2) =", np.trace(P2), " = 평면의 차원 2 ✓") print() print("P2 의 고유값 =", np.round(np.linalg.eigvals(P2), 6), " ← 1이 2개, 0이 1개")
I = np.eye(3) Q = I - P2 print("Q = I - P 가 투영행렬인가") print(" Q² = Q :", np.allclose(Q @ Q, Q)) print(" Qᵀ = Q :", np.allclose(Q.T, Q)) print(" trace(Q) =", np.trace(Q), " = 3 - 2 = 1 (직교 여공간의 차원)") print() print("b = Pb + Qb 로 쪼개지는가") print(" Pb =", P2 @ b3) print(" Qb =", Q @ b3) print(" 합 =", P2 @ b3 + Q @ b3, " = b ?", np.allclose(P2 @ b3 + Q @ b3, b3)) print(" 두 조각이 직교? (Pb)·(Qb) =", round((P2 @ b3) @ (Q @ b3), 12))
이미 직교하는 기저라면 훨씬 쉽습니다 A 의 열이 서로 직교하고 길이가 1(정규직교)이면 ATA = I 가 되어 P = A AT 로 줄어듭니다. 역행렬 계산이 통째로 사라지죠.

그래서 11강에서 그램-슈미트로 직교 기저를 만드는 것입니다. "미리 축을 잘 세워두면 이후 계산이 공짜"라는 전략입니다.
# 직교하는 두 벡터를 단위벡터로 만들어 열로 세운다 q1 = np.array([1., 0., 1.]) / np.sqrt(2) q2 = np.array([0., 1., 0.]) Q_mat = np.column_stack([q1, q2]) print("QᵀQ =") print(Q_mat.T @ Q_mat, " ← 단위행렬") print() P_easy = Q_mat @ Q_mat.T # 역행렬 없이 P_full = Q_mat @ np.linalg.inv(Q_mat.T @ Q_mat) @ Q_mat.T print("AAᵀ 와 전체 공식이 같은가:", np.allclose(P_easy, P_full))

6. 실무: 투영이 등장하는 곳

같은 연산, 다른 이름
  • 선형회귀 — 예측값 ŷ = Pb, 잔차 e = (I−P)b. 회귀는 말 그대로 투영입니다(10강).
  • R² — 피타고라스 ‖b‖² = ‖p‖² + ‖e‖² 에서 설명된 비율이 곧 R²입니다.
  • PCA — 데이터를 주성분이 만드는 부분공간으로 투영해 차원을 줄입니다(15강).
  • 푸리에 변환 — 신호를 각 주파수 축으로 투영한 계수가 스펙트럼입니다(20강).
  • 추천 시스템 — 사용자 취향 벡터를 잠재 공간으로 투영(18강).
전부 "가진 재료로 만들 수 있는 것 중 가장 가까운 것" 을 찾는 같은 문제입니다.

9강 요약

  • 부분공간 위의 가장 가까운 점 = 수직으로 내린 발. 최적화가 기하 문제로 바뀝니다.
  • 조건은 "오차 e = b − p 가 직교" 하나뿐. 여기서 모든 공식이 나옵니다 — 외울 게 없습니다.
  • 직선: x̂ = aTb / aTa. 부분공간: ATA x̂ = ATb (정규방정식).
  • P = A(ATA)−1AT, 성질은 P² = P, PT = P.
  • 고유값은 1 아니면 0. trace(P) = 랭크 = 투영 공간의 차원.
  • I − P 도 투영행렬이며, 어떤 벡터든 두 직교 조각으로 유일하게 나뉩니다.
  • 기저가 정규직교면 P = AAT 로 줄어듭니다 → 11강의 동기.
