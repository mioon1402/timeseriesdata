0. 기초 다지기 — 랭크 1 행렬이란

랭크가 1인 행렬은 모든 열이 같은 방향인 행렬입니다. 그런 행렬은 벡터 두 개의 외적으로 항상 쓸 수 있습니다.

외적 = 랭크 1
u vT = 123 45 = 45 810 1215
  • 저장 비용3×2 = 6개 대신 u(3) + v(2) = 5개만 있으면 복원됩니다. 행렬이 커질수록 이득이 커집니다
  • 패턴모든 행이 v 의 배수, 모든 열이 u 의 배수. 단 하나의 패턴만 담고 있습니다

1. SVD를 층으로 쌓기

SVD 를 외적 합으로
A = σ1 u1v1T + σ2 u2v2T + ⋯ + σr urvrT
  • 각 항랭크 1 행렬. "패턴 하나"
  • σi그 패턴의 세기. 내림차순이라 앞쪽이 가장 중요합니다
  • r랭크. 이 개수만큼의 패턴으로 A 가 완전히 표현됩니다
앞의 k개만 남기면 — 랭크 k 근사
Ak = σ1 u1v1T + ⋯ + σk ukvkT   (k ≪ r)

3. Eckart-Young 정리

"앞의 k개만 남긴다"는 그럴듯한 휴리스틱처럼 보입니다. 그런데 이게 증명된 최적해입니다.

Eckart–Young–Mirsky 정리
랭크가 k 이하인 모든 행렬 B 에 대해
‖ A − Ak ‖ ≤ ‖ A − B ‖
  • 뜻랭크 k로 근사하는 어떤 방법을 써도 SVD 절단보다 잘할 수 없습니다
  • 오차의 크기프로베니우스 노름 기준 ‖A − Ak‖F = √(σk+1² + ⋯ + σr²) — 버린 σ 들만으로 정확히 계산됩니다
  • 2-노름 기준= σk+1. "가장 큰 버린 값"이 곧 최대 오차입니다
이게 왜 대단한가 · 보통 최적화 문제는 답을 찾기 어렵습니다. 그런데 "랭크 k 로 가장 잘 근사하라"는 문제는 SVD 한 번 돌리고 잘라내면 끝입니다. 게다가 오차를 미리 정확히 알 수 있습니다 — 버릴 σ 들만 보면 되니까요. "5% 오차 안에서 최대한 압축" 같은 요구를 정확히 맞출 수 있습니다.

4. 얼마나 이득인가

저장 용량
원본 m × n  →  랭크 k k(m + n + 1)
  • 왜u 벡터 k개(각 m개) + v 벡터 k개(각 n개) + σ k개
  • 예1000×1000 이미지(100만)에서 k=50 이면 50 × 2001 ≈ 10만 — 약 1/10
JPEG 는 SVD 를 쓰지 않습니다 실제 이미지 압축 표준(JPEG, WebP)은 이산 코사인 변환(DCT) 을 씁니다. 고정된 기저를 쓰므로 기저를 저장할 필요가 없고 훨씬 빠르거든요. SVD 는 이미지마다 U 와 V 를 통째로 저장해야 합니다.

SVD 저랭크 근사가 진짜 힘을 발휘하는 곳은 이미지가 아니라 추천 시스템·잠재 의미 분석·차원 축소입니다(18·20강). "숨은 구조를 찾는" 게 목적일 때죠.

5. 잡음 제거 — 왜 되는가

실제 데이터에는 구조와 잡음이 섞여 있습니다. 이 둘은 특이값에서 다르게 나타납니다.

특이값에서이유
구조 (신호)큰 σ 몇 개에 집중 반복되는 패턴이라 낮은 랭크로 표현됨
잡음작은 σ 에 고르게 퍼짐 무작위라 특정 패턴이 없음 → 모든 방향에 조금씩
그래서 꼬리를 자르면 · 잡음이 주로 제거되고 구조는 남습니다. 위에서 [잡음 섞기] 를 켜고 k 를 조절해보세요. k를 너무 크게 하면 잡음까지 되살아납니다 — 적당한 지점이 있습니다.

이건 머신러닝의 과적합과 정확히 같은 구조입니다. "모델을 복잡하게 할수록 잡음까지 학습한다"는 이야기죠.

6. numpy 로 확인하기

import numpy as np np.set_printoptions(precision=4, suppress=True) def 그림(n=64): y, x = np.mgrid[0:n, 0:n] / n img = 0.5 + 0.4 * np.sin(6 * np.pi * x) * np.cos(4 * np.pi * y) img += 0.35 * ((x - 0.3) ** 2 + (y - 0.65) ** 2 < 0.03) # 동그라미 img[int(.2 * n):int(.3 * n), int(.1 * n):int(.9 * n)] = 0.05 # 가로 막대 return np.clip(img, 0, 1) img = 그림() U, σ, Vt = np.linalg.svd(img) print("이미지 크기:", img.shape, " 랭크:", np.linalg.matrix_rank(img)) print("특이값 상위 8개:", np.round(σ[:8], 3)) print("특이값 하위 8개:", np.round(σ[-8:], 6)) print() 누적 = np.cumsum(σ ** 2) / np.sum(σ ** 2) for k in [1, 3, 5, 10, 20]: print(f" 상위 {k:2d}개가 담은 에너지: {누적[k-1]:.2%}")
def 근사(U, σ, Vt, k): return U[:, :k] @ np.diag(σ[:k]) @ Vt[:k] m, n = img.shape 원본크기 = m * n print(f"{'k':>4} {'상대오차':>10} {'이론값':>10} {'저장':>8} {'압축률':>8}") for k in [1, 2, 3, 5, 10, 20, 40]: Ak = 근사(U, σ, Vt, k) 실제 = np.linalg.norm(img - Ak) / np.linalg.norm(img) 이론 = np.sqrt((σ[k:] ** 2).sum()) / np.linalg.norm(img) # 버린 σ 들만으로 저장 = k * (m + n + 1) print(f"{k:>4} {실제:>10.2%} {이론:>10.2%} {저장:>8} {저장/원본크기:>8.1%}") print() print("→ '실제 오차' 와 '버린 σ 로 계산한 이론값' 이 정확히 일치한다.") print(" Eckart-Young 정리 덕분에 오차를 미리 알 수 있다.")
rng = np.random.default_rng(0) k = 5 svd_근사 = 근사(U, σ, Vt, k) svd_오차 = np.linalg.norm(img - svd_근사) print(f"SVD 랭크 {k} 근사 오차: {svd_오차:.4f}") print() print("무작위 랭크 5 행렬 중 가장 좋았던 것:") 최선 = np.inf for _ in range(2000): Bu = rng.normal(size=(64, k)) Bv = rng.normal(size=(k, 64)) B = Bu @ Bv B = B * (np.sum(img * B) / np.sum(B * B)) # 크기만 최적으로 맞춰줌 최선 = min(최선, np.linalg.norm(img - B)) print(f" {최선:.4f} ← SVD 보다 {최선/svd_오차:.1f}배 나쁘다") print() print("→ 어떤 랭크 5 행렬도 SVD 절단을 이길 수 없다 (Eckart-Young)")

# 문제 1. 랭크가 정확히 3인 행렬을 만들고, k=3 근사의 오차가 0인지 확인하세요. # (힌트: 랭크1 세 개를 더하면 됩니다) # 문제 2. 위 그림에서 오차를 5% 이하로 하려면 k 가 몇이어야 할까요? # σ 만 보고 미리 계산해보세요. # 문제 3. 무작위 행렬(구조가 없는)의 특이값은 어떤 모양일까요? # 압축이 잘 될까요? # 아래에 직접 써보세요
모범 답안 보기
rng2 = np.random.default_rng(7) # 문제 1 R = sum(np.outer(rng2.normal(size=20), rng2.normal(size=30)) for _ in range(3)) U1, s1, V1 = np.linalg.svd(R) print("문제 1: 랭크 =", np.linalg.matrix_rank(R)) print(" σ =", np.round(s1[:5], 6), " ← 4번째부터 0") A3 = U1[:, :3] @ np.diag(s1[:3]) @ V1[:3] print(" k=3 오차 =", np.linalg.norm(R - A3)) # 문제 2 — 버린 σ 로 미리 계산 전체 = np.linalg.norm(σ) for k in range(1, 30): if np.sqrt((σ[k:]**2).sum()) / 전체 <= 0.05: print(f"\n문제 2: k = {k} 면 오차 {np.sqrt((σ[k:]**2).sum())/전체:.2%}") break # 문제 3 — 무작위는 σ 가 완만하게 떨어져 압축이 안 된다 노이즈 = rng2.normal(size=(64, 64)) sn2 = np.linalg.svd(노이즈, compute_uv=False) 누적n = np.cumsum(sn2**2) / np.sum(sn2**2) print(f"\n문제 3: 무작위 행렬 — 에너지 99% 에 필요한 k = {int(np.searchsorted(누적n, 0.99))+1} / 64") print(f" 그림 — 필요한 k = {int(np.searchsorted(np.cumsum(σ**2)/np.sum(σ**2), 0.99))+1} / 64") print("→ 구조가 없으면 압축할 게 없다. 압축률이 곧 '구조의 양' 이다.")
실무에서 저랭크 근사
  • 추천 시스템 — 사용자×아이템 행렬을 저랭크로. "취향 몇 가지"로 설명(18강).
  • 잠재 의미 분석(LSA) — 문서×단어 행렬을 저랭크로 → 주제가 드러납니다.
  • 모델 압축 — 딥러닝 가중치 행렬을 저랭크로 쪼개 파라미터를 줄입니다. LoRA 가 정확히 이 아이디어입니다.
  • 이상 탐지 — 저랭크로 복원한 뒤 잔차가 큰 지점을 이상치로 봅니다.
  • 주의 — 데이터가 비선형 구조면 저랭크 근사가 잘 안 됩니다. 그럴 땐 커널 방법이나 오토인코더로 갑니다.

17강 요약

  • SVD 는 행렬을 랭크 1 층들의 가중합으로 쪼갭니다. 가중치가 σ 죠.
  • 앞의 k층만 남기면 랭크 k 근사. Eckart-Young 정리가 이게 최적임을 보장합니다.
  • 오차를 미리 정확히 계산할 수 있습니다 — √(Σ 버린 σ²).
  • 저장 용량: mn → k(m+n+1).
  • 구조는 큰 σ 에, 잡음은 작은 σ 에 퍼집니다 → 꼬리를 자르면 잡음이 걸러집니다.
  • k 가 너무 크면 잡음까지 되살아납니다 — 과적합과 같은 구조.
  • 이미지 압축의 실제 표준은 DCT 입니다. SVD 의 진짜 무대는 숨은 구조 찾기입니다.
