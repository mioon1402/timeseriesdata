0. 기초 다지기 — 복소수 3분 요약

복소수를 몰라도 괜찮습니다. 이 강의에 필요한 건 딱 세 가지뿐입니다.

① i 는 "제곱하면 −1"
i² = −1,   z = a + bi
  • 그림으로복소수는 평면 위의 점입니다. 가로가 실수부 a, 세로가 허수부 b. 그냥 2차원 벡터라고 봐도 됩니다
② 곱셈은 "회전 + 확대"
z = r·eiθ  =  r(cos θ + i sin θ)
  • r = |z|크기(원점에서의 거리) = √(a²+b²)
  • θ각도. z 를 곱한다는 건 θ만큼 돌리고 r배 늘리는 것입니다. 이 한 줄이 이 강의의 핵심입니다
  • i 를 곱하면r=1, θ=90°. 딱 90° 회전입니다. i² = −1 은 "90° 두 번 = 180° = 뒤집기"라는 뜻이죠
③ 켤레 — 허수부의 부호를 뒤집기
z̄ = a − bi,    z z̄ = a² + b² = |z|²
  • 왜 필요한가복소수에서는 z² 이 음수가 될 수 있어 길이 재기가 망가집니다. z z̄ 를 쓰면 항상 0 이상이 되죠. 3절에서 이게 그대로 벡터로 확장됩니다

1. 왜 복소 고윳값이 나오는가

13강에서 회전 행렬의 특성방정식을 풀다 막혔었죠. 다시 봅시다.

90° 회전의 고윳값
A = 0−110    det(A − λI) = λ² + 1 = 0
⇒ λ = i, −i
  • 기하학적 의미당연합니다. 90° 돌렸을 때 방향이 안 변하는 실수 벡터는 없으니까요. 실수 고유벡터가 없는 게 정상입니다
  • 그럼 λ = i 는|i| = 1 이니 크기는 안 변하고, arg(i) = 90° 이니 90° 돌린다는 뜻. 고윳값이 변환을 정확히 설명하고 있습니다
복소 고윳값을 읽는 법 — 이 두 줄이면 끝

실수 2×2 행렬의 고윳값이 λ = ρ eiθ 로 나왔다면:

|λ| = ρ → 한 번 적용할 때마다 ρ배 커진다
arg λ = θ → 한 번 적용할 때마다 θ 만큼 돈다

그래서 점을 계속 찍으면 나선이 그려집니다. ρ < 1 이면 안으로 감기고(안정), ρ > 1 이면 밖으로 퍼지고(불안정), ρ = 1 이면 동그란 궤도를 돕니다.

스펙트럼 반지름 — 안정성의 판정 기준
ρ(A) = max |λi|    Ak → 0  ⟺  ρ(A) < 1
  • 쓰임마르코프 연쇄가 수렴하는가, 순환신경망이 폭주하는가, 수치해법이 발산하는가 — 전부 이 한 숫자로 판정합니다
  • 주의ρ < 1 이어도 초반에는 크게 튈 수 있습니다. 대각화가 안 되는 행렬(19강 전단)에서 특히 그렇습니다. "결국 0으로 간다"와 "가는 길이 얌전하다"는 다른 이야기입니다

3. 켤레전치와 에르미트 행렬

복소 벡터에서는 내적의 정의를 손봐야 합니다. 안 그러면 길이가 0이 아닌데 0으로 나오는 황당한 일이 생깁니다.

그냥 전치를 쓰면 생기는 사고
z = 1+i1−i  ⇒  zTz = (1+i)² + (1−i)² = 2i + (−2i) = 0  ← 영벡터가 아닌데!
켤레전치 (에르미트 전치)
AH = ĀT     ⟨z, w⟩ = zHw     ‖z‖² = zHz
  • 하는 일전치한 뒤 모든 성분의 켤레를 취합니다. numpy 로는 A.conj().T, 또는 A.T.conj()
  • 고쳐진다위의 z 로 계산하면 zHz = |1+i|² + |1−i|² = 2 + 2 = 4, ‖z‖ = 2. 제대로 나옵니다
  • 실수라면켤레가 자기 자신이니 AH = AT. 지금까지 배운 게 특수한 경우였던 셈입니다
에르미트 행렬 = 복소판 대칭행렬
AH = A
  • 15강이 그대로고윳값이 전부 실수이고, 고유벡터가 서로 직교합니다. 스펙트럼 정리가 A = UΛUH 로 확장됩니다
  • 대각 성분자기 켤레와 같아야 하므로 반드시 실수입니다
  • 쓰이는 곳양자역학의 관측량은 전부 에르미트 연산자입니다 — "측정값(고윳값)이 실수여야 하니까"가 그 이유입니다. 신호처리의 공분산 행렬도 에르미트죠

4. 유니터리 행렬과 푸리에 변환

유니터리 = 복소판 직교행렬
UHU = I   ⇒   ‖Ux‖ = ‖x‖
  • 뜻길이와 각도를 보존합니다. 복소공간에서의 "회전"이죠. 모든 고윳값의 크기가 정확히 1입니다
  • 왜 좋은가역행렬이 그냥 켤레전치입니다. 계산이 공짜이고, 수치적으로 절대 안정합니다(11강 QR 과 같은 이유)
이산 푸리에 변환 (DFT) 도 유니터리 행렬이다
Fjk = 1⁄√N e−2πi jk / N     FHF = I
  • 놀라운 사실푸리에 변환은 그냥 행렬 곱셈입니다. 신호를 "주파수 기저"로 갈아타는 좌표 변환(19강 6절)일 뿐이죠
  • 기저벡터F 의 각 행이 특정 주파수의 사인/코사인 파입니다. 그 파들과의 내적이 곧 "그 주파수가 얼마나 들어있나"입니다(5강)
  • FFT 란이 행렬 곱셈은 O(N²) 입니다. 고속 푸리에 변환은 F 의 규칙적인 구조를 이용해 O(N log N) 으로 줄인 알고리즘입니다. 결과는 완전히 같습니다
  • 왜 유니터리가 중요한가에너지가 보존됩니다 — 파스발 정리. 시간 영역의 에너지 = 주파수 영역의 에너지

5. PCA — 배운 것의 총집합

주성분 분석은 이 강의 20개를 한 번에 쓰는 응용입니다. 각 단계가 어느 강의에서 왔는지 표시해 두었습니다.

PCA 절차
① 각 열에서 평균을 뺀다  (중심 이동)
② 공분산 행렬 C = XTX/(n−1)  (대칭! → 15강)
③ C 의 고유분해 C = QΛQT  (직교 고유벡터 → 15강)
④ 큰 λ 순으로 축을 고른다  (저랭크 근사 → 17강)
⑤ 데이터를 그 축에 정사영  (9강)
  • λ 의 뜻그 방향으로의 분산입니다. "가장 많이 퍼진 방향"이 제1주성분이죠
  • 실무에서는C 를 만들지 않고 X 의 SVD 를 직접 씁니다. X = UΣVT 이면 V 가 주성분이고 σ²/(n−1) 이 분산입니다(16강)
왜 공분산 행렬을 만들면 안 되는가
XTX 를 만드는 순간 조건수가 제곱이 됩니다(16강). X 의 조건수가 105 면 XTX 는 1010 — double 정밀도(약 1016)를 상당히 잡아먹죠. SVD 를 직접 쓰면 이 손실이 없습니다. sklearn.decomposition.PCA 도 내부에서 SVD 를 씁니다.

그리고 스케일을 반드시 맞추세요. 키(cm)와 몸무게(kg)를 그대로 넣으면 단위가 큰 쪽이 제1주성분을 독차지합니다.

이게 거듭제곱법(13강)입니다. 웹 전체(수십억 페이지)에서도 행렬 곱셈 몇십 번이면 끝나죠. 고유벡터를 정직하게 구하는 건 불가능하지만, 필요한 건 λ=1 짜리 하나뿐이라 거듭제곱법이 완벽하게 맞아떨어집니다.
페이지랭크 방정식
G = d·A + (1−d)⁄n J     G r = r  ← λ = 1 인 고유벡터!
  • A링크 행렬. 페이지 j 가 내보내는 링크에 자기 점수를 똑같이 나눠줍니다. 열의 합이 1 이 되죠(확률행렬)
  • d = 0.85감쇠 계수. 서퍼가 85% 확률로 링크를 따라가고, 15% 확률로 아무 페이지나 새로 엽니다
  • J전부 1인 행렬. "아무 데나 점프"를 담당합니다
  • 왜 감쇠가 필요한가나가는 링크가 없는 페이지는 점수를 먹고 사라집니다. 서로만 링크하는 무리는 점수를 독식하고요. 점프가 이 두 문제를 한 번에 없앱니다. 그리고 λ=1 고유벡터가 유일함을 보장합니다(페론-프로베니우스 정리)
  • 수렴 속도두 번째로 큰 고윳값의 크기가 정확히 d 입니다. d=0.85 면 한 번 곱할 때마다 오차가 0.85배씩 줄어듭니다. 위 도구의 마지막 칸을 보세요

7. 희소행렬 — 진짜 큰 문제

웹 링크 행렬은 수십억 × 수십억입니다. 다 저장하면 우주의 원자보다 많은 숫자가 필요하죠. 어떻게 할까요?

희소행렬 — 0이 아닌 것만 저장한다
1,000,000 × 1,000,000 밀집 → 8 TB
같은 크기, 행마다 10개만 0이 아니면 → 약 120 MB
  • 저장 방식(행, 열, 값) 세 쌍만 적습니다. scipy 의 csr_matrix 가 표준이죠
  • 할 수 있는 것행렬 × 벡터는 아주 빠릅니다. 그래서 거듭제곱법·켤레기울기법 같은 반복법이 가능합니다
  • 할 수 없는 것역행렬과 LU 분해는 피하세요. 0 이던 자리가 계산 중에 0이 아니게 되면서(fill-in) 메모리가 폭발합니다
  • 교훈큰 문제에서는 "A 를 분해한다"가 아니라 "Ax 를 계산한다"만 허용됩니다. 현대 수치선형대수의 갈림길이 여기입니다

8. numpy 로 확인하기

① 복소 고윳값은 회전각을 알려준다

import numpy as np np.set_printoptions(precision=4, suppress=True) def 회전(도): t = np.radians(도) return np.array([[np.cos(t), -np.sin(t)], [np.sin(t), np.cos(t)]]) for 도 in (90, 30, 180): λ = np.linalg.eigvals(회전(도)) 크기 = np.abs(λ[0]) 각도 = np.degrees(np.angle(λ[0])) print(f"{도:3d}° 회전 → λ = {np.round(λ, 4)}" f" |λ| = {크기:.4f} arg λ = {abs(각도):.1f}°") print("\n→ |λ| 는 확대율, arg λ 는 회전각. 고윳값이 변환을 그대로 설명한다.")

② 회전처럼 안 보이는 행렬도 사실은 회전

import numpy as np np.set_printoptions(precision=4, suppress=True) t = np.radians(32) R = 0.95 * np.array([[np.cos(t), -np.sin(t)], [np.sin(t), np.cos(t)]]) B = np.array([[1.6, 0.], [0., 1.]]) # 가로로 늘려서 찌그러뜨린다 A = B @ R @ np.linalg.inv(B) print("A =\n", A, " ← 회전 행렬처럼 안 보인다") λ = np.linalg.eigvals(A) print("\nλ =", np.round(λ, 4)) print("|λ| =", round(float(np.abs(λ[0])), 4), " ← 0.95, 한 걸음마다 5% 줄어든다") print("arg λ =", round(float(np.degrees(np.angle(λ[0]))), 2), "° ← 한 걸음마다 32도 회전") x = np.array([3., 0.]) for k in (0, 10, 40): print(f" A^{k:2d} x = {np.round(np.linalg.matrix_power(A, k) @ x, 4)}" f" 길이 {np.linalg.norm(np.linalg.matrix_power(A, k) @ x):.4f}")

③ 켤레전치가 왜 필요한가

import numpy as np z = np.array([1 + 1j, 1 - 1j]) print("z =", z) print("zᵀz =", z @ z, " ← 영벡터가 아닌데 0 이다!") print("zᴴz =", np.vdot(z, z), " ← 켤레전치를 쓰면 제대로 나온다") print("‖z‖ =", np.linalg.norm(z)) print() print("np.vdot 은 첫 인자를 자동으로 켤레 취한다:", np.allclose(np.vdot(z, z), z.conj() @ z))

④ 에르미트 행렬 — 고윳값이 전부 실수

import numpy as np np.set_printoptions(precision=4, suppress=True) H = np.array([[2 + 0j, 1 - 1j], [1 + 1j, 3 + 0j]]) print("Hᴴ = H 인가:", np.allclose(H, H.conj().T)) λ, U = np.linalg.eigh(H) # eigh 는 에르미트 전용 print("고윳값 =", λ, " ← 전부 실수") print("\n고유벡터가 직교하는가 (UᴴU = I):", np.allclose(U.conj().T @ U, np.eye(2))) print("복원 UΛUᴴ = H:", np.allclose(U @ np.diag(λ) @ U.conj().T, H)) print("\n대각 성분은 반드시 실수:", H[0, 0], H[1, 1])

⑤ 푸리에 변환은 유니터리 행렬 곱셈이다

import numpy as np np.set_printoptions(precision=4, suppress=True) N = 4 j, k = np.meshgrid(np.arange(N), np.arange(N), indexing="ij") F = np.exp(-2j * np.pi * j * k / N) / np.sqrt(N) print("F =\n", np.round(F, 3)) print("\n유니터리인가 (FᴴF = I):", np.allclose(F.conj().T @ F, np.eye(N))) print("고윳값의 크기 (전부 1):", np.round(np.abs(np.linalg.eigvals(F)), 4)) x = np.array([1., 2., 3., 4.]) print("\nF x =", np.round(F @ x, 4)) print("np.fft/√N =", np.round(np.fft.fft(x) / np.sqrt(N), 4)) print("\n에너지 보존 (파스발): ‖x‖ =", round(float(np.linalg.norm(x)), 6), " ‖Fx‖ =", round(float(np.linalg.norm(F @ x)), 6))

⑥ PCA — 공분산 고유분해와 SVD 가 같다

import numpy as np np.set_printoptions(precision=4, suppress=True) rng = np.random.default_rng(3) X = rng.normal(size=(200, 3)) @ np.array([[2., 1., 0.], [0., 1., 0.], [0., 0., 0.3]]) Xc = X - X.mean(axis=0) # ① 중심 이동 # 길 A — 공분산 행렬의 고유분해 C = Xc.T @ Xc / (len(X) - 1) # ② 대칭행렬 λ = np.sort(np.linalg.eigvalsh(C))[::-1] # ③ 고유분해 # 길 B — X 의 SVD (실무에서 쓰는 길) U, s, Vt = np.linalg.svd(Xc, full_matrices=False) 분산 = s ** 2 / (len(X) - 1) print("공분산 고윳값 =", λ) print("SVD 로 구한 분산 =", 분산) print("같은가:", np.allclose(λ, 분산)) print() print("설명 비율 =", np.round(분산 / 분산.sum() * 100, 2), "%") print("→ 앞의 2개로", round(float((분산[:2].sum() / 분산.sum()) * 100), 1), "% 를 설명한다.")

⑦ AᵀA 를 만들면 조건수가 제곱된다 (직접 측정)

import numpy as np rng = np.random.default_rng(0) U0, _ = np.linalg.qr(rng.normal(size=(50, 6))) V0, _ = np.linalg.qr(rng.normal(size=(6, 6))) X = U0 @ np.diag([1e3, 1e2, 10, 1, 0.1, 3.7e-3]) @ V0.T cX = np.linalg.cond(X) cC = np.linalg.cond(X.T @ X) print(f"X 의 조건수 = {cX:.3e}") print(f"XᵀX 의 조건수 = {cC:.3e}") print(f"비율 = {cC / cX:.3e} ← 대략 조건수만큼 나빠졌다 (제곱)") print(f"\ndouble 정밀도 여유 ≈ 1e16 이므로 XᵀX 는 유효숫자를 크게 잃는다.") print("→ PCA·최소제곱은 공분산을 만들지 말고 SVD/QR 을 직접 쓴다.")

⑧ 페이지랭크 — 거듭제곱법과 고유벡터가 일치

import numpy as np np.set_printoptions(precision=4, suppress=True) 이름 = ["A", "B", "C", "D"] 링크 = {0: [1, 2], 1: [2], 2: [0], 3: [2]} # 페이지 j → 어디로 n = 4 A = np.zeros((n, n)) for j, outs in 링크.items(): if outs: for i in outs: A[i, j] = 1 / len(outs) else: A[:, j] = 1 / n # 막다른 페이지는 균등 분배 d = 0.85 G = d * A + (1 - d) / n * np.ones((n, n)) r = np.ones(n) / n # ① 거듭제곱법 for k in range(1, 41): r = G @ r if k in (1, 3, 10, 40): print(f" {k:2d}회 반복: {np.round(r, 4)}") λ, V = np.linalg.eig(G) # ② 고유벡터로 직접 i = int(np.argmin(np.abs(λ - 1))) 직접 = np.real(V[:, i]); 직접 = 직접 / 직접.sum() print("\nλ = 1 고유벡터:", np.round(직접, 4)) print("두 방법이 같은가:", np.allclose(r, 직접)) print("\n순위:", " > ".join(이름[i] for i in np.argsort(-r))) print("두 번째 고윳값 크기 =", round(float(np.sort(np.abs(λ))[-2]), 4), " ← 감쇠계수 d 와 같다")

⑨ 희소행렬 — 메모리 차이를 실제로 재보기

import numpy as np from scipy import sparse n = 4000 rng = np.random.default_rng(1) 밀집 = np.zeros((n, n)) 행 = rng.integers(0, n, 20000) 열 = rng.integers(0, n, 20000) 밀집[행, 열] = 1.0 # 0.125% 만 채운다 희소 = sparse.csr_matrix(밀집) print(f"밀집 행렬 : {밀집.nbytes / 1e6:8.2f} MB") print(f"희소 행렬 : {(희소.data.nbytes + 희소.indices.nbytes + 희소.indptr.nbytes) / 1e6:8.2f} MB") print(f"0 이 아닌 비율 : {희소.nnz / n**2 * 100:.3f}%") x = rng.normal(size=n) print("\n행렬 × 벡터 결과가 같은가:", np.allclose(밀집 @ x, 희소 @ x)) print("→ 거듭제곱법은 '행렬 × 벡터' 만 쓰므로 희소행렬로 그대로 돌아간다.")

  2. 유니터리 행렬의 행렬식은 어떤 값일까요? (힌트: |det| 을 생각해보세요)
  3. 페이지랭크에서 d = 1 로 두면 어떤 문제가 생길까요? 위 도구에서 감쇠 계수를 1로 놓고 확인해보세요.
모범 답안 보기
import numpy as np np.set_printoptions(precision=4, suppress=True) # 문제 1 — 0.6²+0.8²=1 이므로 순수 회전. |λ|=1 → 영원히 돌기만 한다 A1 = np.array([[0.6, -0.8], [0.8, 0.6]]) λ1 = np.linalg.eigvals(A1) print("문제 1: λ =", np.round(λ1, 4), " |λ| =", round(float(np.abs(λ1[0])), 6)) print(" arg λ =", round(float(np.degrees(np.angle(λ1[0]))), 2), "°") print(" → |λ|=1 인 순수 회전. 커지지도 작아지지도 않고 계속 돈다.") A100 = np.linalg.matrix_power(A1, 100) print(" A¹⁰⁰ =\n", A100) print(" 누적 회전각 =", round(float(np.degrees(np.arctan2(A100[1, 0], A100[0, 0])) % 360), 2), "°") # 문제 2 — |det U| = 1 (복소수이므로 단위원 위의 아무 값) N = 4 j, k = np.meshgrid(np.arange(N), np.arange(N), indexing="ij") F = np.exp(-2j * np.pi * j * k / N) / np.sqrt(N) print("\n문제 2: det F =", np.round(np.linalg.det(F), 4), " |det F| =", round(float(np.abs(np.linalg.det(F))), 6)) print(" → 항상 |det| = 1. UᴴU=I 의 양변에 det 를 취하면 |det U|²=1 이 나온다.") print(" 실수 직교행렬이면 det = ±1 (회전 +1, 반사 −1 — 19강).") # 문제 3 — d=1 이면 막다른 페이지·독점 무리 문제가 살아난다 링크 = {0: [1, 2], 1: [2], 2: [0], 3: [2]} n = 4 A = np.zeros((n, n)) for jj, outs in 링크.items(): for i in outs: A[i, jj] = 1 / len(outs) r = np.ones(n) / n for _ in range(200): r = A @ r print("\n문제 3: d=1 일 때 r =", np.round(r, 4)) print(" → D 는 들어오는 링크가 없어 점수가 정확히 0 이 된다.") print(" A·B·C 끼리만 점수를 돌려 D 는 영원히 소외된다.") λA = np.linalg.eigvals(A) print(" 두 번째 고윳값 크기 =", round(float(np.sort(np.abs(λA))[-2]), 4), "← 1 에 가까워 수렴이 느려진다") print(" 감쇠(1−d)는 '아무 데나 점프' 를 넣어 이 두 문제를 한 번에 없앤다.")
실무에서
  • 안정성 판정 — 제어·시계열·RNN 에서 max|λ| 이 1을 넘는지가 발산 여부를 가릅니다.
  • 신호처리 — np.fft, scipy.signal. 스펙트로그램·필터 설계가 전부 유니터리 기저 변환입니다.
  • 차원 축소 — sklearn.decomposition.PCA, TruncatedSVD(희소행렬용). 시각화·잡음 제거·전처리에 씁니다.
  • 그래프 분석 — networkx.pagerank, 스펙트럴 클러스터링(라플라시안 행렬의 고유벡터).
  • 대규모 계산 — scipy.sparse.linalg.eigsh / svds / cg. 행렬 × 벡터만 쓰는 반복법들입니다.

20강 요약

  • 복소 고윳값 = 회전. |λ| 이 확대율, arg λ 가 회전각입니다.
  • 스펙트럼 반지름 ρ(A) = max|λ| 이 1보다 작으면 Ak → 0. 안정성의 판정 기준입니다.
  • 복소공간에서는 전치 대신 켤레전치 AH 를 씁니다. 안 그러면 길이가 망가집니다.
  • 에르미트(AH=A) = 복소판 대칭행렬 → 고윳값 실수, 고유벡터 직교.
  • 유니터리(UHU=I) = 복소판 직교행렬 → 길이 보존. DFT 가 그 대표입니다.
  • PCA = 공분산의 고유분해 = X 의 SVD. 실무에서는 SVD 를 직접 쓰세요.
  • 페이지랭크 = λ=1 인 고유벡터를 거듭제곱법으로 구하기.
  • 큰 문제에서는 희소행렬 + 반복법. 역행렬과 LU 는 쓰지 않습니다.

9. 20강 전체를 한 장으로

여기까지 오셨습니다. 배운 것을 하나의 흐름으로 정리합니다.

1부 — 벡터와 공간 (1~9강)
벡터는 화살표이자 데이터 한 줄. 내적이 길이와 각도를 준다.
행렬 × 벡터 = 열들의 선형결합. 행렬은 변환이다.
연립방정식은 소거로 푼다. 해는 특수해 + 영공간.
네 부분공간이 행렬의 모든 것을 설명한다. 정사영은 가장 가까운 점 찾기.
2부 — 분해 (10~17강)
해가 없으면 최소제곱. QR 로 안정적으로 푼다.
행렬식은 부피 배율. 고윳값은 방향이 안 변하는 축.
대각화 A=BΛB−1 — 좌표계를 갈아타면 단순해진다.
대칭행렬은 항상 직교 대각화된다. SVD 는 모든 행렬에 통한다.
저랭크 근사 — 큰 σ 몇 개면 충분하다.
3부 — 응용 (18~20강)
의사역행렬 — 역행렬이 없어도 가장 합리적인 답.
선형변환의 기하학 — 행렬의 열은 기저벡터의 행선지.
복소 고윳값은 회전. PCA · 페이지랭크 · 푸리에 는 전부 고유벡터 이야기.
가장 중요한 한 가지를 고른다면

"어려운 문제는 좌표계를 잘못 골라서 어려운 것이다."

대각화도, SVD 도, PCA 도, 푸리에 변환도 전부 같은 이야기입니다 — 문제에 맞는 축을 찾아 갈아타면, 얽혀 있던 것이 따로따로 풀립니다. 그 축을 찾는 방법이 고유벡터와 특이벡터였습니다.
