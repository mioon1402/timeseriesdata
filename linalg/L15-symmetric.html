대칭행렬과 양의 정부호

데이터 공학에서 만나는 행렬은 이상하리만치 자주 대칭입니다 — 공분산 행렬, ATA, 그래프의 인접 행렬, 헤시안. 우연이 아닙니다. 그리고 대칭행렬은 모든 것이 잘 풀립니다 — 고윳값이 전부 실수이고, 고유벡터가 저절로 직교합니다.

0. 기초 다지기 — 왜 대칭행렬이 자주 나오나

대칭행렬은 ST = S, 즉 대각선을 기준으로 거울처럼 같은 행렬입니다. sij = sji 이죠.

"관계"를 담으면 대칭이 됩니다
A와 B의 상관관계는 B와 A의 상관관계와 같습니다. 두 도시 사이의 거리도 방향에 무관하죠. 친구 관계도 서로에게 성립합니다.

이렇게 순서가 상관없는 관계를 행렬로 담으면 자동으로 대칭이 됩니다. 데이터 분석이 결국 "변수들 사이의 관계"를 다루는 일이라 대칭행렬이 계속 나오는 겁니다.
대칭행렬어디서
공분산 행렬 Σ통계·PCA. Cov(X,Y) = Cov(Y,X)
ATA최소제곱(10강), SVD(16강). 항상 대칭입니다
헤시안 행렬 H최적화. 편미분 순서가 무관하므로 대칭
인접 행렬무방향 그래프. 소셜 네트워크
거리·유사도 행렬클러스터링, 커널 방법
import numpy as np np.set_printoptions(precision=4, suppress=True) rng = np.random.default_rng(0) for m, n in [(5, 3), (3, 7), (4, 4)]: A = rng.normal(size=(m, n)) S = A.T @ A print(f"A 가 {m}×{n} → AᵀA 는 {S.shape}, 대칭인가: {np.allclose(S, S.T)}") print() print("증명: (AᵀA)ᵀ = Aᵀ(Aᵀ)ᵀ = AᵀA ← 4강의 (AB)ᵀ = BᵀAᵀ")

1. 스펙트럼 정리 — S = QΛQᵀ

스펙트럼 정리 (Spectral Theorem)
① 실수 대칭행렬의 고윳값은 항상 실수다
② 서로 다른 고윳값의 고유벡터는 항상 직교한다
⟹   S = Q Λ QT
  • Q직교행렬(11강). 고유벡터가 정규직교기저를 이룹니다
  • QT14강의 S−1 자리에 전치가 들어왔습니다. Q−1 = QT 이니까요 — 역행렬 계산이 사라집니다
  • 항상 대각화대칭행렬은 결손행렬이 될 수 없습니다. 고윳값이 중복이어도 고유벡터가 충분히 나옵니다
②의 증명 — 세 줄
Sx = λx, Sy = μy, λ ≠ μ 라 하면
λ(xTy) = (Sx)Ty = xTSTy = xTSy = μ(xTy)
⟹ (λ − μ)(xTy) = 0, 그런데 λ ≠ μ 이므로 xTy = 0 ∎

ST = S 를 쓴 가운데 단계가 전부입니다. 대칭이 아니면 이 증명이 무너집니다.
외적 합으로 읽으면
S = λ1 q1q1T + λ2 q2q2T + ⋯ + λn qnqnT
  • q qT9강의 투영행렬입니다 (정규직교이므로 P = qqT)
  • 읽는 법"S 는 서로 수직인 방향으로의 투영들을 λ배씩 섞은 것"
  • 4강 ④관점행렬 곱의 외적 합 관점 그대로입니다. 16·17강에서 이 형태가 압축의 열쇠가 됩니다

2. 양의 정부호 — 네 가지 동치 조건

대칭행렬 중에서도 고윳값이 전부 양수인 것을 양의 정부호(Positive Definite, PD) 라고 합니다. 최적화 이론의 중심에 있는 개념이죠.

정의
모든 x ≠ 0 에 대해   xTS x > 0
  • xTSx이차 형식(quadratic form). 벡터를 넣으면 숫자 하나가 나옵니다 — 일종의 "에너지"
관점조건확인법
① 에너지모든 x≠0 에 대해 xTSx > 0 정의. 직접 확인은 어려움
② 고윳값모든 λi > 0 eigvalsh — 가장 직관적
③ 피봇소거했을 때 모든 피봇 > 0 3강의 소거. 가장 빠름
④ 소행렬식좌상단부터의 모든 선행 주소행렬식 > 0 손으로 작은 행렬 판정할 때
넷 중 하나만 확인하면 됩니다 · 서로 완전히 동치입니다. 실무 코드에서는 np.linalg.cholesky 가 성공하는지로 판정하는 게 가장 빠릅니다 — 촐레스키 분해는 PD 일 때만 성공하거든요.

최적화에서 왜 중요한가 · 비용 함수를 최소화할 때, 그 지점의 헤시안 행렬이 PD 이면 그래프가 그릇 모양이라 진짜 최소점임이 보장됩니다.

부정부호면 말안장점(saddle point) — 어떤 방향으로는 최소, 다른 방향으로는 최대입니다. 딥러닝에서 학습이 "멈춘 것 같은데 최소가 아닌" 상황의 정체가 이것입니다.

4. 타원의 축이 곧 고유벡터

위 그림에서 고유벡터 축을 켜 보세요. 타원의 장축·단축과 정확히 일치합니다.

타원의 형태는 고유분해가 결정한다
축의 방향 = 고유벡터 q1, …, qn
축의 반지름 = 1 / √λi
  • 주의고윳값이 클수록 축이 짧습니다(역수·제곱근). 그 방향으로 함수가 가파르게 올라가 = 1 에 빨리 닿기 때문이죠
  • 최적화에서고윳값 비율(조건수)이 크면 타원이 길쭉합니다 → 경사하강법이 지그재그로 느리게 갑니다

5. Rayleigh 몫과 PCA

Rayleigh 몫
R(x)  =  xT S xxT x    λmin ≤ R(x) ≤ λmax
  • 최댓값가장 큰 고윳값. 그때 x 는 그 고유벡터
  • 최솟값가장 작은 고윳값. 마찬가지
  • 쓸모고윳값을 최적화 문제로 바꿔 풉니다. 거대한 행렬에서 가장 큰 고윳값만 근사로 찾을 때 씁니다(멱승법)
PCA 는 이 두 가지를 합친 것입니다
데이터의 공분산 행렬(대칭!)을 만들고, "어느 방향으로 투영해야 분산이 최대인가?" 를 묻습니다.

그런데 그 질문이 정확히 Rayleigh 몫의 최대화이고, 답은 가장 큰 고윳값의 고유벡터 — 즉 제1주성분입니다.

고유벡터가 서로 직교하므로(스펙트럼 정리) 주성분들도 자동으로 직교하고, 그래서 서로 중복되지 않는 정보를 담습니다.

S = np.array([[4., 1.], [1., 3.]]) λ, Q = np.linalg.eigh(S) # 대칭 전용 (13강) print("고윳값 =", λ, " ← 전부 실수") print("\n고유벡터 Q =") print(Q) print("\nQᵀQ =") print(np.round(Q.T @ Q, 12), " ← 직교행렬") print("\nQ Λ Qᵀ =") print(Q @ np.diag(λ) @ Q.T) print("S 와 같은가:", np.allclose(Q @ np.diag(λ) @ Q.T, S))
합 = sum(λ[i] * np.outer(Q[:, i], Q[:, i]) for i in range(2)) print("Σ λᵢ qᵢqᵢᵀ =") print(합) print("S 와 같은가:", np.allclose(합, S)) print() for i in range(2): P = np.outer(Q[:, i], Q[:, i]) print(f"q{i+1}q{i+1}ᵀ 가 투영행렬인가: P²=P {np.allclose(P@P, P)}, Pᵀ=P {np.allclose(P.T, P)}")
def 판정(S, 이름): λ = np.linalg.eigvalsh(S) # 피봇 (소거) U = S.astype(float).copy() 피봇 = [] ok = True for i in range(len(U)): if abs(U[i, i]) < 1e-12: ok = False break 피봇.append(U[i, i]) for j in range(i + 1, len(U)): U[j] -= U[j, i] / U[i, i] * U[i] # 선행 주소행렬식 소 = [np.linalg.det(S[:k, :k]) for k in range(1, len(S) + 1)] # 촐레스키 try: np.linalg.cholesky(S) chol = True except np.linalg.LinAlgError: chol = False print(f"[{이름}]") print(f" ② 고윳값 {np.round(λ, 4)} 전부 > 0 : {bool((λ > 1e-12).all())}") print(f" ③ 피봇 {np.round(피봇, 4) if ok else '소거 실패'} 전부 > 0 : {ok and all(p > 1e-12 for p in 피봇)}") print(f" ④ 소행렬식 {np.round(소, 4)} 전부 > 0 : {all(d > 1e-12 for d in 소)}") print(f" 촐레스키 성공: {chol}") print() 판정(np.array([[4., 1.], [1., 3.]]), "양의 정부호") 판정(np.array([[1., 1.], [1., 1.]]), "반정부호 (λ 하나가 0)") 판정(np.array([[1., 2.], [2., 1.]]), "부정부호 (말안장)")
rng = np.random.default_rng(0) x들 = rng.normal(size=(2000, 2)) for 이름, Mx in [("PD", np.array([[4., 1.], [1., 3.]])), ("부정", np.array([[1., 2.], [2., 1.]]))]: 에너지 = np.einsum('ij,jk,ik->i', x들, Mx, x들) # 각 x 에 대해 xᵀSx print(f"[{이름}] 최소 {에너지.min():8.3f} 최대 {에너지.max():8.3f} " f"음수 비율 {(에너지 < 0).mean():.1%}") print() print("→ PD 는 어떤 x 를 넣어도 양수. 부정부호는 방향에 따라 부호가 바뀐다.")
S = np.array([[4., 1.], [1., 3.]]) λ = np.linalg.eigvalsh(S) 각도 = np.linspace(0, np.pi, 721) 값 = [(np.array([np.cos(t), np.sin(t)]) @ S @ np.array([np.cos(t), np.sin(t)])) for t in 각도] print(f"Rayleigh 몫의 최솟값 = {min(값):.6f}") print(f" 최댓값 = {max(값):.6f}") print(f"고윳값 = {λ}") print() best = 각도[int(np.argmax(값))] print(f"최댓값이 나오는 방향 = {np.round([np.cos(best), np.sin(best)], 4)}") print(f"가장 큰 고윳값의 고유벡터 = {np.round(np.linalg.eigh(S)[1][:, -1], 4)}") print("→ 같은 방향 (부호는 다를 수 있음)")
# 길쭉한 방향으로 퍼진 데이터를 만든다 rng = np.random.default_rng(1) 기본 = rng.normal(size=(400, 2)) * np.array([3.0, 0.6]) 각 = np.deg2rad(30) 회전 = np.array([[np.cos(각), -np.sin(각)], [np.sin(각), np.cos(각)]]) X = 기본 @ 회전.T X = X - X.mean(axis=0) # 평균을 0으로 (PCA 의 필수 단계) C = np.cov(X, rowvar=False) # 공분산 행렬 — 대칭이다 print("공분산 행렬 =") print(C, " 대칭:", np.allclose(C, C.T)) print() λc, Qc = np.linalg.eigh(C) 순서 = np.argsort(λc)[::-1] # 큰 것부터 λc, Qc = λc[순서], Qc[:, 순서] print("고윳값(=각 주성분의 분산) =", np.round(λc, 4)) print("설명 비율 =", np.round(λc / λc.sum(), 4)) print() print("제1주성분 방향 =", np.round(Qc[:, 0], 4)) print("실제 만든 방향 =", np.round([np.cos(각), np.sin(각)], 4), " ← 30°") print() print("→ 데이터가 가장 넓게 퍼진 방향을 정확히 찾아냈다.")
PCA 전에 평균을 빼는 걸 잊지 마세요 공분산은 평균 중심을 가정합니다. 안 빼면 첫 번째 주성분이 데이터의 중심 방향을 가리켜버려 아무 의미가 없습니다.

15강 요약

  • "관계"를 담으면 행렬이 대칭이 됩니다. 공분산·ATA·헤시안·인접행렬.
  • 스펙트럼 정리: 고윳값은 전부 실수, 고유벡터는 서로 직교 ⟹ S = QΛQT. 역행렬이 전치로 대체됩니다.
  • S = Σ λᵢqᵢqᵢT — 수직 방향 투영들의 가중합입니다.
  • 양의 정부호: 에너지 > 0 ⟺ 고윳값 > 0 ⟺ 피봇 > 0 ⟺ 선행 소행렬식 > 0. 코드에서는 촐레스키 성공 여부가 가장 빠릅니다.
  • PD = 그릇(유일한 최소점), PSD = 평평한 골짜기, 부정부호 = 말안장.
  • xTSx = 1 은 타원이고, 축 방향 = 고유벡터, 축 반지름 = 1/√λ.
  • PCA = 공분산 행렬(대칭)의 Rayleigh 몫 최대화 = 가장 큰 고윳값의 고유벡터.
