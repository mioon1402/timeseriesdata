연립방정식을 보는 두 가지 눈

중고등학교에서 배운 연립방정식은 "두 직선이 만나는 점"이었습니다. 틀린 건 아니지만, 차원이 조금만 올라가도 머릿속에서 그림이 무너집니다. 선형대수는 같은 문제를 완전히 다르게 봅니다 — 그리고 그 새 관점은 1000차원에서도 그대로 살아남습니다.

0. 기초 다지기 — 연립방정식이란 무엇인가

먼저 용어부터 확실히 하고 갑시다. 이 절은 이미 아는 분은 건너뛰어도 됩니다.

카페에서 시작하는 이야기
아메리카노(2,000원)와 라떼(3,000원)를 합쳐서 5잔 샀고, 13,000원을 냈습니다. 각각 몇 잔씩 샀을까요?

아메리카노를 x잔, 라떼를 y잔이라 하면:
x + y = 5    ← 잔 수
2x + 3y = 13  ← 금액(천원)

이렇게 미지수가 여러 개인 방정식 여러 개를 한 묶음으로 놓고 "전부 동시에 성립하는 값"을 찾는 것이 연립방정식(정확히는 선형방정식계)입니다. "선형(Linear)"이라는 말은 미지수가 1차로만 등장한다는 뜻입니다.

용어위 예에서뜻
미지수 (변수)x, y 우리가 찾으려는 값
계수 (coefficient)1, 1, 2, 3 미지수 앞에 곱해진 숫자
상수항 (우변)5, 13 등호 오른쪽의 목표값
해x=2, y=3 모든 식을 동시에 만족시키는 값
이런 건 "선형"이 아닙니다 x², xy, √x, sin x, 1/x 처럼 미지수가 1차를 벗어나면 선형방정식이 아닙니다. 이 과목이 다루는 건 오직 1차짜리입니다. 대신 그 대가로 차원을 마음껏 올릴 수 있습니다 — 미지수가 100만 개여도 방법이 똑같습니다.

1. Row picture — 직선들의 교점

첫 번째 관점은 익숙한 방식입니다. 방정식계를 가로줄(행, Row) 단위로 읽는 겁니다.

x + y = 5 를 만족하는 (x, y) 를 전부 찍어보면 직선 하나가 됩니다. 2x + 3y = 13 도 마찬가지로 또 다른 직선이죠. 두 식을 동시에 만족하는 점은 두 직선이 겹치는 지점, 즉 교점입니다.

행 하나 = 도형 하나 · 미지수 2개면 직선, 3개면 평면, 그 이상이면 초평면(hyperplane). 해는 그 도형들이 전부 겹치는 자리입니다. 직관적이지만 4차원부터는 상상이 불가능합니다 — 이게 이 관점의 한계입니다.

2. Column picture — 벡터를 섞어 목표 만들기

두 번째 관점이 선형대수의 진짜 무기입니다. 이번엔 세로줄(열, Column) 단위로 묶습니다. x에 곱해진 계수들끼리, y에 곱해진 계수들끼리 모아 각각 벡터로 만드는 거죠.

같은 식, 다른 묶음
행으로 읽으면
2x − y = 1  ,  x + y = 5

열로 묶으면
x 21 + y −11  =  15
  • 왼쪽 열x의 계수 2와 1을 위아래로 모은 벡터
  • 오른쪽 열y의 계수 −1과 1을 모은 벡터
  • 우변두 상수항 1과 5를 모은 목표 벡터

두 표현은 글자 하나 다르지 않은 같은 식입니다. 단지 묶는 방향이 다를 뿐이죠. 그런데 질문의 성격이 완전히 바뀝니다.

질문이 이렇게 바뀝니다
Row picture: "두 직선은 어디서 만나는가?"
Column picture: "첫 번째 벡터를 x배, 두 번째 벡터를 y배해서 더하면 목표 벡터에 도달할 수 있는가?"

뒤쪽은 1강에서 배운 선형결합 그 자체입니다. 그리고 이 질문은 차원이 아무리 올라가도 문장이 안 변합니다.

4. 해가 없거나 무한히 많을 때

위에서 [평행]과 [겹침]을 눌러보세요. 여기서 두 관점의 차이가 확 드러납니다.

Row pictureColumn picture
해 1개 두 직선이 한 점에서 교차 두 열벡터가 서로 다른 방향 → 평면 어디든 도달 가능
해 없음 두 직선이 평행해서 안 만남 두 열벡터가 같은 직선 위인데, 목표는 그 직선 밖에 있음
해 무한 두 직선이 완전히 포개짐 열벡터가 같은 직선 위이고, 목표도 그 직선 위에 있음 → 섞는 방법이 여러 가지
Column picture 가 이긴 지점 · "해가 없다"는 말이 "목표가 열벡터들의 Span 밖에 있다"로 번역됩니다. 이 문장은 100차원에서도 똑같이 성립하고, 그림도 (머릿속에서) 그대로 유지됩니다. 6강에서 배울 열공간이 바로 이 이야기입니다.

5. Ax = b 라는 최종 형태

열벡터들을 나란히 붙여 하나의 상자로 묶으면 행렬(Matrix)이 됩니다. 가중치 x, y 도 벡터로 모으면, 식 전체가 한 줄로 줄어듭니다.

선형방정식계의 최종 형태
2−111 xy  =  15    즉    A x = b
  • A계수행렬. 열벡터들을 나란히 세운 것
  • x미지수 벡터. 각 열을 얼마나 섞을지의 가중치
  • b목표 벡터. 우변의 상수항들
이 강의에서 가장 중요한 문장 · Ax 는 A의 열벡터들을 x의 성분만큼 가중치를 두어 섞은 것입니다. 행렬은 숫자표가 아니라 연산자입니다 — 벡터를 받아서 자기 열들을 섞어 내놓는 기계죠. 앞으로 나올 부분공간·투영·고윳값·SVD가 전부 이 한 문장 위에 세워집니다.
"행렬 곱은 행과 열의 내적"이라고만 외우면 막힙니다 계산할 때는 그 방법이 맞습니다. 하지만 의미를 이해할 때는 열의 선형결합으로 보는 게 압도적으로 유리합니다. 4강에서 행렬 곱을 보는 네 가지 관점을 전부 다루겠습니다.

6. numpy 로 풀어보기

import numpy as np # 2x - y = 1 # x + y = 5 A = np.array([[2, -1], [1, 1]]) b = np.array([1, 5]) x = np.linalg.solve(A, b) print("해 (x, y) =", x)

np.linalg.solve 는 우리가 3강에서 배울 가우스 소거법을 내부에서 돌립니다. 역행렬을 구해서 곱하는 게 아닙니다 — 그게 더 느리고 부정확하거든요(4강에서 다룹니다).

# 행 관점 — 각 식이 성립하는가 print("2x - y =", 2*x[0] - x[1], " (목표 1)") print(" x + y =", x[0] + x[1], " (목표 5)") print() # 열 관점 — 열벡터를 x배, y배 해서 더하면 b 가 되는가 열1 = A[:, 0] # 첫 번째 열 = [2, 1] 열2 = A[:, 1] # 두 번째 열 = [-1, 1] print("열1 =", 열1, " 열2 =", 열2) print("x·열1 + y·열2 =", x[0]*열1 + x[1]*열2) print("b =", b) print() print("A @ x =", A @ x, " ← 같은 계산이다")
세 줄이 전부 같은 계산입니다 · A @ x 와 x·열1 + y·열2 가 같은 값을 냅니다. numpy 가 내부에서 하는 일이 바로 열의 선형결합이라는 증거입니다.
# 두 열이 평행한 행렬 — 열2 는 열1 의 정확히 2배 S = np.array([[1, 2], [2, 4]]) print("행렬식 det =", np.linalg.det(S), " ← 0 이면 특이행렬") print() try: np.linalg.solve(S, np.array([3, 7])) except np.linalg.LinAlgError as e: print("풀 수 없음:", e) print("→ 목표 [3, 7] 이 두 열의 Span(직선) 밖에 있다")
# [3, 6] 은 열1=[1,2] 의 3배 → 직선 위에 있다 b2 = np.array([3, 6]) print("A 의 랭크 :", np.linalg.matrix_rank(S)) print("A|b 를 붙인 랭크 :", np.linalg.matrix_rank(np.column_stack([S, b2]))) print("→ 두 랭크가 같으면 해가 존재한다 (지금은 무한히 많다)") print() # solve 는 여전히 못 쓴다. lstsq 가 해 하나를 골라준다 해, *_ = np.linalg.lstsq(S, b2, rcond=None) print("해 하나:", 해, " → 확인:", S @ 해) print() print("다른 해도 있다:", np.array([3.0, 0.0]), "→ 확인:", S @ np.array([3.0, 0.0]))

랭크(rank)는 7강에서 제대로 다룹니다. 지금은 "서로 다른 방향의 개수" 정도로 알아두면 충분합니다. S의 두 열은 평행하니 방향이 하나뿐이라 랭크가 1이죠.

# 문제 1. 아래 카페 문제를 A, b 로 만들어 풀어보세요. # 아메리카노 x잔(2천원) + 라떼 y잔(3천원), 합쳐 5잔, 총 13천원 # x + y = 5 # 2x + 3y = 13 # 문제 2. 그 해가 '열의 선형결합' 으로도 맞는지 확인해보세요. # 문제 3. 우변을 [5, 20] 으로 바꾸면 해가 어떻게 되나요? # (음수가 나와도 수학적으로는 해입니다 — 현실적 의미는 없지만) # 아래에 직접 써보세요
모범 답안 보기
# 문제 1 A1 = np.array([[1, 1], [2, 3]]) b1 = np.array([5, 13]) 해1 = np.linalg.solve(A1, b1) print("문제 1 → 아메리카노", 해1[0], "잔, 라떼", 해1[1], "잔") # 문제 2 — 열의 선형결합으로 확인 print("문제 2 →", 해1[0]*A1[:, 0] + 해1[1]*A1[:, 1], "= b1 ?", b1) # 문제 3 해3 = np.linalg.solve(A1, np.array([5, 20])) print("문제 3 →", 해3, " (라떼 5잔, 아메리카노 0잔이면 15천원이라 20천원은 불가능)") print(" 수학적 해는 있지만 '잔 수가 음수' 라 현실에는 없는 답이다")
실무에서 이 두 관점
  • Row picture — 제약조건을 하나씩 검토할 때. "이 조건 때문에 해가 좁아졌다"를 설명하기 좋습니다.
  • Column picture — 기본 관점으로 삼으세요. "이 신호를 우리가 가진 기저 함수들로 만들 수 있나?"(푸리에), "이 데이터를 주성분 몇 개로 재구성할 수 있나?"(PCA), "이 색을 RGB로 표현할 수 있나?" — 전부 같은 질문입니다.
  • 해가 없을 때 포기하지 않는 법 — 현실 데이터는 거의 항상 해가 없습니다(식이 데이터 수만큼 많으니까). 그때 "가장 가까운 곳까지라도 가자"가 최소제곱법이고, 10강의 주제입니다.

2강 요약

  • Row picture — 행 하나 = 도형 하나. 해 = 도형들의 교점. 익숙하지만 4차원부터 무너집니다.
  • Column picture — 열 하나 = 벡터 하나. 해 = "열들을 얼마나 섞어야 목표에 닿는가". 차원과 무관하게 유지됩니다.
  • 둘은 완전히 같은 식을 다른 방향으로 묶은 것일 뿐입니다.
  • 해가 없다 = 목표가 열들의 Span 밖. 해가 무한 = 열이 서로 평행한데 목표는 그 위.
  • Ax = b 에서 Ax 는 A의 열들의 선형결합입니다. 이 문장 하나만 가져가도 이 강의는 성공입니다.
