고윳값과 고유벡터

행렬을 곱하면 벡터는 보통 방향이 휩니다. 그런데 어떤 특별한 방향들은 변환 후에도 그대로 그 방향을 봅니다. 길이만 늘거나 줄 뿐이죠. 그 방향이 고유벡터, 늘어난 배율이 고윳값입니다. 이 축을 찾으면 복잡한 변환이 단순한 곱셈으로 바뀝니다.

0. 기초 다지기 — 무엇을 찾고 있는가

4강에서 행렬을 격자를 휘는 기계로 봤습니다. 대부분의 벡터는 이 기계를 통과하면 가리키는 방향이 달라집니다. 하지만 어떤 방향은 통과해도 그대로입니다.

고유벡터의 정의
A x = λ x   (x ≠ 0)
  • x고유벡터(eigenvector). 변환 후에도 같은 직선 위에 남는 방향
  • λ고윳값(eigenvalue), "람다". 그 방향으로 몇 배 늘었는가
  • x ≠ 0영벡터는 제외합니다. A·0 = λ·0 은 어떤 λ 에도 성립해서 아무 정보가 없거든요
  • λ 는 0 가능고윳값 0 은 허용됩니다. 그 방향이 영공간이라는 뜻이죠(6강)
"eigen" 은 독일어로 "고유한, 자기 자신의"
번역하면 "그 행렬 자신의 방향" 입니다. 행렬마다 자기만의 특별한 축이 있고, 그 축에서 보면 행렬이 하는 일이 그냥 늘이기로 단순해집니다.

네 가지를 꼭 눌러보세요 · 대각행렬은 고유벡터가 x축·y축 그대로입니다(가장 쉬운 경우). 대칭행렬은 고유벡터 두 개가 서로 수직입니다(15강의 주제). 전단은 고유벡터가 하나뿐이라 대각화가 안 됩니다(14강). 회전은 실수 고유벡터가 아예 없습니다 — 모든 방향이 돌아가니까요(§4).

2. 특성방정식 — 행렬식이 쓰이는 곳

정의식을 옮겨 적으면 영공간 문제가 됩니다.

유도
A x = λ x  ⟹  A x − λ x = 0  ⟹  ( A − λI ) x = 0
x ≠ 0 인 해가 있어야 하므로 (A − λI) 는 특이행렬
⟹   det( A − λI ) = 0
  • 왜 λI 인가A − λ 는 행렬에서 숫자를 뺄 수 없어 말이 안 됩니다. λI 로 만들어야 크기가 맞습니다
  • 핵심 논리"0이 아닌 x 를 0으로 보낸다" = 영공간이 원점보다 크다 = 특이행렬 = det = 0 (6·12강)
  • 특성방정식λ 에 대한 n차 다항식입니다. 그래서 고윳값은 (중복 포함) n개입니다
2×2 의 경우
det a−λbcd−λ = λ2 − (a+d) λ + (ad − bc) = 0
  • a + d대각합(trace). 고윳값들의 합입니다
  • ad − bc행렬식. 고윳값들의 곱입니다

3. 고유벡터 구하기 = 영공간 구하기

λ 를 찾았으면 (A − λI)x = 0 에 대입해서 영공간을 구합니다. 6강에서 배운 그 작업 그대로입니다.

고유벡터는 길이가 정해지지 않습니다
x 가 고유벡터면 2x 도, −5x 도 고유벡터입니다. 방향(직선)만 의미가 있죠.

그래서 라이브러리는 보통 길이를 1로 맞춰서 돌려줍니다. 부호나 배수가 교과서와 달라도 같은 답입니다.

4. 고윳값이 복소수일 때 (회전)

위에서 [회전] 을 눌러보면 Ax 가 항상 x 와 90° 를 이룹니다. 어떤 방향도 그대로 남지 않죠. 실수 고유벡터가 존재하지 않습니다.

90° 회전행렬
R = 0−110  ⟹  λ2 + 1 = 0  ⟹  λ = ± i
  • 판별식 < 0실근이 없다 = 실수 고유벡터가 없다 = 회전이 섞여 있다는 신호입니다
  • 복소수의 뜻허수부는 회전 속도, 실수부는 늘어나거나 줄어드는 정도를 나타냅니다. 14강의 시스템 안정성 판정에서 결정적입니다
진동하는 시스템은 복소 고윳값을 갖습니다 · 스프링, LC 회로, 흔들리는 다리 — 전부 회전 성분이 있어서 고윳값에 허수부가 생깁니다. "이 시스템이 진동하는가"를 고윳값을 보고 바로 판정할 수 있는 이유입니다.

5. 빠른 확인법 — 대각합과 행렬식

두 가지 검산
λ1 + λ2 + ⋯ + λn = trace(A)  (대각 원소의 합)
λ1 λ2 ⋯ λn = det(A)
  • 쓸모2×2 는 이 둘만으로 암산이 됩니다. 큰 행렬에서도 계산 검산에 유용합니다
  • 따름정리det = 0 ⟺ 고윳값 중 하나가 0. "납작해지는 방향이 있다"는 뜻이죠(12강)

6. numpy 로 확인하기

import numpy as np np.set_printoptions(precision=4, suppress=True) A = np.array([[2., 1.], [1., 2.]]) λ, V = np.linalg.eig(A) # 고유벡터는 V 의 '열' print("고윳값 λ =", λ) print("\n고유벡터 (열마다 하나) =") print(V) print() for i in range(len(λ)): x = V[:, i] print(f"λ={λ[i]:.4f} A@x = {np.round(A @ x, 4)} λ·x = {np.round(λ[i]*x, 4)} 같은가: {np.allclose(A @ x, λ[i]*x)}")
고유벡터는 V[:, i] 입니다 (열!) V[i] 로 쓰면 행을 꺼내게 되어 완전히 다른 벡터가 나옵니다. 가장 흔한 실수 중 하나입니다. 정사각 대칭행렬에서는 우연히 맞을 때도 있어 더 위험합니다.
print("trace(A) =", np.trace(A), " λ 들의 합 =", λ.sum()) print("det(A) =", round(np.linalg.det(A), 6), " λ 들의 곱 =", round(λ.prod(), 6)) print() print("특성방정식 λ² - (a+d)λ + (ad-bc) = 0 을 직접 풀어보면:") tr, de = np.trace(A), np.linalg.det(A) 근 = np.roots([1, -tr, de]) print(" 근 =", 근, " ← eig 와 같다")
from scipy.linalg import null_space for lam in λ: N = null_space(A - lam * np.eye(2)) print(f"λ = {lam:.4f} 일 때 (A - λI) 의 영공간:") print(np.round(N, 4).ravel(), " ← 고유벡터") print() print("→ 고유벡터를 구하는 건 6강의 '영공간 구하기' 와 똑같은 작업이다.")
행렬들 = { "대각 [[3,0],[0,1]]" : np.array([[3., 0.], [0., 1.]]), "대칭 [[2,1],[1,2]]" : np.array([[2., 1.], [1., 2.]]), "전단 [[1,1],[0,1]]" : np.array([[1., 1.], [0., 1.]]), "회전 90°" : np.array([[0., -1.], [1., 0.]]), } for 이름, Mx in 행렬들.items(): w, v = np.linalg.eig(Mx) 독립 = np.linalg.matrix_rank(v) 복소 = np.iscomplexobj(w) and np.abs(w.imag).max() > 1e-12 print(f"{이름:22s} λ = {np.round(w, 3)}") print(f"{'':22s} 독립인 고유벡터 {독립}개" + (" ← 복소수! 실수 고유벡터 없음" if 복소 else "") + (" ← 부족하다. 대각화 불가 (14강)" if (독립 < 2 and not 복소) else "")) print()
S = np.array([[4., 1., 0.], [1., 3., 1.], [0., 1., 2.]]) # 대칭 w, v = np.linalg.eigh(S) # 대칭 전용 함수 (더 빠르고 정확) print("고윳값 =", w, " ← 전부 실수") print("\n고유벡터 =") print(v) print("\nVᵀV =") print(np.round(v.T @ v, 10), " ← 단위행렬 = 서로 직교하고 길이 1") print() print("→ 대칭행렬의 고유벡터는 자동으로 정규직교기저가 된다 (15강)")
대칭행렬에는 eigh 를 쓰세요 eig 는 일반 행렬용이라 대칭행렬에도 아주 작은 허수부를 붙여 돌려줄 수 있습니다. 이론상 실수여야 하는데도요. eigh 는 대칭임을 가정해 실수만 돌려주고, 더 빠르며, 결과를 오름차순으로 정렬해줍니다.
Z = np.array([[1., 2.], [2., 4.]]) # 특이행렬 w, v = np.linalg.eig(Z) print("고윳값 =", w, " ← 하나가 0") print("det =", round(np.linalg.det(Z), 10), " = λ 들의 곱") print() 영_index = np.argmin(np.abs(w)) 영벡터 = v[:, 영_index] print("λ=0 의 고유벡터 =", np.round(영벡터, 4)) print("Z @ 그것 =", np.round(Z @ 영벡터, 10), " ← 0. 바로 영공간이다")

실무에서 고윳값
  • PCA — 공분산 행렬의 가장 큰 고윳값에 해당하는 고유벡터가 데이터가 가장 넓게 퍼진 방향(제1주성분)입니다(15강).
  • 구글 페이지랭크 — 웹 링크 행렬의 고윳값 1에 해당하는 고유벡터가 페이지 순위입니다(20강).
  • 진동 해석 — 건물·다리의 고유진동수가 말 그대로 고윳값입니다. 외력의 주파수가 여기 맞으면 공진으로 무너집니다.
  • 제어 시스템 — 고윳값의 실수부 부호가 안정성을 결정합니다(14강).

13강 요약

  • Ax = λx — 변환해도 방향이 안 바뀌는 축이 고유벡터, 그 배율이 고윳값입니다.
  • 특성방정식 det(A − λI) = 0. "0이 아닌 해가 있다 = 특이행렬 = det 0" 이라는 논리입니다.
  • λ 를 찾은 뒤 (A − λI)x = 0 의 영공간을 구하면 고유벡터입니다.
  • 고유벡터는 길이가 정해지지 않습니다. 방향만 의미가 있습니다.
  • 회전은 실수 고유벡터가 없습니다 — 고윳값이 복소수가 되고, 허수부가 회전 속도입니다.
  • Σλ = trace, Πλ = det 로 빠르게 검산합니다.
  • 코드에서 고유벡터는 V[:, i] (열). 대칭행렬에는 eigh.
