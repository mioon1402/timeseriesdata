그램-슈미트와 QR 분해

9강에서 봤듯이 기저가 정규직교이면 투영 공식이 P = AAT 로 확 줄어듭니다. 역행렬이 통째로 사라지죠. 그렇다면 아무 기저나 직교 기저로 바꿔버리면 어떨까요? 그 방법이 그램-슈미트이고, 그 과정을 기록해두면 A = QR 이 나옵니다.

0. 기초 다지기 — 왜 직교 기저가 좋은가

기저가 비스듬하면 좌표를 구하는 게 번거롭습니다. "이 벡터에는 v₁ 성분이 얼마나 들었나?" 를 알려면 v₂ 의 영향까지 같이 풀어야 하거든요 — 연립방정식을 풀어야 합니다.

그런데 기저가 서로 수직이면 이야기가 달라집니다. 각 축 성분을 따로따로, 내적 한 번으로 읽을 수 있습니다.

정규직교기저에서는 좌표가 그냥 내적
일반 기저   v = c1a1 + c2a2  ⟹  연립방정식을 풀어야 c 를 앎
정규직교   v = c1q1 + c2q2  ⟹  ci = qiTv — 내적 한 번
  • 왜양변에 q₁T 를 곱하면 q₁Tq₂ = 0 이라 다른 항이 전부 사라집니다
  • 어디서 봤나푸리에 계수가 정확히 이렇게 구해집니다. 사인파들이 서로 직교하기 때문이죠(20강)

1. 정규직교기저와 직교행렬 Q

정규직교 (Orthonormal)
qiTqj = 1  (i = j)0  (i ≠ j)   ⟹   QTQ = I
  • 정규길이가 1 (normal)
  • 직교서로 수직 (orthogonal)
  • 이름 주의열이 정규직교인 정사각행렬을 직교행렬(orthogonal matrix)이라 부릅니다. "정규직교행렬"이 더 정확한 이름이지만 관습이 그렇습니다

2. 직교행렬의 성질

역행렬이 공짜다
Q 가 정사각이면   Q−1 = QT
  • 뜻소거법도 역행렬 계산도 필요 없습니다. 행과 열만 뒤집으면 끝입니다
길이와 각도를 보존한다
(Qx)T(Qy) = xTQTQy = xTIy = xTy
⟹ ‖Qx‖ = ‖x‖  그리고  두 벡터 사이 각도도 그대로
  • 기하학적으로직교행렬은 회전 또는 반사뿐입니다. 늘이거나 찌그러뜨리지 않습니다(19강)
  • 수치적으로오차를 증폭하지 않습니다. 그래서 컴퓨터 알고리즘이 직교행렬을 사랑합니다
투영이 단순해진다 · P = Q(QTQ)−1QT = Q I QT = QQT. 역행렬이 통째로 증발합니다. 이게 직교 기저를 만드는 이유입니다.

3. 그램-슈미트 과정

아이디어는 한 줄입니다 — "새 벡터에서 이미 만든 방향의 성분을 빼버린다." 빼고 나면 남은 것은 반드시 수직입니다(9강의 오차 벡터).

–

a₁–
a₂–
q₁–
q₂–
q₁ᵀq₂ (0이어야)–
그램-슈미트 — 두 벡터의 경우
① q1 = a1 / ‖a1‖  — 첫 벡터는 길이만 1로
② B = a2 − (q1Ta2) q1  — q₁ 방향 성분을 뺀다
③ q2 = B / ‖B‖  — 남은 것을 길이 1로
  • ②가 핵심(q₁Ta₂)q₁ 은 a₂ 를 q₁ 위에 투영한 그림자(9강). 그걸 빼면 오차 벡터가 남고, 오차는 정의상 q₁ 과 직교합니다
  • 셋 이상세 번째는 q₁ 성분과 q₂ 성분을 둘 다 빼면 됩니다. 개수만 늘 뿐 방법은 같습니다
  • Span 보존빼기만 했으므로 같은 공간을 생성합니다. 축만 다시 세운 것이죠

4. A = QR 분해

그램-슈미트를 거꾸로 읽어봅시다. 원래 벡터 aj 는 q₁ … qj 의 선형결합으로 다시 적을 수 있습니다. 그 계수들을 모으면 행렬 하나가 됩니다.

A = QR
A = Q R,    R = q1Ta1q1Ta2q1Ta3 0q2Ta2q2Ta3 00q3Ta3
  • R 이 상삼각인 이유a1 은 q2 를 만들기 전에 쓰였으므로 q2Ta1 = 0 입니다. 아래쪽이 자동으로 0이 되죠
  • 간단히R = QTA 입니다. (A = QR 양변에 QT 를 곱하면 나옵니다)
분해나온 곳모양주 용도
A = LU가우스 소거(3강)하삼각 × 상삼각연립방정식 반복해서 풀기
A = QR그램-슈미트직교 × 상삼각최소제곱, 고유값 알고리즘
A = SΛS⁻¹고유분해(14강)고유벡터 × 대각거듭제곱, 동적 시스템
A = UΣVᵀSVD(16강)직교 × 대각 × 직교어떤 행렬이든. 압축, 근사

5. QR 로 최소제곱 풀기

10강의 정규방정식에 A = QR 을 넣어봅시다.

유도
ATA x̂ = ATb
(QR)T(QR) x̂ = (QR)Tb
RTQTQR x̂ = RTQTb  ← = I
RTR x̂ = RTQTb  ⟹  R x̂ = QTb
  • 이득R 은 상삼각이라 후진 대입으로 바로 풀립니다(3강). ATA 를 만들 필요가 없습니다
  • 진짜 이유ATA 를 만들면 조건수가 제곱됩니다. QR 은 그걸 피하죠 — 아래에서 숫자로 봅니다

6. numpy 로 확인하기

import numpy as np np.set_printoptions(precision=4, suppress=True) A = np.array([[1., 1., 2.], [1., 0., 1.], [1., 2., 0.]]) def 그램슈미트(A, tol=1e-12): Q = [] for j in range(A.shape[1]): v = A[:, j].astype(float).copy() for q in Q: # 이미 만든 방향의 성분을 전부 뺀다 v -= (q @ A[:, j]) * q n = np.linalg.norm(v) if n < tol: continue # 이미 있던 방향 = 종속 열, 건너뛴다 Q.append(v / n) return np.column_stack(Q) Q = 그램슈미트(A) print("Q =") print(Q) print("\nQᵀQ =") print(Q.T @ Q, " ← 단위행렬이면 성공")
R = Q.T @ A print("R =") print(R) print("\n상삼각인가:", np.allclose(R, np.triu(R))) print("Q @ R == A :", np.allclose(Q @ R, A))
Q2, R2 = np.linalg.qr(A) print("numpy Q =") print(Q2) print() print("우리 Q 와 부호만 다른가:", np.allclose(np.abs(Q), np.abs(Q2))) print() print("둘 다 맞는 분해인가:") print(" 우리 Q@R == A :", np.allclose(Q @ R, A)) print(" numpy Q2@R2 == A :", np.allclose(Q2 @ R2, A))
부호가 다른 건 정상입니다 q 와 −q 는 같은 방향의 축입니다. 어느 쪽을 양의 방향으로 잡을지는 규약일 뿐이라 라이브러리마다 다릅니다.

또 numpy 는 교과서식 그램-슈미트가 아니라 하우스홀더 반사(19강)를 씁니다. 수치적으로 훨씬 안정하기 때문입니다 — 교과서 그램-슈미트는 벡터가 거의 평행할 때 직교성이 무너집니다.
# 거의 평행한 두 벡터 eps = 1e-8 나쁜A = np.array([[1., 1.], [eps, 0.], [0., eps]]) Q_ours = 그램슈미트(나쁜A) Q_np, _ = np.linalg.qr(나쁜A) print("우리 것 QᵀQ - I 의 최대 오차 :", np.abs(Q_ours.T @ Q_ours - np.eye(2)).max()) print("numpy 것 QᵀQ - I 의 최대 오차 :", np.abs(Q_np.T @ Q_np - np.eye(2)).max()) print() print("→ 열이 거의 평행하면 '빼고 남은 것' 이 아주 작아져") print(" 반올림 오차가 상대적으로 커진다. 실무에서는 라이브러리를 쓰세요.")
rng = np.random.default_rng(0) Qr, _ = np.linalg.qr(rng.normal(size=(4, 4))) # 무작위 직교행렬 x = rng.normal(size=4) y = rng.normal(size=4) print("‖x‖ =", np.linalg.norm(x)) print("‖Qx‖ =", np.linalg.norm(Qr @ x), " ← 같다") print() print("xᵀy =", x @ y) print("(Qx)ᵀ(Qy) =", (Qr @ x) @ (Qr @ y), " ← 같다 (각도 보존)") print() print("det(Q) =", round(np.linalg.det(Qr), 6), " ← ±1 (회전이면 +1, 반사가 섞이면 −1)")
from scipy.linalg import solve_triangular t = np.array([0., 1., 2., 3.]) y = np.array([1., 2., 2., 5.]) Am = np.column_stack([t, np.ones_like(t)]) Qm, Rm = np.linalg.qr(Am) x_qr = solve_triangular(Rm, Qm.T @ y) # R x = Qᵀb — 후진 대입 print("QR 로 푼 해 :", x_qr) print("lstsq 의 해 :", np.linalg.lstsq(Am, y, rcond=None)[0]) print("정규방정식의 해 :", np.linalg.solve(Am.T @ Am, Am.T @ y)) print() print("전부 같지만, 조건이 나쁜 문제에서는 차이가 납니다 ↓")
# 반데르몽드 행렬 — 다항식 회귀에서 나오며 조건이 아주 나쁘다 x_pts = np.linspace(0, 1, 8) V_mat = np.vander(x_pts, 8) c1 = np.linalg.cond(V_mat) c2 = np.linalg.cond(V_mat.T @ V_mat) print(f"cond(A) = {c1:.3e}") print(f"cond(AᵀA) = {c2:.3e}") print(f"비율 = {c2/c1:.3e} ≈ cond(A) = {c1:.3e}") print() print("→ AᵀA 를 만드는 순간 조건수가 제곱된다.") print(" 유효숫자가 절반으로 줄어드는 셈이라, 정규방정식을 직접 풀면 위험하다.") print(" QR 이나 SVD(lstsq) 는 A 를 직접 다뤄 이 문제를 피한다.")

실무에서 QR
  • 회귀 계산의 표준 — R 의 lm(), statsmodels 의 OLS 가 내부에서 QR(또는 SVD)을 씁니다. 정규방정식을 직접 푸는 라이브러리는 거의 없습니다.
  • 고유값 알고리즘 — QR 반복법이 지금도 표준입니다. A = QR → A' = RQ 를 반복하면 놀랍게도 고유값으로 수렴합니다(13강).
  • 딥러닝 — 가중치 초기화에 직교 행렬을 쓰면 길이를 보존해 기울기 소실/폭발을 줄입니다.

11강 요약

  • 기저가 정규직교면 좌표가 내적 한 번으로 나옵니다. 연립방정식이 필요 없습니다.
  • QTQ = I. 정사각이면 Q−1 = QT — 역행렬이 공짜.
  • 직교행렬은 길이와 각도를 보존합니다(회전·반사). 그래서 오차를 증폭하지 않습니다.
  • 그램-슈미트 = "이미 만든 방향의 성분을 빼라". 남은 것은 반드시 직교합니다(9강의 오차).
  • 그 과정을 기록하면 A = QR, 그리고 R = QTA.
  • 최소제곱은 R x̂ = QTb 로 풀립니다 — 후진 대입 한 번.
  • ATA 를 만들면 조건수가 제곱됩니다. QR 이 그걸 피합니다.
