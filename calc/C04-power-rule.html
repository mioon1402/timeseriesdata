미적분 4강 · 미분 공식

기하학으로 보는 미분 공식

(x²)′ = 2x, (x³)′ = 3x² 같은 공식을 보통은 극한 계산으로 증명합니다. 엄밀하지만 "왜 그런 모양인지" 는 안 알려주죠. 이 강의에서는 도형이 자라는 모습으로 같은 공식을 유도합니다. 한 번 그림으로 보고 나면 공식은 외울 것이 아니라 당연한 것이 됩니다.

이 강의에서 배우는 것
  1. 기초 다지기 — '한 번 작은 것'과 '두 번 작은 것'
  2. x² → 2x : 성장하는 정사각형
  3. x³ → 3x² : 팽창하는 정육면체
  4. 일반화 — 왜 차수가 하나 낮아지는가
  5. 1/x : 넓이가 보존되는 직사각형
  6. √x : 거꾸로 보는 정사각형
  7. 공식표 — 전부 그림으로
  8. 파이썬으로 확인하기

0. 기초 다지기 — '한 번 작은 것'과 '두 번 작은 것'

이 강의 전체를 관통하는 규칙이 하나 있습니다. 먼저 이것만 확실히 해둡시다.

dx 가 0.001 이라고 합시다. 그러면 dx² 은 0.000001 입니다 — 천 배 더 작습니다. dx 를 더 줄이면 이 격차는 더 벌어집니다.

미적분에서 가장 자주 쓰는 규칙
변화율을 구할 때는 dx 로 나눕니다. 그러면
2x·dx ÷ dx = 2x  →  살아남는다   ·   dx² ÷ dx = dx  →  0으로 사라진다
  • 한 번 작은 것dx 가 한 번 곱해진 항. 나누면 상수가 남습니다. 이게 답입니다
  • 두 번 작은 것dx 가 두 번 이상 곱해진 항. 나눠도 dx 가 남아서 극한에서 사라집니다. 이건 버립니다
  • 1강에서 이미 봤습니다 A(r+h) − A(r) = 2πr·h + πh² 에서 2πr·h 는 살고 πh² 는 사라졌죠

1. x² → 2x : 성장하는 정사각형

한 변이 x 인 정사각형의 넓이가 x² 입니다. 변을 dx 만큼 늘리면 넓이는 어떻게 변할까요? 새로 붙는 부분은 정확히 세 조각입니다.

① 정사각형을 키우면 어디가 붙는가
넓이 x²–
두 띠 2x·dx–
모서리 dx²–
모서리 비중–
변화율–
2x–

dx 를 왼쪽 끝까지 밀어보세요. 빨간 모서리 조각이 눈에 보이지 않을 만큼 작아지고, 변화율이 2x 에 딱 붙습니다.

(x²)′ = 2x 의 정체
넓이 변화 df = x·dx (오른쪽 띠) + x·dx (위쪽 띠) + dx² (모서리)
dfdx = 2x + dx   dx → 0 이면  → 2x
  • 2x 의 정체새로 붙는 두 띠의 총 길이입니다. 정사각형에는 자랄 수 있는 변이 두 개(오른쪽·위쪽)뿐이라 2 가 나옵니다
  • 모서리는 왜 버리나dx로 나누면 dx가 남습니다. 위 패널에서 dx=0.5 일 때 모서리 비중이 11%, dx=0.05 면 1.2% — 0으로 갑니다
⚠ 흔한 오해 "dx² 도 작지만 어쨌든 있는데 왜 무시하나?"
버리는 게 아니라 나눗셈이 없애줍니다 우리가 구하는 건 넓이 변화가 아니라 변화율(넓이 변화 ÷ dx)입니다.
2x·dx 는 dx로 나누면 2x 로 살아남고, dx² 은 나눠도 dx 가 남아 극한에서 0이 됩니다. '한 번 작은 것'은 살아남고 '두 번 작은 것'은 사라진다 — 미적분 전체에서 반복되는 규칙입니다.

2. x³ → 3x² : 팽창하는 정육면체

3차원으로 올라갑시다. 한 변 x 인 정육면체의 부피가 x³ 입니다. 변을 dx 늘리면 붙는 조각은:

  • 세 면에 얇은 판 3개 — 각각 x · x · dx
  • 세 모서리에 가는 막대 3개 — 각각 x · dx · dx
  • 꼭짓점에 아주 작은 정육면체 1개 — dx³
② 정육면체를 키우면 어디가 붙는가
판 3개 3x²·dx–
막대 3개 3x·dx²–
꼭짓점 dx³–
판의 비중–
변화율–
3x²–

부피 변화의 주인공은 세 면의 판 3x²·dx 입니다. 막대와 꼭짓점 조각은 '두 번, 세 번 작은 것' 이라 사라집니다. dx 를 줄여보면 판의 비중이 100% 로 갑니다.

3. 일반화 — 왜 차수가 하나 낮아지는가

멱함수의 미분
( xn )′ = n · xn−1
  • n 의 정체n차원 도형이 자랄 때 새 부피가 붙는 면의 개수입니다. 정사각형은 변 2개, 정육면체는 면 3개, n차원 정육면체는 n개
  • xn−1 의 정체그 면 하나의 크기입니다. 정사각형의 변은 길이 x(1차원), 정육면체의 면은 넓이 x²(2차원)
  • 그래서미분이 차수를 하나 낮추는 이유가 여기 있습니다 — n차원 도형의 '경계'는 (n−1)차원이니까요
미분 = "지금 자라고 있는 경계의 크기" · 1강에서 원의 넓이 πr² 을 미분하면 둘레 2πr 이 나온 것도 같은 이야기입니다. 원판(2차원)의 경계는 원둘레(1차원)죠. 구의 부피 (4/3)πr³ 을 미분하면 겉넓이 4πr² 이 나오는 것도 마찬가지입니다. 부피의 변화율 = 겉면의 크기.

4. 1/x : 넓이가 보존되는 직사각형

이번엔 다른 상황입니다. 넓이가 1로 고정된 직사각형(가로 x, 세로 y, x·y = 1, 즉 y = 1/x)을 봅시다.

가로를 dx 늘리면 오른쪽에 y·dx 만큼 넓이가 붙습니다. 그런데 전체 넓이는 1로 유지돼야 하므로, 위쪽에서 x·(−dy) 만큼 빠져야 합니다 (세로가 줄어듭니다).

③ 가로가 늘면 세로는 얼마나 줄어야 하나
세로 y–
붙는 넓이 y·dx–
빠지는 넓이–
세로 변화 dy–
dy/dx–
−1/x²–

x 를 오른쪽으로 밀어보세요. 직사각형이 길고 납작해질수록 세로를 아주 조금만 낮춰도 넓이가 유지됩니다 — 그래서 |dy/dx| 가 작아지죠.

(1/x)′ = −1/x²
y·dx + x·dy = 0  ⟹  dydx = − yx = − 1/xx = − 1/x²
  • 첫 식의 뜻"붙는 넓이 + 빠지는 넓이 = 0", 즉 전체 넓이가 그대로다. 이게 조건의 전부입니다
  • 음수 부호x 가 늘면 y 가 준다는 뜻입니다
  • 1/x²x 가 이미 클수록 조금만 줄여도 된다는 뜻. 긴 직사각형은 가로를 늘려도 세로를 아주 조금만 낮추면 되니까요
  • 미리 보기이 "변화량들의 합이 0" 이라는 발상이 7강 음함수 미분의 전부입니다

5. √x : 거꾸로 보는 정사각형

√x 는 '넓이가 x 인 정사각형의 한 변' 입니다. 입력이 넓이, 출력이 변인 셈이죠.

§1에서 변이 df 늘면 넓이가 약 2f·df 는다는 걸 봤습니다. 관계를 거꾸로 읽으면 dx ≈ 2f·df, 즉:

(√x)′ = 1/(2√x)
넓이 변화 dx = 2f·df  ⟹  dfdx = 12f = 12√x
  • 한 일넓이-변 관계를 뒤집기만 했습니다. 새 계산은 하나도 없어요
  • 뜻정사각형이 이미 클수록, 넓이를 조금 늘려도 변은 아주 조금만 길어집니다. √4 = 2 이고 √4.1 ≈ 2.025 죠
  • x → 0 에서1/(2√x) 가 무한히 커집니다. 아주 작은 정사각형은 넓이를 조금만 늘려도 변이 확 길어집니다. 그래서 √x 는 원점에서 수직으로 솟습니다

  • 수치미분의 오차 — 중앙차분의 오차가 h² 에 비례하는 것도 '두 번 작은 것' 이 남기 때문입니다.

4강 요약

  • '한 번 작은 것'은 살아남고 '두 번 작은 것'은 사라집니다. 변화율은 dx로 나눈 값이기 때문입니다.
  • (x²)′ = 2x — 정사각형이 자랄 때 붙는 두 띠의 총 길이.
  • (x³)′ = 3x² — 정육면체에 붙는 세 판의 총 넓이.
  • (xⁿ)′ = n·xⁿ⁻¹ — n차원 도형의 n개 경계면. 미분이 차수를 낮추는 이유는 경계가 한 차원 낮기 때문입니다.
  • (1/x)′ = −1/x² — 넓이를 지키려면 붙는 넓이 + 빠지는 넓이 = 0. 이 발상이 7강 음함수 미분입니다.
  • (√x)′ = 1/(2√x) — 넓이-변 관계를 거꾸로 읽은 것.
  • 공식은 외우는 게 아니라 그림에서 읽는 것입니다.
