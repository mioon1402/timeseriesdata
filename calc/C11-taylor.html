테일러 급수 — 곡선을 다항식으로 번역하기

계산기는 sin(0.7) 을 어떻게 구할까요? 사인의 '진짜 값'을 아는 게 아닙니다. 덧셈·곱셈만으로 계산되는 다항식으로 사인을 흉내 내서, 원하는 자릿수까지 계산합니다. 그 번역 사전이 테일러 급수입니다.

0. 기초 다지기 — 왜 다항식인가

컴퓨터가 확실히 할 수 있는 연산은 딱 넷입니다 — 더하기, 빼기, 곱하기, 나누기. sin, ex, ln 같은 함수는 이 넷으로 정의되지 않습니다.

그런데 다항식(c₀ + c₁x + c₂x² + ⋯)은 덧셈과 곱셈만으로 계산됩니다. 그래서 "복잡한 함수를 다항식으로 흉내 낼 수 있다면" 계산이 가능해집니다.

2강의 국소 선형성이 출발점입니다
2강에서 확대하면 곡선이 직선이 된다고 했습니다. 그건 1차 다항식으로 흉내 낸 것이었죠 — f(x) ≈ f(a) + f′(a)(x−a).

테일러 급수는 여기서 한 걸음 더 나갑니다. "1차로 부족하면 2차, 3차, 4차… 를 계속 붙이면 되지 않나?" 바로 그것입니다.

1. 단계별로 닮아가기 — 값·기울기·곡률

x=0 근처에서 cos(x) 를 흉내 낼 다항식 P(x) = c₀ + c₁x + c₂x² + ⋯ 의 계수를 하나씩 정합시다. 조건을 하나 걸 때마다 한 계수가 결정됩니다.

① 조건을 하나씩 걸어 계수를 정한다
지금 근사식–
맞춘 것–
x = 1 에서의 오차–
x = 2 에서의 오차–

0차는 높이만, 1차는 높이와 방향, 2차는 거기에 휘어짐까지 맞춥니다. 2차에서 처음으로 포물선 1 − x²/2 가 되죠.

cos(x) 의 계수를 하나씩
0차 — 위치 맞추기: cos(0) = 1 이니 P(0) = c₀ = 1
1차 — 방향 맞추기: cos′(0) = −sin(0) = 0 이니 c₁ = 0
2차 — 휘어짐 맞추기: cos″(0) = −1, P″(0) = 2c₂ 이므로 c₂ = −1/2
4차, 6차… 계속: 같은 방식으로 c₄ = 1/24, c₆ = −1/720. 홀수 차수는 전부 0
  • c₂ 계산P = c₀ + c₁x + c₂x² 를 두 번 미분하면 2c₂. 이것이 cos″(0) = −1 과 같아야 하므로 c₂ = −1/2
  • 홀수가 0인 이유cos 은 y축 대칭(우함수)입니다. 홀수 차수는 대칭을 깨므로 계수가 0이어야 하죠
cos 과 eˣ 의 급수
cos(x) ≈ 1 − x²2! + x⁴4! − x⁶6! + ⋯
ex ≈ 1 + x + x²2! + x³3! + ⋯
sin(x) ≈ x − x³3! + x⁵5! − ⋯
  • eˣ 는 왜 전부 1몇 번을 미분해도 eˣ 이고 0에서 값이 1이니, 모든 도함수 값이 1입니다(6강)
  • 부호가 번갈아sin·cos 은 미분할 때마다 cos → −sin → −cos → sin 으로 4주기를 돕니다. 그래서 + − + − 가 반복되죠

2. 차수를 올리면 어디까지 따라오나

② 차수를 올려 보세요
참값 f(x)–
n차 근사–
오차–
오차가 0.001 미만인 범위–

차수를 올릴수록 근사가 유효한 범위가 넓어집니다. cos 은 2차에서 ±0.4 정도, 10차면 ±3 이상까지 따라옵니다. 그런데 ln(1+x) 는 아무리 차수를 올려도 x = 1 을 못 넘습니다 — §4의 이야기입니다.

3. 팩토리얼은 왜 나오나

분모의 2!, 4!, 6! 은 어디서 왔을까요?

n! 의 정체
xn 을 n번 미분하면   n · (n−1) · ⋯ · 1 = n!
n번째 도함수를 원래 함수와 정확히 맞추려면 이 n! 을 미리 나눠 상쇄해둬야 한다
f(x) = Σ f(n)(0)n! · xn
  • 확인x³ 을 세 번 미분하면 3·2·1 = 6 = 3!. 그래서 x³/3! 을 세 번 미분하면 정확히 1이 됩니다
  • f(n)n번 미분한 함수. f⁗ 처럼 프라임을 계속 붙이기 어려워서 쓰는 표기입니다
  • 중심을 옮기면x=a 근처를 흉내 내려면 xn 대신 (x−a)n, f(n)(0) 대신 f(n)(a). 그게 일반 테일러 급수입니다
  • 암기가 아니다n! 은 '값·기울기·곡률·… 을 차례로 맞춘다'는 발상의 자연스러운 부산물입니다

4. 수렴 반경 — 만능은 아니다

주의 하나. 급수가 어디서나 원래 함수와 같아지는 건 아닙니다.

③ 근사에는 유효 사거리가 있다
수렴 반경–
특이점 위치–
x = 0.9 에서의 오차–
x = 1.2 에서의 오차–

차수를 끝까지 올려 보세요. 수렴 반경 안에서는 근사가 곡선에 붙지만, 밖에서는 차수를 올릴수록 오히려 더 크게 빗나갑니다.

수렴 반경이란
1/(1−x) 의 급수   1 + x + x² + x³ + ⋯   는 |x| < 1 에서만 수렴한다
  • 왜 1인가x=1 에서 함수가 무한대로 터집니다(특이점). 중심에서 그 특이점까지의 거리가 수렴 반경입니다
  • 수상한 경우1/(1+x²) 는 실수 어디서도 멀쩡한데 수렴 반경이 1 입니다. 복소수 x = ±i 에 특이점이 숨어 있기 때문이죠
  • 교훈"실수 그래프만 봐서는 왜 여기서 멈추는지 알 수 없다" — 급수의 거동은 복소평면에서만 완전히 보입니다
  • eˣ, sin, cos특이점이 아예 없어서 수렴 반경이 무한대입니다. 어디서든 급수가 통하죠
실무에서의 의미 "이 근사는 어디까지 믿을 수 있는가"를 항상 물어야 합니다.
진자의 sin θ ≈ θ 근사는 θ 가 작을 때만 통합니다 — θ=0.1rad(5.7°)에서 오차 0.017%, θ=1rad(57°)에서는 18% 입니다. 큰 진폭 진자에 이 근사를 쓰면 주기 계산이 통째로 틀립니다.

근사에는 유효 사거리가 있습니다.

5. 공학에서의 쓰임 — 선형화

테일러 1차 근사(접선으로 바꾸기)가 곧 선형화입니다
진자의 sin(θ) ≈ θ 근사처럼, 비선형 시스템을 동작점 근처에서 직선으로 바꿔 다루는 것 — 제어공학에서 모델을 세우는 첫 단계입니다.

계산기·컴퓨터의 함수 계산, 미분방정식의 급수해법, 물리학의 섭동 이론, 기계학습의 2차 최적화(뉴턴법) 도 전부 이 급수 위에 서 있습니다.
근사조건쓰이는 곳
sin θ ≈ θθ 작을 때단진자, 광학의 근축 근사
cos θ ≈ 1 − θ²/2θ 작을 때진자의 위치에너지
ex ≈ 1 + xx 작을 때복리·감쇠의 1차 근사
ln(1+x) ≈ xx 작을 때수익률, dB 계산
(1+x)n ≈ 1 + nxx 작을 때오차 전파, 상대론의 저속 근사
1/(1−x) ≈ 1 + xx 작을 때피드백 루프 게인

테일러 급수가 실제로 하는 일
  • 계산기·라이브러리 — sin, exp, log 의 실제 구현이 급수(또는 그 변형인 미니맥스 다항식)입니다.
  • 제어공학 — 비선형 플랜트를 동작점에서 선형화해 전달함수를 세웁니다.
  • 수치해석 — 룽게-쿠타법, 유한차분법의 오차 분석이 전부 테일러 전개입니다.
  • 기계학습 — 뉴턴법·L-BFGS 는 손실함수의 2차 테일러 근사를 최소화합니다.
  • 물리학 — 상대론의 γ ≈ 1 + v²/2c² 에서 E = mc² + ½mv² 이 나옵니다. 고전역학이 상대론의 1차 근사죠.

11강 요약

  • 컴퓨터는 사칙연산만 할 수 있습니다. 그래서 복잡한 함수를 다항식으로 번역합니다.
  • 값 → 기울기 → 곡률 → … 를 차례로 맞추면 계수가 하나씩 결정됩니다.
  • f(x) = Σ f(n)(0)/n! · xⁿ. n! 은 xⁿ 을 n번 미분할 때 튀어나오는 값을 상쇄하려고 붙습니다.
  • 차수를 올릴수록 유효 범위가 넓어집니다.
  • 다만 수렴 반경이 있습니다. 중심에서 가장 가까운 특이점까지의 거리죠.
  • 1/(1+x²) 처럼 실수에서 멀쩡한데도 반경이 유한할 수 있습니다 — 복소평면에 숨은 특이점 때문입니다.
  • 1차 근사 = 선형화. 제어공학이 모델을 세우는 첫걸음입니다.
  • 근사에는 유효 사거리가 있습니다. 항상 "어디까지 믿을 수 있나"를 물으세요.
