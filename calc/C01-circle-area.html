0. 기초 다지기 — 이 시리즈를 읽는 법

이 시리즈는 세 부류의 독자를 모두 염두에 두고 만들었습니다. 미적분을 아예 처음 보는 사람, 예전에 배웠지만 다 잊어버린 사람, 그리고 공식은 아는데 "이게 대체 무슨 그림인지" 감이 없는 사람. 어느 쪽이든 괜찮습니다. 필요한 사전지식은 사칙연산과 아주 간단한 문자식(x가 2라면 x²은 4)뿐입니다. 그 밖의 모든 기호와 개념은 처음 등장할 때마다 그 자리에서 설명합니다.

읽는 규칙 세 가지

① 그림을 그냥 넘기지 마세요. 이 시리즈의 심장은 글이 아니라 그림입니다. 그림 하나가 이해되면 그 강의의 절반은 끝난 것입니다. 게다가 여기 그림들은 전부 직접 만질 수 있습니다. 슬라이더를 끝까지 밀어보세요.

② 새 공식이 나오면 "이걸 그래프로 그리면 어떤 모양이지?" 라고 스스로 물으세요. 이 질문을 붙이고 가는 습관이 직관을 만듭니다.

③ 강의 끝의 '스스로 점검'에 답해보세요. 답이 막히면 표시된 절만 다시 읽으면 됩니다. 처음부터 다시 읽을 필요는 없습니다.

기호 사전 — 이 시리즈에 나오는 모든 기호

수학이 어렵게 느껴지는 이유의 절반은 기호 때문입니다. 낯선 외국어 문자처럼 보이지만, 사실 하나하나는 짧은 우리말 문장의 줄임말일 뿐입니다. 여기서 전부 미리 소개합니다. 지금 다 외울 필요는 없습니다 — 읽다가 낯선 기호가 나오면 이 표로 돌아오면 됩니다.

미리 보는 전체 지도

길을 떠나기 전에 지도를 봅시다. 미적분 전체는 딱 네 박자의 반복입니다.

미적분의 네 박자
쪼개기  →  근사하기  →  합치기  →  극한 보내기
  • 쪼개기복잡한 대상(곡선, 원, 변하는 속도)을 아주 작은 조각으로 자른다
  • 근사하기작아진 조각은 단순해진다. 곡선 조각은 직선처럼, 고리 조각은 직사각형처럼
  • 합치기단순해진 조각들을 전부 더한다
  • 극한 보내기조각 크기를 0으로 보내면 근사가 정확한 답이 된다

이 위에 두 개의 큰 봉우리가 서 있습니다. 미분(3~7강)은 '쪼개서 순간을 보는' 봉우리이고, 적분(9강)은 '모아서 전체를 보는' 봉우리입니다. 그리고 9~10강에서 두 봉우리가 사실 하나의 산이라는 것(미적분학 기본정리)이 드러납니다. 나머지 강의들은 이 산을 오르는 데 필요한 장비들입니다.

1. 쪼개기 — 양파의 지혜

원을 통째로 다루면 어렵습니다. 곡선이기 때문입니다. 직사각형이나 삼각형은 넓이 공식을 아는데, 원은 그런 게 없죠. 그래서 원을 양파라고 상상합시다. 반으로 자르면 동심원 층들이 보입니다.

이 아이디어대로 원을 중심에서부터 무수히 많은 얇은 고리로 분해합니다. 중심에서 거리 r 만큼 떨어진 고리는 반지름이 r 이고 두께는 아주 얇은 dr 입니다. (dr 에서 d 는 '아주 작다'는 표시일 뿐입니다 — 위 기호 사전 참조.)

2. 근사하기 — 반지에서 직사각형으로

얇은 고리 하나를 가위로 한 곳만 자른 뒤 조심스럽게 펴 봅시다. 거의 완벽한 가느다란 직사각형이 됩니다. 왜 '거의'냐면 안쪽 둘레가 바깥쪽보다 아주 살짝 짧기 때문인데, 고리가 얇을수록 그 차이는 무시할 만해집니다.

고리 하나를 펴면
가로 = 고리의 둘레 = 2πr
세로 = 고리의 두께 = dr
고리 하나의 넓이 ≈ 가로 × 세로 = 2πr · dr
  • 이게 첫 마법곡선을 아주 작게 쪼개면, 각 조각은 직선처럼, 원호는 직사각형처럼 다룰 수 있게 됩니다. 이 문장 하나가 미적분 전체를 관통합니다

3. 합치기 — 거대한 직각삼각형의 탄생

이제 펴낸 직사각형들을 새 좌표평면에 세워 봅시다. 가로축은 그 고리가 있던 반지름 r, 세로 높이는 그 고리의 둘레 2πr 입니다.

r = 0 인 중심 고리는 둘레가 0이라 높이 0, 바깥으로 갈수록 둘레가 정비례로 커져서 r = R 인 마지막 고리는 높이가 2πR 입니다. 안쪽 고리부터 바깥 고리까지 차례로 세우면 — 밑변 R, 높이 2πR 인 직각삼각형이 나타납니다. 원을 분해해 재배열했더니 삼각형이 튀어나온 것입니다.

세 가지를 꼭 눌러보세요 · 안쪽 둘레로 재면 항상 모자라고, 바깥 둘레로 재면 항상 넘칩니다. 참값은 그 사이에 끼어 있죠. 그리고 n을 키우면 양쪽에서 조여 옵니다. 가운데 둘레로 재면 놀랍게도 n이 1이어도 정확히 π 가 나옵니다 — 모자란 부분과 넘치는 부분이 정확히 상쇄되기 때문입니다.

4. 극한 — 오차는 어디로 갔나

남은 미심쩍은 구석 하나. 고리를 직사각형으로 취급한 건 근사였습니다. 실제로는 사다리꼴에 가깝죠. 이 오차는 어떻게 되나요?

두께 dr 을 점점 0에 가깝게 줄이면 안쪽·바깥쪽 둘레의 차이도 0에 가까워지고, 사다리꼴과 직사각형의 차이도 사라집니다. 극한에서 오차는 완전히 소멸하고 근사는 정확한 등식이 됩니다.

오차가 정확히 얼마인지 계산해 보면
안쪽 둘레로 잰 합 = πR² · (n−1)/n    바깥 둘레로 잰 합 = πR² · (n+1)/n
둘의 차이 = 2πR²/n → n을 키우면 0으로 사라진다
  • n = 20안쪽 2.9845, 바깥 3.2987 — 참값 3.1416을 사이에 두고 5% 씩 벗어남
  • n = 80안쪽 3.1023, 바깥 3.1809 — 오차 1.25%. 슬라이더로 확인해 보세요
  • 핵심오차가 작아지는 게 아니라 0으로 사라진다는 것이 요점입니다. 그래서 근사가 등식이 됩니다
⚠ 흔한 오해 "무한히 많은 조각을 더하면 무한히 커지는 것 아닌가?"
그렇지 않습니다 조각의 개수는 무한히 늘어나지만 조각 하나의 크기는 동시에 0으로 갑니다. ∞ × 0 은 정해진 값이 없어서, 어느 쪽이 더 빠른지에 따라 결과가 달라집니다. 여기서는 정확히 πR² 이라는 유한한 값으로 수렴합니다. 슬라이더가 그걸 보여주고 있죠.

5. 다른 길: 부채꼴로 쪼개기

"왜 하필 고리인가? 부채꼴로 쪼개면 안 되나?" — 좋은 질문입니다. 됩니다. 원을 피자처럼 부채꼴로 자른 뒤, 위아래로 번갈아 끼워 맞추면 직사각형에 가까운 도형이 됩니다.

② 부채꼴로 쪼개 다시 붙이기
꼭짓점 사이 폭 n·sin(π/n)–
높이 cos(π/n)–
폭 × 높이–
조각들의 총 넓이3.14159 (항상)

폭과 높이가 각각 πR = 3.14159 와 R = 1 로 다가갑니다. n을 끝까지 밀어 보세요.

여기서 중요한 것 · 조각들의 총 넓이는 처음부터 πR² 그대로입니다. 자르고 옮겼을 뿐이니까요. 달라지는 건 모양입니다. n을 키울수록 그 모양이 우리가 넓이를 아는 도형(직사각형)에 가까워집니다. 가로로 늘어선 호의 총 길이는 언제나 반원 호 πR 이고, 꼭짓점에서 꼭짓점까지 곧게 잰 폭은 n·sin(π/n) 으로, 높이는 cos(π/n) 으로 각각 πR 과 R 에 다가갑니다. 톱니가 평평해지는 것이 여기서의 '극한'입니다.
'폭 × 높이' 가 π 보다 항상 작은 이유 n=8 에서 폭 × 높이 = 2.828 인데 진짜 넓이는 3.142 입니다. 모순일까요? 아닙니다 — 호가 직사각형 밖으로 볼록하게 튀어나와 있기 때문입니다. 그 튀어나온 부분이 정확히 모자란 만큼이죠. 사실 이 n·sin(π/n) · cos(π/n) = (n/2)·sin(2π/n) 은 원에 내접하는 정n각형의 넓이와 같습니다. "다각형으로 원을 근사한다"는 아르키메데스의 2200년 전 방법이 여기 숨어 있습니다.
⚠ 그럼 왜 이 책은 고리를 먼저 썼나 부채꼴 방법이 더 유명한데도요.
고리 방법이 '적분'의 모양을 그대로 갖고 있기 때문입니다 고리 방법의 합 Σ 2πr·dr 은 [높이] × [폭] 을 전부 더한다는 형태입니다. 9강에서 배울 정적분 ∫ f(x) dx 와 문자만 다르고 완전히 같은 꼴이죠. 부채꼴 방법은 예쁘지만 이 문제 하나에만 통하는 재주입니다. 고리 방법은 구의 부피, 회전체, 관성 모멘트로 그대로 확장됩니다.

6. 미리 보는 가장 아름다운 통찰

넓이 공식 πr² 과 둘레 공식 2πr 사이에는 숨은 관계가 있습니다. 넓이를 r로 미분하면(변화율을 구하면) 정확히 둘레 2πr 이 나옵니다.

우연이 아닙니다. 반지름이 살짝 늘 때 넓이가 느는 양이 바로 바깥에 붙는 얇은 고리이고, 그 고리를 편 길이가 둘레이기 때문입니다. 아래에서 반지름과 '살짝'의 크기를 직접 조절해 보세요.

③ 반지름을 살짝 늘리면 넓이는 얼마나 느는가
늘어난 넓이 (정확히)–
고리를 펴서 근사 2πr·h–
버린 조각 πh²–
변화율 (늘어난 넓이)/h–
둘레 2πr–
둘 사이의 차 (= πh)–

h를 왼쪽 끝까지 밀어보세요. 변화율이 둘레에 딱 붙습니다. 그리고 차이는 언제나 정확히 πh 입니다 — r 과는 아무 상관이 없습니다.

지금 눈으로 본 것
A(r+h) − A(r) = π(r+h)² − πr² = 2πr·h + πh²
h로 나누면   = 2πr + πh   h → 0 이면  → 2πr
  • 2πr·h고리를 편 직사각형. 둘레 × 두께
  • πh²고리가 안쪽보다 바깥이 넓어서 생기는 여분. h가 두 번 곱해진 항이라 h로 나눠도 h가 남아 극한에서 사라집니다
  • 이 패턴'한 번 작은 것은 살아남고 두 번 작은 것은 사라진다' — 4강에서 모든 미분 공식이 이 규칙 하나로 나옵니다
미리 보는 미적분학 기본정리
어떤 양의 변화율을 알면 그 양 자체를 복원할 수 있고, 어떤 양의 축적을 알면 그 변화율을 알 수 있습니다. 미분과 적분은 서로를 되돌리는 역연산입니다.

방금 본 것이 그 예고편입니다. 넓이 πr² 을 미분하면 둘레 2πr, 거꾸로 둘레 2πr 을 적분하면 넓이 πr². 9강에서 정식으로 증명합니다.

7. 적분 기호 읽는 법

§3에서 한 일 — 2πr·dr 을 r=0 부터 r=R 까지 전부 더한다 — 을 수학은 이렇게 적습니다.

원의 넓이, 적분으로
원의 넓이 = ∫0R 2πr dr = πR²
  • ∫합(Sum)의 S를 길게 늘인 것입니다. "전부 더하라"는 뜻이에요. 새 개념이 아니라 Σ 의 연속판입니다
  • 0 과 R더하기 시작하는 r 과 끝내는 r
  • 2πr더할 조각의 높이 (그 고리의 둘레)
  • dr조각의 폭. 0으로 보낼 예정인 아주 작은 두께
  • 읽는 법"높이 × 폭 을 r=0 부터 R까지 전부 더하라." 기호 자체가 그림을 담고 있습니다

이 식이 왜 πR² 인지는 이미 그림으로 봤습니다 — 밑변 R, 높이 2πR 인 삼각형의 넓이이니까요. ½ × R × 2πR = πR².

8. 파이썬으로 확인하기

아래 셀의 ▶ 실행 을 누르면 브라우저 안에서 진짜 파이썬이 돕니다. 처음 한 번은 파이썬을 내려받느라 시간이 좀 걸립니다. 숫자를 바꿔가며 직접 실험해 보세요.

import numpy as np R = 1.0 def 고리합(n, 어디="안쪽"): dr = R / n r = np.arange(n) * dr # 각 고리의 안쪽 반지름 if 어디 == "가운데": r = r + dr/2 if 어디 == "바깥": r = r + dr return (2*np.pi*r * dr).sum() # Σ (둘레 × 두께) print(f"{'n':>5} {'안쪽':>12} {'가운데':>12} {'바깥':>12}") for n in [1, 2, 4, 8, 20, 80, 1000]: print(f"{n:>5} {고리합(n,'안쪽'):>12.6f} {고리합(n,'가운데'):>12.6f} {고리합(n,'바깥'):>12.6f}") print(f"\n참값 πR² = {np.pi:.6f}")
가운데로 재면 왜 n=1 에서도 정확한가 고리 하나의 참 넓이는 π(r₂²−r₁²) = π(r₂+r₁)(r₂−r₁) 인데, (r₂+r₁)/2 가 바로 가운데 반지름입니다. 그래서 가운데 둘레 2π·((r₁+r₂)/2) 에 두께를 곱하면 근사가 아니라 정확한 값이 됩니다. 모자란 부분과 넘치는 부분이 정확히 상쇄되는 것이죠. 9강의 중점 리만합이 정확히 이 이유로 더 좋습니다.
print(f"{'n':>5} {'안쪽 합':>11} {'πR²(n-1)/n':>13} {'오차 %':>9}") for n in [2, 5, 10, 50, 200]: s = 고리합(n, "안쪽") 예상 = np.pi * (n-1) / n print(f"{n:>5} {s:>11.6f} {예상:>13.6f} {100*(np.pi-s)/np.pi:>8.3f}%") print("\n→ 정확히 일치한다. 오차는 πR²/n 이므로 n을 키우면 0으로 간다.")
def A(r): return np.pi * r**2 # 넓이 r = 1.0 print(f"반지름 r = {r}, 둘레 2πr = {2*np.pi*r:.8f}\n") print(f"{'h':>10} {'(A(r+h)-A(r))/h':>18} {'차이':>12}") for h in [0.5, 0.1, 0.01, 0.001, 0.0001]: 변화율 = (A(r+h) - A(r)) / h print(f"{h:>10} {변화율:>18.8f} {변화율 - 2*np.pi*r:>12.8f}") print("\n→ 차이가 정확히 πh 다. π×0.0001 =", np.pi*0.0001)
여기서 h = 0 을 넣으면 안 됩니다 (A(r+0) - A(r)) / 0 은 0/0 이라 파이썬도 답을 못 냅니다. 우리가 한 건 h를 0으로 만든 것이 아니라 0에 다가가게 한 것입니다. 이 구분이 미적분 전체의 핵심이고, 2강과 3강의 주제입니다.
# 고리 대신 '양파 껍질(구면)'로 쪼갠다. # 반지름 r 인 구면의 겉넓이는 4πr² 이므로, 껍질 하나의 부피 ≈ 4πr²·dr R = 1.0 for n in [10, 100, 10000]: dr = R / n r = (np.arange(n) + 0.5) * dr # 가운데로 재기 V = (4*np.pi*r**2 * dr).sum() print(f"n={n:>6} Σ 4πr²·dr = {V:.8f}") print(f"\n참값 (4/3)πR³ = {4/3*np.pi:.8f}") print("→ 겉넓이를 적분하면 부피. 넓이·둘레와 완전히 같은 구조다.")
# 문제 1. 부채꼴로 쪼개는 방법에서 '톱니 깊이'는 R(1 - cos(π/n)) 입니다. # n = 4, 16, 64 일 때 값을 계산해보세요. # 문제 2. 반지름 R 인 원의 넓이를 '바깥 둘레'로 재면 πR²(n+1)/n 입니다. # n = 1000 일 때 오차가 몇 % 인지 구해보세요. # 문제 3. 부피 (4/3)πr³ 을 r 로 미분하면 무엇이 나올까요? # 1-3 셀의 방법으로 확인해보세요. # 아래에 직접 써보세요

# 문제 1 — 톱니 깊이 for n in [4, 16, 64]: print(f"n={n:>3} 톱니 깊이 = {1 - np.cos(np.pi/n):.6f}") print("→ n을 4배 하면 깊이는 약 16배 줄어든다 (n²에 반비례)\n") # 문제 2 — 바깥 둘레로 잰 오차 n = 1000 print(f"바깥 합 = {np.pi*(n+1)/n:.6f}, 오차 = {100/n:.3f}%\n") # 문제 3 — 부피를 미분하면 겉넓이 def V(r): return 4/3 * np.pi * r**3 r = 1.0 for h in [0.1, 0.01, 0.001]: print(f"h={h:>6} (V(r+h)-V(r))/h = {(V(r+h)-V(r))/h:.6f}") print(f"겉넓이 4πr² = {4*np.pi*r**2:.6f} ← 같은 값으로 수렴한다")

  • 컴퓨터 그래픽스 — 곡면을 아주 작은 삼각형으로 쪼개 렌더링하는 것이 "쪼개면 단순해진다"의 직접적 응용입니다.
  • 수치해석 — 적분값을 컴퓨터로 구할 때 쓰는 사다리꼴 법칙 · 심프슨 법칙이 전부 §3의 계단 그림입니다(1부 8강).
  • 확률·통계 — 확률밀도함수 아래 넓이가 확률입니다. 정규분포의 확률을 구하는 일이 곧 오늘의 작업입니다.

1강 요약

  • 미적분은 쪼개기 → 근사하기 → 합치기 → 극한 보내기 네 박자의 반복입니다.
  • 쪼개면 단순해집니다. 곡선 조각은 직선처럼, 얇은 고리는 직사각형처럼 다룰 수 있습니다.
  • 고리를 펴면 가로 2πr, 세로 dr. 전부 세워 붙이면 밑변 R, 높이 2πR 인 삼각형이 되고, 그 넓이가 ½ · R · 2πR = πR² 입니다.
  • 근사의 오차는 작아지는 게 아니라 극한에서 0으로 사라집니다. 그래서 ≈ 가 = 로 바뀝니다.
  • ∫₀ᴿ 2πr dr 은 "높이 × 폭을 전부 더하라"는 문장의 줄임말일 뿐입니다.
  • 넓이를 미분하면 둘레, 둘레를 적분하면 넓이 — 미분과 적분은 서로의 역연산입니다(9강).
  • '한 번 작은 것(2πr·h)은 살아남고 두 번 작은 것(πh²)은 사라진다' — 4강 전체가 이 규칙입니다.
