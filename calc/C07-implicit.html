음함수 미분 — 제약 속의 변화율

지금까지는 y = f(x) 처럼 x 를 넣으면 y 가 바로 나오는 '착한' 함수만 다뤘습니다. 그런데 원의 방정식 x² + y² = 25 는 y로 풀면 y = ±√(25−x²) 로 지저분해지고, y = sin(x+y) 같은 건 아예 못 풉니다. 그래도 곡선 위 한 점에서 접선 기울기는 알고 싶죠. 이럴 때 쓰는 것이 음함수 미분입니다.

0. 기초 다지기 — 음함수란 무엇인가

양함수(陽函數) 는 y = x² + 1 처럼 y 가 혼자 왼쪽에 나와 있는 식입니다. 값을 바로 계산할 수 있죠.

음함수(陰函數) 는 x² + y² = 25 처럼 x 와 y 가 뒤섞여 있는 식입니다. y 값이 식 안에 숨어 있어서(陰) 붙은 이름입니다.

왜 음함수를 그냥 y로 풀지 않나요?
① 풀면 지저분해집니다. x²+y²=25 → y = ±√(25−x²). 부호가 둘로 갈리고, 제곱근 미분에 연쇄법칙까지 붙습니다.
② 아예 못 푸는 경우가 많습니다. y = sin(x+y), x³+y³ = 3xy, 열역학의 반데르발스 상태방정식 — 전부 y에 대해 풀리지 않습니다.
③ 애초에 '함수'가 아닐 수도 있습니다. 원은 한 x 에 y 가 두 개입니다. 그래도 각 점에서 접선은 멀쩡히 존재하죠.

음함수 미분은 이 셋을 전부 피해 갑니다.

1. 값의 지형도와 등고선

발상의 전환. x² + y² 을 '평면 위 각 점의 고도' 를 주는 지형으로 봅시다.

  • 점 (1, 2) 의 고도는 1 + 4 = 5
  • 점 (3, 4) 의 고도는 9 + 16 = 25

그러면 방정식 x² + y² = 25 는 이 지형에서 고도가 25로 일정한 등고선 — 즉 반지름 5인 원입니다.

① 등고선 위를 걸으면 고도가 안 변한다
점–
고도 x² + y²–
x 쪽 기여 2x–
y 쪽 기여 2y–
접선 기울기 −x/y–
검산 (수치)–

초록 접선과 빨간 화살표(고도가 가장 빨리 오르는 방향)가 언제나 수직입니다. 당연하죠 — 가장 가파른 방향과 직각으로 가야 고도가 안 변하니까요.

2. 균형 조건 하나로 끝내기

등고선을 따라 걷는 한, 고도는 변하지 않아야 합니다. 점을 dx, dy 만큼 살짝 옮길 때 고도의 변화는 두 기여의 합인데 (x² 항에서 2x·dx, y² 항에서 2y·dy — 4강의 정사각형 논리 그대로), 이 합이 0이어야 등고선 위에 남습니다.

음함수 미분의 전부
2x·dx + 2y·dy = 0  ⟹  dydx = − xy
  • 2x·dxx 를 dx 만큼 밀 때 x² 항이 올려주는 고도. 4강의 정사각형 두 띠죠
  • 2y·dyy 를 dy 만큼 밀 때 y² 항이 올려주는 고도
  • = 0등고선을 벗어나지 않는 조건. 이 한 줄이 전부입니다
  • 확인점 (3,4) 에서 x를 살짝 늘리면 고도가 2×3 = 6 의 비율로 오르려 합니다. 상쇄하려면 y쪽에서 2×4 = 8 의 비율로 내려야 하죠. 6dx + 8dy = 0 ⟹ dy/dx = −3/4
전통적 방법과 비교해 보세요 · y = √(25−x²) 를 미분하면 y′ = −x/√(25−x²) 입니다. x=3 을 넣으면 −3/4 — 같은 답이죠. 그런데 음함수 방법은 제곱근도, 연쇄법칙도, 부호 갈림도 필요 없었습니다. 게다가 아래쪽 반원(y < 0)도 −x/y 하나로 동시에 처리됩니다.

3. 여러 곡선에서 확인하기

원 말고도 해봅시다. 방법은 언제나 같습니다 — 양변을 미세 변화로 바꾸고, 합이 0이 되게 놓는다.

② y 로 풀리지 않는 곡선들
점–
x 쪽 기여–
y 쪽 기여–
접선 기울기–
공식–

데카르트 잎은 원점에서 스스로 교차하고 수직 접선도 갖습니다. y = sin(x+y) 는 y로 풀 방법이 아예 없는데도 접선은 멀쩡히 나옵니다.

일반 공식
F(x, y) = 상수  ⟹  Fx·dx + Fy·dy = 0  ⟹  dydx = − FxFy
  • Fxy 를 상수로 두고 x 로만 미분한 것 (편미분). "x 를 밀 때 고도가 오르는 비율"
  • Fyx 를 상수로 두고 y 로만 미분한 것
  • Fy = 0 이면기울기가 무한대 — 즉 수직 접선입니다. 원에서 (±5, 0) 이 그런 점이죠
  • 기하학적 뜻벡터 (Fx, Fy) 는 고도가 가장 빨리 오르는 방향(기울기 벡터)이고, 접선은 그것과 수직입니다

4. 사다리 문제 — 맞물려 변하는 변수들

길이 5m 사다리가 벽에 기대 있습니다. 바닥 끝이 벽에서 3m 떨어진 순간, 초당 0.5m 로 미끄러지고 있습니다. 꼭대기는 얼마나 빨리 내려올까요?

③ 사다리가 미끄러진다
바닥 거리 x–
높이 y–
바닥 속도 dx/dt–
꼭대기 속도 dy/dt–
속도 비 |dy/dt ÷ dx/dt|–

x 를 오른쪽 끝까지 밀어보세요. 사다리가 눕는 순간 꼭대기 속도가 폭발합니다(y → 0 이라 −x/y 가 무한대). 실제로 사다리가 마지막에 쾅 떨어지는 이유입니다.

시간으로 미분하기 (관련 변화율)
x² + y² = 25  ⟹  2x·dxdt + 2y·dydt = 0
x=3, y=4, dx/dt=0.5 를 넣으면
2·3·0.5 + 2·4·dydt = 0  ⟹  dy/dt = −0.375 m/s
  • 달라진 점§2에서는 x 로 미분했고, 여기서는 t(시간)로 미분했습니다. 방법은 완전히 같습니다
  • 음수꼭대기가 내려온다는 뜻
  • 누가 원인인가어느 쪽도 아닙니다. 둘은 '사다리 길이 일정'이라는 제약으로 맞물려 함께 변할 뿐입니다
⚠ 흔한 오해 "음함수 미분은 별도의 새로운 미분법이다."
아닙니다 — 내용물은 지금까지 배운 미분 그대로입니다 새로운 것은 관점 하나뿐입니다 — "관계식이 유지되려면(등고선을 벗어나지 않으려면) 변화량들의 합이 0이어야 한다" 는 조건을 쓰는 것.
각 항을 미분하는 일 자체는 4·5강에서 배운 것을 그대로 씁니다. y² 을 x로 미분할 때 2y·y′ 이 되는 것도 연쇄법칙일 뿐이죠 (y가 x의 함수니까요).

5. 보너스: ln x 의 미분을 공짜로

y = ln x 는 ey = x 라는 뜻입니다 (로그의 정의). 양변에 미세 변화를 주면:

(ln x)′ = 1/x — 계산 없이
ey = x  ⟹  ey·dy = dx
그런데 ey 가 곧 x 이므로
x·dy = dx  ⟹  (ln x)′ = 1/x
  • 왼쪽 미분ey 를 미분하면 연쇄법칙으로 ey·dy (6강: (eu)′ = eu)
  • 치환 한 방ey = x 를 그대로 대입하면 끝. 이게 음함수 미분의 힘입니다
  • 뜻ln x 는 x가 클수록 천천히 자랍니다. x=1 에서 기울기 1, x=100 에서 기울기 0.01
  • 같은 방법으로y = √x 는 y² = x ⟹ 2y·dy = dx ⟹ 1/(2√x). 4강 §5와 같은 답이죠

음함수 미분이 실제로 하는 일
  • 열역학 — 반데르발스 상태방정식 (P + a/V²)(V − b) = RT 는 V로 풀리지 않습니다. 그래도 압축률 ∂V/∂P 는 음함수 미분으로 바로 나옵니다.
  • 경제학의 무차별곡선 — 효용 U(x,y) = 상수 가 등고선이고, 그 기울기가 한계대체율입니다.
  • 기계학습의 등고선 — 손실함수의 등고선과 기울기 벡터가 수직이라는 사실이 경사하강법의 기하학입니다.
  • 관련 변화율 — 레이더로 항공기 거리 변화율에서 속도를 뽑아내는 계산이 사다리 문제와 똑같은 구조입니다.
  • 제약 최적화 — 라그랑주 승수법이 "목적함수의 등고선과 제약 곡선이 접한다"는 이 그림의 확장입니다.

7강 요약

  • 음함수는 x 와 y 가 뒤섞인 식입니다. y 로 풀면 지저분하거나, 아예 안 풀리거나, 함수가 아닐 수도 있습니다.
  • 관계식을 지형의 등고선으로 봅니다. 등고선 위를 걸으면 고도가 안 변합니다.
  • 그래서 Fx·dx + Fy·dy = 0 — 변화량들의 합이 0. 이 한 줄이 전부입니다.
  • dy/dx = −Fx / Fy. Fy = 0 이면 수직 접선.
  • 접선은 '고도가 가장 빨리 오르는 방향'과 수직입니다.
  • 시간으로 미분하면 관련 변화율 문제가 됩니다. 사다리는 2x·x′ + 2y·y′ = 0.
  • 새 미분법이 아니라 새 관점입니다. 미분 자체는 4·5강 그대로예요.
  • 덤으로 (ln x)′ = 1/x 를 계산 없이 얻었습니다.
