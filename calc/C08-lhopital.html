로피탈 정리와 입실론-델타

0. 기초 다지기 — 부정형이란

3강에서 봤듯이 0/0 은 부정형입니다 — 식만 봐서는 답을 알 수 없는 꼴. 부정형은 이것 말고도 여럿 있습니다.

꼴예실제 극한
0/0sin x / x1
0/0x² / x0
0/0x / x³∞ (없음)
∞/∞(2x+1) / (x−3)2
0 · ∞x · ln x0 (x→0⁺)
1∞(1+1/n)ne (6강!)
같은 꼴인데 답이 다 다릅니다
sin x/x, x²/x, x/x³ 은 전부 0/0 인데 답은 1, 0, ∞ 로 제각각입니다.

그래서 '꼴'이 아니라 '누가 더 빨리 0으로 가는가'를 봐야 합니다. 이 강의는 그 속도 비교를 체계화합니다.

1. 그래프의 구멍 — 극한이 진짜 필요한 순간

f(x) = sin(x)/x 를 봅시다. x=0 을 넣으면 0/0 이라 정의되지 않습니다 — 그래프에 구멍이 있죠. 그런데 0 근처 값을 넣어보면 sin(0.1)/0.1 ≈ 0.9983, sin(0.01)/0.01 ≈ 0.99998 — 값이 1을 향해 몰려갑니다.

① 두 함수가 0으로 가는 '속도'를 비교한다
분자의 기울기 f′(0)–
분모의 기울기 g′(0)–
기울기의 비 f′/g′–
실제 극한 (수치)–

위는 분자 f 와 분모 g 를 따로 그린 것입니다. 둘 다 0을 지나가죠. 확대해 보면 둘 다 직선처럼 보이고(2강), 비율은 두 직선의 기울기 비로 결정됩니다.
아래는 그 비 f/g 입니다. x=0 에 구멍이 뚫려 있지만, 함수는 그 구멍이 어떤 값으로 메워져야 하는지 분명히 가리키고 있습니다.

2. 로피탈 정리 — 0/0은 기울기의 경주

두 함수 f, g 가 모두 x=a 에서 0 이라 합시다. a 근처에서 각 함수를 접선으로 근사하면 (2강의 확대 논리) f(a+dx) ≈ f′(a)·dx, g(a+dx) ≈ g′(a)·dx. 비율을 만들면 공통의 dx 가 약분됩니다.

로피탈 정리
lim x→a f(x)g(x) = lim dx→0 f′(a)·dxg′(a)·dx = f′(a)g′(a)
단, 0/0 또는 ∞/∞ 꼴일 때만
  • 직관둘 다 0으로 향하는 두 함수의 비는 '누가 더 빨리 0으로 가는가' — 두 접선 기울기의 비로 결정됩니다
  • sin x / xcos(x)/1 → cos(0) = 1
  • (eˣ−1)/xeˣ/1 → 1
  • x²/x2x/1 → 0. 분자가 더 빨리 0으로 가니 비는 0
  • 두 번 써도 됩니다(1−cos x)/x² 는 한 번 쓰면 sin x / 2x 로 여전히 0/0 — 한 번 더 쓰면 cos x / 2 → 1/2

3. 쓰면 안 되는 경우

⚠ 흔한 오해 "로피탈은 아무 극한에나 써도 된다."
0/0 또는 ∞/∞ 꼴에서만 성립합니다 limx→1 (x+3)/(x+1) = 4/2 = 2 인데, 분모·분자를 미분하면 1/1 = 1 — 엉뚱한 답이 나옵니다.
0/0 꼴이 아닌데도 기계적으로 미분해버리는 것이 가장 흔한 사고입니다. 먼저 대입해서 꼴을 확인하세요.
순환논증에 주의 sin 의 도함수가 cos 이라는 사실을 증명할 때는 limx→0 sin x / x = 1 이라는 극한 자체가 필요합니다. (정의식을 전개하면 이 극한이 나옵니다.)

그러니 그 맥락에서 sin x/x 를 로피탈로 풀면 "A를 증명하려고 A를 쓰는" 순환논증이 됩니다. 도구에는 사용 조건이 있습니다. (그래도 값을 확인하는 용도로는 아무 문제 없습니다 — 이 강의처럼요.)
로피탈을 써도 안 끝나는 경우 limx→∞ (x + sin x)/x 의 답은 1 입니다. 그런데 로피탈을 쓰면 (1 + cos x)/1 — 진동해서 극한이 없습니다.

로피탈은 "미분한 쪽의 극한이 존재하면" 원래 극한도 그 값이라는 정리입니다. 거꾸로는 성립하지 않습니다. 미분한 쪽이 실패했다고 원래 극한이 없는 건 아닙니다.

4. 입실론-델타 — '한없이 가까이'의 게임화

마지막 관문입니다. "한없이 가까워진다" 는 표현은 직관적이지만 모호합니다. 19세기 수학자들(코시, 바이어슈트라스)은 이를 두 사람의 공방 게임으로 바꿔 못 박았습니다.

ε-δ 게임의 규칙
공격수가 허용 오차 ε(입실론)을 제시한다:
  "f(x) 가 목적지 L 에서 ±ε 안에 들어와야 인정한다."
방어수는 입력 범위 δ(델타)로 응수한다:
  "x 를 a 에서 ±δ 안에만 두면 항상 그렇게 된다."
판정: 공격수가 ε 을 아무리 작게 잡아도 방어수가 매번 δ 를 찾아낼 수 있다면 — 그 극한은 존재한다.
  • ε세로 방향 허용 오차 (결과의 정밀도)
  • δ가로 방향 입력 범위 (내가 통제할 수 있는 것)
  • 순서가 중요ε 이 먼저, δ 가 나중. "어떤 정밀도를 요구하든 그것을 달성할 방법이 있다"는 뜻입니다
  • 무한이 사라졌다'무한히'라는 무한의 언어를 '모든 도전에 응수하는 전략의 존재'라는 유한한 논리로 바꾼 것 — 현대 해석학의 주춧돌입니다
② ε 을 아무리 좁혀도 δ 를 찾을 수 있는가

δ–
δ 안에서 f 가 벗어난 최대치–
판정–

가로 띠(δ) 안의 곡선이 세로 띠(ε) 밖으로 나가면 방어 실패입니다. ε 을 줄여도 δ 를 더 줄이면 다시 성공하죠. [자동 응수] 를 눌러 확인해 보세요.
그런데 점프 함수에서는 ε 을 충분히 작게 잡으면 어떤 δ 로도 방어할 수 없습니다 — 그래서 극한이 없습니다.

5. 실전 방어전

limx→2 (3x+1) = 7 을 방어해 봅시다.

δ = ε/3 이라는 전략
공격수: ε = 0.1  →  3x+1 이 6.9 ~ 7.1 사이여야 한다
계산: 3x 가 5.9 ~ 6.1  →  x 가 1.9667 ~ 2.0333
방어수: δ = 0.0333 (= ε/3) 으로 응수 ✓
공격수: ε = 0.0001  →  방어수: δ = 0.0000333 (= ε/3) ✓
  • 핵심어떤 ε 에도 통하는 전략(δ = ε/3) 이 있습니다. 매번 새로 계산하는 게 아니라 공식 하나로 끝나죠
  • 3 의 정체기울기입니다. 기울기가 클수록 δ 를 더 좁혀야 같은 ε 을 지킬 수 있습니다. 직관과 정확히 맞죠
  • x²의 경우기울기가 x마다 달라서 δ 가 ε/4 보다 조금 작아야 합니다(x=2 에서 기울기 4). ε=0.1 이면 δ ≈ 0.0248
  • 그래서 극한이 참이다전략이 존재하므로 lim = 7 은 참입니다. 증명 끝.
ε-δ 를 실무 언어로 읽으면 · ε 은 '요구 사양', δ 는 '공정 관리 범위' 입니다. "출력 전압을 ±0.1V 안에 유지하라(ε)" 는 요구가 오면 "입력을 ±0.03V 안으로 관리하면 된다(δ)" 고 답하는 것. 어떤 사양이 와도 대응할 관리 범위가 있다면 그 시스템은 '연속'입니다. 공학의 허용오차 설계가 문자 그대로 이 게임입니다.

이 두 도구가 실제로 하는 일
  • 수치해석의 조건수 — "입력 오차 δ 가 출력 오차 ε 으로 얼마나 증폭되는가"가 바로 ε/δ 비입니다. 조건수가 크면 δ 를 아무리 줄여도 답이 흔들립니다.
  • 제어공학의 안정성 마진 — "외란이 δ 안이면 출력이 ε 안"이라는 보장이 입력-출력 안정성의 정의입니다.
  • 알고리즘의 점근 복잡도 — O(n log n) 같은 표기는 "누가 더 빨리 커지는가"의 경주입니다. §2와 정확히 같은 사고죠.
  • 기계학습의 수렴 증명 — "임의의 ε 에 대해 어떤 N 이후로는 오차가 ε 미만"이 수렴 정리의 표준 문장입니다.

  • 0/0 은 부정형입니다. 같은 꼴이라도 답은 1, 0, ∞ 로 제각각. '0으로 가는 속도'가 답을 정합니다.
  • 로피탈 정리: 0/0 또는 ∞/∞ 꼴이면 lim f/g = f′/g′. 두 접선 근사의 dx 가 약분되기 때문입니다.
  • 꼴이 아니면 쓰면 안 됩니다. 대입해서 확인부터 하세요.
  • 미분한 쪽이 실패해도 원래 극한은 있을 수 있습니다. 정리는 한 방향입니다.
  • ε-δ: 공격수가 세로 오차 ε 을 주면 방어수가 가로 범위 δ 로 응수. 모든 ε 에 응수할 전략이 있으면 극한이 존재합니다.
  • δ = ε / (기울기) 가 표준 전략입니다. 기울기가 클수록 δ 를 더 좁혀야 합니다.
  • '무한히 가까이'를 유한한 논리로 바꾼 것 — 이것이 현대 해석학의 주춧돌입니다.
