극한 — '도착'이 아니라 '접근'

1강 끝에서 '두께를 0으로 보낸다' 는 조작을 썼습니다. 이 조작이 미적분 전체를 떠받치는 기둥, 바로 극한입니다. 미분도 적분도 결국 극한 위에 서 있으니, 여기서 확실히 잡고 갑시다. 핵심은 한 문장입니다 — 도착하지 않아도 목적지는 알 수 있다.

0. 기초 다지기 — 왜 극한이 필요한가

1강에서 원을 n개의 고리로 쪼갰습니다. n이 6일 때 오차 16.7%, 80일 때 1.25% 였죠. 그런데 우리가 원한 건 "오차가 작다" 가 아니라 "오차가 없다" 였습니다.

그래서 n을 무한히 키운다고 했습니다. 그런데 곰곰이 생각하면 이상합니다. 무한은 숫자가 아닙니다. n에 ∞ 를 대입할 수는 없어요. "무한히 많은 고리"라는 것도 실제로는 존재하지 않습니다. 그럼 우리가 한 건 대체 무슨 계산이었을까요?

극한은 '무한을 다루는 법'이 아니라 '무한을 피하는 법'입니다
극한은 ∞ 를 대입하지 않습니다. 대신 n = 10, 100, 1000, … 이라는 유한한 계산들의 목록을 만들고, 그 목록이 어디를 가리키는지를 읽습니다.

"n이 커질수록 값이 3.14159… 에 원하는 만큼 가까워진다" — 이 문장은 무한을 한 번도 쓰지 않고 무한의 결론을 말합니다. 이게 극한의 전부입니다.

1. 다가가는 수들

0.9, 0.99, 0.999, 0.9999 … 이 수열은 어디로 갈까요? 어떤 항도 1은 아닙니다. 하지만 원하는 만큼 1에 가까워질 수 있습니다. 소수점 아래 9를 백 개 붙이면 1과의 차이는 상상하기 힘들 만큼 작죠.

이럴 때 우리는 "이 수열의 극한은 1" 이라고 말합니다. 도착하지 않지만, 목적지가 어디인지는 확실합니다.

① 아무리 확대해도 목적지는 그대로다
마지막 항–
1과의 차–
아래 그림의 확대 배율–
목적지1

위는 전체 모습, 아래는 1 근처를 확대한 모습입니다. 슬라이더를 밀면 아래 그림이 계속 확대되는데도 점은 여전히 1의 왼쪽에 있습니다. 영원히 닿지 않습니다. 그런데도 어디로 가는지는 명백하죠.

⚠ 흔한 오해 "극한이 1이라는 건 언젠가 1이 된다는 뜻이다."
아닙니다 — 영원히 1이 되지 않습니다 0.999…9 는 9가 몇 개든 항상 1보다 작습니다. 극한은 "언젠가 도달한다"는 예언이 아니라, "얼마나 가깝게든 만들 수 있다"는 보장입니다.
"1과의 차를 0.000001 아래로 만들어봐" 라고 요구하면 → 7번째 항을 내놓으면 됩니다. 어떤 요구가 와도 응할 수 있다 — 그래서 극한이 1입니다. (8강에서 이 게임을 정식으로 다룹니다.)

2. lim 기호 읽는 법

극한의 표기
lim x→a f(x) = L
  • 읽는 법"x가 a에 한없이 가까워질 때 f(x)는 L에 한없이 가까워진다"
  • x → a다가간다. x = a 는 아닙니다. 오히려 x ≠ a 인 점들만 봅니다
  • L목적지. f가 a에서 실제로 얼마인지와는 상관이 없습니다(§4)
  • = 의 뜻"과정이 끝났다"가 아니라 "이 과정이 가리키는 값이 L이다"

3. 확대의 비유 — 곡선이 직선이 된다

곡선 위 한 점에서의 '방향'을 알고 싶다고 합시다. 그런데 한 점만 보면 방향이라는 게 없습니다 — 방향은 두 점이 있어야 정의되니까요.

그런데 곡선을 그 점 주위로 계속 확대하면 신기한 일이 벌어집니다. 구불구불하던 곡선이 점점 곧게 펴져서, 충분히 확대하면 직선과 구별할 수 없게 됩니다.

② 확대할수록 곡선이 직선이 된다
보이는 x 범위의 폭–
접선 기울기–
곡선이 직선에서 벗어난 정도–
매끈한가–

확대 배율을 끝까지 밀어보세요. x², sin x, √x 는 파란 곡선이 회색 직선 뒤로 완전히 숨습니다. 그런데 |x| 는 아무리 확대해도 꺾인 채로 남습니다 — x₀ = 0 에 맞춰놓고 확대해 보세요.

국소 선형성 (局所線形性)
충분히 확대하면   f(x₀ + d) ≈ f(x₀) + m · d
여기서 m 이 그 극한의 직선(접선)의 기울기 = 미분값
  • 왜 통하는가x² 은 접선에서 d² 만큼 벗어납니다. 창의 폭이 d 이므로 어긋남 ÷ 창 크기 = d → 확대할수록 0으로 갑니다
  • 위 패널의 숫자폭 3 → 어긋남 50%, 폭 0.3 → 5%, 폭 0.03 → 0.5%. 폭을 10배 줄이면 어긋남도 10배 줄어듭니다
  • |x| 는 왜 안 되나꺾인 점에서는 왼쪽 기울기 −1, 오른쪽 기울기 +1. 확대해도 이 둘이 영원히 만나지 않습니다. 그래서 미분이 불가능합니다
"확대를 무한히 반복하면 도달하는 그 직선" · 이것이 극한적 사고입니다. 어떤 유한한 확대에서도 완벽한 직선은 아니지만, 목적지는 명확합니다. 3강의 미분이 정확히 이 아이디어를 수식으로 옮긴 것입니다.

4. 극한값은 함숫값이 아니다

가장 중요한 구분입니다. 극한은 '주변에서 어디를 가리키는가' 이지 '그 점에서 실제로 얼마인가' 가 아닙니다.

아래 [구멍] 을 보세요. f(x) = (x²−1)/(x−1) 은 x=1 에서 0/0 이라 정의되지 않습니다. 그래프에 구멍이 뚫려 있죠. 그런데 x를 1에 가까이 가져가면 값이 2를 향해 몰려갑니다.

③ 극한이 있을 때와 없을 때
지금 x–
f(x)–
x = 1 에서의 함숫값–
x → 1 의 극한–

슬라이더를 오른쪽 끝까지 밀고 왼쪽·오른쪽 접근을 번갈아 눌러보세요. 양쪽이 같은 값을 가리켜야 극한이 존재합니다.

5. 극한이 없을 때 — 점프와 진동

극한이 존재할 조건
lim x→a⁻ f(x) = lim x→a⁺ f(x) = L  ⟺  lim x→a f(x) = L
  • a⁻왼쪽에서 다가감 (a보다 작은 쪽). 좌극한
  • a⁺오른쪽에서 다가감. 우극한
  • 점프좌극한 1, 우극한 2.2 — 둘이 다르므로 극한이 없습니다. 전자회로의 스위칭, 계단 요금제가 이런 모양입니다
  • 진동sin(1/(x−1)) 은 1에 가까워질수록 더 빠르게 위아래로 흔들립니다. 어떤 값에도 정착하지 않으므로 극한이 없습니다
"극한이 없다" 와 "무한대다" 는 다릅니다 1/x² 은 x→0 에서 무한히 커집니다. 이때 lim = ∞ 라고 쓰긴 하지만, 이건 "극한값이 ∞ 라는 수다" 라는 뜻이 아니라 "어떤 유한한 값에도 정착하지 않고 한없이 커진다"는 거동의 서술입니다. 엄밀히 말하면 극한은 존재하지 않습니다. 기호 사전의 "∞ 는 수가 아니라 과정" 이라는 말이 여기서 힘을 발휘합니다.

6. 0.999… 는 1인가

§1의 수열은 영원히 1이 아니라고 했습니다. 그런데 수학은 0.999… = 1 이라고 합니다. 모순일까요?

모순이 아닙니다. 두 문장은 다른 것을 말하고 있습니다.

두 문장을 구분하면
수열의 각 항 0.9, 0.99, 0.999, … 은 전부 1보다 작다 ✓
기호 0.999… 는 항이 아니라 그 수열의 극한을 가리키는 이름이다 ⟹ = 1 ✓
  • 핵심… 이라는 표기 자체가 이미 '극한'을 뜻합니다. "9를 아주 많이 붙인 수"가 아니라 "그 과정이 가리키는 목적지"라는 말이죠
  • 간단한 증명x = 0.999… 라 하면 10x = 9.999… 이고, 빼면 9x = 9 → x = 1
  • 더 짧게1과 0.999… 사이에 낄 수 있는 수가 하나도 없습니다. 서로 다른 두 실수 사이에는 반드시 다른 수가 있으므로, 둘은 같은 수입니다

7. 파이썬으로 확인하기

import numpy as np print(f"{'n':>3} {'항':>22} {'1과의 차':>12}") for n in range(1, 17): 항 = 1 - 10.0**(-n) print(f"{n:>3} {항:>22.16f} {10.0**(-n):>12.0e}") print("\n→ 어떤 항도 1이 아니다. 그런데 '1과의 차'를 원하는 만큼 작게 만들 수 있다.") print(" (16번째부터는 컴퓨터의 소수 자릿수 한계로 1로 보인다 — 수학이 아니라 기계의 한계다)")
컴퓨터의 소수는 무한하지 않습니다 파이썬의 float 은 약 16자리까지만 구분합니다. 그래서 1 - 1e-17 == 1 이 True 로 나옵니다. 수학에서는 절대 같지 않은 두 수인데도요. 극한 개념은 수학의 것이고, 컴퓨터는 그 근사일 뿐이라는 것을 늘 기억해야 합니다. 수치해석에서 이 차이를 놓치면 계산이 조용히 틀립니다.
def 어긋남(f, x0, 반폭, 기울기): """창 안에서 곡선이 접선에서 벗어난 최대 거리를, 창 높이 대비 %로""" d = np.linspace(-반폭, 반폭, 2001) 곡선 = f(x0 + d) 접선 = f(x0) + 기울기 * d return 100 * np.abs(곡선 - 접선).max() / (2 * 반폭) 함수들 = { "x²": (lambda x: x**2, lambda x: 2*x), "sin": (np.sin, np.cos), "√x": (np.sqrt, lambda x: 0.5/np.sqrt(x)), "|x|": (np.abs, lambda x: 0.0), # x=0 에서는 접선이 없다 } print(f"{'창 반폭':>8}", "".join(f"{이름:>10}" for 이름 in 함수들)) for w in [1.0, 0.1, 0.01, 0.001]: 행 = f"{w:>8}" for 이름, (f, df) in 함수들.items(): x0 = 0.0 if 이름 == "|x|" else 1.0 행 += f"{어긋남(f, x0, w, df(x0)):>9.4f}%" print(행) print("\n→ 매끈한 함수는 확대할수록 어긋남이 10배씩 줄어든다.") print(" |x| 는 x=0 에서 50% 로 고정 — 아무리 확대해도 꺾인 채다.")
def f(x): return (x**2 - 1) / (x - 1) # x=1 에서 0/0 print("x = 1 에 왼쪽에서 다가가기") for d in [0.1, 0.01, 0.001, 0.0001]: print(f" x = {1-d:<10.4f} f(x) = {f(1-d):.6f}") print("\nx = 1 에 오른쪽에서 다가가기") for d in [0.1, 0.01, 0.001, 0.0001]: print(f" x = {1+d:<10.4f} f(x) = {f(1+d):.6f}") print("\n→ 양쪽 모두 2를 가리킨다. lim(x→1) f(x) = 2") try: print("f(1) =", f(1)) except ZeroDivisionError: print("f(1) = 계산 불가 (0/0) ← 함숫값은 없는데 극한은 있다")

극한이 실제로 하는 일
  • 수치해석의 수렴 판정 — 반복 계산을 언제 멈출지는 "변화량이 ε 아래로 내려갔는가"로 정합니다. 극한의 정의를 그대로 코드로 옮긴 것입니다.
  • 제어공학의 정상상태 — 시스템이 t → ∞ 에서 어디로 수렴하는가가 안정성 판정입니다.
  • 기계학습의 학습률 — 손실이 어떤 값으로 수렴하는지, 아니면 진동하는지가 학습이 잘 되는지의 신호입니다. §5의 두 그림 그대로입니다.
  • 딥러닝의 ReLU — max(0,x) 는 0에서 |x| 처럼 꺾여 있어 미분이 정의되지 않습니다. 그래서 라이브러리들이 0에서의 값을 임의로 정해 씁니다.

2강 요약

  • 극한은 무한을 다루는 법이 아니라 무한을 피하는 법입니다. 유한한 계산들의 목록이 어디를 가리키는지를 읽습니다.
  • 도착하지 않아도 목적지는 확실합니다. "얼마나 가깝게든 만들 수 있다"는 보장이 극한의 내용입니다.
  • limx→a f(x) 는 x = a 를 보지 않습니다. x ≠ a 인 주변 점들만 봅니다.
  • 매끈한 곡선은 확대하면 직선이 됩니다(국소 선형성). 그 극한의 직선이 접선이고, 기울기가 미분값입니다.
  • 꺾인 점(|x|) 은 아무리 확대해도 펴지지 않습니다 — 미분 불가능.
  • 좌극한 = 우극한 일 때만 극한이 존재합니다. 점프와 진동은 극한이 없는 대표적인 두 경우입니다.
  • 0.999… = 1 입니다 — '…' 이라는 표기 자체가 극한을 뜻하는 이름이니까요.
