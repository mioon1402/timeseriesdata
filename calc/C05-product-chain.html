곱의 미분법과 연쇄법칙

실제 세계의 양들은 혼자 변하지 않습니다. 총수입 = 가격 × 판매량 처럼 두 양의 곱이거나, 기온 → 에너지소비 → 전기요금 처럼 변화가 사슬로 이어집니다. 결합된 함수의 변화를 다루는 두 규칙을 그림으로 이해합시다.

0. 기초 다지기 — 왜 그냥 곱하면 안 되나

가장 먼저 짚어야 할 것. 많은 사람이 (g·h)′ = g′·h′ 이라고 착각합니다. 틀렸습니다. 왜 틀렸는지 숫자 하나로 확인해 봅시다.

⚠ 가장 흔한 실수 (x · x)′ = (x)′ · (x)′ = 1 · 1 = 1 ?
x · x = x² 이고, (x²)′ = 2x 입니다 x=3 이면 답은 6 인데 위 계산은 1 을 줍니다. 완전히 틀렸죠.
미분은 곱셈을 그대로 통과하지 않습니다. 4강의 정사각형 그림을 떠올려 보세요 — 넓이가 늘 때는 가로 쪽 띠와 세로 쪽 띠가 각각 기여했습니다. 두 기여를 더해야 합니다.

1. 곱의 미분법 — 팽창하는 직사각형의 해부

f = g · h 를 가로 g, 세로 h 인 직사각형의 넓이로 봅시다. 입력 x가 dx 만큼 변하면 g는 dg, h는 dh 만큼 변합니다.

새 넓이 (g+dg)(h+dh) 를 전개하면 원래 넓이 g·h 에 세 조각이 더해집니다 — 4강의 정사각형과 완전히 같은 그림인데, 이번엔 가로와 세로가 서로 다른 비율로 늘어날 뿐입니다.

① 가로와 세로가 함께 늘어나는 직사각형
가로 g(x)–
세로 h(x)–
오른쪽 띠 h·dg–
위쪽 띠 g·dh–
모서리 dg·dh–
변화율–
g′h + gh′–

g(x) = x² + 1, h(x) = sin x + 2 입니다. dx 를 왼쪽 끝까지 밀어보세요 — 빨간 모서리가 사라지고 변화율이 g′h + gh′ 에 붙습니다.

곱의 미분법 (Product Rule)
( g · h )′ = g′·h + g·h′
  • g′·h오른쪽 세로 띠. 가로가 늘어난 만큼(dg) × 원래 세로(h)
  • g·h′위쪽 가로 띠. 원래 가로(g) × 세로가 늘어난 만큼(dh)
  • dg·dh모서리 조각. 두 번 작은 것이라 사라집니다(4강)
  • 외우는 말"한쪽 그대로 × 다른 쪽 미분, 서로 바꿔 한 번씩"
  • 왜 대칭인가그림에서 가로와 세로가 대등하기 때문입니다. 누가 g이고 누가 h인지는 아무 상관 없죠

2. 따름정리 — 상수배와 합

곱의 법칙 하나에서 두 가지가 공짜로 나옵니다.

상수배와 합
( c · g )′ = c · g′   ·   ( g + h )′ = g′ + h′
  • 상수배c는 변하지 않으니 c′ = 0. 곱의 법칙에 넣으면 0·g + c·g′ = c·g′
  • 그림으로세로가 고정된 직사각형이라면 위쪽 띠가 아예 안 생깁니다. 오른쪽 띠만 남죠
  • 합두 넓이를 따로 계산해 더하는 것이므로 변화도 따로 더하면 됩니다. 당연하죠
  • 쓸모이 둘 덕분에 (3x⁵ − 7x² + 4)′ = 15x⁴ − 14x 처럼 다항식은 항별로 미분하면 끝납니다

3. 연쇄법칙 — 변화의 도미노

f = h(g(x)) 처럼 함수 속에 함수가 들어 있으면? x가 변하면 먼저 g가 변하고, 변한 g가 h의 입력으로 들어가 f를 변화시킵니다. 도미노죠.

아래는 세 개의 수직선입니다. 맨 위 x 를 조금 움직이면 그 변화가 u = g(x) 로, 다시 f = h(u) 로 전달되면서 확대되거나 축소됩니다.

② 변화가 사슬을 타고 전달된다
dx–
du = g′·dx–
df = h′·du–
안쪽 기어비 g′–
바깥 기어비 h′–
전체 기어비 h′·g′–

보라색 화살표(du)와 초록 화살표(df)의 길이 비를 보세요. x 위치를 옮기면 기어비가 달라집니다. 어떤 지점에서는 확대되고, 어떤 지점에서는 축소되거나 뒤집힙니다.

연쇄법칙 (Chain Rule)
[ h( g(x) ) ]′ = h′( g(x) ) · g′(x)
  • 읽는 말"바깥 미분(안은 그대로) × 안 미분"
  • h′(g(x))주의 — h′ 을 x가 아니라 g(x)에서 계산합니다. h가 받는 입력이 x가 아니라 u = g(x) 니까요
  • 라이프니츠 표기 dydx = dydu · dudx — du 가 약분되는 것처럼 보입니다. 눈속임이 아니라 실제로 정당합니다(12강)

4. 기어비로 보는 연쇄법칙

직관은 '민감도의 곱' 또는 '기어비' 입니다. 첫 톱니가 x보다 g′ 배 빠르게 돌고, 둘째 톱니가 다시 h′ 배 빠르게 돌면, 전체는 g′ × h′ 배입니다.

일상의 예로
기온이 1도 오르면 → 에어컨 전력 사용량이 40kWh 늘고 → 전기요금이 kWh당 120원 오른다.
그럼 기온 1도당 요금은? 40 × 120 = 4,800원 입니다. 두 민감도를 곱했죠. 이게 연쇄법칙의 전부입니다.

단위를 보면 더 명확합니다 — (kWh/도) × (원/kWh) = (원/도). kWh 가 약분됩니다. 라이프니츠 표기의 du 약분이 바로 이 단위 약분입니다.
안쪽 미분을 빼먹는 것이 가장 흔한 실수입니다 (sin(3x))′ 을 cos(3x) 라고 쓰면 틀립니다. 정답은 cos(3x) · 3 = 3cos(3x) 입니다.

확인법: 안쪽이 3배 빠르게 도니까 전체도 3배 빨라야 합니다. sin(3x) 는 sin x 보다 3배 촘촘하게 진동하죠. 그러면 기울기도 3배 가팔라야 합니다. 그림을 떠올리면 안 틀립니다.

5. 실전: 두 규칙을 함께 쓰기

f(x) = x² · sin(x³) 을 미분해 봅시다. 구조를 먼저 봅니다 — 큰 틀은 곱(x² 곱하기 sin(x³))이고, 뒤 인수 안에 연쇄(x³이 sin 안에)가 들어 있습니다.

구조 → 분해 → 조립
① 곱의 법칙: f′ = (x²)′·sin(x³) + x²·(sin(x³))′ = 2x·sin(x³) + x²·(sin(x³))′
② 연쇄법칙: (sin(x³))′ = cos(x³)·(x³)′ = cos(x³)·3x²
③ 조립:   f′(x) = 2x·sin(x³) + 3x⁴·cos(x³)
  • 기술의 전부구조를 분해하고, 각 부분에 맞는 규칙을 적용하고, 결과를 조립한다. 아무리 복잡해 보여도 이 셋뿐입니다
  • 검산x=1 에서 2·sin1 + 3·cos1 = 1.6829 + 1.6209 = 3.3038. 아래 파이썬 셀에서 수치미분과 맞춰봅니다

6. 몫의 미분법 (보너스)

f = g / h 는 새 규칙이 필요 없습니다. g · h⁻¹ 로 보고 곱의 법칙 + 연쇄법칙을 쓰면 나옵니다.

몫의 미분법
(g · h−1)′ = g′·h−1 + g·(−h−2·h′)
= g′·h − g·h′h²
  • (h⁻¹)′4강의 (xⁿ)′ = nxⁿ⁻¹ 에 n=−1, 그리고 연쇄법칙으로 h′ 곱하기 — −h⁻²·h′
  • 기억할 점분자의 순서(g′h 가 먼저)가 중요합니다. 곱의 법칙과 달리 대칭이 아니거든요 — 나눗셈은 위아래가 대등하지 않으니까요
  • 권장외우기보다 g·h⁻¹ 로 바꿔서 푸는 습관이 실수가 적습니다

두 규칙이 실제로 하는 일
  • 딥러닝의 역전파는 연쇄법칙 그 자체입니다. 층이 100개면 기어비를 100개 곱합니다. 각 기어비가 조금씩 작으면 곱이 0으로 붕괴하고(기울기 소실), 조금씩 크면 폭발합니다. ResNet의 skip connection 이 이 문제의 해법입니다.
  • 오차 전파 — 여러 단계를 거친 측정의 오차는 민감도의 곱으로 커집니다.
  • 경제학의 탄력성 — 가격 탄력성 × 수요 탄력성의 연쇄가 정책 효과를 결정합니다.
  • 제어공학의 루프 게인 — 여러 블록을 직렬로 이으면 게인이 곱해집니다. 정확히 연쇄법칙입니다.

5강 요약

  • (g·h)′ = g′h + gh′ — 직사각형에 붙는 오른쪽 띠 + 위쪽 띠. 모서리는 사라집니다.
  • (g·h)′ ≠ g′h′ 입니다. (x·x)′ = 2x 이지 1이 아니죠.
  • 여기서 상수배((cg)′ = cg′)와 합((g+h)′ = g′+h′)이 공짜로 나옵니다.
  • [h(g(x))]′ = h′(g(x))·g′(x) — "바깥 미분(안은 그대로) × 안 미분".
  • 직관은 기어비의 곱입니다. 단위로 보면 중간 단위가 약분되죠.
  • 안쪽 미분을 빼먹는 것이 가장 흔한 실수입니다. (sin 3x)′ = 3cos 3x.
  • 복잡한 식은 구조 분해 → 규칙 적용 → 조립. 이게 미분 기술의 전부입니다.
  • 몫은 g·h⁻¹ 로 바꾸면 두 규칙만으로 나옵니다.
