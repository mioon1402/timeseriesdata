# 티스토리·블로그에 임베드하기

이 저장소의 모듈은 **iframe 한 줄**로 어디든 붙일 수 있게 만들어져 있습니다.
티스토리, 워드프레스, 노션(임베드 블록), Notion-like 도구, 사내 위키 모두 같은 방식입니다.

---

## 왜 iframe인가

티스토리 에디터에 HTML + `<script>`를 **직접** 붙여넣으면 다음 문제가 생깁니다.

- 기본모드 ↔ HTML모드를 오갈 때 에디터가 태그를 "정리"하면서 스크립트가 잘려나갑니다.
- 다른 글의 스크립트와 변수 이름이 충돌할 수 있습니다.
- 코드를 고치려면 **이미 발행한 글을 전부** 다시 수정해야 합니다.

iframe으로 넣으면 이 셋이 전부 해결됩니다. 특히 마지막이 중요합니다 —
저장소의 코드를 고치면 **이미 발행한 모든 글이 자동으로 같이 업데이트**됩니다.

---

## 1단계 · GitHub Pages로 배포하기

1. 이 저장소를 GitHub에 올립니다.
2. 저장소 페이지에서 **Settings → Pages** 로 갑니다.
3. **Source** 를 `Deploy from a branch` 로 두고,
   **Branch** 를 `main` (또는 배포할 브랜치), 폴더는 `/ (root)` 로 지정합니다.
4. **Save**. 1~2분 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 이 열립니다.

> 저장소가 **Public** 이어야 무료 계정에서 Pages를 쓸 수 있습니다.

배포되면 그 주소를 열어 모듈이 잘 뜨는지 먼저 확인하세요.

---

## 2단계 · 임베드 코드 만들기

배포된 사이트의 **첫 화면(index)** 에 코드 생성기가 있습니다.

1. 원하는 모듈 카드에서 **[임베드 코드]** 를 누릅니다.
2. 아래 옵션을 고릅니다.
   - **무엇을 넣을까요**
     - `시각화만` — 인터랙션 패널만. **블로그에는 이쪽을 권장합니다.**
       설명은 본인 문장으로 쓰고, 그림만 심는 방식입니다.
     - `본문까지 전부` — 설명 글까지 통째로. 높이가 5,000px을 넘어갑니다.
   - **색 테마**
     - `자동` — 보는 사람의 시스템 설정(다크모드)을 따라갑니다.
     - `밝게 고정` / `어둡게 고정` — 블로그 스킨에 맞춰 고정할 때.
3. **[코드 복사]** 를 누릅니다.

주소를 직접 조합해도 됩니다.

```
https://<사용자이름>.github.io/<저장소이름>/modules/04-clt.html?embed=1&view=viz&theme=light
```

| 쿼리 | 뜻 |
| --- | --- |
| `embed=1` | 임베드 모드. 상단 네비게이션을 숨기고 여백을 줄입니다 |
| `view=viz` | 시각화 패널만 표시 (설명 글 숨김) |
| `theme=light` / `theme=dark` | 색 테마 고정. 생략하면 보는 사람의 시스템 설정을 따릅니다 |

---

## 3단계 · 티스토리에 붙여넣기

1. 글쓰기 화면에서 상단 우측의 **`<>` (HTML) 아이콘**을 눌러 **HTML 모드**로 전환합니다.
2. 원하는 위치에 복사한 코드를 붙여넣습니다.
3. **바로 [발행] 하거나 미리보기로 확인합니다.**

### ⚠️ 가장 중요한 주의사항

> **붙여넣은 뒤 기본모드로 되돌리지 마세요.**

HTML 모드 ↔ 기본모드를 오가면 에디터가 태그를 재정리하면서
iframe 속성이나 뒤따르는 `<script>` 블록이 깨질 수 있습니다.
글의 나머지 내용은 **먼저 기본모드에서 다 쓰고**, 마지막에 HTML 모드로 전환해
임베드 코드를 넣는 순서를 권장합니다.

## 높이 조절

복사되는 코드는 두 부분입니다.

```html
<iframe id="statviz-04-a1b2c" src="..." width="100%" height="1010" ...></iframe>
<script>
(function(){var f=document.getElementById("statviz-04-a1b2c");
window.addEventListener("message",function(e){
  if(!f||!e.data||e.data.type!=="statviz-height")return;
  if(e.source!==f.contentWindow)return;
  f.style.height=Math.max(320,e.data.height)+"px";
});})();
</script>
```

- **`height="1010"`** 은 안전한 고정 높이입니다. 모바일까지 고려한 값이라
  데스크톱에서는 아래쪽에 여백이 조금 남을 수 있습니다.
- 뒤따르는 **`<script>`** 는 iframe이 자기 실제 높이를 알려주면
  그에 맞게 높이를 줄여주는 코드입니다. 여백이 사라집니다.

### 스크립트가 티스토리에서 잘려나간다면

그래도 **아무 문제 없습니다.** `height` 고정값이 그대로 적용돼서
내용이 잘리는 일은 없고, 여백만 조금 남습니다.
여백이 거슬리면 `height` 숫자를 직접 줄이세요.
데스크톱 기준 적정값은 대부분 고정값보다 **100~200px 정도 작습니다.**

### 스크립트 없이 쓰고 싶다면

`<script>` 블록을 통째로 지우고 `<iframe ...>` 한 줄만 남기면 됩니다.

## 연재 구성 예시

한 글에 한 모듈씩, 8회 연재로 딱 맞습니다.

| 회차 | 모듈 | 글 제목 예시 |
| --- | --- | --- |
| 1 | 01 중심과 퍼짐 | 평균은 사실 시소의 받침점입니다 |
| 2 | 02 분포의 모양 | 히스토그램은 거짓말을 할 수 있습니다 |
| 3 | 03 정규분포 | 확률은 높이가 아니라 넓이입니다 |
| 4 | 04 중심극한정리 | 이상한 데이터, 멀쩡한 평균 |
| 5 | 05 신뢰구간 | "95% 신뢰"는 무엇의 95%인가 |
| 6 | 06 p-값 | p-값을 카드 섞기로 직접 만들어봤습니다 |
| 7 | 07 회귀 | 최소제곱은 진짜로 "넓이의 합"입니다 |
| 8 | 08 심슨의 역설 | 운동할수록 콜레스테롤이 높다? |

각 모듈 페이지의 본문에 **직관 · 수식 · 실무 적용 · 흔한 실수**가 정리돼 있으니
글감으로 활용하세요. 그대로 옮기기보다 **본인 경험과 예시로 바꿔 쓰는 편**이
블로그로서 훨씬 가치가 있습니다.

## 다른 플랫폼

| 플랫폼 | 방법 |
| --- | --- |
| **워드프레스** | 커스텀 HTML 블록에 그대로 붙여넣기 |
| **노션** | `/embed` 블록에 **모듈 주소만** 입력 (스크립트는 불필요) |
| **네이버 블로그** | iframe이 막혀 있습니다. 스마트에디터 ONE에서는 임베드가 어려워, 스크린샷 + 링크를 권장합니다 |
| **벨로그 / GitHub Pages 블로그** | 마크다운에 iframe 태그를 그대로 쓰면 됩니다 |
| **사내 위키(Confluence 등)** | HTML 매크로 / iframe 매크로 사용 |

## 문제 해결

**iframe이 빈 화면으로 나옵니다**
→ 주소를 브라우저에서 직접 열어보세요. 404면 GitHub Pages 경로가 틀린 것입니다.
저장소 이름이 경로에 포함되는지(`.../저장소이름/modules/...`) 확인하세요.

**혼합 콘텐츠(mixed content) 경고가 뜹니다**
→ 블로그가 `https`인데 iframe 주소가 `http`인 경우입니다. `https`로 바꾸세요.
GitHub Pages는 기본적으로 https를 지원합니다.

**모바일에서 아래가 잘립니다**
→ 자동 높이 스크립트가 제거된 상태에서 `height`를 너무 줄인 경우입니다.
기본 제공 값으로 되돌리세요.

**글꼴이 블로그와 다릅니다**
→ 의도된 동작입니다. iframe은 독립된 문서라 블로그 스킨의 CSS가 적용되지 않습니다.
덕분에 스킨을 바꿔도 시각화가 깨지지 않습니다.
